# Death Note notebook assets

- `rules-seal.png`: transparent cutout made with image editing from the skull-medallion reference supplied by the user in this session. It replaces the generic icon in the rulebook; it is not executable addon content.
- `shadows-into-light-two.woff2`: Shadows Into Light Two, regular Latin subset, by Kimberly Geswein; SIL Open Font License in `ShadowsIntoLightTwo-OFL.txt`.
- `mali-thai.woff2`, `mali-latin.woff2`: Mali, regular Thai / Latin subsets; SIL Open Font License in `Mali-OFL.txt`.

Fonts were obtained from Google Fonts. Rule text uses the Latin handwriting face with the Thai handwriting fallback. Interface controls continue to use RoleForge’s shared fonts from `assets/chat-fonts/`. All assets are served locally by SillyTavern; opening the notebook makes no third-party font/image request.
