# Aster artwork

app-art.png: original minimalist sixteen-icon artwork generated and refined for this release, 2026-10-25. Displayed as a CSS atlas, with no external image requests. Phone, Messages, Contacts, Wallet, Harbor Store, Drift, Gather, Lumen, Murmur, Stickers, Photos, Notes, Maps and Settings use this original artwork. The extra calendar/camera art is not presented as shipped apps.

wave-cat.png: original transparent sticker artwork generated for the upload demonstration, 2026-10-25.

Noto Sans Thai / Noto Sans Display fonts: Open Font License, see FONT-LICENSE.txt. The three stock photo fixtures and their attributions came from the earlier smartphone prototype; see the copied prototype credit record in docs/phone-release/PROTOTYPE-CREDITS.md.

Voice showcase: synthetic English fixture audio made locally with FFmpeg/libflite. ElevenLabs requests are intercepted in tests, with no external voice service use. Production uses the user's existing Voice Addon connection.
