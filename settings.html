Tretaresia RPG

A persistent Tretaresia role-play state linked to the current chat.

Notification events
Every normal reply checks progression, power and combat proficiency, Origin skills, long-distance travel, regional currency, dungeons, NPC relationships/stats, Scene, maps, inventory, quests, and Mailbox without a background AI request. Values change only when the story gives a reasonable basis; hidden power types obey Tretaresia sensing rules. Manual Sync and sent UI actions use a request. 0 extension-started requests.
How automatic UI updates work
  1. After your first reply, the extension adds the current structured state and short patch rules to the normal role-play prompt.
  2. The character produces its normal reply once. If a confirmed fact changed, it appends an invisible state patch to that same reply.
  3. The extension removes the patch from view, validates every operation against a strict allowlist, saves it to this chat, and redraws the relevant tabs.
  4. If no patch is returned, the activity capsule says “No state changes.” This means tracking ran successfully but had nothing confirmed to save.
