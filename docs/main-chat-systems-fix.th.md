# ตรวจและแก้ระบบเสริมใน Main Chat — v0.50.2

## สาเหตุที่ตรวจพบจากโค้ดและทำซ้ำได้

1. สวิตช์เปิดระบบเพียงอนุญาตให้ส่งคำสั่งและแสดงข้อมูล การ์ดร้านค้า ข้อเสนอซื้อ กระดานภารกิจ กระดานรับสมัคร และประมูลยังต้องได้รับวัตถุเฉพาะใน `tretaresia_patch` การส่งเพียง `sceneTracker` และ `ops` เรื่องเงิน/ของจึงทำให้มี Scene Tracker และแจ้งเงิน/ของ แต่ไม่มีการ์ดเหล่านี้ คำสั่งตรวจท้าย prompt เดิมย้ำฉาก ไดอารี่ และคำเชิญ แต่ไม่ได้ย้ำการ์ดที่ผู้เล่นกำลังขอ
2. ตัวตรวจร้านค้าปฏิเสธหลักฐานทั้งก้อนเมื่อมีคำว่า “ถ้า”, “หาก” หรือคำเกี่ยวกับอนาคต แม้อีกประโยคยืนยันการแสดงสินค้าตรงหน้าแล้ว ตัวตรวจประมูลบังคับคำเดินเข้า/มาถึง จึงไม่ยอมรับการแสดงแคตตาล็อกขณะที่ผู้เล่นอยู่ในห้องเดิม และตัวตรวจชื่อ NPC ร้านค้าบังคับชื่อในประโยคหลักฐาน แม้ชื่ออยู่ใน `tr-header`/`tr-dialogue` แล้ว
3. ข้อมูลการ์ดที่ขาด location/evidence ถูกทิ้งก่อนตรวจบริบท ทั้งที่ฉากยืนยันสถานที่และคำตอบมีประโยคหลักฐานตรงกันอยู่แล้ว เมื่อข้อมูลขาดหรือถูกปฏิเสธ แชตไม่แสดงเหตุผล
4. หากคำตอบส่งทั้งการซื้อขายที่จบแล้วและรายการร้านค้ารอบใหม่ ตัวกรองเดิมตัด inventory/currency ทุก operation ทิ้ง จึงไม่บันทึกการซื้อขายที่ยืนยันแล้วในคำตอบนั้น

ภาพหน้าจอแสดงข้อความและ UI แต่ไม่แสดง raw reply/patch จึงระบุไม่ได้ว่าข้อใดเกิดขึ้นในคำตอบของผู้ใช้โดยตรง ทั้งสี่กรณีข้างต้นตรวจจาก production code และมี regression tests ทำซ้ำได้

## การแก้ไข

- เพิ่มคำสั่งตรวจการ์ดท้าย prompt ตามระบบที่เปิดและข้อความล่าสุดของผู้เล่น ใช้การตอบหลักครั้งเดิม ย้ำ catalog/offer เป็นข้อมูลระดับบนของ patch และให้ใช้สถานที่เดียวกับ Scene Tracker
- รองรับการดูรายการ/ต่อรอง/เปิดแคตตาล็อกในสถานที่เดิม ตรวจประโยคที่ยืนยันการกระทำจริงแยกจากเงื่อนไขราคาในอีกประโยค รองรับ HTML และช่องว่างในหลักฐาน และใช้ชื่อผู้พูดจาก header/dialogue ที่สัมพันธ์กับหลักฐาน
- เมื่อ location/evidence ไม่ได้ส่งมา ใช้สถานที่ปัจจุบันที่ยืนยันแล้วและคัดประโยคจริงจากคำตอบในเครื่อง ไม่แทนที่หลักฐานที่ส่งมาแล้วแต่ผิด และไม่ใช้ข้อมูลจากคำถาม OOC หรือแผนในอนาคต
- กู้ร้านค้าจากข้อความที่ระบุผู้ขายเพียงคนเดียวและรายการชื่อสินค้า/ราคาตัวเลข/หน่วยเงินชัดเจนได้ ไม่เดารายการที่ไม่มีราคา ไม่แปลงสกุลเงินปะปน ไม่สร้างจำนวนสต็อกหรือคุณสมบัติลับ และแสดงสต็อก/เงื่อนไขที่ไม่ทราบว่าไม่ระบุ
- หากข้อมูลของระบบที่ขอยังไม่ครบ มีข้อความแจ้งในคำตอบล่าสุด พร้อมปุ่ม **เตรียมข้อความขอดูรายการ** ปุ่มเติม draft ให้ตรวจสอบก่อนกดส่งเอง ไม่เรียกโมเดลอัตโนมัติ
- อนุญาต money/item ops ที่ระบุผลการซื้อขาย `purchase`/`sale` ผ่านเมื่อมีแคตตาล็อกรอบใหม่พร้อมกัน ข้อเสนอที่ยังไม่ซื้อขายไม่จ่ายเงินหรือแจกของเอง การประมูลยังใช้ engine และ receipts เดิม
- แสดงคำแนะนำที่หน้า Optional systems เมื่อ Auto tracking ปิดอยู่ และเปลี่ยน release/import/style cache query เป็น 0.50.2

## ระบบทั้งแปดทำอะไร

| ระบบ | ผลที่ควรเห็น |
|---|---|
| กระดานภารกิจ | การ์ดงานใน Main Chat เมื่ออ่านกระดานจริง แล้วกดอ่าน/รับภารกิจ |
| กระดานปาร์ตี้และกิลด์ | การ์ดกลุ่มใน Main Chat เมื่ออ่านกระดานรับสมัคร แล้วส่งคำขอเข้าร่วม |
| ประมูล | การ์ดรายการใน Main Chat; เข้าร่วม เสนอราคา และรับผลผ่าน engine |
| ตลาดต่อรองราคา | ร้านค้า/ข้อเสนอ NPC ใน Main Chat; ปุ่มซื้อ ขาย และต่อรองส่งการกระทำตามเนื้อเรื่อง |
| บันทึกเรื่องสำคัญ | ข้อเท็จจริง คำสัญญา ความลับ และเรื่องค้างใน workspace ความจำ ไม่ใช่ popup ทุกบทสนทนา |
| นัดหมายและกำหนดเวลา | รายการใน workspace นัดหมายและเตือนตามเวลาในเรื่อง |
| เช็กลิสต์เป้าหมายเควส | ขั้นตอนย่อยในรายละเอียดเควสและความคืบหน้าจากขั้นตอนที่เสร็จ |
| คลังสรุปความจำ | workspace สรุปความจำและสถานะการสรุป; เรียก API ตามการตั้งค่าของระบบนี้ |

## ผลการตรวจสอบ

- `npm test`: 490 tests ผ่าน
- `npm run check` และ `git diff --check` ผ่าน
- `node tests/main-chat-systems.browser.mjs`: production loader/event/metadata/DOM บนจอ 320, 390, 1280px ผ่านการกู้ร้านค้าโดยไม่มี patch, ต่อรองในที่เดิม, ซื้อ/ขาย, กดรับข้อเสนอ NPC, ประมูล, กระดานทั้งสอง, บันทึกเรื่องสำคัญ, นัดหมาย, checklist, ข้อความข้อมูลไม่ครบ/draft และ OOC gates
- `node tests/optional-systems.browser.mjs`: สวิตช์ทั้งแปด ค่าเริ่มต้นปิด การเก็บข้อมูลเดิม การนำคำสั่งออก การพัก storage/API และการจัดการวงเงินประมูลค้าง ผ่านทั้งสามขนาดจอ
- `node tests/auctions.browser.mjs`: เงินมัดจำ การแข่งราคา save rollback/retry, reload, จ่ายเงิน/ส่งของครั้งเดียว และแยกแชต ผ่านทั้งสามขนาดจอ
- `node tests/regex-compat.browser.mjs`: native HTML/regex compatibility ผ่านทั้งสามขนาดจอ
- `CHROMIUM_EXECUTABLE=/usr/bin/chromium node tests/story-systems.browser.mjs`: บันทึกเรื่องสำคัญ เป้าหมายเควส รางวัลครั้งเดียว นัดหมาย การแก้ไข reload/swipe และแยกแชต ผ่านทั้งสามขนาดจอ

Browser tests ใช้ host fixture กับ production extension และคำตอบจำลอง ไม่ได้เรียกโมเดลจริงหรือเข้าถึงแชตบนอุปกรณ์ผู้ใช้ โมเดลจริงยังอาจส่งรายละเอียดไม่ครบ จึงมี feedback ให้เห็นและขอข้อมูลใหม่ได้ การแก้ไขไม่สร้างสินค้า/ภารกิจ/กฎประมูลที่ไม่มีข้อมูลยืนยันเพื่อฝืนให้มีการ์ด

## วิธีรับการแก้ไข

อัปเดต RoleForge ให้เป็น **0.50.2** แล้วโหลดหน้า SillyTavern ใหม่หนึ่งครั้ง ตรวจว่า Auto tracking และระบบที่ต้องการเปิดอยู่ ทดลองขอดูสินค้าหรือกระดานอีกครั้ง ข้อมูลเดิมไม่ต้องรีเซ็ต ข้อความเก่าที่ไม่มีรายการหรือราคาไม่ถูกสร้างข้อมูลย้อนหลังขึ้นเอง
