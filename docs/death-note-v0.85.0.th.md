# RoleForge 0.85.0 — Death Note

รวมงานจาก Preview บันทึกคดี ความสงสัย เศษกระดาษ ความเชื่อต่อกฎปลอม และหน้ารายชื่อที่อธิบายผลการเขียน พร้อมปรับพื้นที่เขียนสำหรับคอมและมือถือ

## ระบบที่เพิ่มเข้ามา

- หน้ารายชื่อแยกยังไม่ส่ง / รอเวลาในเรื่อง / รอคำยืนยัน / ไม่เกิดผล / เกิดผลแล้ว แสดงเหตุผลและหลักฐานโดยไม่เฉลยชื่อจริงที่ผู้เล่นยังไม่รู้
- บันทึกคดีแยกผู้สังเกตและผู้ถูกสงสัย ทั้ง NPC → ผู้เล่น และ NPC → NPC ใช้หลักฐานที่เกิดขึ้นจริง คะแนนความสงสัยไม่ใช่คำตัดสินว่ามีความผิด หลักฐานหักล้างลดความสงสัยได้
- เศษกระดาษเป็นของใน Inventory มีรหัสของตัวเองและผูกกับสมุดต้นทาง เขียน ส่งต่อ วาง หยิบ และทำลายได้ การถือเศษกระดาษไม่ให้สิทธิ์เจ้าของสมุดหรือสิทธิ์แลกดวงตา
- ติดตามว่า NPC คนไหนอ่านจารึกปลอมแล้ว เชื่อ สงสัย หรือไม่เชื่อ ความเชื่อไม่เปลี่ยนกติกาจริงของ Death Note และไม่แพร่ให้ทุก NPC โดยอัตโนมัติ
- ข้อมูลผูกกับแชท ข้อความ และ Swipe ที่เลือก การสร้าง Branch ใช้เฉพาะข้อมูลก่อนจุดนั้น การแก้ข้อความจนหลักฐานหายไปทำให้หลักฐานนั้นหมดอำนาจ

## หน้าเขียนเศษกระดาษและข้อความยาว

กด “เขียน” บนเศษกระดาษเพื่อเปิดใบกระดาษแยกจากตัวสมุด ไม่มีสันปกหรือหน้ากฎติดกับกระดาษ ส่วนการเปิดสมุดเต็มเล่มยังใช้หน้าตาเดิม

หน้าเขียนเลื่อนอ่านแนวตั้งได้ทั้งเต็มหน้าจอและเหนือ Chatbar ข้อความยาวไม่ถูกตัดทิ้ง ขนาดตัวอักษรและพิกัดที่บันทึกยังอยู่ แผงย้ายตำแหน่ง/ปรับขนาดยังยืนยันหรือยกเลิกได้

บนมือถือ แตะพื้นที่ว่างเพื่อเริ่มเขียน ปัดบนพื้นที่ว่างเพื่อเลื่อนอ่านโดยไม่สร้างหมึกเพิ่ม แตะข้อความเพื่อเลือก แล้วลากกรอบที่เลือกเพื่อย้ายตำแหน่ง ตัวเลือกสมุดและเศษกระดาษมีทั้งในหน้าเต็มและใน Chatbar

การล้างกระดาษหรือทำลายชิ้นกระดาษไม่ลบผลการเสียชีวิตที่ยืนยันแล้ว และไม่ยกเลิกชื่อที่จดไว้ก่อนหน้า

## วิธีเขียน

```text
ชื่อจริงของตัวละคร
หัวใจวาย หลังจาก 10 นาที
รายละเอียดเหตุการณ์ก่อนเสียชีวิตที่เป็นไปได้ตามกติกาโลก
```

ชื่อและสาเหตุอยู่บรรทัดเดียวกันได้ ต้องเคยเห็นและจำใบหน้าได้ และใช้ชื่อจริงหรือชื่อแปลที่การ์ดรองรับ เวลาเป็นเวลาในเรื่อง กด “ต่อเรื่อง” เพื่อ Continue ข้อความ AI เดิม หรือปล่อยหมึกแล้วส่งโรลถัดไปได้ ไม่มีการส่งข้อความฝั่ง User แทนผู้เล่น ปิดสมุดระหว่างรอ AI ได้

ข้อความสาเหตุ/รายละเอียดที่ส่งให้ AI ยังคงจำกัด 500 ตัวอักษรต่อชื่อ ส่วนหมึกบนกระดาษเก็บได้ตามขีดจำกัดเดิมของตัวแก้ไข การอ่านถึงท้ายข้อความบนหน้าจอไม่ใช่การเพิ่มขีดจำกัดข้อมูลที่ส่งให้โมเดล

## ข้อมูลเดิมและการอัปเดต

อัปเดต RoleForge แล้วรีโหลด SillyTavern ใช้ Death Note ที่ติดตั้งไว้ต่อได้ ข้อมูลใช้ journal เดิม ไม่ล้างหมึก สิทธิ์ ประวัติการเขียน หรืออายุขัย เมื่อปิด Addon หน้าระบบและ prompt เสริมจะพัก ข้อมูลและผลที่เกิดในเรื่องยังเก็บไว้

แชทเก่าไม่ถูกเติมคะแนนคดีหรือความเชื่อย้อนหลังโดยเดาเหตุการณ์ ระบบต้องมีข้อความและหลักฐานที่ตรวจยืนยันได้จาก AI จึงเพิ่มเหตุการณ์ใหม่

ระบบนี้ติดตามประวัติการเขียนของผู้เล่นหลายเล่ม การแปลงข้อความในโรลที่ NPC จดชื่อให้กลายเป็นหน้าหมึกของ NPC ที่เปิดอ่านได้ ยังเป็นส่วนที่ต้องพัฒนาเพิ่มเติม การเลือกเล่มไม่ได้เปิดเผยสมุดหรือข้อมูลลับที่ผู้เล่นยังไม่เข้าถึง
