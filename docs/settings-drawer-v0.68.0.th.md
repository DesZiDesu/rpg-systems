# หน้าตั้งค่า RoleForge 0.68.0

เปิด **ส่วนขยาย → RoleForge** จะเห็นช่องค้นหาและเมนูหลัก 6 หมวด ใช้หน้าตา สี และปุ่มตามธีม SillyTavern ที่ตั้งไว้

| หมวด | การตั้งค่าที่อยู่ภายใน |
| --- | --- |
| การเล่นทั่วไป | ภาษา การส่งคำสั่ง สานต่อข้อมูลในแชทใหม่ และแนวการเขียน |
| หน้าต่างและรูปลักษณ์ | หน้าต่างเหนือ Chatbar, Scene Tracker, การเลือกโมดูล, Header/Dialogue/Narrative, Regex และสี RoleForge |
| โลกและกติกา | Stats/Training, ค่าเงิน, Power, Character Creation, Incantation, ระบบเสริม และ NPC Diary |
| Preset และการ์ดตัวละคร | คลัง Preset, Import/Export และแพ็กข้อมูลลงการ์ด |
| ติดตามและแจ้งเตือน | ติดตามคำตอบ AI, แนบสถานะใน prompt และเลือกเหตุการณ์แจ้งเตือน |
| ขั้นสูงและตรวจปัญหา | จำนวนคำขอและคู่มือการติดตามข้อมูล |

ค้นหาได้ทั้งภาษาไทยและอังกฤษ เช่น `Header`, `ค่าเงิน`, `HP` หรือ `Regex` แล้วเลือกผลลัพธ์เพื่อเปิดหน้าที่เกี่ยวข้อง การค้นหาอ่านชื่อระบบและคำอธิบายการตั้งค่า ไม่อ่านค่าที่พิมพ์ในฟอร์มหรือข้อความแชท

มือถือเปิดทีละหน้าเต็มความกว้าง drawer ปุ่ม **กลับ** อยู่ด้านบนและยังมองเห็นเมื่อเลื่อนฟอร์ม ลงรายละเอียดแล้วกลับมาได้โดยร่างที่ยังไม่บันทึกยังอยู่ ต้องกดปุ่มบันทึกของฟอร์มตามเดิม การเปิดหน้าและค้นหาไม่เรียก AI และไม่บันทึกค่าตั้งค่า

ค่าตั้งค่า ข้อมูลแต่ละแชท และ Preset ใช้รูปแบบข้อมูลและตัวบันทึกเดิม ไม่ต้องนำเข้าหรือตั้งค่าใหม่ ส่วน Voice และ Memory ยังเป็น drawer แยกแบบเดิม

อัปเดตส่วนเสริมจาก `main` แล้ว Reload SillyTavern หลังบันทึกร่างและจบการเจน เพื่อโหลดเลขเวอร์ชันและ CSS ใหม่
