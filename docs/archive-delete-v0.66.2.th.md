# RoleForge 0.66.2 · ลบหลายรายการ

ลบ Character/NPC และ Lore หลายรายการพร้อมกันได้จากหน้าจัดการเดิม โดยคงแถบมือถือและพื้นที่รายชื่อไว้ตามเดิม

## วิธีใช้

1. เปิด Character/NPC Management หรือ Lore Management เลือกคลัง คำค้น และตัวกรองที่ต้องการ
2. กด **เลือก** ที่แถบด้านล่าง แล้วทำเครื่องหมายรายการที่จะลบ การเลือกคงอยู่เมื่อเปลี่ยนหน้า
3. ใช้ **⋯** ด้านล่างเพื่อเลือกทั้งหน้า หรือผลค้นหาทุกหน้า หากต้องการ
4. กด **⋯ → ลบที่เลือก** ปุ่มเป็นสีแดงและกดไม่ได้เมื่อยังไม่ได้เลือกอะไร
5. ตรวจจำนวนและคลังในหน้าต่างยืนยัน แล้วกดยืนยันหรือยกเลิก

## ขอบเขตการลบ

- **NPC · Chat**: ลบจากคลังของแชทที่เปิด
- **NPC · Character**: ลบจากคลังของการ์ดที่ใช้ร่วมกันทุกแชท
- **Lore**: ลบจากคลังของการ์ด มีผลกับทุกแชทของการ์ดนั้น

ลบเฉพาะ ID ที่เลือก รายการที่ไม่ได้เลือกและสำเนาในอีกคลังยังอยู่ ข้อความแชทและไฟล์ภาพไม่ถูกลบ เพื่อให้ประวัติและสำเนาอื่นยังใช้งานได้ ความสัมพันธ์ของ NPC ในกลุ่ม/ผู้ติดต่อและ snapshot ของแชทปัจจุบันใช้เส้นทางทำความสะอาดเดิม จึงไม่ดึง NPC ที่ลบกลับมาจาก snapshot เก่า

ยกเลิกแล้วไม่บันทึก หากบันทึกคลังไม่สำเร็จก่อนระบบยืนยัน รายการและการเลือกยังอยู่ให้ลองใหม่ เมื่อบันทึก NPC สำเร็จแล้ว การรีเฟรชหน้าจอที่ล้มเหลวภายหลังไม่ย้อนข้อมูลที่บันทึกไปหรือรายงานว่าคลังยังไม่ถูกลบ การตอบกลับช้าหลังเปลี่ยนแชทไม่ใช้รายการเก่ากับแชทใหม่

**Undo ยังใช้กับสถานะเปิด/ปิด ไม่กู้รายการที่ลบ** หลังลบสำเร็จระบบล้าง Undo ของการเปลี่ยนสถานะก่อนหน้า เพื่อไม่ให้เข้าใจว่ากดย้อนแล้วจะได้รายการที่ลบกลับมา

หากคลัง Lore เดิมมีข้อมูลเกินงบส่งที่ลดลงภายหลัง ยังลบลดข้อมูลได้โดยไม่ต้องลบทั้งหมดพร้อมกัน งบที่ส่งให้ AI ยังถูกจำกัดตามเดิม และไม่อนุญาตให้เพิ่มข้อมูลที่เปิดจนเกินงบมากกว่าเดิม
