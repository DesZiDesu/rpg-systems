# RoleForge 0.53.2 — เจตนาซื้อขาย ห้องพัก และกุญแจสถานที่

ซื้อและขายจะเปิดหน้าต่างเมื่อคำตอบ AI มีข้อเสนอปัจจุบันของ NPC ที่ตรวจสอบได้ คำว่า “ซื้อ” หรือ “ขาย” ในข้อความผู้เล่นเพียงอย่างเดียวจะไม่เปิดแถบรอรายการเหนือช่องพิมพ์แล้ว

## AI อ่านเจตนาในคำตอบเดียวกัน

คำสอนที่ส่งเข้าการเจนปกติ รวมถึง Swipe และ Regenerate ให้ AI อ่านข้อความผู้เล่นทั้งหมดพร้อมบริบท แล้วระบุ `commerceIntent` ใน patch เดียวกับฉากและรายการซื้อขาย:

- `buy` เมื่อขอดูสินค้า ถามราคาปัจจุบัน เช่าห้อง จ้างบริการ หรือต่อรองเพื่อซื้อจริง
- `sell` เมื่อเสนอของที่เป็นเจ้าของให้ NPC ซื้อจริง
- `none` เมื่อแค่พูดถึงซื้อขาย พูดเล่น เล่าอดีต ปฏิเสธ ยังไม่ตัดสินใจ หรือวางแผนในอนาคต

`evidence` ต้องอ้างข้อความผู้เล่นจริง ระบบไม่รับคำอ้างที่แต่งขึ้น ถ้า AI ระบุ `none` อย่างถูกต้อง จะไม่เปิดซื้อขาย แม้ส่งรายการมาด้วยโดยผิดพลาด ทิศทางซื้อ/ขายที่ระบุต้องตรงกับรายการ ส่วนข้อมูลรุ่นเก่าที่ไม่มี field นี้ยังใช้การตรวจข้อเสนอและหลักฐานเดิมได้

การแยกเจตนาอยู่ในการเรียก AI ตามปกติ ไม่มี API เพิ่มสำหรับจำแนกข้อความ การมีหน้าต่างซื้อขายที่เปิดอยู่แล้วไม่ให้สิทธิ์โอนเงินหรือของจากการคุยเฉยๆ: AI ต้องใช้ `talk / unchanged` จนกว่าจะมีการกระทำที่ผู้เล่นอนุญาต

## ห้องพักขึ้นจากคำตอบปัจจุบัน

แก้การตรวจชื่อกุญแจที่เคยเข้มเกินไป: เมื่อ NPC เสนอห้องหรือสถานที่ชัดเจนและนำกุญแจของสถานที่นั้นมาให้ดู AI ใช้ชื่อไอเทมเช่น “กุญแจห้องพักเดี่ยวธรรมดาชั้นสอง” ได้ โดยไม่ต้องให้ NPC เอ่ยชื่อ UI ยาวๆ ตรงทุกตัวอักษร กุญแจของสถานที่อื่นยังถูกปฏิเสธ

คำสอนหลักยังให้ AI ส่งรายละเอียดทุกรายการ ราคา ประเภท สิทธิ์ กำหนดเวลา สิ่งที่รวม และกุญแจใน patch ท้ายคำตอบเดียวกัน นอกจากนี้ ตัวอ่านรองรับเมนูโรงเตี๊ยมภาษาไทยที่บอกข้อมูลครบในบทพูดแล้ว แม้ไม่มี object รายการ โดยใช้ข้อความที่มีอยู่ในคำตอบนั้นโดยตรง:

- ผู้เล่นกำลังขอซื้อ/เช่าหรือถามรายการจริง และมีผู้เสนอห้องที่ระบุชื่อชัดเจนเพียงคนเดียว
- ทุกตัวเลือกมีชื่อและราคาต่อคืนที่อ่านได้ รวมทั้งราคาที่สะกดด้วยคำไทย
- มีการแสดงกุญแจจริงในฉาก และระบุเวลาเช็กเอาต์วันนี้หรือพรุ่งนี้ชัดเจน เช่น “คืนกุญแจก่อนเที่ยงวันพรุ่งนี้”
- ใช้วันและเวลาภายในเรื่อง จากฉากปัจจุบัน; ไม่ตั้งอายุสิทธิ์เป็น 24 ชั่วโมงโดยเดา
- เก็บรายละเอียดที่ประกาศ สิ่งที่รวม และกฎในข้อความ; จำนวนห้องและการต่อรองยังเป็น “ไม่ทราบ” เมื่อไม่ได้บอก

ถ้า AI ส่ง object รุ่นเก่าที่มีเพียงชื่อห้องกับราคา ตัวอ่านใช้เงื่อนไขในคำตอบปัจจุบันเติมได้เมื่อทุกรายการตรงกับชื่อและราคาที่ประกาศจริง จำนวนตัวเลือกต้องตรง และไม่แก้สัญญาที่ระบุชนิดไว้ชัดเจนแล้ว

ตัวอ่านนี้จำกัดเฉพาะรูปแบบที่ตรวจสอบได้ ถ้าไม่มีกุญแจ ไม่มีเวลาเช็กเอาต์ ระบุผู้ขายกำกวม มีมัดจำ/ค่าธรรมเนียมที่ต้องแยกเงื่อนไข หรือราคามีความกำกวม จะไม่แต่งข้อมูลเพิ่ม การเปิดรายการไม่เรียก API อีกรอบ และไม่เปลี่ยนเงินหรือ Inventory

## ซื้อสถานที่แล้วรับกุญแจ

บ้าน ห้อง อาคาร โกดัง หรือสถานที่อื่นที่ซื้อกรรมสิทธิ์ถาวร ยังคงใช้ชื่อและราคาของสถานที่ในรายการซื้อ แต่ส่งกุญแจเข้าคลัง เช่น “กุญแจบ้านริมแม่น้ำ” พร้อมคำอธิบาย “กรรมสิทธิ์ถาวร · บ้านริมแม่น้ำ” และรายละเอียดที่ NPC เปิดเผย

ข้อมูลใช้ `terms:{mode:"permanent",scope:"บ้านริมแม่น้ำ",delivery:{name:"กุญแจบ้านริมแม่น้ำ",category:"Key",description:"..."}}` สถานที่หนึ่งรายการซื้อได้จำนวน 1 ชื่อกุญแจใช้ภาษาของการโรลตามข้อมูลที่ AI ส่งมา การยืนยันซื้อหักราคาสถานที่และส่งกุญแจครั้งเดียว ข้อความแจ้งรับไอเทมใช้ชื่อกุญแจจริง

การพักห้องหนึ่งคืนยังเป็น `access` ที่มีวันหมดอายุและกุญแจเชื่อมสิทธิ์ กุญแจของเช่า/สิทธิ์ยังขายไม่ได้ ส่วนกุญแจกรรมสิทธิ์ถาวรเป็นไอเทมของผู้เล่น ระบบบันทึกขอบเขตกรรมสิทธิ์ในไอเทมและประวัติการซื้อ; การลบหรือขายกุญแจไม่ได้จำลองการโอนโฉนด การยึดครอง หรือระบบบริหารอาคารเพิ่มเติม

## ภาพ UI และการตรวจสอบ

[เปิดภาพหน้าแชตและ Inventory ที่ใช้โค้ดจริง](previews/commerce-v0532/index.html)

ทดสอบกับตัวโหลดจริงบนจอ 320, 390 และ 1280 พิกเซล: การพูดถึงซื้อขายไม่เปิดหน้าต่าง, AI เลือก `none` ระงับรายการที่ส่งผิด, เมนูห้องพักครบเปิดจากคำตอบเดียวโดย API เพิ่มเป็นศูนย์, ยืนยันซื้อห้องได้กุญแจและเช็กเอาต์วันถัดไปตรงเรื่อง, ซื้อบ้านได้กุญแจกรรมสิทธิ์ถาวร, ขายของที่เป็นเจ้าของจริงยังเปิดข้อเสนอได้ และข้อเสนอไม่โอนของเอง

ผ่าน 757 unit/host tests และการตรวจ syntax พร้อมตรวจชุดทดสอบซื้อขาย/ประมูล กระดาน สิทธิ์และคืนมัดจำ ฝึกฝน และการเปิดปิดส่วนเสริมด้วย คำตอบโมเดลในการทดสอบเป็นข้อมูลควบคุม ไม่ได้เรียกบัญชีโมเดลจริงของผู้ใช้

อัปเดตส่วนเสริมและโหลดหน้าใหม่หนึ่งครั้ง แล้วใช้กับคำตอบที่จะเจนต่อไป ข้อมูลเก่าและประวัติการซื้อยังคงอยู่
