# RoleForge 0.55.0 — เสียงผู้บรรยาย บทพากย์ และข้อเสนอห้องพัก

เพิ่มเสียงเริ่มต้นชาย/หญิงตามข้อมูล NPC เสียงผู้บรรยายแยกต่างหาก และกล่องแก้บทเสียงที่ไม่เปลี่ยนข้อความ AI เดิม ดู [วิธีใช้ Voice Addon](voice-addon.th.md) และ [ภาพ UI จริง](previews/v0550/index.html)

## ข้อเสนอห้องพักล่าสุด

คำตอบที่ผู้ใช้ส่งมามี `ห้องพักธรรมดาสำหรับหนึ่งคืน... คืนละห้าเหรียญเงิน` และบทถัดไปจาก Garrick พูด `จ่ายเงินมาแล้วข้าจะเอากุญแจห้องให้ ส่วนเวลาเช็คเอาท์ก็ก่อนเที่ยงวันพรุ่งนี้` แต่ไม่มี marketplace หรือ tretaresia_patch

ตัวอ่านเดิมไม่ผ่าน `...` ระหว่างชื่อกับราคา และอ่านเฉพาะ Dialogue ที่มีราคาต่อคืน ทำให้ไม่เห็นกำหนดเช็คเอาท์ในบทถัดไป แก้ให้อ่านจุดไข่ปลาและเว้นบรรทัด เก็บชื่อ `ห้องพักธรรมดา` โดยแยก `สำหรับหนึ่งคืน` ออก และอ่านเงื่อนไขจาก Dialogue ของผู้ขายคนเดียวกันในคำตอบปัจจุบัน

รายการเปิดจากข้อความนั้นโดยไม่เรียก API เพิ่ม: 5 เงิน มีเตียงเดี่ยว โต๊ะเล็ก รวมอาหารเช้า กุญแจห้องพักธรรมดา และสิทธิ์สิ้นสุดก่อนเที่ยงวันถัดไป ไม่เปลี่ยนการพักค้างคืนเป็นกรรมสิทธิ์ถาวร ไม่เดามัดจำ สต็อกหรือการต่อรอง หากคำตอบระบุค่าบริการเพิ่ม/เงื่อนไขกำกวมหรือราคาจากคนละผู้ขาย จะไม่ละทิ้งข้อมูลเหล่านั้นแล้วเปิดข้อเสนอผิด ๆ

Prompt ยังสอนให้ AI ส่ง marketplace และข้อมูลทุกตัวเลือกในคำตอบปกติ ตัวอ่านข้อเสนอที่ชัดเจนในเรื่องรองรับกรณี AI ลืมข้อมูลเครื่อง โดยไม่เรียกโมเดลรอบสอง และไม่แทนข้อมูลเครื่องที่ส่งมาขัดแย้งกับราคาในเรื่อง คำใน private reasoning ไม่ใช่หลักฐานเปิดรายการ

เปิดรายการ/เลือกของไม่หักเงิน ปุ่มยืนยันเรียก NPC ตัดสินและต่อโรลตามเดิม ยอมรับแล้วจึงหักเงินและรับกุญแจครั้งเดียว รับ event ซ้ำไม่ชำระซ้ำ การขายยังเลือกรายการที่ NPC ต้องการซื้อจาก Inventory และเอาของที่ไม่อยากขายออกได้ ป้องกันการเปิดซื้อขายจากการพูดถึง สมมุติ ปฏิเสธ หรือ commerceIntent:none ตามเดิม

ตรวจข้อความล่าสุดแบบไม่มี patch ด้วย production loader ที่ 320/390/1280px ตั้งแต่เปิดรายการจนจ่าย 5 เงิน รับกุญแจพร้อม deadline และรับ event ซ้ำ ตรวจซื้อสินค้าปกติ ขายดาบโดยเก็บโล่ และระบบเช่า/บริการ/มัดจำ/คืนของเดิมร่วมด้วย คำตอบ AI เป็น fixture ไม่มีการเรียกบัญชีจริงในการทดสอบ
