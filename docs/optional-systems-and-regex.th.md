# เปิด–ปิดระบบเสริมและการใช้ร่วมกับ Regex — 0.45.5

ตั้งแต่เวอร์ชัน **0.45.3** ระบบเสริมทั้งหกด้านล่างเริ่ม **ปิด** หากยังไม่มีค่าของสวิตช์นั้นบันทึกไว้ ผู้เล่นเลือกเปิดเฉพาะระบบที่ต้องการได้เอง ค่าเปิด/ปิดที่เคยบันทึกไว้อย่างชัดเจนยังใช้ตามเดิม

หากอัปเดตจากรุ่นที่ยังไม่มีสวิตช์เหล่านี้ ระบบทั้งหกจะเริ่มปิดเช่นกัน แม้เคยใช้งานมาก่อน ให้เปิดสวิตช์ของระบบที่ต้องการเล่นต่อ ข้อมูลเดิมไม่ถูกลบ

## เปิดระบบที่ต้องการ

1. อัปเดตส่วนเสริมและรีโหลด SillyTavern
2. เปิด **Extension Settings → RoleForge** หรือเปิดหน้าต่าง RoleForge แล้วกดปุ่มรูปแถบปรับค่าเพื่อเข้า **Control center**
3. เลือกเปิดสวิตช์ของระบบที่ต้องการ การตั้งค่าทั้งสองตำแหน่งใช้ค่าเดียวกัน
4. หากต้องการให้ AI ติดตามจากเรื่อง ให้เปิด **Auto tracking** ด้วย
5. เล่นต่อในแชต ระบบที่เปิดจึงเริ่มทำงานตามข้อมูลที่ยืนยันในเรื่อง

| สวิตช์ | เมื่อเปิด | ตัวอย่างการใช้งาน |
| --- | --- | --- |
| **Mission Board / กระดานภารกิจ** | แสดงกระดานภารกิจในแชตเมื่อเดินถึงกระดานตามเนื้อเรื่อง | เปิดกระดาษ → อ่านรายละเอียด → รับภารกิจหรือย้อนกลับ |
| **Auction House / ระบบประมูล** | แสดงงานประมูลและเปิดการเข้าร่วม/เสนอราคา | อ่านสินค้าและค่าธรรมเนียม → เข้าร่วม → เสนอราคา → กดรอนับราคา → จ่ายเงินและรับของเมื่อชนะ |
| **Story Memory / บันทึกเรื่องสำคัญ** | เก็บข้อเท็จจริง คำสัญญา ความลับ และเรื่องที่ยังค้าง | AI ยืนยันเหตุการณ์สำคัญ → บันทึก → ใช้ข้อมูลประกอบการเล่นต่อ |
| **Story Agenda / นัดหมายและกำหนดเวลา** | ติดตามนัดหมายตามเวลาในเรื่อง | ตกลงเวลานัด → บันทึกกำหนดเวลา → ตรวจรายการเมื่อเวลาในเรื่องเดินถึง |
| **Quest Checklists / เช็กลิสต์เป้าหมายเควส** | แยกเป้าหมายย่อยและคำนวณความคืบหน้าของเควส | รับเควส → ติดตามแต่ละเป้าหมาย → อัปเดตเมื่อมีหลักฐานว่าทำสำเร็จ |
| **Memory Summaries / คลังสรุปความจำ** | เก็บประวัติและใช้ API แยกเพื่อสร้างสรุปความจำ | เปิดระบบ → ตั้งค่า API และการสรุป → สรุปประวัติ → เลือกความจำที่เกี่ยวข้องเพื่อใช้เล่นต่อ |

สวิตช์เป็นการตั้งค่าของส่วนเสริม ข้อมูล RPG ยังอยู่ในแชตและใช้ Continuity ตามการตั้งค่าเดิม การเปิดสวิตช์ไม่ได้รับประกันว่าโมเดลจะส่งข้อมูลสมบูรณ์ทุกครั้ง หากไม่เห็นการ์ดให้ตรวจ Auto tracking และเนื้อเรื่องว่าผู้เล่นถึงสถานที่นั้นแล้ว

## ปิดแล้วข้อมูลเป็นอย่างไร

การปิดสวิตช์ **ไม่ลบข้อมูลเดิม** ภารกิจ ความจำ นัดหมาย เป้าหมายเควส และประวัติประมูลที่บันทึกแล้วจึงไม่หายเพราะปิดระบบ เมื่อเปิดอีกครั้งข้อมูลเดิมยังอยู่

- **Memory Summaries ปิด:** ไม่เก็บประวัติเพิ่มสำหรับคลังสรุป ไม่เรียก API สรุป และไม่แนบความจำจากระบบนี้เข้า context ของคำตอบใหม่ สรุปเดิมยังเก็บไว้
- **Auctions ปิด:** หยุดการเข้าร่วม เสนอราคาใหม่ และเปิดรายการถัดไป การปิดไม่ยกเลิกราคาที่เสนอไว้หรือปล่อยวงเงินที่ยังผูกพันโดยอัตโนมัติ
- หากมีงานประมูลค้าง ให้เปิด **RoleForge → Ranks & Progression → Auctions** เพื่อกด **รอ / ให้ผู้ดำเนินงานนับราคา** จนรายการจบ หรือ **ออกจากการประมูล** หากไม่ได้เป็นผู้เสนอราคาสูงสุด ระบบยังตรวจวงเงิน ป้องกันเงิน/ไอเทมซ้ำ และบันทึกผลตามเดิมระหว่างปิดสวิตช์
- ถ้าคุณนำอยู่จะออกจากงานทันทีไม่ได้ เมื่อนับราคาจบและชำระผลแล้วจึงออกได้ตามสถานะของงาน การคืนมัดจำคือปล่อยวงเงินที่กันไว้ ไม่ใช่เพิ่มเงินใหม่

## เปิด–ปิดการแจ้งเตือน

**Event notifications** เริ่มปิดสำหรับการตั้งค่าใหม่ หากผู้ใช้เคยบันทึกว่าเปิดไว้ ระบบยังคงเปิดตามค่านั้น

เปิดสวิตช์นี้ใน Extension Settings เมื่อต้องการรับการแจ้งเตือน เช่น ฝึกสำเร็จ ซื้อของ ของเข้า/ออก ได้สกิลใหม่ หรือผลประมูล แล้วเลือกหมวดที่ต้องการ การปิดการแจ้งเตือนไม่หยุดระบบที่เปิดใช้งานอยู่ ข้อความกำลังบันทึกและข้อผิดพลาดในหน้าจอทำรายการยังแสดงเพื่อให้ทราบผล

## ทำไม Regex หรือหน้าตาแชตจากส่วนเสริมอื่นเคยแสดงผิด

SillyTavern อาจใช้ Regex แบบแสดงผลเพื่อเปลี่ยนข้อความเป็น HTML หรือมีส่วนเสริมสร้างการ์ดและองค์ประกอบของตัวเองไว้ในข้อความแชต แต่ Chat Presentation รุ่นก่อนของ RoleForge สร้างเนื้อหาแสดงผลใหม่จากข้อความต้นฉบับอีกครั้ง การแทนที่นี้จึงอาจทับ HTML ที่ Regex จัดไว้ ทำให้รูปแบบหาย การ์ดเพี้ยน หรือองค์ประกอบที่ต้องใช้ปุ่มของส่วนเสริมอื่นทำงานไม่ถูกต้อง

เวอร์ชัน **0.45.3–0.45.4** มีเงื่อนไขกว้างเกินไป: เมื่อมี Regex แบบแสดงผลเปิดอยู่ ก็หยุดทั้งคำสั่งให้ AI สร้างแท็กและการจัด Header / Dialogue / Narrative แม้ Regex ไม่ได้เปลี่ยนข้อความนั้น จุดนี้แก้เพิ่มใน **0.45.5** แล้ว

ตั้งแต่ 0.45.5 สวิตช์ **Header / Dialogue / Narrative** ใน NPC Management ควบคุมการขอรูปแบบจาก AI ตามเดิม แม้มี Regex เปิดอยู่ ตัวแสดงผลตรวจผลของแต่ละข้อความ: หากแท็ก RoleForge และเนื้อหายังตรงกัน สามารถจัดบล็อกผู้พูดได้ แต่ถ้าเป็น HTML/widget แบบกำหนดเองหรือข้อความที่ถูกแปลงจริง จะเก็บผลของ SillyTavern ไว้ รวมถึงปุ่มและสถานะ input การแก้ช่อง Edit จาก 0.45.4 ยังอยู่

ข้อความเก่าที่มีแท็ก `<tr-header>`, `<tr-narrative>` และ `<tr-dialogue>` สามารถกลับมาแสดงรูปแบบหลังรีโหลดได้ ส่วนข้อความที่ AI สร้างโดยไม่มีแท็กในช่วงเกิดปัญหาจะยังเป็นข้อความธรรมดา ให้สร้างคำตอบใหม่หรือ regenerate คำตอบนั้นหากต้องการรูปแบบเดิม ระบบไม่เดาผู้พูดหรือแก้เนื้อเรื่องที่บันทึกไว้ย้อนหลัง

การแก้ไขนี้จัดการจุดที่ RoleForge เคยทับผลการแสดงผล ยังไม่ได้หมายความว่าส่วนเสริม Regex ทุกตัวหรือสคริปต์ทุกแบบผ่านการทดสอบ หาก Regex เปลี่ยนข้อความต้นฉบับจนข้อมูลติดตามของ RoleForge ถูกลบไป ระบบติดตามอาจอ่านข้อมูลนั้นไม่ได้ แม้การแสดงผล HTML จะถูกเก็บไว้แล้วก็ตาม

## ลองตรวจใน SillyTavern

1. ใช้แชตที่มีข้อความหรือการ์ดจาก Regex อยู่แล้ว แล้วรีโหลดหลังอัปเดต
2. เปิดและปิด **Chat Presentation** ของ RoleForge ตรวจว่ารูปแบบเดิมยังอยู่ ไม่มีข้อความหรือการ์ดซ้ำ และปุ่มของการ์ดเดิมยังกดได้
3. สร้างคำตอบใหม่ ทดลอง swipe แล้วออกและกลับเข้าแชต ตรวจทั้งข้อความเก่าและข้อความใหม่
4. เปิดเฉพาะ Mission Board ลองเดินถึงกระดาน อ่าน/รับภารกิจ จากนั้นปิดและเปิดสวิตช์อีกครั้ง ตรวจว่าภารกิจที่รับไว้ยังอยู่
5. หากใช้งานประมูล ให้ลองปิดสวิตช์ขณะที่มีรายการค้าง ตรวจว่ากดราคาใหม่ไม่ได้ แต่เปิด Ranks & Progression เพื่อทำรายการค้างให้จบได้
6. ปิด Memory Summaries แล้วเล่นต่อ ตรวจว่าไม่มีงานสรุปใหม่หรือคำขอ API สรุปจากระบบนี้

ถ้ายังพบปัญหา ให้รายงานชื่อส่วนเสริม Regex, สคริปต์ที่ทำให้เกิดปัญหา, ตัวอย่างข้อความก่อนและหลังแสดงผล และขั้นตอนที่ทำให้เกิดซ้ำ ข้อมูลเหล่านี้ช่วยแยกปัญหาการทับ DOM ออกจากปัญหาที่ Regex เปลี่ยนข้อมูลต้นฉบับ
