# แก้เมนูเลือกหลายรายการ NPC / Lore ใน 0.68.5

เมนู **เลือก → ⋯** เคยปิดทันทีเมื่อเสียโฟกัส หากการแตะบนมือถือทำให้ `<summary>` เสียโฟกัสโดยไม่มีปุ่มใหม่รับโฟกัส (`relatedTarget=null`) เมนูจะซ่อนตัวเลือกก่อนเหตุการณ์คลิก ทำให้จำนวนที่เลือกไม่เปลี่ยน

เปลี่ยนให้เมนูปิดเมื่อแตะนอกเมนู หรือย้ายโฟกัสไปยังตัวควบคุมอื่น การเสียโฟกัสโดยไม่มีปลายทางจะไม่ซ่อนตัวเลือก ปุ่ม Escape ยังปิดเมนูและคืนโฟกัสให้ปุ่มสามจุด การเลือกยังคงอยู่เมื่อเปลี่ยนหน้า และถูกล้างเมื่อเปลี่ยนคำค้นหาหรือตัวกรองตามเดิม

NPC และ Lore ใช้ตัวจัดการเมนูร่วมกัน จึงแก้ทั้งสองส่วน การรับเหตุการณ์ผูกกับหน้าต่างจัดการเพียงครั้งเดียว ไม่สะสมใหม่ทุกครั้งที่รายการ Lore บันทึกหรือวาดใหม่

## วิธีใช้

1. เปิดจัดการตัวละครหรือข้อมูลโลก แล้วกด **เลือก** ด้านล่าง
2. กด **⋯ → เลือกหน้านี้** เพื่อเลือก 20 รายการ หรือ **เลือกผลค้นหาทั้งหมด** เพื่อเลือกทุกรายการที่ตรงกับคำค้นหา/ตัวกรองในทุกหน้า
3. ใช้ **เปิดรายการที่เลือก / ปิดรายการที่เลือก** หรือ **⋯ → ลบที่เลือก** การลบยังต้องยืนยันก่อน
4. กด **ล้างการเลือก** หรือ **เสร็จ** เมื่อต้องการออกจากการเลือกหลายรายการ

## ตรวจสอบบนแอปจริง

ทดสอบส่วนเสริมกับ frontend และ server ของ **SillyTavern 1.19.0** ในโปรไฟล์ทดสอบแยก ใช้การ์ดทดสอบที่นำเข้าผ่าน API การ์ดจริง มี 500 NPC และ 4,019 Lore ไม่ได้เชื่อมต่อแชตหรือเซิร์ฟเวอร์ของผู้ใช้

- WebKit ที่ความกว้าง 390px ใช้การแตะจอ
- Chromium ที่ความกว้าง 390px ใช้การแตะจอ และ 1440px ใช้เมาส์
- ตรวจเลือก 20 รายการ เลือกข้ามหน้า 21 รายการ เลือกทั้งหมด 500/4,019 รายการ ล้างการเลือก ปิดรายการและ Undo เลือกผลค้นหาเพียงรายการเดียว ยกเลิก/ยืนยันการลบ ปิดเมนูเมื่อแตะนอกเมนู และใช้คีย์บอร์ด
- โหลด SillyTavern ใหม่จาก server จริง แล้วยืนยันจำนวนและสถานะที่บันทึก

WebKit บน Linux ไม่ได้ใช้นโยบายโฟกัสของปุ่มเหมือน iOS ทุกกรณี ชุดทดสอบจึงเรียก native `blur()` ที่ไม่มี `relatedTarget` ก่อนแตะตัวเลือกด้วย เพื่อทดสอบเงื่อนไขที่เคยปิดเมนูโดยตรง โค้ดเดิมล้มเหลวในการตรวจนี้ และโค้ดที่แก้ผ่าน ไม่มีการเรียกโมเดล AI ระหว่างทดสอบ และยังไม่ได้ตรวจบน iPhone จริง

รันซ้ำโดยติดตั้ง Playwright/Chromium/WebKit และตั้ง RoleForge ใน SillyTavern โปรไฟล์ทดสอบแยก:

```sh
ST_REAL_URL=http://127.0.0.1:18174/ npm run test:archive-menu:real
```

สคริปต์สร้างการ์ดทดสอบใหม่และบันทึกผลจริง จึงควรใช้เฉพาะโปรไฟล์ทดสอบ หากต้องการเฉพาะ Chromium ให้เพิ่ม `ST_REAL_BROWSERS=chromium` กำหนดตำแหน่งภาพและ JSON ได้ด้วย `ST_ARCHIVE_MENU_ARTIFACTS`
