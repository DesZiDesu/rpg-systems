# Workshop ติดตั้งไม่ผ่าน — 0.81.2

ข้อความ “ไฟล์ดาวน์โหลดไม่ตรงกับแพ็กเดิม คลังที่ติดตั้งอยู่ยังถูกเก็บไว้” มาจากการตรวจ SHA-256 ก่อนติดตั้ง ไม่ใช่ปัญหาสิทธิ์ครอบครอง Death Note ในโรล

จำลองสาเหตุได้เมื่อ Git บน Windows checkout ไฟล์ JSON เป็น CRLF: Death Note 0.3.0 เปลี่ยนจาก 924 เป็น 947 ไบต์ ทำให้ hash ต่างจาก catalog แม้เนื้อหาไม่เปลี่ยน จากภาพอย่างเดียวระบุระบบปฏิบัติการของผู้ติดตั้งไม่ได้ แต่ยืนยันได้ว่าเป็นด่านตรวจ hash นี้

แก้โดยกำหนด `.gitattributes` ให้ catalog และ packages ใช้ LF เสมอ พร้อมยอมรับ UTF-8 BOM/CRLF เฉพาะเมื่อแปลงกลับแล้ว SHA-256 ตรงกับ catalog เท่านั้น การเปลี่ยนข้อความ ช่องว่าง หรือข้อมูลในแพ็กยังถูกปฏิเสธ และไม่เขียนทับแพ็กเก่า เพิ่ม hash ใน URL ดาวน์โหลดและใช้ no-store ป้องกันแคชของคนละรุ่น

ให้ผู้ติดตั้งอัปเดต RoleForge แล้ว reload SillyTavern และติดตั้งจาก Workshop อีกครั้ง ไม่ต้องล้างข้อมูลหรือถอนแพ็กเดิม

ทดสอบ Worker/IndexedDB และปุ่มติดตั้งจริงใน SillyTavern 1.19.0 ทั้ง desktop และ Chromium mobile emulation: ติดตั้งครบสาม Addon จากไฟล์ CRLF + BOM, reload แล้วยังอยู่, แพ็กแก้เนื้อหาถูกปฏิเสธและข้อมูลเดิมอยู่ครบ ไม่ใช่การทดสอบบน iPhone จริง
