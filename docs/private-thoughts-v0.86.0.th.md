# RoleForge 0.86.0 — ความคิดผู้เล่นและ NPC

ความคิดทั้งสองฝั่งไม่มีกรอบ พื้นหลัง หรือเส้นข้าง ใช้ตัวเอียงเล็กลงและโทนเงาเหมือนกันครบ 5 ธีม ไม่ขึ้นกับการเปิด/ปิด Dialogue · กรอบบทพูด ข้อความอยู่กับที่ ส่วนสามจุดข้างป้ายพูดในใจขยับไล่กันรอบละ 2.2 วินาที

## การใช้งาน

ผู้เล่นพิมพ์ `|ฉันต้องระวังตัวไว้ก่อน|` ในข้อความของตัวเอง โดยเปิดสวิตช์ UI บทพูด / บรรยาย / พูดในใจ เฉพาะ User

AI ใช้ `<tr-thought name="ชื่อหรือไอดี NPC">เขาดูมีอะไรปิดบัง แต่ฉันยังไม่รู้ว่าเป็นอะไร</tr-thought>` เป็นบล็อกแยก ไม่ซ้อนในบรรยายหรือบทพูด คำสั่งและตัวอย่างนี้รวมใน prompt และ Manual Sync แล้ว เปิดระบบจัดรูปแบบ NPC เพื่อให้แสดง UI

ไม่มีสวิตช์ความคิดแยกในรุ่นนี้ Dialogue คุมกรอบบทพูดเท่านั้น ลูกเล่นการเคลื่อนไหวของดีไซน์คุมอนิเมชันและมีให้เลือกทุกธีม รองรับ Reduce Motion ของระบบและ SillyTavern

ตัวเอียง `*ข้อความ*` ในบรรยายคงเป็นบรรยาย ไม่ถูกแปลงเป็นความคิดเอง ความคิดไม่ถูกพากย์ เล่นเสียงทั้งหมดหรือ autoplay ก็ข้ามความคิด

AI ได้รับคำสั่งว่าความคิดเป็นข้อมูลส่วนตัวของเจ้าของความคิด NPC ไม่ได้ยินความคิดผู้เล่นหรือ NPC คนอื่นเพียงเพราะผู้อ่านมองเห็น ยกเว้นมีความสามารถอ่านใจที่กำหนดไว้ในโรลและเข้าเงื่อนไขจริง ความคิดไม่ใช่การอนุญาตให้ซื้อ โอนเงิน ใช้สมุด หรือทำรายการในเกม และระบบไม่แต่งคำพูดหรือความคิดของผู้เล่นแทน

## การตรวจ

Unit tests ผ่าน 1,863 ข้อ และ npm run check ผ่าน ตรวจใน SillyTavern 1.19.0 ด้วย Chromium และ WebKit ทั้ง PC และมือถือ ครบ 5 ธีม เปิด/ปิด Dialogue รวม Motion/Reduce Motion ภาษาไทย/อังกฤษ โหมด shared/original และการไม่เปลี่ยนข้อความต้นฉบับหรือสถานะเกม ไม่มีการเรียกโมเดลใน browser tests มือถือใช้ touch emulation ไม่ใช่ iPhone เครื่องจริง
