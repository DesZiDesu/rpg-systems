# RoleForge 0.85.8 / Death Note 0.4.2

ตั้งค่าได้ที่ Workshop → Death Note → ตั้งค่า → การแสดงผลดวงตา → รูปแบบอายุขัยที่ดวงตาเห็น

- เวลามนุษย์: แสดงเวลาที่เหลือ เช่น `เหลือ 1 ปี` / `Remaining 1 yr`
- แบบเดิม: แสดงวันและเวลาสิ้นสุดในเรื่อง เช่น `วันที่ 465 · 12:00`
- ทั้งสองแบบ: `เหลือ 1 ปี · วันที่ 465 · 12:00`

เลขเดิมเป็นวันสิ้นสุดบนตัวนับวันในโรล เวลาที่เหลือ = กำหนดเดิม − นาฬิกาในเรื่องปัจจุบัน โดย 365 วัน = 1 ปี เช่น วันที่ 100 ถึงวันที่ 465 เวลาเดียวกัน เท่ากับ 365 วัน หรือ 1 ปี เมื่อโรลเดินหน้าไปวันที่ 101 จะเหลือ 364 วัน ใช้เวลาในเรื่องในการคำนวณ

รูปแบบนี้ใช้กับอายุขัยที่ดวงตาแสดงใน Header, Dialogue และ NPC Management จำค่าตามการ์ดทันทีและใช้ต่อได้หลังรีโหลดหรือเริ่มแชทใหม่ ค่าเริ่มต้นยังเป็นแบบเดิม ใช้ได้ทั้งไทยและอังกฤษ และปรับให้การแสดงผลภาษาอ่านค่าที่เลือกตามการ์ดด้วย

การสลับรูปแบบไม่เขียนทับวันสิ้นสุด ไม่สุ่มอายุขัยใหม่ ไม่เปลี่ยนค่าที่เสียไปกับข้อตกลง และคงข้อจำกัดว่าใครอ่านอายุขัยใครได้ตามเดิม หากมีแต่วันที่ปฏิทินโดยไม่มีวันอ้างอิงในเรื่อง จะคงวันที่ที่บันทึกไว้และอธิบายข้อจำกัดในรายละเอียด

ตรวจสอบผ่าน 1,848 unit/integration tests และ Native SillyTavern 1.19.0 ใน Chromium / WebKit ทั้ง PC และมือถือจำลอง ครอบคลุมสามรูปแบบ การคำนวณข้ามวัน การเดินเวลาของโรล ภาษาอังกฤษ รีโหลด แชทใหม่ และการไม่เรียกโมเดลเพิ่มเพื่อเปลี่ยนรูปแบบ
