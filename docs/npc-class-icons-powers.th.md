# ไอคอนคลาส NPC และหน้าพลัง — RoleForge 0.71.0

รุ่นนี้เพิ่มไอคอนภาพที่เลือกใช้ได้ และจัดหน้าพลังให้กระชับ **ไม่ได้เพิ่มระบบ Custom Status แยกใหม่** ตามที่ผู้ใช้ยกเลิกไว้ หลอดยังใช้ชนิด **Resource** ใน Power Preset เดิม

## เลือกภาพคลาสให้ NPC

1. เปิด **NPC Management** เลือกตัวละคร แล้วกด **แก้ไขข้อมูล / Edit**
2. เปิด **CHAT APPEARANCE / ภาพและสีประจำตัว** แล้วเปิด **ไอคอนภาพ (เลือกใช้)**
3. เลือกภาพจากชุด **Servant** หรืออัปโหลดภาพเอง แล้วกด **บันทึกตัวละคร**

มีภาพของ **gears 161 ภาพ** ในชุด Classic, Brown, Blue, Grand, Anti-Servant และ Beast จาก [แหล่งที่ผู้ใช้ส่งมา](https://drive.google.com/drive/folders/1rULXe6FctvTbg_AWXrZPgO-TpBl7_vys) ดูเครดิตที่ [ATTRIBUTION](../assets/servant-classes/ATTRIBUTION.md)

- ใช้ไอคอนเดิม 12 บทบาท, Medallion และ Emblem ได้ตามเดิม ภาพเป็นตัวเลือกเพิ่มเติม
- **ใช้สัญลักษณ์บทบาทเดิม / Use selected role symbol** เอาภาพไอคอนออก โดยยังเก็บบทบาทที่เลือกไว้
- ภาพคลาสแยกจากภาพใบหน้าตัวละคร ไม่เปลี่ยนการครอปหรือขนาด portrait
- รองรับการอัปโหลด PNG, JPG, WebP, GIF, AVIF และ SVG ไม่เกิน 8 MiB ภาพถูกย่อไม่เกิน 192px และเก็บเป็นภาพ raster ขนาดเล็กในข้อมูลตัวละคร ไม่รัน SVG หรือ HTML ที่อัปโหลด
- GIF/ภาพเคลื่อนไหวที่อัปโหลดถูกเก็บเป็นภาพนิ่งสำหรับไอคอน หากภาพละเอียดจนข้อมูลเกิน 32 KiB จะมีข้อความให้เลือกภาพที่เล็กลง
- ใส่ URL ภาพ HTTPS ได้เช่นกัน แต่ต้องเข้าถึง URL นั้นได้เมื่อเล่นบนเครื่องอื่น การเลือกจากชุดหรืออัปโหลดจะฝังข้อมูลภาพไปด้วย

### ตัวละครหลายเวอร์ชัน

เวอร์ชันที่ยังไม่ได้ตั้งภาพคลาสจะใช้ภาพจากตัวหลัก เลือกภาพใหม่เพื่อกำหนดเฉพาะเวอร์ชันนั้น หรือใช้ **Inherit base icon / ใช้ไอคอนตามตัวหลัก** เพื่อกลับไปอ้างอิงภาพหลัก

การเลือกภาพไม่ได้เปลี่ยนชื่อคลาส อาชีพ Stats หรือ Ability ให้เอง เช่น เลือกภาพ Caster ให้ NPC แล้วช่องอาชีพเดิมจะยังอยู่ตามที่ผู้เขียนตั้งไว้

### การแชร์และ World Pack

ภาพที่เลือกจากชุดหรืออัปโหลดเก็บใน `roleIconImage` ของ NPC และของเวอร์ชันที่มีภาพเฉพาะ:

```json
{
  "roleIcon": "warrior",
  "roleIconImage": "data:image/webp;base64,..."
}
```

ไม่มี `roleIconImage` ในเวอร์ชันหมายถึงรับค่าจากตัวหลัก ส่วนสตริงว่างหมายถึงใช้สัญลักษณ์บทบาทแทนภาพ

NPC ที่ผูกกับ **Character** จะพกภาพไปกับการ Export การ์ดของ SillyTavern ถ้าใช้ World Pack บีบอัด ให้ใช้ **Update embedded archive / Export self-contained card** หลังบันทึกการแก้ไขตามขั้นตอนเดิม สำหรับ NPC เฉพาะ Chat ต้องใช้การส่งออกของขอบเขตนั้นหรือย้ายเป็น Character ก่อน

ไอคอนแสดงใน Header ของ RoleForge Original, The Mage’s Folio, The Gilded Chapter, The Royal Codex และ Aincrad AI อัปเดตข้อมูลโรลได้ แต่ไม่มีสิทธิ์แก้ภาพคลาสที่ผู้ใช้บันทึกไว้

## หน้าพลังแบบใหม่

หน้าพลังแสดงเฉพาะพลังที่เลือกไว้ หรือมีค่ามากกว่า 0 เป็นรายการกระชับ กดแต่ละแถวเพื่อดูคำอธิบาย ความชำนาญ และปุ่มฝึก ช่องแก้ตัวเลขทั้งหมดไม่อยู่ในหน้าหลักแล้ว

กด **Manage / จัดการ → Current powers / พลังปัจจุบัน** เพื่อแก้ค่าใน Extension Drawer รายการที่ยังไม่ใช้ยังอยู่ครบใน Preset และแก้ได้จากตรงนี้ การแก้ Resource จะอัปเดตหลอดตามค่าที่บันทึก

ถ้าต้องการหลอด เช่น 3/3 ให้ใช้ **Power Preset → Custom → สร้างพลัง → รูปแบบ Resource / หลอดพลัง** แล้วกำหนดค่าสูงสุดและค่าเริ่มต้นตามต้องการ หลอดที่หมดแล้วยังคงแสดงเมื่อเป็นพลังที่เลือกหรือเคยถูกติดตามไว้ กติกาการใช้/ฟื้นเป็นไปตามคำอธิบายพลังและผลโรลเดิม ไม่มีระบบ Custom Status เพิ่มซ้อนเข้ามา
