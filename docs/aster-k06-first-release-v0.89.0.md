# Aster K06 — First Release

RoleForge **0.89.0** · Aster Phone **1.2.0**

Aster K06 เป็นมือถือฝาพับที่ใช้งานใน SillyTavern ได้จริง เพิ่มเป็นตัวเลือกภายใน Aster Phone เดิม ไม่ต้องติดตั้ง Addon โทรศัพท์อีกชุด และ **ไม่กำหนดปีหรือยุคให้โรล** ระบบแจ้ง AI เฉพาะว่าคุณใช้เครื่องชนิดไหน มีหน้าตาและความสามารถอย่างไร

## เริ่มใช้งาน

1. อัปเดต RoleForge เป็น 0.89.0 แล้ว reload SillyTavern
2. เปิด Workshop → Aster Phone → อัปเดตเป็น 1.2.0
3. กด Configure / ตั้งค่า → Handset / ชนิดโทรศัพท์ → **Aster K06 · มือถือฝาพับ**
4. เปิดจากปุ่มลอยหรือ Wand Menu เช่นเดิม

ตัวเลือกเดิมยังเริ่มที่ Aster One เพื่อไม่เปลี่ยนเครื่องให้ผู้ใช้ที่ไม่ได้เลือก K06 ตั้งค่าให้ตัวละครมีโทรศัพท์แล้วได้ หรือรับเครื่องในโรล/มีใน Inventory ชื่อเช่น `Aster K06`, `flip phone`, `keitai` และ `มือถือฝาพับ` รองรับโดยไม่ต้องใช้ชื่อไอเทมตายตัวเพียงชื่อเดียว

## ใช้มือถือฝาพับ

- **PC:** หน้าต่างลอยเหนือแชท ลากแถบชื่อหรือบริเวณหูฟังเพื่อย้ายตำแหน่ง กด × เพื่อปิดหน้าต่าง แล้วอ่านโรลต่อได้
- **มือถือ:** เปิดเป็นหน้าจอเฉพาะ จัดขนาดเครื่องให้พอดีจอ คีย์บอร์ดขึ้นแล้วลดพื้นที่แป้นกดจำลองเพื่อให้ช่องเขียนยังอยู่ในพื้นที่ที่ใช้ได้
- **ปุ่มกลาง:** เปิดเมนูหรือเลือกคำสั่ง ใช้ปุ่มทิศทางและตัวเลขเลือกเมนูได้ บนคอมรองรับลูกศรและ Enter
- **ปุ่มสีเขียว/แดง:** โทรหรือรับสาย / วางสายหรือกลับหน้าหลัก
- **ฝาพับ:** ปิดหรือเปิดได้จริง จอนอกแสดงเวลา ผู้ส่งเมล หรือสายเข้า พร้อมไฟแจ้งเตือน เลือกซ่อนชื่อบนจอนอกได้
- การปิดฝาหรือหน้าต่าง **ไม่ใช่การปิดเครื่อง ไม่ยกเลิกงานตอบ และไม่รับสายเอง** การเปิดฝาเพื่อรับสายทำงานเมื่อเปิดตัวเลือกนี้เท่านั้น
- เลือกตัวเครื่อง Pearl Silver, Midnight Ink หรือ Sakura Pearl ได้ พร้อมพื้นหลัง ภาษาปุ่ม เสียง และ motion

## ข้อความและรายชื่อ

SMS กับเมลมือถือแยกช่องทางและกล่องเข้า/กล่องส่ง มีหัวข้อเมล รูปแนบ และร่างข้อความ การนับ SMS รองรับ GSM-7, อักขระพิเศษที่ใช้สองหน่วย และ Unicode/emoji ที่มีความยาวต่างกัน โดยไม่ตัดเนื้อหาก่อนส่ง

รายชื่อแก้ชื่อที่บันทึก หมายเลข อีเมล และหมายเหตุได้ เมลต้องมีที่อยู่ที่ทราบ หรือเป็นช่องทางเมลที่เคยรับเข้ามาแล้ว SMS/การโทรต้องมีหมายเลขหรือช่องทางติดต่อที่ได้รับการยืนยัน ระบบไม่เสกหมายเลข/ที่อยู่เมลให้เป็นข้อมูลที่รู้แล้ว

NPC ส่งเมลหรือโทรเข้าครั้งแรกได้แม้ยังไม่มีในรายชื่อ หากโรลยืนยันเหตุการณ์และเปิด permission ไว้ ระบบสร้างผู้ติดต่อและเชื่อม NPC เดิมให้ ส่วนรายชื่อสร้างเองจะสร้าง NPC เมื่อเริ่มโต้ตอบ โดยใช้กระบวนการเดียวกับ Aster One

ภาพและเสียงประจำผู้ติดต่อเดิมยังอยู่เมื่อแก้รายละเอียดผ่าน K06 การบล็อกมีผลกับการรับข้อความ/สายเข้า และยกเลิกคำตอบที่ยังรอของผู้ติดต่อนั้น

## AI และงานเบื้องหลัง

เลือกให้ตอบทันทีหรือรอข้อความโรลถัดไปได้ งานตอบใช้โมเดลที่ตั้งไว้ใน SillyTavern สามารถปิดหน้าต่างระหว่างรอ และเปิดกลับมาอ่านคำตอบได้

AI ได้ข้อมูลว่า **Aster เป็นแบรนด์, K06 เป็นมือถือฝาพับ** มีโทรศัพท์ SMS เมล กล้อง/อัลบั้ม เว็บมือถือ โน้ต นาฬิกาปลุก และทำนอง ไม่ใช่ Aster One และไม่มีแอป Gather/Lumen/Murmur/Harbor Store บนเครื่องนี้ ระบบตรวจข้อจำกัดนี้กับเหตุการณ์ที่รับเข้าจริงด้วย

การสลับชนิดเครื่องไม่ลบแอปหรือประวัติสมาร์ทโฟนเดิม ข้อมูลเหล่านั้นเก็บไว้และกลับไปใช้ได้เมื่อเลือก Aster One งานค้างของแอปที่ K06 ไม่รองรับไม่ถูกเปลี่ยนเป็น SMS อย่างเงียบ ๆ

คำตอบที่ยืนยันแล้วอัปเดตเวลาโลกและ relationship engine ชุดเดียวกับแชทหลัก เก็บหลักฐานและใช้ขีดจำกัดการพัฒนาความสัมพันธ์เดิม การส่งข้อความหรือการอ้างถึงการกระทำทางกายไม่ทำให้เกิด physical encounter โดยอัตโนมัติ

## การโทรและ Voice

โทรออก รับสาย ปฏิเสธ วางสาย และดูประวัติได้ บทสนทนาในสายอ่านได้ทั้งจากช่องเขียนในเครื่องหรือข้อความในแชทหลักตามการตั้งค่า Call speech sources

ถ้าเปิดและเชื่อม Voice Addon สามารถอ่านเสียง NPC ในสายอัตโนมัติ ใช้เสียงที่กำหนดให้ NPC/ผู้ติดต่อหรือเสียงสำรองเดียวกับ Aster เดิม ปิดหน้าต่างแล้วยังอยู่ในสายได้ วางสาย ปิด Addon หรือเปลี่ยนแชทจึงหยุดคิวเสียงตามกฎเดิม ไม่เปิดไมโครโฟนจริงของผู้ใช้เอง

## กล้อง เว็บ และเครื่องมือ

- **กล้องในโรล:** บันทึกภาพของฉากพร้อมสถานที่และเวลา ใช้ภาพอ้างอิงที่ผู้ใช้นำเข้า หรือเก็บเป็นบันทึกภาพแบบคำบรรยายเมื่อไม่มีไฟล์ภาพ ไม่แอบเปิดกล้องเครื่องจริงและไม่อ้างว่า AI เห็นภาพเมื่อมีเพียงคำบรรยาย
- **อัลบั้ม:** นำเข้า ดู ลบ แนบเมล และตั้งภาพเป็นพื้นหลังได้ ภาพส่วนตัวยังไม่ส่งให้ NPC จนกว่าจะเลือกแชร์ ภาพพื้นหลังที่เลือกจากอัลบั้มใช้เมื่อภาพนั้นมีอยู่ในแชทปัจจุบัน ส่วนแชทอื่นใช้พื้นหลังสำเร็จรูปที่ตั้งไว้
- **Mobile Portal:** ขอข่าว อากาศ หรือข้อมูลการเดินทางจากบริบทโรลผ่าน AI แล้วเก็บหน้าไว้ในแชท เป็นข้อมูลในโลกของเรื่อง ไม่ใช่การค้นอินเทอร์เน็ตจริง
- **โน้ต:** บันทึก/แก้ข้อความส่วนตัวของผู้เล่น
- **นาฬิกาปลุก:** ใช้เวลาโลกในโรล เมื่อเวลาผ่านจุดที่ตั้งไว้จึงแจ้งเตือน ไม่ใช้เวลาจริงของโทรศัพท์ และไม่บันทึกหรือเรียก AI ทุกวินาที
- **เครื่องคิดเลขและทำนอง:** คำนวณพื้นฐาน ฟัง/เลือกทำนอง พร้อมเสียงปุ่ม เมล และชัตเตอร์ที่สร้างภายในเบราว์เซอร์

## การบันทึกและการย้อนโรล

การตั้งค่าผูกกับตัวละคร ส่วนรายชื่อ ข้อความ ร่าง สายโทรศัพท์ รูป โน้ต เว็บ และนาฬิกาปลุกอยู่ใน phone state เดียวกับ Aster เดิม ซึ่งผูกกับแชท/Branch

โทรศัพท์และสถานะ RoleForge บันทึกผ่าน transaction เดียวกัน คำตอบเบื้องหลังมี scope guard เพื่อไม่ให้เขียนไปยังแชทหรือสาขาที่เปลี่ยนไป การอัปโหลดรูปและการเก็บร่างก็ยกเลิกการเขียนข้าม scope ด้วย

สไวป์กลับ สไวป์ไปอีกคำตอบ ลบข้อความ และสร้าง Branch ใช้ journal เดิม ข้อมูลโทรศัพท์ย้อนตามโรล ขณะที่การตั้งค่ารุ่นเครื่องของตัวละครยังคงอยู่

## การตรวจ release

ผลสุดท้าย: **1,998 unit tests ผ่าน, 0 failures** และ syntax checks ผ่าน Native flows ผ่านบน Chromium ทั้งคอม/มือถือ และ WebKit บนจอมือถือ รวมถึง native regression ของ Aster One ทั้งคอมและมือถือด้วย

มี unit tests สำหรับการแยก mail/SMS, รายชื่อแบบมีเฉพาะเมล, การรับเมลครั้งแรก, request IDs, การนับ SMS, การเก็บร่าง, ข้อจำกัดแอป, relationship updates, หน้าเว็บ, ความเป็นส่วนตัวของภาพ, การปลุกข้ามวัน, imported metadata และการรักษาภาพ/เสียงผู้ติดต่อเดิม

Native browser tests รันบน **SillyTavern 1.19.0** ผ่านการติดตั้งแพ็กใน Workshop การเปลี่ยนเครื่อง ส่ง/รับจริงผ่าน host generation API การตอบเบื้องหลัง SMS แบบ deferred การสร้าง NPC การโทร Voice Addon เวลา/relationship โน้ต/ปลุก reload การสลับเครื่อง สไวป์ ลบข้อความ และ Branch

คำตอบ AI เป็น controlled provider fixtures เพื่อทดสอบเส้นทางของแอปโดยไม่เรียกโมเดลแบบเสียค่าใช้จ่าย Voice provider ใช้เสียงทดสอบที่สร้างในเครื่องเพื่อตรวจการเชื่อมต่อและคิว ไม่ใช่การยืนยันคุณภาพเสียงจากผู้ให้บริการจริง การทดสอบมือถือใช้ browser touch/viewport emulation และ WebKit จึงยังไม่ใช่การทดสอบบน iPhone เครื่องจริง

วิดีโอ release บันทึกจาก SillyTavern ที่เชื่อมระบบแล้ว ทั้ง PC 16:9 และจอมือถือ มี 19 ช่วง คำบรรยายไทย และเสียงของเครื่อง พร้อมข้อมูลตัวอย่างที่ระบุว่าเป็น fixture
