# RoleForge 0.86.1 — Character Creation

- ลบ First Message จนแชทว่างแล้วเปิดหน้าสร้างตัวละคร ใช้กับการ์ดที่มีข้อความเปิดอยู่เดิมได้
- รีโหลดแล้วยังเก็บร่างไว้ นำออกเฉพาะข้อความเปิดเดิมที่ SillyTavern เติมกลับในแชท/การ์ดเดิม ไม่ลบข้อความที่ AI สร้างหรือแชทอื่น
- ปิด Death Note ใช้ RoleForge creator เดิม เปิด Death Note ใช้แฟ้มตัวละครเฉพาะ: ตัวตน/นามแฝง ประวัติ เส้นเรื่อง สมุด ดวงตา และทบทวน
- สมุดและดวงตาเป็นสถานะจริงตั้งแต่เริ่มเรื่อง ไม่แจกสมุดซ้ำ ไม่หักอายุขัยสำหรับดวงตาติดตัวแต่เกิดหรือได้รับพลังโดยไม่แลก และไม่แต่งยมทูตเจ้าของเล่มโดยไม่มีข้อมูล
- ตัวเลือกของหน้าสร้างแตะได้ทั้งช่อง มีค้นหาและรายการของเราเองแทน dropdown iOS ช่องเดิมที่พิมพ์ค่าเองได้ยังคงพิมพ์ได้ผ่านรายการนี้
- ไม่เปลี่ยน preset หรือการตั้งค่าที่บันทึกไว้ ไม่ล้างความคืบหน้า RoleForge เพียงเพราะลบข้อความ

Pokémon Addon และหน้าสร้าง Pokémon ที่ต้องใช้ engine ของมันยังอยู่ใน `preview/addon-character-creation` ไม่รวม engine/catalog/ทรัพยากร Pokémon เข้า main รุ่นนี้ ส่วนตัวเลือกและหน้าตาที่เตรียมรองรับจะทำงานได้เมื่อรวม Addon ในอนาคตเท่านั้น

อัปเดต RoleForge ใน SillyTavern แล้วกด Apply update/รีโหลดหน้าเมื่อบันทึกงานและไม่มีข้อความกำลังสร้างอยู่ รุ่นใหม่คือ 0.86.1

## การตรวจรุ่น main

ทดสอบกับ SillyTavern 1.19.0 โดยใช้คำตอบ AI แบบ controlled SSE ไม่เรียกโมเดลหรือ Voice ภายนอก มือถือเป็น browser touch emulation ไม่ใช่ iPhone จริง

- ชุด unit/integration รวม 1,879 tests ผ่าน ไม่มี fail หรือ skip
- `npm run check` และ `git diff --check` ผ่าน
- หน้าสร้าง RoleForge เดิมที่ 320/390/1280px ผ่าน ทั้ง preset/ช่องเลือก/ร่าง/เริ่มเรื่อง
- Native Chromium PC/มือถือ: ลบ greeting → creator, แตะเต็มช่อง, draft reload, DN สมุดหนึ่งเล่ม/ดวงตาตั้งแต่เกิด, ไม่มีข้อความผู้เล่นปลอม, ภาษาไทย/อังกฤษ และ reload หลังเริ่มเรื่อง ผ่าน
- Native WebKit PC/มือถือ: ขั้นตอนเดียวกับ Chromium ผ่าน ไม่มี errors/warnings ในรายงานสุดท้าย
