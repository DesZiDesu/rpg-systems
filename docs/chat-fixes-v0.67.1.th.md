# RoleForge 0.67.1 · ภาพ Header, บรรยายผู้เล่น และสถานะ

กรอบภาพ Header ใช้ขนาดที่ตั้งใน NPC Management **48–144 px** ทั้ง RoleForge Original, The Mage’s Folio, The Gilded Chapter, The Royal Codex และ Aincrad Interface ไม่มีเพดานขนาดแยกตามธีมแล้ว ข้อความที่ยาวตัดบรรทัดได้โดยไม่ล้นแนวนอน

พรีวิวใน NPC Management ใช้ renderer เดียวกับ Main Chat รวมป้าย สวิตช์แยกกรอบ ตำแหน่งภาพ และการครอปสำหรับมือถือ/คอม

บรรยายของผู้เล่นยังอยู่ฝั่งขวา แต่เนื้อความชิดซ้ายภายในบล็อกเพื่อให้อ่านยาวได้ง่าย ปากกาและเส้นตกแต่งอยู่ทางขวา โดยสามดีไซน์ใหม่ใช้รูปปากกาเดียวกับฝั่ง AI และไม่มี padding เก่าซ้อนทับเมื่อเปิด NPC Management ภายหลัง ปิดกรอบ Narrative แล้วยังคงแสดงเป็นตัวเอียง

ตัวติดตามเดิมค้นคำบาดเจ็บจากทั้งคำตอบ เช่น `burned`, `bleeding`, `ไหม้` แล้วสร้างสถานะผู้เล่นและหัก HP 7/15 เอง จึงอาจนับแผลของ NPC ศพ แผลเก่า หรือบทพูดเป็นความเสียหายของผู้เล่น รุ่นนี้เลิกเดาความเสียหาย การรักษา และสถานะจากคำเหล่านั้น

ผลจริงในโรลยังบันทึกด้วย RoleForge patch ของผู้เล่นได้ ส่วนการอ่านค่า HP/MP/ST จากเนื้อความจะรับเฉพาะตัวเลขที่ระบุเจ้าของเป็นผู้เล่นโดยตรง ไม่นับบทพูด ความทรงจำ ความฝัน หรือสถานะของ NPC ถ้า patch ระบุผู้รับเป็น NPC จะไม่เขียนลงสถานะผู้เล่น AI ได้รับคำสั่งให้แยกผู้รับและใช้กฎความเสียหายที่มีหลักฐาน โดยไม่มีการเรียก AI เพิ่ม

สถานะจริงยังลด HP/ST ตามจำนวนต่อเทิร์นที่บันทึกไว้ และหมดอายุได้ รุ่นนี้แก้สถานะที่เหลือ 0 เทิร์นไม่ให้หักค่าเพิ่มอีกครั้ง

สถานะเก่าจากตัวเดาคำจะถูกตัดออกเมื่อข้อมูลตรงกับรูปแบบเก่าทั้งชุด **พร้อม combat log การสร้างที่ตรงกัน** ไม่ลบสถานะกำหนดเองหรือสถานะจาก patch ที่ยืนยันไว้ และไม่แตะข้อความแชทหรือข้อมูล MVU

**HP ที่ลดไปก่อนอัปเดตไม่ได้เติมคืนอัตโนมัติ** เพราะไม่สามารถแยกความเสียหายจริงย้อนหลังจากภาพได้ หากทราบค่าที่ถูกต้อง ให้ปรับใน **RoleForge → สถานะ → แก้ไขสถานะ → HP**
