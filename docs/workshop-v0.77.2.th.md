# Workshop — RoleForge 0.77.2

ปิด Addon ใน Workshop แล้ว ปุ่มลอยและรายการเปิดเฉพาะ Addon นั้นใน Wand Menu จะถูกนำออกทันที หากปิดทุก Addon แถบปุ่มลอยจะหายไปทั้งหมด เมื่อเปิดกลับมา ระบบใช้ตำแหน่งปุ่ม การตั้งค่า และข้อมูลเดิม ไม่ต้องติดตั้งใหม่

แก้สาเหตุที่ปุ่มลอยอิงรายการแพ็กที่ติดตั้งทั้งหมด ให้แสดงเฉพาะแพ็กที่เปิดใช้งานในแชทปัจจุบัน ระหว่างเปลี่ยนแชทและรอข้อมูลตั้งค่า จะไม่แสดงปุ่มจากแชทเดิม

ชื่อธีม Great Sage แสดง **Prismatic** และ **Azure Sage** โดยเอาคำอธิบายต่อท้ายออก ค่า theme ที่บันทึกไว้ยังใช้ค่าเดิม

อัปเดต RoleForge แล้ว Reload เพื่อใช้การแก้ไขครั้งนี้ เปิดหรือปิด Addon ได้ที่ **Workshop → แชทนี้**

ผลทดสอบ:

- Syntax ผ่าน และ unit tests ผ่าน 1,414 / 1,414
- ใช้ SillyTavern 1.19.0 จริง ธีม Dark Lite บน Chromium ทั้งคอม 1440×1000 และมือถือจำลอง 390×844
- ติดตั้งแต่ยังไม่เปิดใช้: ไม่มีปุ่มลอยหรือ Wand ของ Addon นั้น
- เปิด Field Notes และ Great Sage แล้วปิด Field Notes: ปุ่ม Field Notes หาย แต่ Great Sage ยังอยู่
- ปิดทุกตัว: ปุ่มลอยทั้งหมดและแผง Great Sage ถูกนำออก
- เปิดใหม่: ปุ่มและตำแหน่งที่บันทึกไว้กลับมา
- เปลี่ยนการ์ดแล้วกลับมา หรือ Reload: สถานะเปิด/ปิดไม่ปะปนและถูกเก็บไว้
- ตัวเลือกชื่อธีมตรงตามที่แสดง และค่าที่เลือกยังอยู่หลัง Reload
- ชุดทดสอบปิด/เปิดไม่เรียกโมเดล และไม่แก้สถานะ RPG ของแชท
- การลากปุ่มด้วยนิ้ว/เมาส์ เปิดผ่าน Wand ลูกกลมขยับตามเสียง และการหยุดเสียงเมื่อเปลี่ยนแชท ยังผ่าน การทดสอบเสียงใช้คำตอบ ElevenLabs ที่ควบคุมพร้อม MP3 สังเคราะห์ในเครื่อง และการทดสอบวิเคราะห์ใช้ model fixture ไม่ได้เรียกผู้ให้บริการจริง
