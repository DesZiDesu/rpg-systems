# RoleForge 0.54.1 — Voice Addon

Voice Addon เป็นส่วนเสริมใน RoleForge เดิม เปิดจาก **ตั้งค่าส่วนเสริม → RoleForge → ระบบเสริม → RoleForge Voice Addon** แล้วจะมี drawer เสียงแยกแสดงขึ้น ปิดไว้เป็นค่าเริ่มต้น เช่นเดียวกับ Memory Addons ค่าที่ผู้ใช้เปิดไว้ก่อนหน้าได้รับการรักษา การปิดไม่ลบคลังความจำหรือการกำหนดเสียง

## เริ่มใช้งาน

1. เปิด Voice Addon แล้วใส่ **ElevenLabs API key** ใน drawer ของเสียง ช่องนี้แยกจากการเชื่อมต่อเจนข้อความของ SillyTavern
2. กด **เชื่อมต่อ** เพื่อโหลด My Voices และโควตาที่ API ของบัญชีรายงาน การเชื่อมต่อไม่ได้สร้างเสียง
3. เลือก **เสียงสำรอง** และเลือกเสียงของ NPC แต่ละคนในหัวข้อ **เสียงของตัวละคร** ระบบใช้ NPC ID และขอบเขต Chat / Character จึงจำเสียงเดิมเมื่อใช้ชื่อเล่น และไม่รวมคนละตัวละครหรือคนละการ์ดเข้าด้วยกัน
4. ถ้าต้องการเสียงเพิ่ม เปิด **Voice Library** ค้นหาแล้วกด **เพิ่ม** เพื่อเพิ่มเสียงสาธารณะใน My Voices ใช้ได้ตามสิทธิ์บัญชี ElevenLabs; Library ผ่าน API ต้องเป็นบัญชีเสียเงิน ตัวเลือกค้นหาไม่จำกัดภาษาเพราะเสียงที่ติดป้ายภาษาอื่นยังใช้กับบทพูดไทยได้เมื่อโมเดลรองรับ
5. เลือก **Eleven v4** หรือ **Eleven v3** ทั้งสองรองรับภาษาไทย โดยใช้ Text to Dialogue API และเสียงของ NPC สำหรับแต่ละบทพูด

## ปุ่มฟัง

ภายในกรอบ dialogue แต่ละบทมีแถบ **ฟังบทพูด**, **เสียง** และปุ่ม **หยุด** เมื่อกำลังทำงาน ใช้สีหมึกของกรอบเดิม ชื่อตัวละครยังเปิดโปรไฟล์ตามเดิม ไม่มีปุ่มเสียงซ้อนอยู่ในปุ่มชื่อ

- ยังไม่เชื่อมบัญชีหรือยังไม่เลือกเสียง: ปุ่มฟังปิดใช้งาน พร้อมปุ่มเชื่อม/เลือกเสียงที่กดได้
- กำลังสร้างเสียง: ปุ่มเปลี่ยนเป็น **ยกเลิก**
- กำลังเล่น: ปุ่มเปลี่ยนเป็น **พัก**; เมื่อพักเปลี่ยนเป็น **ฟังต่อ**
- **ฟังทั้งหมด** เล่นเฉพาะบทพูดในคำตอบนั้นตามลำดับ โดยใช้เสียงของแต่ละตัวละคร ไม่มีการอ่าน narrative หรือการ์ดระบบ
- การกดปุ่ม **เสียง** เปิด drawer ตั้งค่าและส่วนเลือกเสียง NPC โดยตรง
- เปลี่ยนความเร็วฟังได้ 0.75–1.5× เป็นความเร็วเล่นไฟล์ ไม่สร้างเสียงใหม่

AI ได้รับ instruction สำหรับ delivery และคำกำกับเสียงในคำตอบโรลเดิม เช่น:

```html
<tr-dialogue name="Garrick" delivery="warmly">ห้องพร้อมแล้วครับ</tr-dialogue>
<tr-dialogue name="Cora" delivery="whispers">ทางเดินมืดมาก [sighs] ระวังด้วยนะคะ</tr-dialogue>
```

ผู้เล่นเห็นคำพูดตามปกติ ส่วน delivery และแท็กเสียงที่รองรับจะส่งให้ ElevenLabs เท่านั้น แท็กชื่อสิ่งของเช่น `[Ruin Staff]` ยังคงแสดง ไม่เรียก AI เพิ่มเพื่อสร้างอารมณ์หรือเลือกเสียง ไม่มีการสร้างเสียงจนกดฟัง เว้นแต่ผู้ใช้เปิด **ฟังคำตอบ AI ใหม่อัตโนมัติ** ซึ่งปิดไว้โดยค่าเริ่มต้น เบราว์เซอร์บางตัวอาจต้องกดฟังก่อนจึงยอมให้เล่นอัตโนมัติ

ขอบเขตการอ่านคือบล็อก Header / Dialogue ของ RoleForge ในแชตหลัก รวมถึงบทพูดที่ต่อหลังซื้อขาย ประมูล และกิจกรรมอื่นเมื่อใช้บล็อก dialogue ไม่อ่านข้อความผู้เล่น narrative บันทึกความจำหรือรายละเอียดระบบ ต้องเปิดรูปแบบ Header / Dialogue / Narrative จึงมีปุ่มฟัง หากผู้ใช้รักษา HTML / regex ซึ่งแทนที่บล็อก RoleForge ข้อความนั้นอาจไม่มีปุ่มเสียง

## โควตาและการเก็บเสียง

แสดงยอดที่เหลือ/ทั้งหมดจาก `GET /v1/user/subscription` วันที่รีเซ็ต และเวลาอัปเดตล่าสุด อ่านอีกครั้งหลังสร้างเสียงและกดรีเฟรชได้ ไม่แปลงเลขโควตาเป็นจำนวนตัวอักษร v4 หรือยอด USD โดยเดา เพราะอัตราขึ้นกับโมเดลและเสียง ถ้า API key ไม่มีสิทธิ์อ่าน Usage ยังใช้เสียงได้เมื่อสิทธิ์ Voices / Text to Speech พร้อม ข้อผิดพลาดการอ่านโควตาแสดงแยกและรักษายอดเดิมพร้อมเวลาอัปเดต ไม่เปลี่ยนยอดที่ไม่ทราบเป็นศูนย์

เก็บไฟล์เสียงใน IndexedDB แยกจากแชต โดยใช้ขอบเขตผู้ใช้ RoleForge โมเดล voice ID และข้อความจริงเป็นคีย์ กดฟังซ้ำหรือโหลดหน้าใหม่แล้วฟังข้อความเดิมจะใช้ไฟล์เดิมเมื่อเชื่อมบัญชีและเลือกเสียงที่ใช้ได้แล้ว แม้ต้องใส่ key ใหม่ในรอบนั้น กรณีที่เก็บไฟล์ลงเครื่องไม่ได้ยังมีแคชในรอบที่เปิดหน้า ล้างแคชได้ใน drawer จำกัดแคชรวม 80 ไฟล์หรือ 32 MB

ข้อความยาวแบ่งเป็นช่วงไม่เกิน 1,800 ตัวอักษรต่อคำขอ ไม่ตัดแท็กเสียงหรืออักขระ Unicodeกลางตัว แต่ละคำขอสร้างเสียงใช้โควตาจริง มีแจ้งเตือน API ก่อนส่งคำขอ รวมทั้งการอ่านบัญชี ค้นหาเสียง และโหลดตัวอย่าง ตัวอย่างเสียงที่มีอยู่ใน Library เป็นไฟล์เดิม ส่วน **สร้างเสียงทดลอง** สร้างเสียงใหม่และใช้โควตา

Swipe / Edit / Regenerate / เปลี่ยนแชต / ปิด Addon จะหยุดเสียงและยกเลิกคิวเดิม ผลลัพธ์ที่มาหลังยกเลิกไม่เริ่มเล่นทับคำตอบใหม่ ไม่เปลี่ยนบทโรล ไอเทม หรือทรัพยากรของผู้เล่น

## API key

key อยู่ในระบบเสียงเท่านั้น ไม่ใส่ใน prompt การตั้งค่าเจนข้อความ chat metadata หรือไฟล์ส่งออกของ RoleForge

เลือก **จำ key ในเบราว์เซอร์นี้** ได้เมื่อเบราว์เซอร์รองรับ IndexedDB และ Web Crypto เช่น HTTPS หรือ localhost บันทึกด้วย AES-GCM และคีย์เข้ารหัสที่ไม่ส่งออกจาก CryptoKey หากใช้งานผ่าน HTTP ที่ไม่มี Web Crypto จะเก็บ key เฉพาะรอบที่เปิดหน้าและต้องใส่ใหม่หลัง reload ปุ่ม **ลืม key** ลบ key ที่จำไว้ แต่คงการกำหนดเสียงและแคชเสียง

ElevenLabs key ต้องมีสิทธิ์อ่าน Voices และสร้าง Text to Speech; การอ่านโควตาและ Library ต้องมีสิทธิ์ของ endpoint นั้น ๆ การเข้าถึง Voice Library และเสียงที่มีอัตราพิเศษขึ้นกับบัญชี สำหรับเสียงระบบ TTS อื่นที่เปิดใน SillyTavern ให้เลือกว่าจะให้ระบบใดอ่านบทนี้ เพื่อไม่ให้เสียงสองระบบเล่นซ้ำกัน รุ่นนี้ไม่เปลี่ยนการตั้งค่า TTS ของผู้ใช้เอง
