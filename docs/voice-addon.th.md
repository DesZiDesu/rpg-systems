# RoleForge Voice Addon — 0.55.0

Voice และ Memory ปิดโดยค่าเริ่มต้น ค่าเปิดใช้งานที่ผู้ใช้บันทึกไว้ยังคงอยู่ เปิด Voice ในตั้งค่าส่วนเสริม RoleForge แล้ว drawer **RoleForge Voice Addon** จะแสดงขึ้น ระบบใช้ ElevenLabs API key แยกจากการเจนข้อความของ SillyTavern

## เลือกเสียง

เชื่อม key เพื่ออ่าน My Voices และโควตา จากนั้นเลือก **เสียงเริ่มต้น · ชาย**, **เสียงเริ่มต้น · หญิง**, **เสียงผู้บรรยาย** และ **เสียงสำรอง · ไม่ทราบเพศ** เสียงเฉพาะ NPC ที่ตั้งในหัวข้อ **เสียงของตัวละคร** มาก่อนเสียงเริ่มต้น ระบบอ่านเพศจากข้อมูลตัวละครที่บันทึกไว้ ไม่เดาจากชื่อ ส่วนคำบรรยายใช้เสียงผู้บรรยายแยกต่างหาก

หากไม่ทราบเพศหรือยังไม่ได้เลือกเสียงตามเพศ ระบบใช้เสียงสำรองที่ผู้ใช้เลือกไว้ ถ้าเสียงที่เลือกไม่อยู่ใน My Voices ปุ่มฟังจะปิดใช้งาน ให้เลือกเสียงใหม่หรือรีเฟรชรายชื่อ เลือกเสียงผู้บรรยายเพื่อใช้ **ฟังทั้งหมด** และ **ฟังอัตโนมัติ** กับคำตอบที่มีคำบรรยาย

Voice Library ใช้ค้นหาแล้วเพิ่มเสียงเข้าบัญชีตามสิทธิ์ ElevenLabs เสียงที่ติดป้ายภาษาอื่นยังเลือกใช้กับบทพูดไทยได้เมื่อโมเดลรองรับ เลือก Eleven v4 หรือ Eleven v3 ได้ เสียงตัวอย่างของผู้ให้บริการเล่นจากไฟล์ที่มีอยู่ ส่วนปุ่มสร้างเสียงทดลองสร้างเสียงใหม่และใช้โควตา

## ปุ่มในเรื่อง

กรอบ Dialogue มี **ฟังบทพูด** และ **✎ บทพากย์** อยู่ภายในกรอบ ใช้สีหมึกเดิม กรอบ Narrative มี **ฟังคำบรรยาย** และ **✎ บทพากย์** ขนาดเล็กอยู่ในกรอบขนนก ชื่อตัวละครยังเปิดโปรไฟล์ได้ตามเดิม

ปุ่มฟังเปลี่ยนเป็น **ยกเลิก** ระหว่างสร้างเสียง **พักเสียง** ขณะเล่น และ **ฟังต่อ** เมื่อพัก พร้อมปุ่มหยุด **ฟังทั้งหมด** อ่าน Narrative และ Dialogue ตามลำดับในคำตอบ โดยเปลี่ยนเสียงตามผู้บรรยาย/ตัวละคร ไม่อ่านชื่อปุ่ม การ์ดระบบหรือข้อความผู้เล่น ปุ่มที่ยังใช้ไม่ได้มีสถานะ disabled และคำอธิบายเหตุผล

## กล่องบทพากย์

กด **✎ บทพากย์** เพื่อเปิดกล่องแก้บท มือถือใช้แผ่นเปิดจากด้านล่าง เดสก์ท็อปใช้กล่องกลางจอ ปิดได้ด้วย ×, Escape หรือกดนอกกล่อง ไม่เพิ่มหน้าต่างเหนือ chatbar

กล่องแสดงชื่อตัวละครหรือผู้บรรยาย เสียงที่ตั้งไว้ และ **ข้อความที่จะส่งให้ ElevenLabs** รวม delivery ที่แปลงเป็น `[tag]` แล้ว เปลี่ยนเสียงเฉพาะบทนี้ แก้คำพูด แทรกอารมณ์/เสียงตรงเคอร์เซอร์หรือพิมพ์ `[tag]` เองได้ การแสดงอารมณ์ขึ้นกับโมเดลเสียง

- **คืนต้นฉบับ**: คืนข้อความและการเลือกเสียงในกล่อง กดบันทึกเพื่อเอาบทพากย์ที่เคยบันทึกออก
- **บันทึกบทพากย์**: เก็บเฉพาะบทเสียงในเบราว์เซอร์นี้ แยกจากข้อความ AI, chat metadata และไฟล์ส่งออก ไม่เรียก API
- **สร้างและฟัง**: ใช้ข้อความและเสียงที่อยู่ในกล่องทันที หากต้องการใช้การแก้ไขครั้งต่อไปให้กดบันทึกด้วย
- **หยุดเสียง**: หยุดเสียงและคำขอที่ยังค้าง

บทที่บันทึกผูกกับการ์ด แชต ลำดับข้อความ Swipe และบล็อกเรื่อง รวมข้อความ/Delivery ต้นฉบับแบบตรงกัน หาก AI ตอบใหม่ แก้ข้อความหรือเปลี่ยน Swipe จะใช้ต้นฉบับใหม่ กล่องเก่าปิดและคิวเสียงหยุด บทเก่าไม่ไหลเข้าคำตอบใหม่ กลับมายัง Swipe เดิมที่ข้อความเดิมยังอยู่สามารถใช้บทของ Swipe นั้นอีกครั้ง

## API และแคช

เปิดกล่อง แก้บท แทรก tag คืนต้นฉบับ และบันทึกไม่เรียก API การสร้างเสียงใหม่มีแจ้งเตือน API และใช้เครดิต ElevenLabs เมื่อโมเดล เสียง และข้อความตรงกับไฟล์ที่มีในแคชจะใช้เสียงเดิม ไม่สร้างใหม่ แคชเสียงอยู่ใน IndexedDB แยกจากแชต จำกัดรวม 80 ไฟล์หรือ 32 MB มีแคชในรอบเปิดหน้าเมื่อเก็บไฟล์ลงเครื่องไม่ได้ ข้อความยาวแบ่งเป็นช่วงไม่เกิน 1,800 ตัวอักษรต่อคำขอ ไม่ตัด Unicode หรือแท็กเสียงกลางตัว

AI ได้รับ instruction ให้ส่ง delivery และแท็กอารมณ์ในคำตอบโรลปกติ เช่น `<tr-dialogue name="Cora" delivery="whispers">ทางเดินมืด [sighs] ระวังด้วยนะคะ</tr-dialogue>` แท็กเสียงที่รองรับซ่อนจากเรื่อง แต่ส่งไปสร้างเสียง ชื่อสิ่งของเช่น `[Ruin Staff]` ยังคงแสดง ไม่เรียก AI เพิ่มเพื่อวิเคราะห์อารมณ์หรือเลือกเสียง

ฟังอัตโนมัติปิดโดยค่าเริ่มต้น หากเปิดจะใช้โควตาเมื่อสร้างเสียงคำตอบใหม่ เบราว์เซอร์บางตัวต้องกดฟังก่อน เปลี่ยนความเร็วได้ 0.75–1.5× โดยไม่สร้างเสียงใหม่ Swipe / Edit / Regenerate / เปลี่ยนแชต / ปิด Addon จะหยุดคิวและไม่เล่นผลเสียงที่กลับมาหลังยกเลิก

## key และโควตา

API key อยู่ในระบบเสียงเท่านั้น ไม่ใส่ใน prompt, การตั้งค่าเจนข้อความ, chat metadata หรือไฟล์ส่งออก เลือกจำ key ได้บน HTTPS/localhost ที่รองรับ Web Crypto และ IndexedDB โดยใช้ AES-GCM และ CryptoKey ที่ส่งออกไม่ได้ บน HTTP ที่ไม่มี Web Crypto ใช้ key เฉพาะรอบเปิดหน้า ต้องใส่ใหม่หลัง reload ลืม key ได้โดยยังเก็บการกำหนดเสียงและแคชไว้

ยอดโควตาและวันรีเซ็ตอ่านจาก `/v1/user/subscription` พร้อมเวลาอัปเดต รีเฟรชได้และอ่านหลังสร้างเสียง ไม่เดาจำนวนตัวอักษร v4 หรือยอด USD หากไม่มีสิทธิ์อ่าน Usage จะแสดงข้อผิดพลาดแยกและเก็บยอดเดิมพร้อมเวลา ยังสร้างเสียงได้เมื่อสิทธิ์ Voices/TTS พร้อม
