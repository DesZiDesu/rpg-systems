# Prototype assets

Phone casing, wallpaper, app illustrations and map are original CSS/SVG UI work.
The map is a schematic story location mockup, not a geographic navigation service.

Phone shell is inspired by modern iPhone proportions; no affiliation with Apple.

App icon Design 02: eight original self-contained SVG illustrations built by `tools/build-smartphone-icons.mjs`. No external icon set or icon font is required for home/dock app art. Compact navigation glyphs remain original SVG UI controls.
