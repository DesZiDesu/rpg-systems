# Smartphone — งานที่พักไว้

สถานะ: พักงานสมาร์ทโฟนเพื่อกลับไปทำ Pokémon ตามคำขอผู้ใช้ วันที่ 25 ตุลาคม 2026

หน้าตาไอคอนและ Dock ทำใน `preview/smartphone-addon` แล้ว ยังไม่เข้า main ระบบด้านล่างเป็นงานที่ต้องทำ ไม่ใช่ความสามารถที่ใช้งานได้แล้วในต้นแบบ

## ระบบโทรและเสียงในสาย

- [ ] เชื่อมการโทรกับเหตุการณ์ในโรล: กำลังเรียก / รับสาย / ไม่รับสาย / สายไม่ว่าง / จบสาย โดย AI ตัดสินจากสถานการณ์จริงในเรื่อง
- [ ] เก็บบทสนทนาแยกตามสาย ผู้โทร ผู้รับ และเวลา พร้อมบันทึกลงข้อมูลแชท
- [ ] เพิ่มตัวเลือก “อ่านเสียงในสายอัตโนมัติ” ในตั้งค่าสมาร์ทโฟน รองรับไทยและอังกฤษ
- [ ] เมื่อเปิดและเชื่อม Voice Addon ใช้เสียงที่กำหนดให้ NPC หรือเสียงสำรองเดิม
- [ ] อ่านเฉพาะบทพูด NPC หลังรับสาย ไม่อ่านความคิด คำบรรยาย หรือแต่งเสียงผู้เล่นแทนผู้เล่น
- [ ] ใช้รหัสเหตุการณ์และคิวเสียงของสาย เพื่อไม่ให้พากย์ซ้ำกับ autoplay ในแชทหลัก
- [ ] มีปุ่มฟังซ้ำ และรองรับการแตะเริ่มเสียงบน iOS หากเบราว์เซอร์บล็อก autoplay
- [ ] วางสายแล้วหยุดเสียงและยกเลิกคิวของสายนั้นทันที
- [ ] ย่อหรือปิดหน้าต่างโทรศัพท์ยังคงสายไว้ และเปิดกลับมาต่อได้
- [ ] เปลี่ยนแชทหรือปิด Addon แล้วหยุดเสียงและคิวของแชทเก่า
- [ ] เมื่อปิดหรือยังไม่เชื่อม Voice Addon ยังโทรคุยด้วยข้อความได้ตามปกติ
- [ ] แยกความหมายปุ่มลำโพงในโรลออกจากการเล่นเสียงจริงของเบราว์เซอร์
- [ ] ใช้ cache และการเชื่อมต่อ Voice เดิม สร้างเสียงเฉพาะบทพูดใหม่ที่ต้องฟัง
- [ ] ผูกเหตุการณ์สายกับ checkpoint เพื่อให้ Branch / swipe / ลบข้อความไม่ดึงสายหรือบทพูดจากอนาคต
- [ ] ทดสอบ PC และมือถือ: รับสาย/ไม่รับ วางสายระหว่างสร้างเสียง ปิดหน้าต่าง เปลี่ยนแชท รีโหลด และปิด/เปิด Voice Addon
