# ระบบเงินหลายหน่วย · RoleForge 0.68.2

ระบบเงินไม่จำกัดไว้ที่ 3 หน่วยแล้ว เพิ่มได้ตามที่โลกของคุณต้องใช้ แต่ต้องเหลืออย่างน้อย 1 หน่วย ตั้งชื่อ สัญลักษณ์ ชื่อเรียกอื่น มูลค่า สี รูปทรง และชุดไอคอนเคลื่อนไหวแยกกันได้ หน่วยเรียงจากมูลค่าสูงลงต่ำ เมื่อมูลค่าเท่ากันจะรักษาลำดับเดิม

## ตั้งค่าในแชท

1. เปิดแชทที่ต้องการ แล้วไป **ส่วนเสริม → RoleForge → โลกและกติกา → ค่าเงินและอัตราแลก**
2. เลือกชุดตั้งต้น หรือใช้ชุดปัจจุบัน กด **เพิ่มหน่วยเงิน** เพื่อเพิ่มทีละหน่วย
3. กดแถวหน่วยเพื่อแก้ชื่อ สัญลักษณ์ มูลค่าเทียบหน่วยเล็กสุด สี ชุดไอคอน และรูปทรง เช่น Platinum = 100,000 Copper
4. หน่วยเล็กสุดมีค่า 1 อัตราเป็นจำนวนเต็ม และต้องหารลงตัวกับหน่วยเล็กถัดไป รองรับหน่วยที่มีมูลค่าเท่ากัน เช่น Token A และ Token B แลกกัน 1:1
5. กด **บันทึกค่าเงินและไอคอน** เพื่อใช้กับแชทนี้ เงินผู้เล่น เงินส่วนกลางปาร์ตี้ และคลังกิลด์จะเก็บมูลค่าเดิมครบ การเพิ่ม/แก้/ลบในแบบร่างยังไม่เปลี่ยนกระเป๋าจนกดบันทึก
6. มี **ค้นหาหน่วยเงิน** และแบ่งหน้า **10 หน่วยต่อหน้า** การเปลี่ยนหน้าเก็บข้อมูลที่กำลังแก้ไว้
7. ปุ่ม **ลบหน่วยนี้** อยู่ภายในแถวที่เปิด หากลบหน่วยเล็กสุด ระบบปรับอัตราแบบร่างให้หน่วยเล็กสุดใหม่มีค่า 1 ตรวจอัตราแล้วจึงบันทึก หน่วยสุดท้ายลบไม่ได้

เมื่อมีการซื้อขาย การประมูล หรือมัดจำที่ยังต้องคืน ให้จบหรือยกเลิกรายการก่อนเปลี่ยนหน่วยและอัตราแลก การเปลี่ยนไอคอน/สีอย่างเดียวทำได้โดยไม่เปลี่ยนจำนวนเงินที่ถูกกันไว้

## Import / Export และการ์ดตัวละคร

- **Export preset ค่าเงิน** สร้างไฟล์ JSON ของชุดตั้งค่า ไม่รวมยอดเงินผู้เล่น
- **Import preset ค่าเงิน** โหลดเป็นแบบร่าง ตรวจแล้วกดบันทึกเพื่อใช้กับแชทนี้ เงินยังไม่เปลี่ยนทันทีที่เลือกไฟล์
- ชุดตั้งค่าเงินยังรวมอยู่ใน world/chat preset และ RoleForge character pack จึงพ่วงกับการ์ดตัวละครได้ตามวิธีเดิม หน่วยเพิ่มเติมไม่ถูกตัดเหลือ 3
- แต่ละแชทเก็บชุดค่าเงินของตนเอง ไม่เปลี่ยนหน่วยของแชทอื่น

จำนวนหน่วยไม่มีเพดานที่ระบบกำหนด อัตราและจำนวนเงินยังใช้ขอบเขตตัวเลขเดิมเพื่อคำนวณจำนวนเต็มได้แม่นยำ: อัตรา/ยอดรายหน่วยไม่เกิน 999,999,999 และยอดรวมต้องอยู่ในช่วงจำนวนเต็มปลอดภัยของ JavaScript ไฟล์ preset ยังมีขนาดสูงสุด 1 MB
