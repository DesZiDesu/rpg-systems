# Pokémon 1.6.4 / RoleForge 0.90.14 — Sprite ขยับทุกเมนูและเสียงเล่นร่วมกับวิดีโอ

ไปที่ **Pokémon → Settings / ตั้งค่า**

- Appearance / หน้าต่างและธีม → **Pokémon art style / รูปแบบภาพโปเกมอน → Sprite**
- Experience / เสียงและการเล่น → **Animations / แอนิเมชัน**: เปิดเพื่อให้ภาพขยับทุกหน้าที่ใช้ Sprite ปิดเพื่อใช้ไฟล์ภาพนิ่ง
- **Button volume / ความดังเสียงปุ่ม**: 0–100% ค่าเริ่มต้น 32% เท่าความดังเดิม 0% ไม่เริ่มเล่นเสียง ปรับแล้วบันทึกและลองเสียงหนึ่งครั้ง
- **Mix with other media / เล่นร่วมกับวิดีโอ**: เปิดเป็นค่าเริ่มต้นเพื่อพยายามเล่นเสียงปุ่มร่วมกับคลิป

การตั้งค่าทั้งหมดผูกกับตัวละคร ค่า Sprite และ Animations ที่ตั้งไว้ก่อนอัปเดตใช้ต่อได้ทันที ไม่ต้องลบแชทหรือรีเซ็ตความคืบหน้า การตั้งค่าความดังนี้ใช้กับเสียงปุ่ม Pokémon เท่านั้น

## ภาพเคลื่อนไหวทำงานตรงไหน

ตัวแสดงภาพร่วมของส่วนเสริมเลือกไฟล์ GIF/WebP ด้านหน้าเมื่อเปิดแอนิเมชัน ใช้กับหน้าเลือกคู่หู ทีม รายละเอียดตัวที่เป็นเจ้าของ Pokédex/ฟอร์ม กล่อง Journey, Center/Training, ภารกิจ Sandbox เมนูเปลี่ยนตัวในสนาม และแผงเหนือแชท หน้าสร้างตัวละครทั้งตอนเลือกคู่หูและทบทวนรับสวิตช์เดียวกัน โดยเปลี่ยนได้ขณะมีแบบร่างอยู่

ฟอร์ม Shiny/เพศเมียใช้ข้อมูลรายตัวตามดัชนีเดิม ภาพอ้างอิงมาตรฐานมีแอนิเมชันให้เลือก 1,570 จาก 1,579 ฟอร์ม อีก 9 ฟอร์มใช้ภาพนิ่งตรงฟอร์มพร้อมขยับขึ้นลงเบา ๆ หากไฟล์เคลื่อนไหวล้มเหลว จะลองแหล่งสำรองแล้วใช้ภาพนิ่งพร้อม idle ก่อน fallback เป็น Artwork ไม่มีการใช้ภาพคนละฟอร์มแทน

เมื่อปิด Animations จะเปลี่ยนเป็นไฟล์ PNG และเอา idle ออกจริง ไม่ได้เพียงซ่อนเอฟเฟกต์ ข้อกำหนด **Reduce Motion** ของระบบมีผลด้วย: แม้สวิตช์เปิดอยู่ หากเปิด Reduce Motion จะใช้ภาพนิ่งทั้งหน้าหลัก แผงคู่หู และ Character Creation ส่วน Artwork ยังคงเป็นภาพนิ่ง สนามยังรักษาภาพผู้เล่นหันหลังและคู่แข่งหันหน้าเหมือนเดิม

## เสียงกับวิดีโอ

ใช้ sample WAV เดิมที่เตรียมไว้ในหน่วยความจำ แล้วปรับ gain ตาม slider โดยไม่ดาวน์โหลดหรือถอดรหัสใหม่ทุกครั้ง

ในโหมดผสมจะใช้ Web Audio และขอ audio session แบบ `ambient` เมื่อเบราว์เซอร์รองรับ ไม่ใช้ HTML media playback สำรองที่อาจแย่งสิทธิ์เสียงจากคลิป เมื่อใช้ ambient จะคืน session เดิมหลัง sample จบและ context เงียบ พร้อมหลีกเลี่ยงการทับ session ของระบบโทร/ไมโครโฟน

**บน iOS ที่ไม่สามารถใช้โหมดผสมได้ จะงดเสียงปุ่มในโหมดนี้** เพื่อไม่เริ่มตัวเล่นที่อาจพักวิดีโอ หากต้องการใช้วิธีเล่นเสียงปกติสามารถปิด Mix with other media ได้ ซึ่งอาจกลับไปพักคลิปตามนโยบายของเครื่อง

การทดสอบวิดีโอใน Chromium ผ่านทั้งคอมและมือถือจำลอง: ขณะกดปุ่มและปรับความดัง วิดีโอยังเล่น เฟรมเดินต่อ และไม่มี pause event แต่ยังไม่ได้ยืนยันกับแอป YouTube, PiP หรือ Safari บน iPhone จริง จึงเป็นโหมดสำหรับให้ผู้ใช้ทดลองกับอุปกรณ์จริง ไม่รับประกันการเล่นร่วมกันได้ทุกเครื่อง

## ตรวจสอบ

- 406 unit/host tests และ syntax checks ผ่าน รวมการบันทึก volume/mix, การไม่ใช้ media fallback ในโหมดผสม, iOS ที่ไม่รองรับ, volume 0, การคืน ambient session และไม่ทับ session เสียงโทร/ไมโครโฟน
- ทดสอบใน SillyTavern 1.19.0 ทั้งสองธีม คอม/มือถือจำลอง ตรวจภาพขยับและภาพนิ่งในเมนู พร้อมเปรียบเทียบเฟรมที่แสดงจริงของ GIF
- ตรวจ Reduce Motion แบบสลับสด, idle ของฟอร์มที่ไม่มีแอนิเมชัน, แผงเหนือแชท และ Character Creation รวมจำลองไฟล์แอนิเมชันล้มเหลวเพื่อยืนยันภาพ Sprite นิ่งสำรอง
- ตรวจ Settings/slider ที่ความกว้าง 320/390/1280/1920px, gain และค่า 78%, ความดัง 0%, การเล่นร่วมกับวิดีโอทดสอบ, รีโหลดและแชทใหม่
- ตรวจเมนูเดิม 168 กรณี รวมฝึกท่า ภารกิจ Sandbox เมนูในสนาม และ Character Creation ทั้งสองธีม
- ชุด Artwork/Sprite แบบปิดแอนิเมชันผ่าน รวม Shiny เพศเมีย ภาพฟอร์ม และการจำค่าข้ามตัวละคร
- ติดตั้ง Pokémon 1.6.4 ผ่าน Workshop และเลือกคู่หูจากการ์ดไทย/อังกฤษ

ใช้การ์ด QA กับเหตุการณ์ควบคุม ไม่แก้แชทจริง ไม่มี live model, live voice หรือการทดสอบไมโครโฟนจริง ข้อมูลครอบคลุมแอนิเมชันอ้างอิงมาจากดัชนีที่มีอยู่ ไม่ใช่การดาวน์โหลดตรวจทุก URL ใหม่ทั้งหมด
