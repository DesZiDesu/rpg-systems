# Skill Storage 0.58.7

คลังทักษะใช้กรอบเหลี่ยม พื้นกริด และฟอนต์ของ RoleForge ชื่อกับคำอธิบายอ่านเต็มแถว ปุ่มฝึกและดูวิชาอยู่แถวล่าง แก้กริดเดิมที่ปุ่มฝึกขยายคอลัมน์แรกและบีบรายละเอียดจนแคบมากบนมือถือ

## การแบ่งหน้า

- หน้าจอกว้างไม่เกิน 900px: 1 สกิลต่อหน้า รวมถึงโทรศัพท์แนวนอนและจอแคบ
- หน้าจอกว้างกว่า 900px: 3 สกิลต่อหน้า
- ปุ่มก่อนหน้า/ถัดไปและจำนวนหน้าอยู่เหนือการ์ด เพื่อเปลี่ยนหน้าได้แม้รายละเอียดสกิลยาว
- กรองหมวดแล้วเริ่มหน้าแรก ลบรายการในหน้าสุดท้ายแล้วปรับหน้าที่เหลือให้อัตโนมัติ
- ปรับขนาดจอแล้วคงสกิลที่เริ่มอ่านไว้ในหน้าที่เกี่ยวข้อง เปลี่ยนแชทหรือเจ้าของตัวละครแล้วเริ่มหมวดทั้งหมด/หน้าแรก
- เปลี่ยนหน้าและกรองหมวดไม่ล้างข้อมูลที่กำลังพิมพ์ในฟอร์มเพิ่มสกิล

## หมวดอัตโนมัติ

หมวดมีเวทมนตร์ ต่อสู้ ฟื้นฟู/สนับสนุน ติดตัว งานช่าง/สร้างสรรค์ อรรถประโยชน์/สำรวจ และทั่วไป ระบบจัดหมวดในเครื่องจากข้อมูลเดิม ไม่เรียก AI เพิ่มและไม่เขียนทับประเภทหรือคุณสมบัติที่บันทึกไว้

ความสามารถที่ระบุ `ability.kind:passive` อยู่หมวดติดตัว จากนั้นใช้ประเภท/หมวดที่ระบุชัด ก่อนใช้ชนิดความสามารถและคำที่ปรากฏในชื่อ ผล และคำอธิบาย รองรับคำไทยและอังกฤษ เช่น Storage → อรรถประโยชน์, เวทมนตร์ → เวท, ปรุงยา → งานช่าง ข้อมูลที่ยังไม่บอกลักษณะจะอยู่หมวดทั่วไป การอนุมานจากข้อความอาจไม่ตรงเจตนาของชื่อเฉพาะทุกเรื่อง; ประเภทที่ AI ให้ชัดเจนช่วยให้จัดหมวดแม่นขึ้น

สกิล Character Life เข้าร่วมตัวกรองและการแบ่งหน้า คงการตัดชื่อซ้ำกับสกิล RoleForge และไม่มีปุ่มลบข้อมูลต้นทางจาก Character Life

## การตรวจสอบ

- Syntax checks ผ่าน และ unit/host tests ผ่าน 1,055 รายการ
- Browser ใช้ production loader ที่ 320/390/900/901/1280px: จำนวนการ์ดต่อหน้า ลำดับครบทุกสกิล ขอบเขตหน้า ตัวกรองหลายหมวด การปรับขนาดจอ และการลบหน้าสุดท้าย
- ปุ่มเพิ่ม/ลบ/ฝึก/ดูวิชาใช้ handler จริง ฟอร์มคงร่างขณะเปลี่ยนหน้า ข้อความ HTML แสดงเป็นข้อความ ป้ายความชำนาญและปุ่มแสดงได้หลังการเปิดหน้าต่าง
- ตรวจคลังว่าง สกิล Character Life การเปลี่ยนแชท ข้อความยาวและการขยายตัวอักษร ไม่มีข้อความล้นแนวนอน และการดู/จัดหมวดไม่เรียก AI
- รวมบน main 0.58.6 เพื่อเก็บการแก้ร้านค้าล่าสุด ก่อนเพิ่ม cache version 0.58.7

เปิดตัวอย่างผ่าน HTTP server ที่ [preview-skills.html](previews/preview-skills.html?lang=th&list=1) ซึ่งโหลดหน้าจอจริงโดยใช้ข้อมูลตัวอย่างและไม่มี AI connection

รันทดสอบด้วย `npm run test:skills` (ต้องมี Playwright และ Chromium) ใช้ `SKILL_ARTIFACT_DIR` เพื่อกำหนดโฟลเดอร์ภาพ และ `SKILL_VISUAL_FONTS=1` เมื่อต้องการภาพที่โหลดฟอนต์และไอคอนของ preview host
