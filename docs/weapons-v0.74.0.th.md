# อาวุธเหนือ Chatbar · RoleForge 0.74.0

เปิดที่ **Extensions → RoleForge → โลกและกติกา → อาวุธและกระสุน**
ระบบปิดไว้เป็นค่าเริ่มต้น และการเปิดใช้เป็นของแชท/การ์ด Preset นั้น
ไม่เปิดตามกันทุกบอท

1. ให้มีอาวุธใน Inventory ก่อน ผ่านโรลหรือการเพิ่มไอเทมตามปกติ
2. เปิดระบบ แล้วกด **จัดการอาวุธและกระสุน** หรือปุ่มตั้งค่าบนแถบอาวุธ
3. เลือกไอเทม ประเภทอาวุธ ภาพ และรูปแบบทรัพยากร
4. ใส่จำนวนที่บรรจุ/ความจุเมื่อทราบจริง เว้นว่างไว้หากยังไม่ทราบ
5. ถ้ามีกระสุนสำรอง ให้เลือกแท็บกระสุน ระบุไอเทมกระสุนในคลัง
   ชนิด/ขนาดต้องตรงกับอาวุธ หรือเชื่อมกับไอเทมกระสุนโดยตรง
6. ติ๊กสวมใส่แล้วบันทึก เปิดแท็บอาวุธเหนือช่องพิมพ์เพื่อใช้งาน

ภาพกลางมี 34 หมวด ตั้งแต่ดาบ ปืน ธนู คทา โล่ ไปจนถึง Relic
หากไม่มีภาพเฉพาะจะใช้ภาพกลางตามประเภท และอัปโหลดภาพแทนได้
ภาพเหล่านี้เป็นภาพ 2D ส่วน Excalibur/Ea มีเอฟเฟกต์ Canvas
ไฟล์ภาพไม่ได้เพิ่มอาวุธเข้าคลังหรือให้ความสามารถพิเศษแก่ผู้เล่น

## กระสุนและการต่อโรล

- ไอเทมปืนมีจำนวนบรรจุ เช่น 6/30 กระสุนสำรองเป็นอีกไอเทมใน Inventory
- Quantity ของแม็กคือจำนวนแม็ก; roundsPerUnit คือจำนวนลูกในแต่ละแม็ก
  แม็กที่มีจำนวนลูกต่างกันต้องแยกแถวในคลัง
- เปลี่ยนแม็กใช้หนึ่งแม็กที่มีจริง และเก็บแม็กเดิมพร้อมลูกที่เหลือกลับคลัง
  แม็กเปล่าก็เก็บไว้ แต่ไม่นับเป็นกระสุนพร้อมใช้
- กระสุนแยกลูก/ลูกธนูลดจากจำนวนไอเทมเมื่อบรรจุ ส่วนกระสุนที่ยิงลดจากอาวุธ
- จำนวนไม่ทราบแสดง `—` ไม่สมมุติว่าบรรจุเต็มหรือมีกระสุนสำรอง
- ปุ่มใช้/บรรจุ/ปลดปล่อยส่งการกระทำเข้าบทสนทนาปกติ รอผลสำเร็จในคำตอบ
  การกดปุ่มอย่างเดียวยังไม่หักจำนวน ผู้เล่นพิมพ์การกระทำเองก็ใช้กระบวนการเดียวกัน
- เปิดการติดตามคำตอบ AI เพื่อบันทึกผลจาก `weaponEvents` ใน patch เดิม
  ไม่มีการเรียก AI เพิ่มเพื่อตรวจอาวุธอีกหนึ่งรอบ
- คำตอบต้องมีหลักฐานตรงกับเหตุการณ์ของผู้เล่น การพูดของ NPC แผนการ
  เหตุการณ์สมมุติ และผลที่ไม่สำเร็จไม่หักทรัพยากรของผู้เล่น
- ค่า MP, เงื่อนไขโฮกุ และ cooldown ใช้กฎของโลกเดิม ระบบภาพไม่กำหนดต้นทุนใหม่

ชื่ออาวุธที่ผู้เล่นมีจริงตรงกับ alias ของ Excalibur หรือ Ea จะเลือกภาพนั้นให้
โดยอัตโนมัติ (ตัวอย่าง `Excalibur`, `Excalibur (Saber)`, `Ea (Gilgamesh)`)
การกล่าวถึงอาวุธในบทสนทนาอย่างเดียวไม่ทำให้แถบแสดงขึ้น
เอฟเฟกต์ขึ้นเมื่อผลในโรลยืนยันการเปิดใช้ และหยุดได้จากการพักพลังในโรล
Reduce Motion แสดงเฟรมคงที่แทนการหมุน/เคลื่อนไหว

## Preset และการ์ด

คลัง Preset มีตัวเลือก **อาวุธและภาพ** แยกให้ Import/Export ลบ และโหลดได้
Preset เก็บรูปแบบ/ภาพ ไม่แจกไอเทมหรือกระสุนให้แชทที่นำไปใช้
การแพ็กข้อมูลลงการ์ดจะพ่วง weaponPreset กับระบบที่เปิดไว้ หากเลือกเก็บ
ค่าเริ่มต้นด้วยจึงจะพ่วง Inventory/อาวุธที่สวมใส่/จำนวนเริ่มต้นไปด้วย
ไม่พ่วง receipts ของแชทหรือการเปิดเอฟเฟกต์ค้างไว้เป็นค่าเริ่มต้น

ไฟล์ทั่วไปยังใช้ World Preset เดิม ส่วนไฟล์เฉพาะระบบใช้ได้ดังนี้:

```json
{"format":"roleforge-weapon-preset","version":1,"name":"Arsenal","preset":{"version":1,"definitions":[]}}
```

รายละเอียดโครงสร้างภาพ ขนาดไฟล์ แหล่งภาพ และข้อจำกัดอยู่ที่
[assets/weapons/README.md](../assets/weapons/README.md)

## ขอบเขต

เป็นภาพแสดงอุปกรณ์และระบบนับตามผลที่ยืนยัน ไม่ใช่ระบบ ballistics หรือโมเดล 3D
หากมีปืนรุ่นเดียวกันหลายกระบอกที่บรรจุไม่เท่ากัน ให้แยก Inventory เป็นคนละ ID
ระบบไม่สามารถยืนยันผลจากผู้ให้บริการ AI ทุกรุ่นได้หากโมเดลไม่ส่ง patch
จึงมีหน้าจัดการสำหรับแก้ค่าที่ผู้เล่นทราบจริงได้โดยตรง
