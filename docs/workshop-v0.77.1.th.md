# Workshop — RoleForge 0.77.1

Workshop บนมือถือแสดงเต็มพื้นที่หน้าจอของเบราว์เซอร์แล้ว มีส่วนหัวและเมนูด้านล่างคงที่ เลื่อนเฉพาะเนื้อหา ใช้สีดำ ทอง และตัวอักษรสีงาช้างตาม RoleForge ส่วนคอมใช้หน้าต่างกว้างพร้อมเมนูด้านซ้าย

[ดูภาพทุกหน้า — มือถือและคอม](previews/workshop-v0.77.1/index.html)

- เปลี่ยนไอคอนเป็นชุด Font Awesome ที่ SillyTavern มีอยู่แล้ว “แชทนี้” ใช้ไอคอนบทสนทนา
- Great Sage ใช้ลูกกลมเคลื่อนไหวของตัวเองเป็นภาพประจำ Addon
- จัดหน้าสำรวจ ติดตั้งแล้ว แชทนี้ และสำรองข้อมูลใหม่ ลดข้อความซ้ำและแยกปุ่มให้ชัด
- ปุ่มกลับจากรายละเอียดจำหน้าที่เปิดมา และเมนูแสดงหน้าปัจจุบันต่อเนื่อง
- ปรับตามพื้นที่ visual viewport เมื่อพื้นที่แสดงผลเปลี่ยน รองรับ safe-area ผ่าน CSS และขนาดตัวอักษร 16px ในช่องพิมพ์ของมือถือ
- สวิตช์ใช้หัววงกลมของ Workshop โดยไม่รับรูปเครื่องหมายถูกจาก CSS checkbox ของ SillyTavern

อัปเดต RoleForge แล้ว Reload เพื่อใช้หน้าตาใหม่ หากติดตั้ง Great Sage อยู่แล้วไม่ต้องติดตั้งแพ็กซ้ำ การตั้งค่าและประวัติใช้ข้อมูลเดิม วิธีตั้งเสียงและใช้งานยังเป็น [คู่มือ Workshop / Great Sage](workshop-great-sage-v0.77.0.th.md)

ตรวจ syntax ผ่าน และ unit tests ผ่าน **1,414 / 1,414** รันบน SillyTavern **1.19.0** จริงด้วย Chromium และธีม **Dark Lite** ตรวจมือถือจำลองขนาด 320×568, 390×844, 430×932, แนวนอน 844×390 และพื้นที่สั้น 390×420 รวมถึงหน้าคอม 768×900, 1024×768 และ 1440×1000

ตรวจว่าหน้าต่างเต็มจอ เมนูไม่เลื่อนตามเนื้อหา ปุ่มท้ายรายการเข้าถึงได้ การเปิด/ปิด Addon บันทึกได้ ไอคอนโหลดจากฟอนต์จริง ลูกกลมเคลื่อนไหว และปุ่มกลับพากลับหน้าที่เปิดมา ชุดทดสอบการติดตั้ง อัปเดต hash ผิด พื้นที่ไม่พอ สำรองไปเบราว์เซอร์ว่าง และเปลี่ยนแชทยังผ่านด้วย การเรียก AI ในชุดทดสอบ lifecycle ใช้ fixture ควบคุม ส่วนชุดตรวจหน้าตาไม่เรียกโมเดล
