# แก้ข้อความแชตและข้อความคำสั่งที่หลุดมา — 0.45.4

## ปัญหาเปิด Edit แล้วไม่เห็นช่องแก้

SillyTavern ใช้ช่อง `#curEditTextarea.edit_textarea` แต่ตัวแสดงผลแชตของ RoleForge เดิมตรวจเฉพาะ `.mes_edit_textarea` ซึ่งไม่ตรงกับช่องจริง ทำให้ยังแทรกการ์ดขณะเปิด editor รุ่นนี้หยุดการแสดงการ์ดในข้อความที่กำลังแก้ และเก็บช่องแก้ข้อความเดิมไว้ ให้ SillyTavern จัดการการพิมพ์ บันทึก ยกเลิก และการบันทึกอัตโนมัติเอง

1. อัปเดตส่วนเสริมเป็น **0.45.4** แล้วรีโหลด SillyTavern หลังบันทึกข้อความที่กำลังพิมพ์
2. เปิดข้อความเดิม กดรูปดินสอ ควรเห็นช่องแก้ของ SillyTavern โดยไม่มีการ์ด RoleForge แทรกอยู่ในช่องนี้
3. พิมพ์ข้อความและกดบันทึก ข้อความที่แก้ต้องยังอยู่เมื่อเปิด Edit อีกครั้ง
4. ทดลองแก้แล้วกดยกเลิก ข้อความที่บันทึกก่อนหน้ายังอยู่ตามพฤติกรรมการตั้งค่า autosave ของ SillyTavern

ไม่ต้องล้างข้อมูลแชตหรือข้อมูลเบราว์เซอร์

## `SET clock.time`, `SET npc...` และ `sex_stage` ในภาพ

RoleForge ปัจจุบันใช้ JSON ภายใน `<!--tretaresia_patch:...-->` เวลาใช้ `worldClock.time` และการอัปเดต NPC ใช้ collection/operation ที่กำหนดไว้ บรรทัด `SET clock.time`, `SET rng.last`, `SET npc...`, `SET sex.stage` และ `sex_stage:` ไม่ใช่คำสั่งที่ RoleForge รองรับ จึงไม่ถูกนำไปปรับสถานะและไม่ถูกลบจากข้อความโดยเดา

รุ่นนี้ย้ำให้ AI เก็บคำสั่งของ RoleForge ใน patch เท่านั้น แต่การแก้จุดชนของ regex ไม่ได้แปลงหรือซ่อน protocol ของทุกการ์ด/preset หากบรรทัดเหล่านี้ยังแสดง ต้องดูชื่อการ์ด/preset และกฎ regex ที่ตั้งใจใช้ซ่อนข้อมูลของชุดนั้นก่อน จึงจะระบุได้ว่าคำสั่งต้นทางหรือตัวแสดงผลส่วนใดต้องแก้

ข้อความเก่าที่มีบรรทัดเหล่านี้ไม่ได้ถูกลบย้อนหลังอัตโนมัติ เพื่อคงข้อมูลของการ์ดหรือส่วนเสริมอื่นไว้
