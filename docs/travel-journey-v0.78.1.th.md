# RoleForge 0.78.1 — จบการเดินทางแล้วปิดแถบ Journey

แก้แถบ Journey ลอยเหนือแชตค้างที่ `Arrived · 100% · 0 วันคงเหลือ` สาเหตุเดิมคือเงื่อนไขการแสดงแถบนับ Arrived เป็นทริปที่ยังต้องแสดงด้วย

## พฤติกรรมใหม่

- แถบลอยแสดงเฉพาะ **Preparing / Traveling / Delayed** เมื่อถึงปลายทางหรือกลับเป็น Idle จะซ่อนทันทีและล้างข้อความแถบเก่า
- แชตเก่าที่บันทึก Arrived ไว้แล้วจะไม่แสดงแถบค้างเมื่อเปิดแชตหรือ reload ไม่ต้องเริ่มเรื่องใหม่หรือล้างข้อมูล
- เมื่อสถานที่ปัจจุบันของผู้เล่นเปลี่ยนมาตรงกับปลายทางที่บันทึกไว้ ระบบปิดทริปเป็น Arrived / 0 ได้ แม้ AI ลืมส่งคำสั่งแก้ travel.status แยก ใช้ชื่อสถานที่ตรงกันหลังปรับช่องว่าง/ตัวพิมพ์ ไม่ใช้การกล่าวถึงสถานที่หรือจุดใกล้เคียงเป็นหลักฐานว่าถึง
- คำถาม เช่น “Have we arrived?” / “มาถึงหรือยัง” การพูดถึงอนาคต เช่น “We will arrive tomorrow” และการบอกว่ายังไม่ถึง ไม่ปิดทริปจากตัวอ่านข้อความ User
- ทริปที่ยังไม่ตั้งระยะเวลาและเก็บค่าเริ่มต้นเป็น 0 ไม่ถูกตีความว่าเดินทางครบแล้ว แสดง **ยังไม่ทราบเวลาเดินทาง** และ `—` แทนเปอร์เซ็นต์ที่ไม่มีข้อมูลพอคำนวณ
- ข้อมูลปลายทางและทริปเดิมยังอยู่ในหน้า Journey/สถานะสำหรับย้อนดู การเดินเข้าฉากอื่นหลังถึงไม่ถูกดึงกลับปลายทางเก่า และเริ่มทริปใหม่ได้
- ปัดเปลี่ยนคำตอบแล้วใช้สถานะของคำตอบนั้น: คำตอบที่ยังเดินทางแสดงแถบ คำตอบที่ถึงแล้วซ่อนแถบ ปิด/เปิดการแสดงแถบไม่ลบข้อมูลการเดินทาง

ไม่มี API หรือโมเดลเพิ่มเพื่อปิดแถบ ใช้ข้อมูลแชตและฉากที่ระบบได้รับอยู่แล้ว
