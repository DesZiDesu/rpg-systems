# จำนวนตัวละครใน RoleForge 0.68.4

เปิด **NPC Management → ⋯ → จำนวนตัวละคร** แล้วเลือก:

- **ไม่จำกัดจำนวน**: ไม่มีเพดานจำนวนรายการที่ RoleForge กำหนด
- **กำหนดจำนวนสูงสุด**: ใส่จำนวนเต็มบวก เช่น 500 แล้วกด **บันทึกการตั้งค่าตัวละคร**

ค่าตั้งนี้บันทึกแยกตามแชต และใช้กับคลัง Character และ Chat โดยนับแต่ละคลังแยกกัน ตัวละครที่เปิดและปิดอยู่ถูกนับรวมในจำนวนที่เก็บ ตัวเลือกแหล่งข้อมูลด้านบนใช้เลือกคลังที่กำลังจัดการ

ถ้ามี 500 ตัวแล้วลดเพดานเหลือ 20 ข้อมูลทั้ง 500 ตัวยังอยู่ครบ สามารถอ่าน แก้ไข เปิด/ปิด และลบตัวเดิมได้ การเพิ่ม สร้างสำเนา หรือนำเข้าตัวใหม่จะต้องรอให้มีพื้นที่ หรือปรับเพดานขึ้นก่อน การนำเข้าจะเก็บสถานะเปิด/ปิดจากไฟล์ไว้

## ตัวละครที่ปิดไว้ยังใช้อ้างอิงได้

RoleForge ยังคงส่งดัชนีชื่อและชื่อเรียกอื่นของตัวละคร เพื่อให้ AI รู้ว่ามีใครอยู่ในคลัง และเลือกข้อมูลอ้างอิงไม่เกิน 16 โปรไฟล์ โดยให้ความสำคัญกับชื่อหรือชื่อเรียกอื่นที่ถูกพูดถึงล่าสุดในแชต

ตัวอย่าง: ถ้า Archive NPC 0499 ปิดอยู่และมีชื่อเรียกอื่นว่า Alias-0499 เมื่อพิมพ์ถึง Alias-0499 ระบบจะเลือกโปรไฟล์นี้มาเป็นข้อมูลอ้างอิง การเรียกข้อมูลไม่ได้เปลี่ยนสวิตช์ให้เปิด และ AI ไม่สามารถแก้ Stats ความสัมพันธ์ สมุดบันทึก หรือข้อมูลติดตามของตัวที่ปิดอยู่ได้ หากต้องการติดตามตัวละครนั้น ให้เปิดสวิตช์ในหน้าจัดการตัวละคร

เก็บ 500 ตัวแต่เปิด 20 ตัว ช่วยลดงานติดตามแบบละเอียดได้ แต่ข้อมูลที่เก็บ การบันทึก และดัชนีชื่อยังมีต้นทุนด้านหน่วยความจำและบริบท AI จึงไม่เท่ากับเก็บแค่ 20 ตัวทั้งหมด รายการหน้าจอยังคงแบ่งหน้าละ 20 ตัว

## Preset และการ์ดตัวละคร

ค่าจำนวนตัวละครอยู่ใน Preset ส่วน **จำนวนตัวละคร / Character capacity** และใน World Preset จึงนำเข้า/ส่งออกผ่านคลัง Preset ได้

ใช้ **ส่วนเสริม → RoleForge → Preset และการ์ดตัวละคร → แพ็กการ์ดตัวละคร** เพื่อบันทึกค่าตั้งและคลัง Character ลงในการ์ด แล้วส่งออกการ์ดผ่าน SillyTavern ตามปกติ การ์ดที่นำเข้าใหม่ใช้ค่าในแพ็กเป็นค่าเริ่มต้น; แชตที่มีค่าตั้งของตัวเองอยู่แล้วจะใช้ค่าของแชตนั้น คลัง Chat เก็บเฉพาะแชต ไม่รวมในคลัง Character ที่พ่วงมากับการ์ด

## การตรวจสอบ

ทดสอบกับ SillyTavern 1.19.0 จริงในโปรไฟล์ทดสอบแยก บน Chromium ที่ความกว้าง 390px และ 1440px รวมถึงตรวจการพอดีหน้าจอ 320px: นำเข้า 500 ตัว เปิดอยู่ 20 ตัว, ค้นหาและกรองตัวที่ปิด, บล็อกการสร้างเมื่อเต็ม, ลดเพดานแล้วข้อมูลไม่หาย, แก้ตัวเดิมที่เกินเพดาน, บันทึกแล้วโหลดใหม่, แยกค่าระหว่างแชต, ส่งออกการ์ดพร้อม 500 โปรไฟล์และค่าตั้ง และเรียกข้อมูลตัวที่ปิดผ่าน generation interceptor จริง

ชุดทดสอบใช้ข้อมูลจำลองและไม่เรียก API ของโมเดล ไม่ได้ทดสอบ Safari บน iPhone จริง ผลตอบของ AI ขึ้นกับโมเดลที่ใช้
