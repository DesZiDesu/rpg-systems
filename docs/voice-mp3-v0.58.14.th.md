# Voice Addon: บันทึกเสียงทดลองเป็น MP3 — 0.58.14

## วิธีใช้

เปิด Extensions → RoleForge Voice Addon → ทดลองพากย์บทพูด เชื่อม ElevenLabs และเลือกเสียงสำรอง (Fallback voice) ก่อน ใส่บทพูดแล้วกดสร้างเสียงทดลอง เมื่อได้เสียงสำเร็จจะมีส่วนเสียงทดลองล่าสุด ชื่อเสียง โมเดล ขนาดไฟล์ และข้อความที่สร้างจริง

ตั้งชื่อไฟล์ในช่องชื่อไฟล์ แล้วกด **บันทึก MP3** ชื่อเริ่มต้นใช้ชื่อเสียงและวันเวลา เพิ่มนามสกุล .mp3 ให้เอง รองรับชื่อไทยและตัดอักขระที่ใช้เป็นชื่อไฟล์ไม่ได้ รวมทั้งจำกัดความยาวตามจำนวนไบต์เพื่อไม่ให้ชื่อไทย/emoji ยาวเกินระบบไฟล์ ถ้าปล่อยชื่อว่างจะใช้ชื่อเริ่มต้น

การดาวน์โหลดใช้ไฟล์ต้นฉบับที่สร้างไว้ ไม่เรียก API ซ้ำและไม่ใช้โควตาเพิ่ม ไฟล์บันทึกที่ความเร็วต้นฉบับ 1× แม้ตั้งความเร็วการฟังไว้ต่างจากนี้ การสร้างเสียงทดลองใหม่ยังใช้โควตาตาม ElevenLabs ตามเดิม; การสร้างข้อความเดิม/เสียงเดิม/โมเดลเดิมใช้แคชได้

ปุ่ม **ล้างเสียงทดลองล่าสุด** เอาเสียงล่าสุดออกจากส่วนนี้และหยุดคำขอทดลองที่กำลังรอ ไม่ลบไฟล์ที่ดาวน์โหลดแล้วหรือแคชเสียงอื่น ใช้ปุ่มล้างแคชเสียงเดิมเมื่อต้องการลบแคชด้วย ไฟล์ที่ดาวน์โหลดจัดการได้ใน Downloads/Files ของอุปกรณ์ เก็บเสียงล่าสุดเพียงหนึ่งชุดในหน่วยความจำ ไม่สร้างคลัง MP3 เพิ่มใน metadata แชทหรือไฟล์ตั้งค่า

เมื่อปิดหน้า/รีโหลด ปิด addon หรือออกจากการเชื่อมต่อ จะไม่แสดงเสียงทดลองล่าสุดต่อ ไฟล์ที่ดาวน์โหลดแล้วคงอยู่ และแคชเดิมยังทำงานตามระบบเก่า การเปลี่ยนข้อความในช่องทดลองไม่เปลี่ยนไฟล์ล่าสุดที่สร้างแล้ว; กล่องเสียงล่าสุดแสดงข้อความที่ใช้สร้างจริงเพื่อแยกให้ชัด

## พฤติกรรมและการตรวจสอบ

- เสียงจากคำตอบแชท/ฟังทั้งหมด/ตัวอย่าง My Voices ไม่ทับไฟล์เสียงทดลองล่าสุด
- ทดลองได้ 1–2,000 ตัวอักษร และส่งเป็นคำขอ MP3 ไฟล์เดียว ไม่ต่อ MP3 หลายไฟล์หรือเปลี่ยนนามสกุล WAV เป็น MP3
- ตรวจลายเซ็น MP3 ของเสียงทดลองก่อนเปิดให้บันทึก; แคชทดลองที่เป็นรูปแบบอื่นจะถูกสร้างใหม่ และผลที่ผิดรูปแบบไม่ถูกบันทึกลงแคช
- เก็บไฟล์ทันทีเมื่อเสียงสร้างสำเร็จ ดังนั้นถ้าเบราว์เซอร์ไม่ยอมเล่นเสียง ยังบันทึกไฟล์ได้
- ยกเลิก/ล้าง/ออกจากการเชื่อมต่อระหว่างรอจะไม่เปิดให้บันทึกผลที่มาช้า
- การดาวน์โหลดทำใน click gesture จริงผ่าน Blob URL และปล่อย URL หลังเริ่มดาวน์โหลด ไม่ส่ง key หรือขอ fetch จาก URL ตัวอย่างภายนอก
- ช่องชื่อไฟล์และบททดลองใช้ 16px บนอุปกรณ์สัมผัสเพื่อหลีกเลี่ยงการซูมช่องกรอก

ผ่าน 1,100 unit/host tests และ syntax checks ชุด production-loader Voice browser ตรวจที่ 320/390/1280px ครอบคลุมระบบเสียงเดิม แคช/รีโหลด การเข้ารหัส key การยกเลิก editor/NPC/Library และดาวน์โหลด MP3 จริงด้วยชื่อไทย เปรียบเทียบทุกไบต์กับไฟล์เสียงต้นฉบับ และใช้ ffprobe ตรวจพบ codec mp3 ที่ 44.1 kHz ตรวจว่า download/clear ไม่สร้าง API request เพิ่ม และตรวจความกว้างกับขนาด font บนมือถือ

เสียงที่ใช้ทดสอบเป็นโทนสั้นเข้ารหัส MP3 ในเครื่อง ไม่ใช่เสียงคนหรือคำขอ ElevenLabs ที่เสียเงิน ทดสอบ browser ด้วย Chromium; ไม่ได้ทดสอบ Safari บน iPhone จริง พฤติกรรม Save/Downloads/Files ขึ้นกับเบราว์เซอร์ของอุปกรณ์
