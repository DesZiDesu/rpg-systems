# RoleForge 0.66.0 · จัดการ Character / Lore

เปิด NPC Management หรือ Lore Management จาก RoleForge หน้าหลักมีช่องค้นหา ตัวกรอง และรายชื่อ ส่วนเครื่องมือสร้าง นำเข้า สำรองภาพ และตั้งค่าต่าง ๆ อยู่ในปุ่ม **⋯** ข้างหัวหน้าต่าง

## เปิด / ปิดสะดวกขึ้น

- ใช้ **ทั้งหมด / เปิดอยู่ / ปิดอยู่** เพื่อค้นหารายการ พร้อมจำนวนที่ตรงกับคำค้น
- กดปุ่มเปิด–ปิดในแถวได้โดยตรง รายการปิดมีกรอบขีด สีจาง และป้าย **ปิดอยู่** โดยข้อมูลยังอยู่ครบ
- กด **เลือก** ที่แถบด้านล่าง แล้วเลือกรายการทีละแถว หรือใช้ **⋯** ด้านล่างเพื่อเลือกทั้งหน้า หรือผลค้นหาทุกหน้า
- กด **เปิดที่เลือก / ปิดที่เลือก** เพื่อบันทึกพร้อมกัน หากบันทึกไม่สำเร็จ สถานะเดิมและการเลือกยังอยู่ให้ลองใหม่
- กด **ย้อนกลับ** เพื่อคืนสถานะจากการเปลี่ยนล่าสุด ปุ่มอยู่ที่แถบด้านล่างหรือในเมนูการเลือกเมื่อกำลังเลือกหลายรายการ

แสดง 20 รายการต่อหน้า การเลือกคงอยู่เมื่อเปลี่ยนหน้า และล้างเมื่อเปลี่ยนคำค้น ตัวกรอง แหล่งข้อมูล หรือแชท เพื่อไม่ให้แก้รายการที่ซ่อนอยู่จากบริบทอื่น

## มือถือ

รายชื่อเลื่อนในพื้นที่เดียว ปุ่มเปลี่ยนหน้าและจัดการหลายรายการอยู่ด้านล่าง เครื่องมือรองเปิดเป็นแผงจากปุ่ม ⋯ จึงไม่ดันรายชื่อไปอยู่ครึ่งล่างของจอ กดชื่อเพื่อดูรายละเอียดเต็ม บนมือถือให้ลบ Lore จากหน้าแก้ไขเพื่อหลีกเลี่ยงการกดลบผิดในแถวรายการ

## การเก็บข้อมูล

NPC ยังคงมีคลัง **Chat / Character** เลือกจากเมนู ⋯ ส่วน Lore ใช้คลังของการ์ดร่วมกันทุกแชทตามระบบเดิม การเปลี่ยนสถานะแก้เฉพาะค่าเปิด–ปิด ไม่ลบประวัติ ภาพ เวอร์ชันตัวละคร คำค้น หรือการปักหมุด ไม่มีคำขอ AI เพิ่มจากการค้นหา เลือก หรือเปิด–ปิด

Lore ยังตรวจงบเดิมก่อนบันทึก หากเปิดหลายรายการแล้วเกินงบ ระบบเก็บสถานะเดิมทั้งหมด เปิด Lore หมายถึงอนุญาตให้ระบบส่งตามโหมดและงบที่ตั้งไว้ ไม่ใช่ส่งทุกรายการทุกครั้ง

Undo เก็บเฉพาะการเปลี่ยนสถานะล่าสุดระหว่างเปิดหน้าต่าง ไม่ใช่ประวัติถาวร ไม่สร้างรายการที่ลบไปแล้วกลับมา และจะข้ามรายการที่สถานะเปลี่ยนไปจากผลเดิม ข้อมูลอื่นที่แก้ภายหลังยังอยู่
