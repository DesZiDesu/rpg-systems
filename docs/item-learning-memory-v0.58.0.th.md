# ไอเทมสอนสกิล/วิชา และการลบ Memory รายแชต — RoleForge 0.58.0

ฐานก่อนอัปเดต: main `e70c348c95ade782da066d2010100f99e06e8b6d` วันที่ 5 ตุลาคม 2026

## สาเหตุและสิ่งที่เปลี่ยน

รายการประวัติใน Memory เป็นคลัง IndexedDB ในเบราว์เซอร์ แยกจากแชตต้นฉบับของ SillyTavern การลบห้องใน SillyTavern จึงไม่ลบคลังนี้ และปุ่มเดิมมีเพียงนำมาใช้/ไม่นำมาใช้ ไม่มีปุ่มลบประวัติ

เพิ่มปุ่ม **ลบประวัติ** พร้อมหน้าตรวจจำนวนต้นฉบับ/รุ่นข้อความ บทสรุป และความจำย้ายแชต ก่อนยืนยันลบ ลบสรุปที่สืบทอดหรือแก้ไขข้อมูลของแชตนั้น รวมความจำย้ายแชตและงานค้างที่เกี่ยวข้อง ต้นฉบับของแชตอื่นยังอยู่และสรุปใหม่ได้ การลบไม่เรียก AI และไม่ลบห้องต้นฉบับใน SillyTavern ต้องเปลี่ยนไปอีกห้องก่อนลบคลังของห้องปัจจุบัน

เก็บรหัสการลบไว้เพื่อกันการเก็บต้นฉบับกลับอัตโนมัติ การนำเข้า backup เก่า หรือการบันทึกข้อมูลเก่าจากอีกแท็บ หากเปิดห้องเดิมอีกครั้ง จะมีปุ่ม **เริ่มเก็บแชตนี้ใหม่** ให้เก็บจากแชตต้นฉบับปัจจุบันอย่างชัดเจน สรุปใหม่ใช้รหัสที่ไม่ชนกับสรุปที่เคยลบ ข้อมูลการลบไม่มีข้อความต้นฉบับ

ก่อนเขียนการลบ ตรวจคลังล่าสุดและใช้การเปรียบเทียบใน transaction ของ IndexedDB เพื่อไม่ทับงานที่เปลี่ยนไปแล้ว ระหว่างลบจะกันงานซ้อนและทิ้งการสร้าง prompt ที่ค้างอยู่ หากเขียนคลังหรือบันทึกข้อมูลเชื่อมแชตล้มเหลวจะคืนข้อมูลเดิม การคืนข้อมูลก็ต้องตรงกับรุ่นที่เพิ่งเขียน หากคืนไม่ได้จะรายงานให้โหลดคลังใหม่ ไม่แจ้งว่าลบสำเร็จ

ไอเทมเดิมรองรับผลต่อสเตตัส แต่ไม่มีนิยามการสอนวิชาที่เชื่อมกับชุดสกิลจริง การตั้ง `powerType` อย่างเดียวไม่สร้างสกิลให้เลือกฝึกหรือดูบทสวดได้ เพิ่ม `usage.learns` เป็นคุณสมบัติของไอเทมร่วมกับ `usage.stats` โดย **AI ออกแบบให้** ผ่านคำตอบแชตหลัก Loot ร้านค้า ประมูล และปุ่มเติมรายละเอียดไอเทม ผู้ใช้ไม่จำเป็นต้องเขียน effect หรือโครงสร้างวิชาเอง

หนึ่งไอเทมสอนสกิล/พลังใน `skills` หรือวิชาใน `proficiencies.techniques` ได้รวมสูงสุด 8 รายการ พร้อมเพิ่มหลายสเตตัสในครั้งเดียว ระบุชื่อ คำอธิบาย ความชำนาญเริ่มต้น ผล ระยะ เป้าหมาย ค่าใช้จ่าย เงื่อนไข คูลดาวน์ จุดแข็ง/ข้อจำกัด และบทสวดตามประเภทวิชา ใช้สำเร็จจึงเพิ่มเข้าชุดสกิลจริงและมองเห็นใน Training/Incantation การพบ เก็บ ซื้อ หรือชนะประมูลยังไม่สอนวิชา

กฎเมื่อรู้วิชาแล้วต้องแสดงก่อนใช้:

- `reject`: ปิดการใช้ ไม่เสียไอเทม
- `mastery`: เพิ่มความชำนาญตามค่าต่อชิ้น ไม่เกิน 100% และไม่กินของถ้าเพิ่มไม่ได้
- `upgrade`: อัปเกรดข้อมูล/ความชำนาญโดยไม่ลดความชำนาญเดิมหรือรีเซ็ตคูลดาวน์ที่กำลังทำงาน

ใช้หลายชิ้นจะคำนวณกฎซ้ำตามจำนวนจริง ถ้าวิชาใดใช้ไม่ได้ จะไม่ลดของหรือให้ผลบางส่วน ข้อมูลวิชาที่ผิดหรือหายจากตำราที่ใช้งานได้ถูกปิดการใช้และส่งเติมรายละเอียดได้ สูตรเดียวกันใช้ทั้งปุ่มเหนือ chatbar และ itemEvents ในคำตอบหลัก กรอง ops ที่ซ้ำกับวิชาที่ระบบไอเทมให้แล้ว ป้องกันรับซ้ำเมื่อประมวลผลข้อความเดิม และคืนไอเทม/สกิล/ข้อความเมื่อบันทึกการใช้ล้มเหลว

สูตรสอนวิชาแสดงในแผงไอเทม รายการ Loot คลัง และหน้าซื้อ/ประมูล ข้อมูลเต็มยังอยู่หลังการส่งมอบและโหลดใหม่ รายการที่มีสูตรต่างกันไม่ถูกรวมเป็นกองเดียวกัน ไม่สร้างหรือแก้ชุด custom power preset ของผู้ใช้เอง

## การตรวจสอบ

- `npm test`: 968 กรณีผ่าน รวมโฮสต์จริงและกรณีเรียนหลายวิชา ใช้ซ้ำ/หลายชิ้น เต็มความจุ ข้อมูลผิด การซ่อมข้อมูล AI การรับผ่าน Loot/ร้านค้า/ประมูลโดยยังไม่เรียน การกรอง ops ซ้ำ และการรักษาคูลดาวน์
- Memory: ตรวจต้นฉบับ/รุ่นข้อความ ความสัมพันธ์ parent/correction ของสรุป แชตอื่นไม่สูญเสียต้นฉบับ การยืนยันที่หมดอายุ งานซ้อน การเปลี่ยนตัวละคร การบันทึก/metadata ล้มเหลว การคืนข้อมูลล้มเหลว backup เก่า และการเริ่มเก็บห้องเดิมแล้วสรุปได้ใหม่
- `npm run check` และ `git diff --check` ผ่าน
- Browser ผ่าน production loader ที่ 320/390/1280px: Items/Loot พร้อมใช้ตำราผ่านปุ่มและแชตหลัก, Memory summaries พร้อมลบ/โหลดใหม่/กัน stale write ใน IndexedDB จริง, native Memory lifecycle, shop stock/selection, purchase rights, Incantation และ optional systems
- ทดสอบ Memory metadata rollback เพิ่มด้วย IndexedDB จริงที่ 390px ยืนยันว่าคลังและลิงก์เดิมกลับครบก่อนลองลบใหม่
- ปัญหาชุดรวม `test:chat` เก่าเรื่อง `/NORMAL CHAT COMMERCE/` ที่เคยทำซ้ำบน baseline ได้ ยังเป็นข้อจำกัดของผลทดสอบตาม [รายงาน 0.57.0](items-loot-v0.57.0.th.md) ไม่อ้างว่าชุดรวมนั้นผ่าน

คำตอบ AI ใน browser tests เป็น fixture ที่กำหนดไว้ จึงยืนยันเส้นทางทำงานและการป้องกันข้อมูลผิด ไม่ได้รับรองคำตอบของทุกโมเดลจริง ไม่เพิ่มงาน AI อัตโนมัติใหม่สำหรับการลบ Memory หรือการให้วิชาตามสูตรที่มีอยู่ และไม่เพิ่มตัวติดตาม DOM หรือ timer ถาวรสำหรับฟีเจอร์นี้

อัปเดตส่วนเสริมจาก main แล้ว reload SillyTavern ให้ manifest และ JavaScript/CSS ใช้ 0.58.0 พร้อมกัน อ่านข้อมูลไอเทม/คลัง Memory เดิมได้โดยไม่ต้องล้างข้อมูล
