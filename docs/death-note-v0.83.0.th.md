# Death Note · RoleForge 0.83.0 / Addon 0.4.0

ตั้งค่าได้ที่ **Workshop → แชทนี้ → Death Note → ตั้งค่า** หรือหน้ารายละเอียด Addon ส่วนข้อมูลโลกบันทึกในแชท ณ ข้อความและ Swipe ที่เลือก ไม่เขียนทับแฟ้มตัวละครต้นฉบับ

## ดวงตาของผู้เล่นและ NPC

- แยกรายตัวเป็น ไม่มี / ข้อตกลง / มีตั้งแต่เกิด / ได้รับพลังโดยไม่แลก / กำหนดจากโรล ผู้เล่นใช้แบบไม่แลกได้เช่นเดียวกับ NPC ไม่ต้องมีสมุด ไม่หักอายุขัย และพลังประเภทนี้ไม่หายเพียงเพราะสละสมุด
- ข้อตกลงจริงใช้หน้าสิทธิ์ในสมุด ต้องมีสิทธิ์ สัมผัสสมุด และมียมทูตประจำเล่ม หักครึ่งอายุขัยที่เหลือทุกครั้ง ไม่คืนส่วนที่จ่ายไปเมื่อสละสิทธิ์หรือแก้แหล่งพลังในตั้งค่า
- Beyond Birthday ยังคงมีเผ่าพันธุ์ Human พร้อมดวงตา innate ตามข้อมูลการ์ด ไม่ถูกนับเป็นยมทูต ไม่ได้รับสมุด และไม่แจกความรู้ของตนให้ผู้เล่น การ์ดเก่าที่ระบุ Congenital Shinigami Eyes อ่านย้อนหลังได้
- ความรู้ใบหน้าของ NPC แต่ละตัวแยกจากของผู้เล่น ดวงตาไม่อ่านใจ ไม่รู้หน้าใครที่ยังไม่เห็น และไม่เปลี่ยนชื่อที่ผู้เล่นเคยได้ยินให้เป็นชื่อจริงโดยเงียบ ๆ
- เห็น `??? (ชื่อจริง)` หรือ `ชื่อที่อ้าง (ชื่อจริง)` ด้วยหมึกแดง อ่านอายุขัยของตนเองและมนุษย์เจ้าของสิทธิ์สมุดไม่ได้ ผู้ยืมสมุดไม่ถูกนับเป็นเจ้าของสิทธิ์ อายุขัยว่างอาจแปลว่าข้อมูลยังไม่มี จึงไม่ติดป้ายเปิดโปงเจ้าของลับ

## สมุดหลายเล่มและยมทูต

`race: Shinigami` / `race: ยมทูต` ใช้ระบุชนิดตัวละคร แต่ละสมุดมีรหัสคงที่ พร้อมข้อมูลแยกกันดังนี้:

| ข้อมูล | ความหมาย |
| --- | --- |
| `id` / `itemId` | สมุดเล่มเดิมและสิ่งของใน Inventory |
| `originalShinigamiId` | ยมทูตดั้งเดิมที่บันทึกไว้ |
| `currentShinigamiId` | ยมทูตเจ้าของปัจจุบัน |
| `attachedShinigamiId` | ยมทูตประจำเล่มในปัจจุบัน |
| `firstHumanOwnerId` | มนุษย์เจ้าของคนแรก |
| `ownerId` | ผู้มีสิทธิ์มนุษย์ปัจจุบัน |
| `holderId` | ผู้ถือสมุดทางกายภาพ |

การแลกของยมทูตเปลี่ยนการอ้างอิงสองเล่มพร้อมกัน รหัสสมุด หมึก กฎที่จารึก ผลการเขียน ผู้ถือ และสิทธิ์มนุษย์คงเดิม เลือกได้ว่าจะสลับยมทูตประจำเล่มด้วยหรือเปลี่ยนเพียงเจ้าของ ยมทูตดั้งเดิมไม่ถูกทับด้วยเหตุการณ์แลก; ช่องแก้การผูกในตั้งค่ามีไว้ให้ผู้สร้างโรลแก้ข้อมูลอ้างอิงโดยตรง

รองรับการพบสมุด การถือ/หยิบ การส่งให้ NPC อีกตัวหรือผู้เล่น การโอนสิทธิ์ การทิ้ง การสละสิทธิ์ และข้อตกลงของ NPC จากเหตุการณ์ที่ยืนยันแล้ว ผู้ถือและเจ้าของสิทธิ์ไม่ถูกรวมเป็นคนเดียว ประวัติข้อตกลง NPC เก็บเวลาเหตุการณ์ไว้เพื่อให้อายุขัยไม่เลื่อนเมื่อเวลาในเรื่องเดินต่อ

ช่องข้อมูลใน NPC Management แสดงการถือ/สิทธิ์ที่ผู้เล่นทราบ และบทบาทยมทูตของสมุดที่สัมผัสแล้ว ไม่เปิดโปงผู้มีสมุดที่ยังเป็นความลับ หน้าสิทธิ์เลือกเล่มได้ และสมุดแต่ละเล่มมีหน้ากระดาษของตนเอง การจดแบบทันทีและแบบรอคำตอบถัดไปบันทึกรหัสเล่มไว้ รายการเก่าที่ไม่เคยเก็บรหัสจะระบุว่าเป็นบันทึกเก่าโดยไม่เดาเล่มย้อนหลัง

## การแสดงผลและอายุขัย

Header และ Dialogue ใช้ได้กับ RoleForge Original, The Mage’s Folio, The Gilded Chapter, The Royal Codex และ Aincrad Interface รวมกรณีปิด Header แต่เปิด Dialogue และเปิด/ปิด Voice Addon หมึกแดงไม่ถูก gradient ของธีมกลบ และไม่ลบพื้นหลังป้ายชื่อเมื่อชื่อที่รู้ตรงกับชื่อจริง

ตั้งค่าแยกการแสดงดวงตาใน Header / Dialogue / NPC Management สีหมึก และอายุขัยได้ การซ่อนข้อมูลเป็นการเปลี่ยนหน้าตา ไม่ลบพลังในเรื่อง

ค่าเริ่มต้นใช้อายุขัยที่ผู้สร้างระบุไว้เท่านั้น หากเลือกสร้างค่าจำลองเกม ระบบจะจดจำค่าที่สร้างในประวัติแชท ไม่สุ่มใหม่จากการเปิดหน้าต่าง โหลดแชท หรือปิด–เปิด Addon มีคำอธิบายว่าเป็นค่าจำลอง ไม่ใช่วันตายจากต้นฉบับ การกลับไปใช้ข้อมูลที่ระบุไว้จะซ่อนค่าจำลอง แต่เก็บค่าเดิมไว้ ค่าจริงที่ระบุโดยการ์ดมีลำดับก่อนค่าจำลอง

## ปิด Addon และกลับมาเปิด

ปิดแล้วซ่อนหน้าสมุด ปุ่มเปิด ป้ายดวงตา และส่วนข้อมูลเฉพาะ Addon ใน Lore / NPC Management พร้อมหยุดส่งคำสั่งโลกและรายการรอของ Addon ให้ AI และล้างส่วนแสดงผลเก่าที่ค้างไว้ ข้อมูลจริงยังอยู่ในแชท เปิดใหม่ใช้ต่อได้

แฟ้ม NPC และ Lore หลักของการ์ดยังอยู่ การปิดบังชื่อแบบ `???` / ชื่อที่อ้างจะหยุด จึงกลับไปเห็นข้อมูลชื่อปกติของ RoleForge การปิดไม่ถือเป็นการสละสิทธิ์ ไม่คืนอายุขัย ไม่ชุบชีวิต และไม่ลบข้อความโรลหรือความตายที่เกิดแล้ว AI ยังอาจอ้างอิงเนื้อหาโลกจากการ์ด/Lore/แชทเดิมได้

## วิธีเขียนและการ์ด

มีหน้าวิธีใช้ในสมุด และคำแนะนำไทย/อังกฤษใน Workshop รองรับชื่อกับสาเหตุคนละบรรทัดหรือบรรทัดเดียวกัน เช่น `คุโร่ โอโตฮาราดะ หัวใจวาย` ใช้ `ชื่อ — สาเหตุ` เมื่อแยกยาก เว้นสาเหตุไว้ใช้หัวใจวาย ชื่อปลอมหรือยังไม่เห็นหน้าไม่ทำให้เกิดผล

กด “ต่อเรื่อง” เพื่อให้ AI ต่อคำตอบเดิม หรือปล่อยหมึกไว้แล้วส่งโรลปกติครั้งถัดไป Addon ไม่สร้างข้อความ User สามารถปิดสมุดและอ่านโรลรอระหว่างเจนได้ ล้างกระดาษไม่ลบผลที่เกิดในเรื่อง

การ์ดทั้งฉบับมีภาพและไม่มีภาพอัปเดต metadata / คำสั่งแล้ว ยังมี 208 ตัวละคร / 652 เวอร์ชัน / 65 Lore / 146 ภารกิจ / 13 เส้นทาง ฉบับไม่มีภาพยังมี 10 ข้อความเปิดเดิม ฉากสมุดตกต่อหน้าผู้เล่นแสดงตัวเลือกพบสมุด ส่วนฉากไลท์หยิบสมุดบันทึกให้ไลท์ตามข้อความเปิดที่เลือกเท่านั้น ไม่ดึงข้อมูลจากฉากเริ่มอื่น
