# แก้ไอคอนโอนเงินและการติดตามความสัมพันธ์ — RoleForge 0.79.1

รุ่นนี้แก้หน้าสำเร็จของการโอนเงินที่ไอคอนยืดผิดรูป และแก้กรณีหลักฐานความสัมพันธ์ที่ถูกปฏิเสธเกินจำเป็น พร้อมแก้ H-Stats ของผู้เล่นที่อัปเดตไม่ถึงข้อมูลที่บันทึกจริง

## สิ่งที่แก้

- **ไอคอนโอนเงิน:** แยกกรอบวงกลมออกจากตัวอักษร Font Awesome เพื่อให้ CSS ไอคอนส่วนกลางไม่บีบกรอบ ก่อนแก้ทำให้เกิดซ้ำใน SillyTavern/Dark Lite ได้ที่ประมาณ **14.94 × 38px** หลังแก้กรอบเป็น **38 × 38px** และเครื่องหมายถูกอยู่กลางกรอบ
- **หลักฐานความสัมพันธ์:** ตรวจประโยคและผู้พูดจาก parser เดียวกับบทสนทนา คำว่า “ยังไม่ได้” หรือ “will” ในอีกประโยคไม่ลบล้างเหตุการณ์ที่เกิดขึ้นจริง รองรับชื่อผู้เล่น นามแฝง NPC และสรรพนามบุรุษที่หนึ่งของผู้พูดที่ระบุได้ชัดเจน คำขอ แผน ข่าวลือ เหตุการณ์ปฏิเสธ และคู่ตัวละครที่กำกวมยังไม่เพิ่มค่า
- **คำเตือน:** ข้อเสนอที่ไม่มีการเปลี่ยนค่า เช่น `trust: 0` ไม่สร้างคำเตือนผิดบริบท หากเสนอการเปลี่ยนค่าที่ตรวจไม่ผ่าน จะแจ้งเหตุผล เช่น ยังเป็นคำขอ หรือระบุคู่ไม่ชัดเจน เก็บรหัสเหตุผลขนาดเล็กกับข้อมูลตรวจสอบของเทิร์นนั้น ไม่เพิ่มการเรียก AI
- **H-Stats ผู้เล่น:** เขียนค่าลงสถานะผู้เล่นจริง จึงบันทึกทั้งผู้เล่นและ NPC ที่เกี่ยวข้องได้ครบ แก้การกรองคำสั่งซ้ำให้คงข้อมูลร่างกาย/ความชอบอื่นที่เป็นอิสระจากเหตุการณ์ไว้ด้วย
- **การนับและข้อมูลเดิม:** เหตุการณ์ NPC–NPC ไม่เพิ่มสถิติให้ผู้เล่น การประมวลผลข้อความเดิมซ้ำไม่นับซ้ำ ยังใช้กรอบพัฒนาการช้า การยืนยันข้อตกลง และการรักษาค่าที่ผู้ใช้แก้เองของ 0.79.0

## ผลตรวจสอบ

[เปรียบเทียบไอคอนก่อนแก้](previews/fixes-v0.79.1/before-transfer.png)

ดูรายละเอียดและไฟล์ผลลัพธ์ใน [validation-summary.json](previews/fixes-v0.79.1/validation-summary.json)

- **Unit / host integration:** `npm test` ผ่าน **1,513 tests** และ `npm run check` ผ่าน รวม regression ภาษาไทย การระบุคู่ การป้องกันเหตุการณ์สมมติ การนับซ้ำ การเก็บ H-Stats และคำสั่งอัปเดตที่ผิดรูปแบบ
- **เบราว์เซอร์จริง:** SillyTavern **1.19.0**, Chromium บนเดสก์ท็อปและการจำลองมือถือแบบ touch ตรวจการโอนเงินผ่าน Inventory/Status, Known Name, ความสัมพันธ์/H-Stats, save/reload, swipe, import/export และการแยกข้อมูลแต่ละการ์ด
- **ธีม/ขนาดจอ:** ไอคอนและแผงเหนือ chatbar ตรวจ Dark Lite, Azure, Dark V 1.0 ที่ 320/390/430/768/1440px รวมการป้องกัน gesture ไปกระตุ้น swipe และข้อมูลล้นกล่อง
- **ระบบอื่นใน SillyTavern จริง:** อาวุธ/กระสุนและ native Continue, Excalibur/Ea/Morgan, Travel Journey, Story editor ทุกหน้าและส่งออก World Pack, การกลับเข้าแชตเดิมโดยไม่ต้อง edit/cancel, ปุ่ม Workshop/Great Sage/Field Notes เมื่อเปิด–ปิด addon ผ่านการตรวจถดถอย
- **Fixture browser เพิ่มเติม:** H-Stats, Inventory/Loot และ Preset ผ่านที่ 320/390/1280px รัน production loader/runtime ใน host จำลอง แยกผลจาก SillyTavern จริง

การทดสอบการเจนใช้คำตอบควบคุมที่ป้อนผ่านเส้นทาง generation/streaming จริงของ SillyTavern เพื่อให้ตรวจผลซ้ำได้ ไม่ได้ส่งคำขอไปโมเดลภายนอก และยังไม่ได้ทดสอบบน iPhone/Safari เครื่องจริง กรณีคำเตือนใช้ข้อความภาษาไทยลักษณะเดียวกับภาพที่แจ้ง เพราะภาพไม่มี patch ของข้อความเดิม

## ไฟล์หลัก

`src/money-transfer-composer.js`, `styles/money-transfer.css`, `src/relationship-core.js`, `index.js` และชุดทดสอบ regression รุ่น/URL cache ของโมดูลและ CSS เปลี่ยนเป็น 0.79.1 พร้อมกัน

อัปเดตส่วนเสริมจากหน้า Extensions แล้ว reload SillyTavern หลังบันทึกข้อความร่างเรียบร้อย การติดตามยังต้องได้รับข้อมูลอัปเดตที่ถูกต้องจาก AI; เหตุการณ์ที่ยังระบุคู่หรือการกระทำไม่ได้จะคงค่าเดิมและแจ้งเหตุผล
