# RoleForge 0.76.0 — หน้าต่างเหนือ Chatbar

รวมการตั้งค่าหน้าต่างเหนือช่องพิมพ์ไว้ที่ **Extensions → RoleForge → หน้าต่างเหนือ Chatbar** ไม่ต้องเปิดคนละหมวดเพื่อหาสถานะ บทร่าย หรืออาวุธ การย้ายหน้าตั้งค่าใช้ค่าที่บันทึกไว้เดิม ไม่ต้องตั้งใหม่

[ดู Preview มือถือ / PC](previews/chatbar-windows-0760/index.html) · [รายงานการทดสอบ](validation-chatbar-v0.76.0.json)

## วิธีเปิดใช้

1. อัปเดต RoleForge แล้ว reload SillyTavern
2. เปิดแชทที่ต้องการ จากนั้นเข้า **Extensions → RoleForge → หน้าต่างเหนือ Chatbar**
3. เลือกเปิด/ปิด **สถานะ, กระเป๋า, ภารกิจ, H-Stats, ฝึกค่าสถานะ, วิชา/ทักษะ/บทร่าย และอาวุธ** แต่ละอย่างแยกกันได้
4. ขยายหัวข้อในหน้าเดียวกันเพื่อปรับรูปแบบสถานะ/หน้าฝึก ไอคอนเงิน ภาษาบทร่าย กติกา NPC หรือจัดการอาวุธและกระสุน
5. หัวข้อ **หน้าต่างตามสถานการณ์** มีสวิตช์ระบบซื้อขาย ประมูล และ Memory หน้าต่างเหล่านี้แสดงเมื่อมีเหตุการณ์หรือข้อมูลของระบบนั้น ส่วนรายละเอียดการสรุปความจำยังเปิดผ่าน RoleForge Memory Addons ได้ตามเดิม

กระเป๋า ภารกิจ และ H-Stats เริ่มต้นปิด ให้เลือกเปิดเอง สถานะและหน้าฝึกคงค่าเริ่มต้นเดิม อาวุธและบทร่ายยังใช้การเปิดตาม Preset ของแชท/การ์ด

| การตั้งค่า | ขอบเขต |
| --- | --- |
| แสดงสถานะ กระเป๋า ภารกิจ H-Stats หน้าฝึก / รูปแบบหน้าต่าง / ชุดไอคอนเงิน | ค่ารวมของผู้ใช้ ใช้ข้ามแชท |
| เปิดบทร่าย อาวุธ กติกา NPC ภาษาบทร่าย ซื้อขาย และประมูล | Preset แชท/การ์ดเดิม |
| เปิดระบบสรุปความจำ | ค่ารวมเดิมของ Memory Addons |

การปิดหน้าต่างเก็บข้อมูลที่เล่นไว้ หน้าดูไอเทมและ Loot แสดงตามไอเทมที่เลือกหรือของที่พบในโรล ไม่มีสวิตช์ซ่อนถาวรเพิ่มให้สองหน้าต่างนี้

## การใช้แถบหน้าต่าง

ปัดแถบแท็บแนวนอนเพื่อสลับหน้าต่าง หรือกด **ปุ่มสี่ช่องพร้อมจำนวนหน้าต่าง** เพื่อเลือกจากรายการทั้งหมด ปุ่มนี้และปุ่มย่อมีพื้นที่แยกจากแท็บ ซื้อ/ขาย/ประมูลจึงไม่ถูกปุ่มย่อทับ แม้เปิดหลายหน้าต่างพร้อมกัน

เมื่อมีหน้าซื้อขายใหม่ แถบแท็บเลื่อนไปให้เห็นแท็บนั้นโดยไม่สั่งเลื่อน main chat ปุ่มเลือกทั้งหมดใช้ได้แม้ย่อ dock อยู่ การใช้ลูกศรซ้าย/ขวา Home/End บนแท็บรองรับคีย์บอร์ด

หน้าภารกิจแสดงชื่อ เป้าหมายถัดไป ความคืบหน้า รางวัล และตัวเลือกเปลี่ยนภารกิจ รายละเอียดเป้าหมายทั้งหมดพับได้ เป้าหมายเสริมแยกป้ายและไม่นำไปนับเป็นเป้าหมายหลักในเปอร์เซ็นต์ การเปิดดูไม่รับ/จบภารกิจหรือจ่ายรางวัลเอง

กระเป๋าค้นหา แบ่งหมวด และเปลี่ยนหน้าได้ แตะไอเทมเพื่อเปิดรายละเอียดก่อนใช้ ส่วน H-Stats อ่านข้อมูลที่มีอยู่ ช่องที่ไม่มีข้อมูลแสดงว่ายังไม่ทราบ การเปิดดูทั้งสามแผงไม่เรียก AI

## ปุ่มอาวุธ

ใช้/บรรจุ/ปลดปล่อย/หยุดเอฟเฟค/Inspect ใช้ **Continue คำตอบ AI เดิม** ผ่าน Generate ของ SillyTavern ไม่เพิ่มข้อความ User ไม่ส่งข้อความที่พิมพ์ค้างไว้ และไม่รัน slash command ในช่องพิมพ์ ต้องมีคำตอบ AI ก่อนจึงจะใช้ได้

การติดตามทรัพยากรรอผลสำเร็จที่ AI ยืนยันในข้อความส่วนที่เจนเพิ่ม ใบอนุญาตของปุ่มผูกกับไอเทม การกระทำ และ swipe จึงไม่ใช้คำบรรยายเก่าหักทรัพยากรซ้ำ คำสั่งที่รออยู่ไม่ไปมีผลกับแชทใหม่เมื่อเปลี่ยนแชท

## การบันทึกค่าต่อเนื่อง

แก้การแข่งขันของการบันทึกค่าประเภท Preset เช่น กรอกภาษาบทร่ายแล้วเปลี่ยนสวิตช์ถัดไปทันที คำสั่งบันทึกจะเข้าคิวและรวมกับค่าล่าสุด ตรวจแชท/การ์ดก่อนบันทึกแต่ละรายการ หากบันทึกล้มเหลว ช่องนั้นย้อนกลับโดยไม่ทิ้งรายการถัดไป

## ผลทดสอบรุ่นนี้

**Unit / syntax**: `npm test` ผ่าน **1,403** รายการ, ไม่ fail หรือ skip; `npm run check` ผ่าน รวมกรณีคิวบันทึกสำเร็จ บันทึกล้มเหลว และเปลี่ยนแชทระหว่างรอ

**เบราว์เซอร์ host จำลอง**: settings navigation ที่ 320/390/768/1440 px, dock 11 แผงที่ 320/390/430/768/1440 px, extension drawer ที่ 320/390/1280 px (รวม pane 300 px บน PC), Optional Systems และ Memory Addons ที่ 320/390/1280 px และชุดป้องกันแชทเลื่อนผิดตำแหน่ง แยกจากผล SillyTavern จริงด้านล่าง

**SillyTavern จริง**: 1.19.0 revision `06bde93` เปิดผ่าน HTTP ใน Chromium ใช้ไฟล์ธีม Dark Lite และธีมที่มากับโปรแกรม Azure

- หน้าตั้งค่ารวม: มือถือ 320/390/430 px และ PC 1440 px ทั้งสองธีม; สวิตช์ 7 ตัวใช้งานจริง รูปแบบ/ภาษาบทร่าย/ค่าที่กรอกอยู่ครบหลัง reload, เปิดหน้าจัดการอาวุธได้, ลิงก์เก่าและค้นหายังพามาถูกหน้า
- ค่าผู้เล่น Inventory ภารกิจ และ NPC ไม่เปลี่ยนจากการเปิดดูหรือเปลี่ยนหน้าตั้งค่า
- กระเป๋า/ภารกิจ/H-Stats: มือถือและ PC รวม 12 กรณีขนาดแผง, reload และเปลี่ยน owner; ไม่มี API เพิ่มจากการเปิดดู
- ปุ่มอาวุธ: Continue 16 ครั้งรวมมือถือและ PC ตรวจข้อความ User ไม่เพิ่ม, draft และ slash command ไม่ถูกส่ง, การหักกระสุนครั้งเดียวและผลหลัง reload
- แถบแท็บ: 9 แผงพร้อมซื้อ/ขาย/ประมูลแยกกัน รวม 12 กรณีขนาดมือถือ/PC ตรวจพื้นที่กดทุกแท็บ ปุ่มเลือกทั้งหมด และเปิดจากสถานะย่อ
- ชุดอาวุธเดิมผ่าน 12 ข้อ รวม artwork, Morgan, Import/Export, ของที่เป็นเจ้าของจริง และค่าเริ่มต้นปิด

มือถือเป็นการจำลองขนาดและสัมผัสใน Chromium ไม่ใช่อุปกรณ์ iOS/Safari จริง การทดสอบ Generate ใช้ SSE fixture ภายในผ่านขั้นตอนเจนและสตรีมจริงของ SillyTavern ไม่มีคำขอไปโมเดลภายนอก จึงยืนยันโค้ดรับส่งและการประมวลผลผลลัพธ์ที่ควบคุมไว้ การตอบตามกติกาของโมเดลภายนอกยังขึ้นกับโมเดลที่ผู้ใช้เลือก

## คำสั่งสำหรับนักพัฒนา

```sh
npm test
npm run check
CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:chatbar
ST_REAL_URL=http://127.0.0.1:18180 npm run test:chatbar:real
ST_REAL_URL=http://127.0.0.1:18180 UTILITY_DEVICE=desktop node tests/utility-dock-preview.real.browser.mjs
```

ชุด `*.real.browser.mjs` ต้องมี SillyTavern ที่รันอยู่และติดตั้ง working tree นี้เป็น extension ใช้ profile ทดสอบแยกจากข้อมูลส่วนตัว สคริปต์นำเข้าการ์ดและบันทึกแชทสำหรับทดสอบเอง ภาพ Preview สร้างด้วย `tools/build-chatbar-release-preview.mjs` จากภาพที่จับในรอบนี้
