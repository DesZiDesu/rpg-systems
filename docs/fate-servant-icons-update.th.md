# อัปเดตไอคอน Servant โดยใช้การ์ดและแชทเดิม

RoleForge **0.72.0** เพิ่มการนำเข้าไฟล์อัปเดตไอคอนที่หน้า **Preset และการ์ดตัวละคร → แพ็กข้อมูลลงการ์ดตัวละคร** รองรับทั้งคลัง NPC ที่ฝังตรงในการ์ดและ World Pack บีบอัด ไม่ต้องติดตั้งปลั๊กอินเพิ่มหรือเรียก AI เพื่ออัปเดตภาพ

ใช้ไฟล์อัปเดตเดียวกับรหัสชุด Fate v3 รุ่น Core และ Native ได้ ถ้า Native มี reference แบบ optional แต่ยังไม่ได้ติดตั้งคลัง ระบบอัปเดต NPC ที่ฝังในการ์ดตามโหมดที่ใช้งานจริง ไม่บังคับให้ Import ZIP เพื่อใส่ไอคอน

## ไฟล์ที่ให้

- `Fate-Servant-Icons-Update.json` — ใช้กับ **การ์ด Fate เดิมที่เล่นอยู่** เปลี่ยนเฉพาะภาพไอคอนของ NPC ตาม ID เดิม
- `Fate-Nasuverse-Servant-Icons-Card.json` — การ์ดพร้อมใช้สำหรับผู้ที่ยังไม่ได้ติดตั้ง มีคลังบีบอัดและไอคอนครบในไฟล์เดียว
- `Icon-Coverage-Report.json` — รายการ NPC ที่ใส่ภาพ คลาส ภาพที่เลือก รายการที่ไม่เปลี่ยน และรายการ Unknown
- `ATTRIBUTION.md` — เครดิตชุดไอคอน gears และลิงก์ต้นทาง

## ถ้ามีการ์ดและแชท Fate อยู่แล้ว

1. ใน SillyTavern เปิด **ส่วนเสริม → จัดการส่วนเสริม** แล้ว Update **RoleForge** เป็น **0.72.0 หรือใหม่กว่า** จากนั้น Reload หน้าเว็บ ไม่ต้องล้างข้อมูลเว็บไซต์หรือ IndexedDB
2. เปิด **การ์ด Fate ใบเดิมและแชทเดิม** ที่ต้องการใช้ต่อ รอให้ข้อความที่กำลังเจนและการบันทึกจบก่อน
3. เปิด **ส่วนเสริม → RoleForge → Preset และการ์ดตัวละคร → แพ็กข้อมูลลงการ์ดตัวละคร** ถ้าใช้ภาษาอังกฤษคือ **Presets & character cards → Pack setup into a character card**
4. ในหัวข้อ **อัปเดตไอคอน NPC ของการ์ดเดิม / Update NPC icons in this card** กด **เลือกไฟล์อัปเดตไอคอน / Undo** แล้วเลือก `Fate-Servant-Icons-Update.json` ปุ่มนี้เป็นของ RoleForge ไม่ใช่ปุ่ม Import การ์ดของ SillyTavern
5. ตรวจรายการที่แสดง ครั้งละ 10 รายการ ตัวนับบอกว่าพร้อมอัปเดต ตรงกันแล้ว เก็บภาพเดิม ไม่พบ ID หรือข้ามเพราะภาพถูกเปลี่ยนภายหลัง การ์ดต้นฉบับที่ยังไม่ใส่ภาพจะมี **พร้อมอัปเดต 521**
6. ค่าเริ่มต้นจะ **ข้ามภาพ custom ที่คุณตั้งไว้** ถ้าต้องการแทนภาพเหล่านั้นด้วย ให้ติ๊กตัวเลือกแทนที่ แล้วเลือกไฟล์อีกครั้งเพื่อตรวจรายการใหม่
7. กด **ดาวน์โหลดไฟล์ย้อนกลับก่อนอัปเดต** เก็บ `RoleForge-NPC-Icons-Undo.json` ไว้ ไฟล์นี้ย้อนเฉพาะภาพที่รอบนี้จะเปลี่ยน ไม่ใช่การย้อนความคืบหน้าในแชท
8. กด **ใช้การอัปเดตไอคอน / Apply icon update** รอจนขึ้น **อัปเดต … ไอคอนแล้ว / Updated … icons** ระหว่างนี้มีความคืบหน้าการตรวจและบันทึกคลัง แพ็กใหญ่ใช้เวลาตามเครื่องและพื้นที่เก็บข้อมูล
9. กลับไปเล่นแชทเดิมได้ทันที ไอคอนแสดงในรายการ NPC และ Header ของ NPC เมื่อข้อความนั้นมี Header ของ RoleForge เปิดใช้อยู่ ร่างอื่นที่ยังไม่พบไม่ได้ถูกเปิดใช้หรือทำเครื่องหมายว่าพบแล้วเพราะการใส่ภาพ
10. หากต้องการเก็บหรือส่งต่อการ์ดล่าสุด กด **ส่งออกการ์ดที่อัปเดตแล้ว / Export updated card** แล้วกดลิงก์ **ดาวน์โหลดการ์ด** ที่ปรากฏ สำหรับ World Pack การอัปเดตภาพได้รวมการแก้ NPC/Lore ที่บันทึกไว้ลง payload ใหม่แล้ว

**ไม่ต้อง Import การ์ดฉบับใหม่ทับการ์ดเดิม** และไม่ต้องเริ่มแชทใหม่ ไฟล์อัปเดตไม่ได้เปลี่ยน HP, Stats, Ability, ความสัมพันธ์, ความทรงจำ, เงิน, enabled/met, เวอร์ชันที่เลือก หรือ checkpoint การสนทนา การเปลี่ยนภาพในคลัง Character มีผลกับแชทของการ์ดใบนั้น ส่วนภาพที่ตั้ง override เฉพาะ Chat ไว้ยังใช้ภาพของ Chat ตามเดิม

## ถ้ายังไม่เคยติดตั้งการ์ดนี้

1. อัปเดต RoleForge เป็น 0.72.0 หรือใหม่กว่า แล้ว Reload
2. ใช้ **Import Character** ตามปกติของ SillyTavern เลือก `Fate-Nasuverse-Servant-Icons-Card.json`
3. เปิดการ์ดและเปิดแชท รอให้ RoleForge เตรียมคลังอัตโนมัติ ไม่ต้อง Import ZIP หรือเชื่อมคลังเอง
4. Character Creation และ `first_mes` ว่างยังทำงานตามการ์ดเดิม ไม่ต้องนำเข้าไฟล์อัปเดตไอคอนซ้ำ เพราะการ์ดนี้มีภาพอยู่แล้ว

## ย้อนกลับเฉพาะไอคอน

เปิดการ์ดเดิม ไปที่ปุ่ม **เลือกไฟล์อัปเดตไอคอน / Undo** แล้วเลือก `RoleForge-NPC-Icons-Undo.json` ที่เก็บไว้ ตรวจรายการและกด Apply เช่นเดียวกัน ระบบตรวจว่าภาพยังตรงกับที่รอบนั้นใส่ให้หรือไม่ ถ้าคุณแก้ภาพเองภายหลัง รายการนั้นจะถูกข้าม แม้เปิดตัวเลือกแทนภาพเดิมอยู่ ข้อมูล NPC/Lore และแชทที่แก้เพิ่มหลังอัปเดตยังอยู่

ถ้าขึ้นว่า Chat/card หรือ archive เปลี่ยนระหว่างเตรียม ให้เปิดการ์ดและแชทที่ถูกต้องแล้วเลือกไฟล์อีกครั้ง ระบบไม่ย้ายข้อมูลไปยังการ์ดที่เพิ่งเปิด ถ้าบันทึกไม่สำเร็จ ระบบเก็บ reference/payload เดิมไว้และแสดงข้อผิดพลาด ไฟล์ย้อนกลับยังคงใช้ได้กับภาพที่บันทึกสำเร็จเท่านั้น

## ขอบเขตของชุด Fate

- ตั้งแต่ **0.72.1** เมนูเลือกชุด Servant แสดงเฉพาะการ์ด Fate ไม่ติดไปยังบอทอื่น การ์ด Fate v3 ที่แจกก่อนหน้านี้ใช้ได้ทันทีหลัง Update ส่วนเสริมและ Reload ไม่ต้องนำเข้าการ์ดหรือไฟล์อัปเดตภาพซ้ำ [รายละเอียด](card-icon-packs-v0.72.1.th.md)
- คง **800 NPC / 1,771 เวอร์ชัน / 178 Lore โลก / 4,329 ข้อมูลพลังเสริม**
- ใส่ภาพให้ **521 ร่าง** รวมร่าง Servant และร่างพิเศษในแค็ตตาล็อก โดย **1,466 เวอร์ชัน** ของร่างเหล่านั้นรับภาพจากฐาน ไม่เก็บภาพซ้ำทุกเวอร์ชัน
- มนุษย์ เช่น Waver และ Shirou ยังคงใช้ไอคอนเดิม ไม่จับคู่คลาสจากชื่อที่คล้ายกัน
- ตัวเลขใต้ภาพนับเฉพาะร่าง NPC ที่ได้รับภาพในแพ็ก ไม่ใช่จำนวน Servant ทั้งหมดใน canon: **Galahad เป็น Servant คลาส Shielder** แต่รายการ `Galahad — Arthurian Knight` ในไฟล์นี้ระบุ `race: Human` และเวอร์ชัน `Arthurian background — Current body` จึงคงไอคอนเดิมไว้ **Shielder 1 คือ Mash** ส่วน **Galahad Alter ใน Fate/Requiem เป็น Saber** ภาพไอคอนของ Galahad ร่างมนุษย์ยังเลือกเป็น Shielder เองใน NPC Management ได้โดยไม่แก้ Stats หรือสถานะของเขา
- **6 รายการใช้ Unknown** เพราะคลาสไม่ยืนยันในแฟ้มต้นทาง: E-Flare Marie, E-Aqua Marie, E-Grand Marie, E-Stellar Marie, U-Olga Marie และ Bragi ไม่เปลี่ยนเนื้อหาเพื่อเดาคลาสขึ้นมาเอง
- Alcides ใช้ภาพ Archer ตามร่างหลัก รายละเอียด Avenger ยังคงอยู่ในประวัติเดิม ส่วน Beast ที่ไม่มีเลขระบุใช้ตรา Beast ทั่วไป
- นี่เป็นการอัปเดตภาพ ไม่ใช่การตรวจแก้ข้อเท็จจริงทั้งหมดของแพ็ก Fate
- การเลือกสีและภาพตัวละครเดิมยังทำงาน ภาพคลาสเป็นภาพสีของชุด gears จึงไม่ได้ถูกย้อมเป็นสีประจำตัวละครอัตโนมัติ

## การทำงานและการตรวจสอบ

ไฟล์อัปเดตใช้ `roleforge-npc-icon-update` version 1 มีคลังภาพ raster แบบฝังและรายการ `npcId`/`versionId` ยอมรับเฉพาะคำสั่งเปลี่ยน `roleIconImage` ข้อมูล Stats/สคริปต์/HTML ในคำสั่งอัปเดตจะถูกปฏิเสธ ภาพถูก deduplicate ในไฟล์อัปเดต

World Pack ทำแผนอัปเดตใน Worker โดยไม่เขียนทับ session เดิม สร้าง revision ใหม่ที่รวมการแก้ NPC/Lore เดิม ตรวจ manifest/hash/ลิงก์เวอร์ชันและ staged import สำเร็จก่อนบันทึก reference กับ payload พร้อมกันบนการ์ด ไม่ลบ revision เก่าอัตโนมัติ และไม่ใส่ payload ลง chat metadata, global settings หรือ prompt

เครื่องมือสร้างการ์ด: `tools/build-fate-servant-icons.py` ต้องใช้ Python กับ Pillow รักษาข้อความไฟล์ย่อยที่ไม่เปลี่ยน **3,031 ไฟล์** ตามเดิม และตรวจทุกไบต์/hash ก่อนสร้าง payload ใหม่ ตรวจทุกเวอร์ชันก่อนให้รับภาพฐาน

ผลทดสอบและภาพหน้าจอของรุ่นนี้อยู่ใน `validation-npc-icon-update-v0.72.0.json` และ `previews/fate-servant-icons-0720/` การทดสอบเบราว์เซอร์ใช้ SillyTavern จริงบนเครื่องทดสอบแยก ไม่ได้เข้าถึง SillyTavern หรือแชทส่วนตัวของผู้ใช้ ข้อความตัวอย่างสำหรับตรวจการแสดงผลเป็น fixture ไม่มีการเรียกโมเดลหรือ API ผู้ให้บริการ
