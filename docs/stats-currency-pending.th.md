# Stats, Status composer และค่าเงิน — อัปเดต 0.59.0

เผยแพร่ร่วมกับ UI และไอคอนที่อนุมัติในเวอร์ชัน `0.59.0` ฐานงานเดิมคือ `main` ที่ `8c38e63` ดู [รายงาน release และภาพจริง](stats-currency-v0.59.0.th.md)

## การฝึกค่าสถานะ

- มีแท็บฝึกเหนือช่องพิมพ์สำหรับ HP / MP / ST / INT / STR / DF / AG พร้อมความหมาย วิธีฝึก และค่าปัจจุบัน
- เลือกวิธีแล้วกดฝึกจะส่งการกระทำเข้าแชทหลัก ให้ AI ต่อฉากและตัดสินผล การเลือกปุ่มอย่างเดียวยังไม่เพิ่มค่า
- HP / MP / ST เพิ่ม **ค่าสูงสุดถาวร** เมื่อฝึกสำเร็จ โดยไม่เติมค่าปัจจุบัน ค่าใช้จ่ายหรือความเหนื่อยระหว่างฝึกบันทึกแยก
- INT / STR / DF / AG เพิ่มค่าตัวเลขของสถิตินั้น วิธีฝึกครอบคลุมการศึกษา แรงต้าน การตั้งการ์ด ฟุตเวิร์ก และการตอบสนอง
- พิมพ์การฝึกในแชทหลักใช้เส้นทางบันทึกเดียวกัน เช่น “ฉันฝึก STR ด้วยการยกน้ำหนัก” หรือ “ฉันฝึกยกน้ำหนัก”
- AI ต้องยืนยันผลการฝึกสำเร็จในบทโรล จึงรับการเพิ่มค่า มีขอบเขตต่อคำตอบ และรองรับการกู้ค่าจากบทบรรยายที่ยืนยันชัดแต่ขาด numeric patch
- คำถาม แผนอนาคต OOC การดูคนอื่นฝึก และการฝึกที่ล้มเหลวไม่ให้รางวัล เมื่ออ่านข้อความซ้ำไม่เพิ่มค่าซ้ำ
- ค่าเริ่มต้นเพิ่มได้ไม่เกิน 2 ต่อคำตอบสำหรับ HP / MP / ST และ 1 สำหรับ INT / STR / DF / AG
- เมื่อบันทึกการเพิ่มสำเร็จ มีแจ้งเตือน SillyTavern ว่าสถิติใดเพิ่มเท่าไร ถ้าบันทึกล้มเหลวจะย้อนค่าและไม่แจ้งว่าสำเร็จ

ที่ `Extension drawer → RoleForge → User stats` สามารถเปิด/ปิดแท็บสถานะ แท็บฝึก และแจ้งเตือน ปรับค่าด้วยมือ ซ่อนปุ่มฝึกแต่ละสถิติ และเพิ่มสถิติ custom ได้ สถิติ custom กำหนดชื่อ ความหมาย วิธีฝึก ค่าเริ่มต้น ค่าต่ำสุด/สูงสุด หน่วยแสดงผล และจำนวนเพิ่มสูงสุดต่อการฝึกสำเร็จ รวมถึงเลือกแสดงในสถานะหรือแสดงปุ่มฝึกได้

สถิติ custom จำกัด 32 รายการ แต่ละรายการมีวิธีฝึกได้ 1–8 วิธี การซ่อนปุ่มยังใช้การฝึกผ่านแชทได้ การแก้ค่าด้วยมือไม่เรียก AI และไม่ถือว่าเป็นผลการฝึก ข้อมูลใหม่รองรับผลไอเทมและการ export/import สถานะด้วย

## แถบสถานะและการย่อหน้าต่าง

แท็บ Status แสดง HP / MP / ST / HUNGER / THIRST เป็นแถบ พร้อมชื่อ เลเวล สภาพร่างกาย สถิติ อาชีพ Party สถานที่ และเงิน ทั้ง Status และหน้าฝึกใช้กรอบโค้ง หัวแถบ ไอคอนเส้น และปุ่มชุดเดียวกับ Incantation โดยแชร์ CSS ส่วนเดียวกัน แถบค่าพลังอิงสี RoleForge ที่ตั้งไว้ ส่วนฟอร์มตั้งค่าใน extension drawer ใช้ช่องกรอกและปุ่มตาม SillyTavern

เมื่อเปิดใหม่หรือสลับเข้าแชท แถบเหนือช่องพิมพ์เริ่มแบบย่อทั้งหมด แม้มีไอเทม ร้านค้า หรือการประมูลค้างอยู่ เลือกแท็บหรือกดเปิดเพื่อดูรายละเอียด สถานะงานและรายการค้างยังอยู่ครบ การปิดหน้าฝึกวิชาเดิมกลับไปยังแท็บก่อนหน้าได้

## ค่าเงินและไอคอน

ที่ `RoleForge settings → Currency setup` กำหนดระบบเงินของแชทนี้ได้ 1–3 หน่วย พร้อมชื่อ สัญลักษณ์ ชื่อเรียกอื่น และอัตราแลก มี preset เหรียญแฟนตาซี Dollar/Cent ธนบัตรหน่วยเดียว และ Credit

- หน่วยเล็กสุดมีค่า 1 อัตราของหน่วยอื่นระบุเทียบหน่วยเล็กสุด และต้องเป็นจำนวนเต็มที่แปลงลงหน่วยถัดไปได้พอดี เช่น 1 Dollar = 10 Cent หรือ 100 Cent
- เมื่อเปลี่ยน preset หรืออัตรา จะเก็บมูลค่าเงินเดิมในหน่วยเล็กสุดครบ ทั้งกระเป๋าผู้เล่น เงิน Party และคลัง Guild
- ชื่อ สัญลักษณ์ และอัตราใหม่เชื่อมกับร้านค้า การขาย การประมูล ค่าธรรมเนียม มัดจำ การคืนเงิน ค่าตั้ง Guild และประวัติธุรกรรม
- สัญลักษณ์หน้าราคา เช่น `$12` และชื่อหน่วยที่ตั้งเองใช้ในบทโรลได้ ระบบเก็บ `gold/silver/copper` เป็นรหัสภายในเดิมเพื่อรองรับข้อมูลเก่า
- รายการซื้อขายที่ยังเปิด การประมูล และมัดจำที่ยังคืนไม่ครบต้องจบก่อนเปลี่ยนความหมายของค่าเงิน สามารถเปลี่ยนรูปลักษณ์ไอคอนได้ระหว่างนั้น
- มี SVG 8 ชุด: stack, minted, outline, pixel, banknote, gem, crest, neon แต่ละหน่วยเลือกชุด รูปทรง และสีแยกกันได้
- ทั้ง 8 ชุดเป็นพิกเซล 8-bit มีแอนิเมชันสี่เฟรม เลือกเปิด/ปิดได้ และหยุดเมื่ออุปกรณ์ตั้ง Reduce Motion
- การแปลงเงินใช้การหารจำนวนเต็มแบบแม่นยำ ไม่ปัดเศษเพื่ออนุมัติราคา ยอดที่ใหญ่เกินช่วงเก็บค่าที่แม่นยำจะไม่ถูกบันทึกหรือจ่ายออก

การตั้งค่าทั้งสองระบบบันทึกกับสถานะแชท การย้อนสถานะบทโรลทั้งชุดจะย้อนการตั้งค่าใน snapshot นั้นด้วย ฟอร์มที่แก้ค้างไว้ไม่ถูกอัปเดตทับขณะพิมพ์ การบันทึกซ้อนกันหรือสลับแชทระหว่างบันทึกไม่ส่งผลไปยังแชทใหม่

## การตรวจสอบ

ทดสอบตัวเลข การย้ายมูลค่า ชื่อหน่วย ราคาผสม การจ่ายครั้งเดียว มัดจำ/คืนเงิน การประมูล ขอบเขตสถิติ Unicode ภาษาไทย การบันทึกล้มเหลว และการสลับแชท ด้วย unit และ host integration tests

ตรวจพบและแก้การอ่านหน่วยเงินที่ตั้งเองในข้อความมัดจำ พร้อมเชื่อมชื่อหน่วยและ SVG ในรายละเอียดมัดจำ ตรวจการเช่าจริงผ่านแชทด้วย Dollar/Cent อัตรา 10:1 จนจ่ายค่าเช่าและมัดจำ รับอุปกรณ์ และสร้างสิทธิ์ได้ โดยไม่เรียก API เพื่อเติมข้อมูลเพิ่ม

ทดสอบ production loader ที่ความกว้าง 320 / 390 / 1280 px สำหรับฟอร์มและแถบใหม่ การฝึกผ่านแชท การกดซ้ำ การโหลดใหม่ การซ่อนปุ่ม การย่ออัตโนมัติ Reduce Motion และการไม่ล้นแนวนอน รวมถึง regression ไอเทม/Loot ร้านค้า รายการซื้อขายขาดข้อมูล การกู้รายการ สิทธิ์เช่า วิชา และ Character Forge

ผลรอบสุดท้าย: `npm test` ผ่าน 1,155/1,155, `npm run check` และ `git diff --check` ผ่าน แถบ Stats/Status ผ่านทั้ง 320 / 390 / 1280 px หลังปรับ aesthetic และ Incantation เดิมผ่านทั้งสามขนาด ตรวจว่าใช้พื้น กรอบ และฟอนต์เดียวกัน รวมถึงสีปุ่มที่เลือกยังอ่านชัดเมื่อวางเมาส์บน PC

ภาพจากโค้ดจริงอยู่ใน `/workspace/artifacts/stats-currency-pending/` ส่วน log อยู่ใน `/workspace/artifacts/stats-currency-*.log` และ `/workspace/artifacts/stats-commerce-*.log`

การตั้งค่าและการแสดงแถบไม่เรียก AI เพิ่ม การฝึกใช้การตอบในแชทหลักตาม API ที่ผู้ใช้เลือก การทดสอบใช้คำตอบจำลอง ไม่ได้เรียกโมเดลเสียเงิน รายละเอียดและข้อจำกัดของ Proxy BEGIN อยู่ใน `forge-opening-proxy-pending.th.md`; ยังไม่สามารถยืนยันการรับคำขอของ Proxy จริงได้หากไม่มีข้อมูลจากผู้ให้บริการ
