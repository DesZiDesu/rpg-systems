# Pokémon 1.6.1 / RoleForge 0.90.11 — แผงเหนือ Chatbar และการเปิดสนาม

## สาเหตุและสิ่งที่แก้

| ปัญหา | สาเหตุ | การแก้ |
| --- | --- | --- |
| แผงเหนือ Chatbar ยังเป็น UI เก่า | กฎ Dossier เดิมเจาะจง `#roleforge-pokemon` แต่แผงย่อเป็น `#roleforge-pokemon-dock` อีก element หนึ่ง | แผงย่อมีกรอบเหลี่ยม สี และไอคอน Poké Ball ของตัวเอง ครอบคลุม Original/Aperture |
| ขอบปุ่มท่าชนแถวบอลด้านล่าง | แถวท่าและแถวการกระทำไม่มีช่องว่างระหว่างส่วนเพียงพอ และใช้เงากรอบจากดีไซน์เดิม | ใช้ grid body แยกส่วน เว้น 11–12px ระหว่าง container และ padding ก่อนปุ่มแถวล่าง เอาเงาปุ่มที่ยื่นชนกันออก |
| เริ่มสู้แล้วแสดงเฉพาะแผงย่อ | ระบบอัปเดตสถานะ แต่ไม่มีคำสั่งเปิดหน้าต่าง และแอนิเมชันเดิมเล่นเฉพาะเมื่อหน้าต่างเปิดอยู่แล้ว | เปิดหน้าสู้เต็มเมื่อเริ่มศึกใหม่ที่บันทึกสำเร็จ หรือพบเหตุการณ์ต่อสู้ใหม่จากข้อความ AI ก่อนเริ่มแอนิเมชัน |
| ชื่อเล่นยาวล้นกรอบ | หัวรายละเอียดและบางตัวเลือกใช้คำยาวแบบไม่ตัดบรรทัด | หัวรายละเอียด/ไอเทมถือรองรับการตัดบรรทัด รายการเลือกและแถบทีมจำกัดข้อความในช่อง |
| กล่องยืนยันบังปุ่ม Sandbox | กล่องยืนยันใช้ sticky footer และลอยทับการกระทำด้านหลัง | ย้ายเป็นส่วนหนึ่งในลำดับหน้า และเลื่อนมาที่สรุปหลัง Review |
| Pokédex แน่นเกินไปที่ 320px | หัวเรื่องกับตัวนับแย่งพื้นที่แถวเดียวกัน | หัวเรื่องและตัวนับเรียงใหม่บนจอแคบ |
| กระเป๋าตอนสู้มีรายการมาก | เมนูที่ยาวเพิ่มความสูงจนแย่งพื้นที่สนาม | เมนูย่อยเลื่อนภายในช่องคำสั่งบน PC โดยรักษาสนามที่ใช้เล่นได้ |

อัปเดตนี้รวมหน้าต่าง PC 16:9 และหน้า Settings แบบแบ่งหมวดจากพรีวิวก่อนหน้าไว้ด้วย สนามยังเป็น 16:9 ทั้ง PC/มือถือ ปุ่มและ HP ใช้ผลเกมที่บันทึกจริง

## พฤติกรรมเปิดสนามอัตโนมัติ

- การพบตัวป่าในโรล การสำรวจจากแผงย่อ และการรับคำท้าเมื่อเริ่มการต่อสู้จริง จะเปิดหน้าสู้เต็ม
- ใช้งานได้ทั้ง Motion on/off การท้าของ Trainer ยังต้องให้ผู้เล่นยอมรับ ไม่รับคำท้าแทนผู้เล่น
- ปิดหน้าต่างแล้วข้อความธรรมดาไม่เปิดซ้ำ การเรียกอ่านสถานะ การโหลดการ์ด สไลด์กลับ และการลบ/คืนประวัติไม่บังคับเปิดหน้าต่าง
- การบันทึกล้มเหลวไม่เปิดสนามที่ไม่มีผลบันทึก และข้อความในช่องพิมพ์ยังอยู่
- แผงย่อยังใช้โจมตีและเปิดสนามต่อได้ บอลของ Trainer ถูกปิดใช้งานในแผงย่อด้วย

## ตรวจอะไรบ้าง

ตรวจการจัดวาง 268 กรณีของสองธีม: PC 1280×720 / 1920×1080 และมือถือ 320×844 / 390×844 พร้อมข้อมูลชื่อเล่นยาวและบอลหลายชนิดในกระเป๋า ตรวจความกว้างล้น ปุ่มทับกัน การเลื่อนถึงตัวควบคุมท้ายหน้า และพื้นที่สนามที่ยังใช้ได้

ครอบคลุมหน้าเริ่มเลือกคู่หู Journey/การต่อสู้, Party/รายละเอียด/ชื่อเล่น, Pokédex/ตัวกรอง/ฟอร์ม/ข้อมูลสายพันธุ์, Storage, Bag/ทะเบียน/ยา/ฟื้น PP, Settings, Journal, Services, Center, Training/ช่องท่า/ยืนยัน, Trainer/Gym/ยืนยัน, Quests, Sandbox เพิ่มตัว/แก้ตัว/IV/EV/ค่าสเตตัส/ไอเทม/ยืนยัน, คลังร่วม, Ability/ไอเทมถือ, คู่มือ, เมนูต่อสู้ Moves/Bag/Party และแผง Chatbar แบบยังไม่มีคู่หู/เดินทาง/สู้ตัวป่า/สู้ Trainer

- 370 unit/host tests และ syntax checks ผ่าน
- ชุดทดสอบเล่นจริงใน SillyTavern ผ่านทั้งคอม/มือถือ: ฝึกท่าและ TM, Center, Trainer/Gym, จับและหักไอเทม, คลังร่วม, สถานะ/อากาศ, Ability/ไอเทมถือ, วิวัฒนาการ, ภารกิจหายาก, รีโหลดและ Branch
- ชุดเรขาคณิตสนาม/ฐาน/HP 108 กรณีผ่าน และชุดแอนิเมชันจับสำเร็จ/ล้มเหลว การล็อกปุ่ม ย้อนข้อความ และ Motion/reduced motion ผ่าน
- ติดตั้ง Pokémon 1.6.1 ผ่าน Workshop และเลือกคู่หูจากการ์ดไทย/อังกฤษได้จริง

ใช้ SillyTavern 1.19.0 กับการ์ด QA และเหตุการณ์ควบคุม ภาพมือถือเป็น browser emulation ไม่ใช่ iPhone จริง ไม่มีการเรียกโมเดลภายนอกหรือแก้แชทจริงของผู้ใช้
