# เริ่มเล่น RoleForge 0.56.2

RoleForge เป็นส่วนเสริม RPG สำหรับ SillyTavern รองรับไทย/อังกฤษและมือถือ ใช้โมเดลที่เชื่อมต่อใน SillyTavern เพื่อเล่าเรื่องและส่งข้อมูลสถานะให้ส่วนเสริมบันทึก

## ติดตั้ง

1. เปิด Extensions → Install extension ใน SillyTavern
2. ใส่ `https://github.com/DesZiDesu/rpg-systems` และติดตั้งจาก `main`
3. รีโหลดหน้า แล้วเปิด Extensions → RoleForge เพื่อเลือกภาษาไทยและปรับการตั้งค่า
4. ใช้ปุ่มเปิด RoleForge เพื่อดูหน้าต่างตัวละครและระบบ RPG

ชื่อโฟลเดอร์มาตรฐานคือ `third-party/rpg-systems` ไม่ต้อง build หรือติดตั้ง npm เพื่อเล่น ใช้ SillyTavern รุ่นปัจจุบันที่รองรับส่วนเสริมและเชื่อมต่อโมเดลสร้างข้อความไว้แล้ว โครงการยังไม่ได้กำหนดขั้นต่ำเป็นหมายเลขเวอร์ชัน SillyTavern

## เริ่มต้น

Auto Track, Chat Presentation และ Scene Tracker เปิดไว้เป็นค่าเริ่มต้น คุณโรลตามปกติได้ แล้วดูตัวละคร ทรัพยากร อุปกรณ์ ไอเทม พลัง ทักษะ วิชา NPC และสถานะฉากใน RoleForge

ระบบเสริม เช่น ซื้อขาย ประมูล บทร่าย กระดานภารกิจ/รับสมัคร และเครื่องมือเรื่องราว ต้องเปิดเองใน Extension Settings ส่วน Memory กับ Voice เป็น addon แยกและปิดเป็นค่าเริ่มต้นเช่นกัน การอัปเดตจะรักษาค่าที่เคยเลือกไว้

หน้าต่างเหนือช่องพิมพ์ใช้ Tab เมื่อมีหลายระบบ เปิดรายละเอียด ย่อจนแบน และปิดได้ การดูข้อมูลหรือเลือกสินค้าไม่ใช่การจ่ายเงิน กดเสนอราคาแล้ว NPC ยอมรับยังต้องยืนยันก่อนชำระ

AI จะกำหนดสต็อกตามบริบทของร้านแยกจากจำนวนที่ขอซื้อ เช่น ร้านมี 12/8 ขวด แต่ขออย่างละ 3 ขวด ตะกร้าจะเลือก 3/3 ให้ เมื่อยืนยันผ่านการตรวจจะหักเงิน เพิ่มของ และหักสต็อกหนึ่งครั้ง [รายละเอียดซื้อขาย](commerce-ai-stock.th.md) · [ระบบ Loot และไอเทม](items-update.th.md)

## API และ addon

คำตอบโรลปกติใช้การเชื่อมต่อสร้างข้อความของ SillyTavern ข้อมูลที่ส่งครบในคำตอบเดียวจะถูกอ่านจากข้อความนั้น ปุ่มซื้อขาย ฝึก ไอเทม หรือการทำ Summary บางงานจะเรียก API เพิ่ม โดยมีแจ้งเตือนก่อนเริ่มคำขอ งานที่แบ่งเป็นหลาย batch อาจใช้หลายคำขอ ดูข้อมูลเฉย ๆ ไม่เรียกโมเดล

Voice ต้องใส่ ElevenLabs API key แยกจาก API สร้างข้อความ ตั้งเสียงชาย หญิง ผู้บรรยาย และเสียงเฉพาะ NPC ได้ แก้บทพากย์โดยไม่แก้ข้อความ AI เดิม การสร้างเสียงใช้เครดิตของ ElevenLabs ตามบัญชี ส่วนฟังเสียงที่อยู่ใน cache ไม่สร้างคำขอใหม่ ค่าเริ่มต้นคือกดฟังเอง [ตั้งค่า Voice](voice-addon.th.md)

Memory มี drawer สำหรับ Summary และคลังข้อความ เปิดใช้เองตามต้องการ การสร้าง Summary อาจเรียก API เพิ่มตามการตั้งค่า [ตั้งค่า Memory](memory-addons.th.md)

## อัปเดตและดูแลข้อมูล

กด Update ในรายการ Extensions รอ AI เจนเสร็จและเก็บข้อความร่างก่อนรีโหลด หรือกด Apply update ถ้าปุ่มแสดง การอัปเดตตามปกติไม่ต้อง Reset RPG หรือล้างข้อมูลเบราว์เซอร์

ข้อมูล RPG อยู่ใน chat metadata และ NPC เลือก scope แชต/ตัวละครได้ ส่วน Memory archive และ voice cache มีข้อมูลในเบราว์เซอร์ด้วย ใช้ Export state สำรองข้อมูลสำคัญก่อนย้าย และส่งออก Memory แยกเมื่อเปิดใช้ การล้าง storage หรือเปลี่ยนเบราว์เซอร์อาจทำให้ archive/cache ในเครื่องหาย

ถ้าหน้าต่างไม่ขึ้น ให้ตรวจสวิตช์ระบบแล้วเจนคำตอบใหม่ ถ้าข้อมูลไม่ครบ ให้ดู diagnostic: โมเดลต้องส่งข้อมูลที่อ่านได้ คำว่า “จ่ายแล้ว” ใน planning อย่างเดียวไม่ยืนยันว่าระบบตัดเงินสำเร็จ หากจำเป็นต้องข้ามการโหลด RoleForge ชั่วคราว เติม `tretaresia-safe=1` ใน query ของ URL SillyTavern แล้วรีโหลด โดยไม่ลบข้อมูลแชต

แจ้งปัญหาที่ [GitHub Issues](https://github.com/DesZiDesu/rpg-systems/issues) พร้อมเวอร์ชัน RoleForge/SillyTavern เบราว์เซอร์ วิธีทำซ้ำ และ diagnostic ถ้ามี ลบ API key และข้อความส่วนตัวก่อนแชร์
