# ชุดไอคอนแยกตามการ์ด — RoleForge 0.72.1

แกลเลอรีไอคอนคลาส **Servant** แสดงเฉพาะการ์ด Fate ที่ระบุชุดไอคอนของตัวเอง เมื่อสลับไปบอทอื่นจะไม่มีชื่อชุด Servant ตัวเลือกสี แกลเลอรี หรือเครดิตชุด Fate อยู่ในเมนูแก้ NPC บอทอื่นยังใช้สัญลักษณ์บทบาทเดิม 12 แบบและอัปโหลดภาพ custom ได้ตามปกติ

ภาพ NPC เป็นข้อมูลของ NPC ในการ์ด/แชทนั้นอยู่แล้ว ไม่ได้ใส่ภาพ Servant ให้ตัวละครของบอทอื่นอัตโนมัติ การอัปเดตนี้ไม่ลบภาพที่ผู้ใช้เคยตั้งไว้เอง และเพิ่มปุ่ม **อัปโหลดไอคอนเอง / Upload custom icon** ที่กดได้จริง เพราะ SillyTavern ซ่อนช่อง file input ตามค่าเริ่มต้น

## ผู้ใช้การ์ด Fate v3 เดิม

1. Update ส่วนเสริม **RoleForge** จาก `main` ให้เป็น **0.72.1 หรือใหม่กว่า** แล้ว Reload SillyTavern
2. เปิดการ์ด Fate ใบเดิม ไปที่ **NPC Management → ตัวละคร → Edit → CHAT APPEARANCE → ไอคอนภาพ** จะมีชุด Classic, Brown, Blue, Grand, Anti-Servant และ Beast ตามเดิม
3. เปลี่ยนไปการ์ดบอทอื่น เมนูไอคอนจะเหลือภาพ custom และสัญลักษณ์ทั่วไป ไม่ต้องลบหรือตั้งชุดใหม่เอง

ไม่ต้องนำเข้าการ์ด Fate ซ้ำ ไม่ต้องนำเข้าไฟล์อัปเดตไอคอนอีก และไม่ต้องเริ่มแชทใหม่ รองรับรหัสการ์ด Fate v3 Core/Native และรหัส archive ของแพ็กที่ให้ไปแล้ว ไม่ตรวจจากชื่อแสดงผล จึงยังทำงานแม้ผู้ใช้เปลี่ยนชื่อการ์ด

## สำหรับผู้สร้างการ์ด

ใส่ข้อมูลนี้ใน extensions ของการ์ด:

```json
{
  "data": {
    "extensions": {
      "roleforge_icon_packs": ["fate-servant-classes"]
    }
  }
}
```

ฟิลด์นี้เลือกแกลเลอรีในหน้าแก้ NPC เท่านั้น ไม่เปลี่ยนคลาส Stats, enabled/met, ภาพเดิม หรือเวอร์ชันที่เลือก ตัวเลือกถูกเก็บกับการ์ดและติดไปกับ Native Export/Import ของ SillyTavern ไม่เก็บเป็น global setting หรือคัดลอกลงทุก checkpoint

`roleforge_icon_packs: []` ปิดแกลเลอรีบนการ์ดนั้นอย่างชัดเจน แม้เป็นรหัส Fate เดิม การ์ดอื่นที่ไม่ระบุฟิลด์จะไม่เปิดชุด Fate เพราะชื่อ NPC เป็น Saber หรือชื่อการ์ดมีคำว่า Fate หากสร้างการ์ดใหม่จากการคัดลอกการ์ด Fate และต้องการเอาชุดนี้ออก ให้ตั้งฟิลด์เป็นอาร์เรย์ว่าง

เครื่องมือ `tools/build-fate-servant-icons.py` ใส่ฟิลด์นี้ให้การ์ด Fate ที่สร้างใหม่ โดยไม่ต้องแก้ข้อมูล payload เพื่อแสดงเมนู
