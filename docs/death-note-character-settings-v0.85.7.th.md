# RoleForge 0.85.7 / Death Note 0.4.1

## การตั้งค่าตามการ์ด

การตั้งค่า RoleForge และ preset ที่เลือกใช้จำตามการ์ดตัวละครในโปรไฟล์ SillyTavern เดิม แชทใหม่หรือ Branch ของการ์ดเดียวกันใช้ตัวเลือกเดียวกัน การเปิดแชทเก่าไม่เปลี่ยนค่าที่ผู้เล่นเพิ่งเลือก และการ์ดอื่นยังมีชุดตั้งค่าของตนเอง คลัง preset เดิมยังอยู่ครบ

Workshop ใช้ชุดเปิด/ปิด Addon, ปุ่มลอย, Wand, Great Sage และการตั้งค่า Death Note ร่วมกันระหว่างแชทของการ์ดเดียวกัน ส่วนผลวิเคราะห์ Great Sage ยังคงอยู่ในแชทที่วิเคราะห์ การย้ายจากรุ่นเก่าจะใช้โปรไฟล์แชทที่เปิดหรือโปรไฟล์เดิมของการ์ดที่ยังเก็บอยู่ โดยไม่คัดลอกประวัติวิเคราะห์ไปแชทใหม่

ข้อมูลที่เล่นสะสม เช่น เงิน ไอเทม ความสัมพันธ์ เจ้าของสมุด ข้อตกลงที่จ่ายอายุขัย รายชื่อที่เขียน และความรู้ที่ได้ในโรล ยังอยู่ในแชทและ checkpoint ของ Branch การตั้งค่าดวงตาที่ผู้สร้างกำหนดเองเป็นค่าเริ่มต้นของการ์ด การจ่ายอายุขัยจากข้อตกลงจริงยังเป็นเหตุการณ์เฉพาะแชทและไม่คืนอายุขัย

API key และการเชื่อมต่อบัญชียังเป็นข้อมูลการเชื่อมต่อเดิม ไม่คัดลอกไป preset หรือโปรไฟล์ Addon การส่งออก World preset / Workshop backup และการบันทึกชุดข้อมูลลงการ์ดยังใช้ได้ตามเดิม

## ดวงตาและชื่อ NPC

บันทึกดวงตาแบบมีตั้งแต่เกิด / ได้รับพลัง / กำหนดจากโรลแล้วมีผลกับ UI และคำสั่งที่ AI รับรู้ทันที รวมถึงข้อความล่าสุดที่มีอยู่แล้ว การตั้งค่าถูกบันทึกก่อนเติมแฟ้ม NPC จึงไม่ต้องรอ AI ยอมรับการตั้งค่า

กรณีชื่อจริงปรากฏชัดในโรล เช่น `ชื่อจริงตามทะเบียนราษฎร์— ทานากะ เคนจิ` แต่แฟ้มเป็น `คนเดินถนน` จะกู้ชื่อเข้าระเบียนเดิม รักษา ID เดิม และย้ายคำบรรยายบทบาทไป title/occupation การตรวจชื่อครอบคลุมไทยและอังกฤษ และไม่แทนชื่อจริงจาก canon ที่กำหนดไว้ด้วยชื่อที่ขัดกัน

เมื่อเปิดดวงตาจากหน้าตั้งค่าแล้วแฟ้มของมนุษย์ที่ผู้เล่นเห็นในฉากล่าสุดยังขาด ระบบใช้ AI ที่ตั้งอยู่ใน SillyTavern เติมเฉพาะแฟ้มที่จำเป็น โดยไม่ส่งข้อความฝั่งผู้เล่น ไม่เปลี่ยนเหตุการณ์ในโรล และรักษาข้อความที่พิมพ์ค้างใน chatbar ไว้ ไม่เปิดเผยตัวละครนอกฉากหรือใบหน้าที่ถูกปิดบัง

ตัวกรองชื่อ NPC ไม่ยอมรับ `???`, `คนเดินถนน` และบทบาทอย่าง `เจ้าของร้านสะดวกซื้อ` เป็นชื่อบุคคลอีกต่อไป กลไกนี้ใช้กับทุกแชทและไม่ผูกกับรุ่นโมเดลใดรุ่นหนึ่ง
