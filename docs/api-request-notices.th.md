# แจ้งเตือนการเรียก API · v0.52.1

RoleForge ใช้ `toastr.info` ของ SillyTavern แจ้งก่อนส่งงาน AI เพิ่ม เช่น **ประมูล: กำลังเรียก API เพิ่ม** ไม่ต้องกดยืนยันและไม่เพิ่มคำขอ AI เพื่อสร้างแจ้งเตือน

- ครอบคลุมปุ่มประมูล/ซื้อ/ขาย การฝึกพลัง/วิชา/ทักษะ สรุปความจำทั้งแบบอัตโนมัติและสั่งเอง Manual Sync สร้าง/เติมข้อมูล/ค่าสถานะ NPC อ่านภาพอ้างอิง และสร้างโปรไฟล์ H-Stats
- แจ้งทุกคำขอจริง รวมถึงแต่ละชุดของ Summary และการลองสร้างข้อมูล NPC ซ้ำ สถานะรอคิวและการอ่านคลังความจำไม่ส่งแจ้งเตือน API
- การเปิดเรื่องและคำสั่งโรลที่ RoleForge ส่งผ่านแชตหลักแจ้งว่าเรียก API โดยไม่ระบุว่าเป็น API เพิ่ม ส่วนการส่งแชตปกติด้วยตัวเองไม่ได้เพิ่ม toast ของ RoleForge
- เปิดหน้าต่าง อ่านข้อมูล สลับแท็บ พับหน้าต่าง Copy บทร่าย และฝึกผ่านข้อความโรลปกติไม่สร้างคำขอ AI เพิ่มจากแจ้งเตือนนี้
- จำนวนคำขอเป็นข้อมูลของรอบที่เปิดหน้า เก็บในหน่วยความจำ ไม่บันทึกการตั้งค่าซ้ำและไม่ใช่ยอดเรียกเก็บของ provider

ใช้หน้าตา/ตำแหน่ง toast ของ SillyTavern ที่ผู้ใช้ตั้งไว้ ข้อความตามภาษา UI ของ RoleForge มีชื่อระบบและหมายเลขชุดเมื่อเกี่ยวข้อง ปิดเองในประมาณ 5 วินาที หาก toast ใช้งานไม่ได้ งาน AI ยังทำต่อได้

ตรวจด้วย unit/host tests และเบราว์เซอร์: การฝึกบน production loader ที่ 320/390/1280 px, การเจน NPC/อ่านภาพ/ลองซ้ำ, งาน Summary และการอ่านโดยไม่เรียก AI คำตอบ provider ในการทดสอบเป็นข้อมูลจำลอง
