# RoleForge 0.55.5 — คลังสิ่งของ

นำแบบการ์ดสิทธิ์/ของเช่าที่ผู้ใช้อนุมัติจากตัวอย่าง 0.55.4 มาใช้ในหน้าคลังจริง ให้พื้นหลัง สี และกรอบสี่เหลี่ยมเข้ากับการ์ดไอเทมเดิม

- กุญแจห้องแสดงไอคอนกุญแจ ชื่อ สถานที่ และสถานะ พร้อมแถวสรุปกำหนดคืน
- รายละเอียดเริ่มพับไว้ กด “ดูสิทธิ์และเงื่อนไข” / เครื่องหมายบวกเพื่อขยาย และกด “ซ่อนสิทธิ์และเงื่อนไข” / เครื่องหมายลบเพื่อพับ รองรับคีย์บอร์ด
- เงื่อนไข ผู้ให้บริการ สถานที่ วันเริ่มสิทธิ์ สิ่งที่รวม ราคา มัดจำ และประวัติสิทธิ์ยังแสดงได้ตามข้อมูลเดิม ข้อมูลยาวตัดบรรทัดภายในกรอบ
- ปุ่มลบไอเทมทั่วไปใช้ไอคอนถังขยะแบบ SVG พร้อมคำว่า “ลบ” และชื่อไอเทมสำหรับเครื่องอ่านหน้าจอ ไอคอนกล่องไอเทมใช้ SVG ด้วย จึงไม่ต้องรอชุดไอคอนของ SillyTavern

การเปิด/พับรายละเอียดไม่เรียก API และไม่เปลี่ยนยอดเงินหรือรายการไอเทม การลบยังใช้กฎเดิม รวมถึงการป้องกันไอเทมที่อยู่กับผู้ให้บริการ ราคาที่เคยจ่ายและประวัติธุรกรรมไม่ได้ถูกแก้ย้อนหลัง

## ตรวจสอบ

ผ่าน 806 unit/host tests และ syntax checks ทดสอบผ่าน loader จริงบนจอ 320, 390 และ 1280 พิกเซล ทั้งการเปิด/พับด้วยเมาส์และคีย์บอร์ด ปุ่มลบที่ไม่พึ่ง icon font การซื้อในราคาที่ต่อรอง 190 ทองแดง ตลอดจนสิทธิ์เช่า/ถาวร/บริการ การหมดอายุในเรื่อง การคืนของและมัดจำ การทดสอบใช้คำตอบ API จำลอง ไม่ได้เรียกผู้ให้บริการจริง
