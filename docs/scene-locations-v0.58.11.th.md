# Scene Tracker และ Location List 0.58.11

## สาเหตุช่องภูมิภาคและทวีปว่าง

คำสั่งเดิมหลายชุดระบุว่าภูมิภาค/ทวีปเป็น optional และตัวตรวจความครบของฉากนับเพียง 19 ช่อง จึงแสดง LIVE ได้ทั้งที่สองช่องนี้ว่าง ข้อมูลลำดับสถานที่ใน Location Memory ยังไม่ได้ถูกนำมาใช้เติมข้อมูลฉาก และชื่อเขตที่อยู่ในวงเล็บของชื่อร้านถูกเก็บรวมเป็นชื่อสถานที่อย่างเดียว

## การแก้และวิธีใช้

คำสั่งทุกชุดใน normal reply กำหนดฉากครบ 21 ช่อง รวม region และ continent พร้อมตัวอย่าง compact JSON ที่ครบตรงกับตัวตรวจ UI รุ่นนี้ใช้ชื่อจากบทโรลก่อนหน้า, lore และ Location Memory; ถ้ายังไม่ได้ตั้งชื่อภูมิภาคหรือทวีป ให้ AI สร้างลำดับภูมิศาสตร์ที่สอดคล้องกับโลกในบทบรรยายและ patch เดียวกัน สำหรับโลกที่ไม่มีทวีป ใช้ชื่อโลก/realm แทนช่อง continent ไม่ใช้แผนที่หรือเมืองหลวงตายตัวของส่วนเสริม

ชื่อเขตที่ระบุชัดในวงเล็บ และลำดับ parent ของจุดปัจจุบันที่บันทึกไว้แล้ว สามารถเติมช่องว่างได้ ไม่ยืมภูมิภาคจากสถานที่อื่นหรือ alias ที่กำกวม และไม่ทับค่าที่มีอยู่ Scene Tracker เหนือข้อความและหน้าฉากใช้ข้อมูลเดียวกัน ตัวแสดงฉากตรวจความครบเองด้วย; เมื่อ AI ยังส่งไม่ครบจะแสดง PARTIAL แทน LIVE

แชทเก่าที่ข้อมูลตกหล่นให้เปิด **RoleForge → Scene → ให้ AI เติมฉากและสถานที่** กดเมื่อบทโรลระบุสถานที่แล้ว แต่ช่องฉาก/ลำดับสถานที่/ระยะยังไม่ครบ ปุ่มอ่าน 24 ข้อความล่าสุดร่วมกับ lore และข้อมูลที่เก็บไว้ ใช้ API เพิ่มหนึ่งครั้งต่อการกด และมีข้อความบอกหน้าที่/จำนวนคำขอบนปุ่ม ไม่มี API เพิ่มเพียงเพราะเปิดแท็บ ค้นหา หรือเลื่อน Location List และ normal reply ใช้ patch ในคำตอบเดียวตามเดิม

คำขอเติมฉากรับเฉพาะข้อมูลฉากและสถานที่ ไม่รับ ops ซื้อขาย/เงิน/ไอเทม/สกิล ไม่เปลี่ยนค่าฉากที่มีอยู่แล้ว ไม่ย้ายผู้เล่นหรือเดินเวลา ตรวจ chat/card, ข้อความและ metadata ก่อนบันทึก ถ้าแชทเปลี่ยน ผลไม่ครบ หรือการบันทึกล้มเหลว จะไม่ทับข้อมูลใหม่และคืนข้อมูลก่อนบันทึก การเติมฉากอัปเดต checkpoint ของคำตอบล่าสุดด้วยเพื่อไม่ให้ค่าหายเมื่อสลับคำตอบแล้วกลับมา

## Location List และระยะทาง

เพิ่มรายการแบบแถบเล็กในหน้าฉาก กดแถบรายการสถานที่เพื่อเปิดดูและค้นหา แสดง 10 รายการต่อหน้าบนมือถือและคอมพิวเตอร์ โดยจุดปัจจุบันอยู่ก่อน แต่ละสถานที่เป็นแถวสั้น กดชื่อเพื่อเปิดรายละเอียดเต็ม ลำดับสถานที่ สภาพ จุดสำคัญ และระยะ เช่น `Central Continent → Kingsberg River → Cave near River` ไม่เรียก API เมื่อเปิด/ปิด รองรับ parent มากกว่าสามชั้นและป้องกันวงวน ลำดับทวีป/ภูมิภาคจะถูกสร้างเป็น nodes ของ ledger จากค่าที่รู้แล้ว ไม่เพิ่มจำนวนครั้งที่ไปเยือนบรรพบุรุษเพียงเพราะสถานที่นั้นเป็น parent

แต่ละแถวแสดงระยะจากจุดปัจจุบัน:

- ระยะตรงจากเส้นทางที่เก็บไว้ ใช้ข้อความระยะ/เวลาเดินทางตามเรื่อง
- ระยะที่ AI ออกแบบโดยไม่มีตัวเลขยืนยันในบทโรลจะติดป้ายประมาณเสมอ
- เส้นทางหลายช่วงสามารถคำนวณจากเมตร/กิโลเมตรที่รวมกันได้ พร้อมป้ายตามเส้นทางที่บันทึก และเก็บป้ายประมาณถ้ามีช่วงใดเป็นค่าประมาณ
- ถ้าไม่มีเส้นทางที่เชื่อม หรือมีหน่วยที่รวมไม่ได้ แสดงยังไม่ทราบระยะ ไม่เดาจาก parent, จำนวนครั้งที่ไปเยือนหรือเปอร์เซ็นต์เดินทาง

เส้นทางย้อนกลับใช้ได้เมื่อระบุ bidirectional:true เท่านั้น ไม่เปลี่ยนระยะที่รู้แล้วด้วยการเติมข้อมูลทั่วไป; การแก้ข้อเท็จจริงเดิมจากบทโรลยังใช้ correction:true ตามระบบเดิม การเติมฉากไม่ใช้ correction เพื่อทับภูมิศาสตร์ที่รู้แล้ว รูปแบบ save เดิมยังอ่านได้; estimated/bidirectional ที่ไม่มีถือเป็น false มีเพดานเดิม 160 สถานที่และ 40 เส้นทางต่อสถานที่ ส่วน UI เก็บกราฟที่ใช้ค้นหาร่วมกันระหว่างเปลี่ยนหน้า/คำค้นเพื่อลดงานบนมือถือ
