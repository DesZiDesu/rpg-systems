# RoleForge v0.46.3 — การเลือกหมวดและสถานะสรุปความจำ

ทั้งสามรูปแบบใช้ข้อมูลและหน้าระบบเดียวกัน เลือกหน้าตาที่ต้องการได้จากการตั้งค่าส่วนเสริม โดยใช้สีดำ ทอง และไอคอน SVG ให้เข้ากับ RoleForge

## ตั้งค่ารูปแบบเลือกหมวด

1. อัปเดต RoleForge และโหลด SillyTavern ใหม่หนึ่งครั้ง ไม่ต้องรีเซ็ตข้อมูล RPG
2. เปิด **Extension Settings → RoleForge → General & continuity / ทั่วไปและการเล่นต่อเนื่อง**
3. ใน **Module navigation / รูปแบบเลือกหมวด** เลือก **Classic carousel / เลื่อนทีละหมวด (เดิม)**, **Quick menu / เมนูเลือกหมวด** หรือ **Module grid / ตารางหมวด**
4. เปิด RoleForge เพื่อใช้หน้าตาที่เลือก การตั้งค่าบันทึกทันทีและใช้ต่อหลังโหลดหน้าใหม่

ตัวเลือกเปลี่ยนรูปแบบอยู่ในตั้งค่าส่วนเสริมเท่านั้น หน้าต่าง RPG แสดงเครื่องมือเลือกหมวดของรูปแบบที่ใช้อยู่ ค่าเริ่มต้นยังเป็นการเลื่อนแบบเดิม

## 1. เลื่อนแบบเดิม

คงลูกศรซ้าย/ขวา การปัด และลำดับหมวดเดิมไว้ เหมาะกับการเปิดหน้าที่อยู่ใกล้กัน หากต้องการเปลี่ยนรูปแบบ ให้เลือกในตั้งค่าส่วนเสริม

## 2. เมนูเลือกหน้า

1. กด **เลือกโมดูล** ข้างชื่อหน้าปัจจุบัน
2. รายการแบ่งเป็นตัวละคร เนื้อเรื่อง ผู้คนและความสัมพันธ์ และเครื่องมือ
3. เลือกหน้าจากรายการได้ทันที เมนูไม่โฟกัสช่องค้นหาและไม่เปิดคีย์บอร์ดเอง หากต้องการค้นหาให้แตะช่องค้นหาแล้วพิมพ์ชื่อหน้า
4. เลื่อนรายการภายในเมนูได้ถึง **System Audit / ตรวจสอบระบบ** รายการท้ายไม่ถูกแถบสถานที่และปุ่ม Sync บัง
5. เมนูปิดและเปิดหน้าที่เลือก โดยไม่ต้องเลื่อนผ่านหน้าระหว่างทาง

## 3. ตารางโมดูล

1. กด **เลือกโมดูล** เพื่อเปิดตารางไอคอนที่แบ่งกลุ่ม
2. เลือกไอคอนของหน้าที่ต้องการ หน้าปัจจุบันมีเครื่องหมายกำกับ
3. ตารางปิดและเปิดหน้าที่เลือก หากต้องการเปลี่ยนกลับแบบเมนูหรือแบบเดิม ให้เลือกในตั้งค่าส่วนเสริม

## Summary ใน Main Chat

1. เริ่มสรุปข้อความจาก Memory Summaries แล้วปิดหน้าต่าง RPG ได้
2. ถ้าคำตอบหลักกำลังสร้าง งานสรุปแสดงสถานะรอคิวเหนือช่องพิมพ์ ยังไม่เรียก API สรุปและเริ่มเองเมื่อคำตอบหลักจบ
3. เมื่อเริ่ม API เหนือช่องพิมพ์แสดง **AI กำลังสรุปความจำเนื้อเรื่อง** พร้อมความคืบหน้าและเวลาที่ใช้
4. ขณะงานสรุปทำงานและไม่มีคำตอบเนื้อเรื่องกำลังสร้าง ปุ่มส่งแสดงปุ่มสี่เหลี่ยมสำหรับหยุดเฉพาะงานสรุป
5. หากคำตอบเนื้อเรื่องกำลังสร้าง ปุ่มหยุดของ SillyTavern ยังคุมคำตอบนั้น ส่วนคิวสรุปมีปุ่มยกเลิกของตนเอง
6. เมื่อสรุปสำเร็จ หยุด หรือเกิดปัญหา ปุ่มส่งกลับมาตามปกติ ชุดที่บันทึกสำเร็จยังอยู่
7. กด **รายละเอียด** เพื่อดู Memory Summaries หรือกด **ลองใหม่ / ทำต่อ** เมื่อเกิดปัญหา

## เมื่อพบ Error

- **รอ API เกินกำหนด:** หน้าจอบอกขั้นตอนและระยะเวลาที่รอ ตั้งเวลารอได้ 60–600 วินาที เริ่มต้น 240 วินาที
- **ตัวนับโทเคนของคำขอสรุปมีปัญหา:** รอสูงสุดสองวินาทีแล้วใช้ค่าประมาณจากไบต์ UTF-8 แบบเผื่อ และแสดงว่าจำนวนโทเคนเป็นค่าประมาณ การตรวจงบความจำที่แนบคำตอบหลักยังใช้การนับแบบเข้มงวด
- **สรุปเสร็จ แต่เตรียม prompt ไม่สำเร็จ:** แสดงคำเตือนและล้าง prompt ความจำส่วนที่มีปัญหา บทที่บันทึกแล้วอยู่ครบ แต่ยังไม่พร้อมแนบความจำในคำตอบ ตรวจตัวนับโทเคนหรืองบแล้วลองใหม่โดยไม่ต้องสรุปบทเดิมซ้ำ
- **API ปฏิเสธหรือโควต้าเต็ม:** แสดงประเภทปัญหาเมื่อ API ส่งข้อมูลนั้นกลับมา ไม่มีการเรียกซ้ำเสียโควต้าเอง
- **ทำต่อหลัง API Timeout:** ลดขนาดชุดที่เคยรอนานเพื่อให้คำขอถัดไปสั้นลง โดยรักษาค่าขนาดชุดปกติที่ตั้งไว้ ชุดที่บันทึกแล้วไม่ถูกสรุปใหม่

API ปัจจุบันบางแบบของ SillyTavern อาจยังประมวลผลคำขอที่ส่งแล้วหลังหยุดหรือหมดเวลารอ RoleForge จะไม่รับผลที่มาช้าจากงานนั้น โปรไฟล์ Connection Manager ที่รองรับสัญญาณยกเลิกสามารถหยุดคำขอแยกได้ตามความสามารถของผู้ให้บริการ

ค่าเริ่มต้น API สำหรับสรุปใช้ API และโมเดลเดียวกับแชตหลักของ SillyTavern ผ่านคำขอสรุปแยก ไม่เพิ่มข้อความเรื่องเล่า ตัวเลือกโปรไฟล์ใช้เมื่อต้องการโมเดลสรุปอื่น ผู้ใช้ใหม่เริ่มชุดละห้าข้อความ ผู้ใช้เดิมคงค่าที่บันทึกไว้ ตัวอย่าง 90 ข้อความ ชุดละห้า ใช้อย่างน้อย 18 API calls หากข้อความพอดีงบและแต่ละชุดสำเร็จครั้งแรก ข้อความยาวหรือการกดลองใหม่อาจเพิ่มจำนวนคำขอ

สำหรับทดลองโดยไม่ใช้โควต้า หน้าตัวอย่าง `docs/previews/preview-navigation-summary.html` ใช้ตัวโหลดและหน้าจอจริงร่วมกับข้อมูลตัวอย่างและ API จำลอง การกดในหน้าตัวอย่างไม่เรียก API เสียเงิน
