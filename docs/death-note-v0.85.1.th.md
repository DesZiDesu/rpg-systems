# RoleForge 0.85.1 — รายละเอียดการเขียนและคีย์บอร์ดมือถือ

## รายละเอียดที่ส่งให้ AI

เอาการตัดสาเหตุที่ 160 ตัวอักษรและรายละเอียดที่ 500 ตัวอักษรออก ทั้งตอนอ่านหน้ากระดาษและตอนบันทึกคำขอเขียนชื่อ ข้อมูลที่อ่านจากกล่องข้อความบนหน้าเดียวกันส่งต่อครบ รวมถึงข้อความท้ายกล่องสุดท้าย

ใช้ได้ทั้งการกด **ต่อเรื่อง** และการเขียนทิ้งไว้แล้วส่งโรลปกติในเทิร์นถัดไป คำขอที่รอผล การลองใหม่ และการโหลดแชทกลับมาเก็บรายละเอียดที่บันทึกไว้ครบ ไม่มีการสร้างข้อความ User แทนผู้เล่น

ขีดจำกัดของกระดาษยังเท่าเดิม: 1,200 ตัวอักษรต่อกล่อง, 24 กล่องต่อหน้า, 32 หน้า และข้อความรวม 48,000 ตัวอักษรต่อสมุด การส่งข้อมูลตรงเข้าระบบเกินขีดจำกัดจะถูกปฏิเสธแทนการตัดข้อความเงียบ ๆ รุ่นนี้ไม่เติมรายละเอียดที่หายจากคำขอเก่าหรือเปลี่ยนผลที่เกิดไปแล้วย้อนหลัง

## พิมพ์บนมือถือ

- เลื่อนหน้ากระดาษตามตำแหน่งพิมพ์ รวมถึงเมื่อย้ายเคอร์เซอร์ไปต้นหรือท้ายข้อความ
- กล่องพิมพ์ขยายตามข้อความ โดยให้หน้ากระดาษเป็นพื้นที่เลื่อนหลัก แก้ข้อจำกัดความสูงของ textarea จาก SillyTavern ที่เคยทำให้เกิดการเลื่อนซ้อนกัน
- เครื่องมือปรับขนาด ยืนยัน/ยกเลิกตำแหน่ง และปุ่มต่อเรื่องอยู่ในพื้นที่ที่มองเห็นเหนือคีย์บอร์ด
- แผงสมุดเหนือ Chatbar ย้ายมาอยู่ในพื้นที่หน้าจอที่เหลือชั่วคราวระหว่างใช้คีย์บอร์ด ปุ่มลอยไม่บังพื้นที่เขียน เมื่อเลิกพิมพ์จะคืนตำแหน่งปกติ
- การเปลี่ยนขนาดหน้าจอและการเลื่อน visual viewport ไม่สร้างกล่องใหม่ ไม่เปลี่ยนหมึก และไม่แทนที่ข้อความที่กำลังแก้ไข

## ซ่อมปุ่มหยิบสมุดและการหยิบผ่านโรล

ตรวจซ้ำจากจุดก่อนพิมพ์หยิบแล้ว พบว่าปุ่มหยิบเทียบสถานที่แบบต้องตรงทุกตัวอักษร สมุดระบุสถานที่ย่อยรวมกับสถานที่หลัก แต่ Scene Tracker แยกสองค่านี้ไว้ จึงแจ้งว่าสมุดไม่อยู่ในฉาก รุ่นนี้เทียบสถานที่หลักร่วมกับตำแหน่งในฉากให้ตรงกัน ใช้กับทั้งสมุดและเศษกระดาษ โดยยังปฏิเสธห้อง บ้าน หรือสถานที่อื่น ไม่ใช้การค้นคำบางส่วนแบบกว้าง ๆ

อีกปัญหาคือไฟล์แชทมีทั้งคำสั่งหยิบของผู้เล่นและคำยืนยันการหยิบในเรื่องแล้ว แต่ตัวอ่าน `acquire` เดิมรับเฉพาะ NPC ทำให้แผงยังค้างเป็น “พบสมุด” และจำนวนใน Inventory เป็น 0

รุ่นนี้รับเหตุการณ์หยิบของผู้เล่นเมื่อมี **ข้อความ User ที่หยิบจริง** ตามด้วย **คำยืนยันที่มองเห็นในคำตอบ AI** การเห็นสมุด แตะปก วางแผน หรือคำบอกเล่าของ AI เพียงอย่างเดียวไม่ให้สิทธิ์ถือครอง ไม่ดึงสมุดออกจากมือ NPC และไม่เปลี่ยนเจ้าของสิทธิ์เดิมหากมีอยู่แล้ว

เมื่อเปิดแชทเดิม ระบบอ่านเหตุการณ์นั้นใหม่และซ่อมจำนวน/แท็กของสมุดใน Inventory โดยเก็บชื่อ รายละเอียด และคุณสมบัติอื่นไว้ จึงไม่ต้องให้ AI เล่นเหตุการณ์หยิบซ้ำ สมุดยังผูกกับยมทูตเดิม การแก้ข้อความจนหลักฐานหายหรือสร้าง Branch ก่อนหยิบจะไม่ถือว่าหยิบแล้ว

## ภาพและการทดสอบ

[ดูภาพ PC / มือถือและรายงาน](previews/death-note-v0851/index.html)

ตรวจใน SillyTavern 1.19.0 ด้วย Chromium และ WebKit ทั้ง PC และหน้าจอมือถือ คำตอบ AI ใช้ controlled SSE ผ่าน Generate จริง มีการตรวจข้อมูลในคำขอที่ส่งออกและ Branch ของโฮสต์จริง

ภาพคีย์บอร์ดเป็นการจำลอง visual viewport ที่เหลือเหนือคีย์บอร์ด รวมถึงความสูง 330/440px และกรณี viewport เลื่อนตำแหน่ง ไม่ใช่ภาพจาก iPhone จริงและไม่ได้วาดคีย์บอร์ดจำลองทับภาพ ทดสอบไฟล์แชทที่ผู้ใช้ส่งด้วยตัว replay จริง โดยไม่เผยแพร่ไฟล์แชทหรือข้อมูลส่วนตัวใน repository
