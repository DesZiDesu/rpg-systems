# RoleForge 0.67.0 · ดีไซน์ในแชท

เลือกที่ **Extensions → RoleForge → Chat appearance & NPCs → Chat design** การตั้งค่าจำแยกแชท รวมอยู่ใน World Preset และการ์ดที่มี One-card setup

| ดีไซน์ | รูปทรง |
| --- | --- |
| RoleForge Original | ดีไซน์เดิม เป็นค่าเริ่มต้น |
| The Mage’s Folio | ภาพฝั่งขวา ป้ายชื่อแบบหนังสือ กรอบบทพูดโค้ง |
| The Gilded Chapter | ภาพฝั่งซ้าย ป้ายชื่อแกะสลัก กรอบบทพูดน้ำตาลทองตัดมุม |
| The Royal Codex | ภาพฝั่งขวา กรอบทองสองชั้น รางปากกาฝั่งขวา |
| Aincrad Interface | กรอบบทพูดสีเงิน แถบเลือกสีส้ม และป้าย HP/Lv สีเขียว |

ดีไซน์ใหม่ใช้ภาพตัวละครสี่เหลี่ยม 1:1 จากภาพและตำแหน่งครอปที่ตั้งไว้ ชื่อและรายละเอียดอิงสีประจำตัวผู้พูด พื้นแผ่นบทพูดคงโทนของแต่ละดีไซน์ **Header และ Narrative ไม่มีพื้นหลัง** ตัวเลือกใน Extension drawer ยังใช้หน้าตาแบบ SillyTavern ปกติ

เปิด/ปิด **Header / Dialogue / Narrative** ได้อิสระ โดยข้อความยังเรียงตามเดิม เมื่อปิด Header จะเหลือชื่อผู้พูด เมื่อปิด Dialogue จะแสดง `"text"` ด้วยสีประจำตัวผู้พูด เมื่อปิด Narrative จะแสดงตัวเอียงโดยไม่มีดอกจัน ปุ่มเสียงยังใช้ได้ และ User UI อยู่ด้านขวา

ป้ายข้อมูล Header เลือกได้จาก **อาชีพ + ระดับ NPC**, **ชื่อสกิล + ขั้นความเชี่ยวชาญ** หรือ **ซ่อน** ทุกค่ามาจากข้อมูล NPC ที่มีอยู่ หากหมวดสกิลมีหลายรายการ ให้เลือกชื่อสกิลโดยตรง ข้อมูลที่ยังไม่มีจะถูกซ่อน ใช้กับบอทที่ไม่มีเวทมนตร์ได้

ใน Aincrad เลือกแสดง **HP / Lv ของ NPC** ได้ อ่านจาก `stats.hp` และ `stats.level` โดยแสดง HP 0 และซ่อนค่าที่ไม่มีข้อมูล **เส้นใต้ HP เป็นของตกแต่ง ไม่ใช่เปอร์เซ็นต์เลือด** ไม่มีการสมมุติ HP สูงสุด

ลูกเล่นเข้าแชทของ Aincrad จบภายใน 330ms และปิดได้ที่ **Design motion effects** รองรับ Reduce Motion ของเครื่อง เล่นเฉพาะข้อความล่าสุดที่เพิ่งแสดงหรือเมื่อเปลี่ยนดีไซน์ ไม่เล่นซ้ำระหว่างสตรีม/อัปเดตข้อมูล และไม่ทำให้ทั้งประวัติแชทเคลื่อนไหวพร้อมกัน

ธีมเปลี่ยนเฉพาะ UI ของ RoleForge หน้าต่างที่ Regex/MVU สร้างใช้หน้าตาของตัวเอง ข้อความที่ Regex ซ่อนไว้จะไม่ถูกนำกลับมาแสดงซ้ำ การเปลี่ยนดีไซน์ไม่แก้ข้อความที่บันทึก ไม่เรียก AI และไม่ซิงก์สถานะข้ามระบบ

[พรีวิวมือถือ / PC](previews/chat-designs/index.html) · [พรีวิวออฟไลน์](previews/chat-designs/standalone.html) · [ดาวน์โหลด ZIP](previews/chat-designs/roleforge-chat-designs-preview.zip)

พรีวิวใช้ renderer และ CSS จริง กรอบ SillyTavern ข้อมูล NPC และข้อความด้านนอกเป็นตัวอย่าง ไม่ได้เชื่อมต่อ SillyTavern ของผู้ใช้ ปุ่มบทพากย์ในพรีวิวเปิดคำอธิบาย ปุ่มฟังปิดไว้ การฟังเสียงในส่วนเสริมจริงต้องเชื่อมต่อ Voice Addon ก่อน

ตรวจด้วย Chromium ในโฮสต์ทดสอบที่ขนาด 320/390/768/1440px รวมสวิตช์ทั้ง 8 แบบ ภาพ/ไม่มีภาพ สีตัวละคร ข้อความยาว ปุ่มเสียง การเปลี่ยนแชท Import/Export และการรักษา DOM/iframe ของ Regex/MVU ดู [บันทึกผลตรวจ](validation-chat-designs-v0.67.0.json)
