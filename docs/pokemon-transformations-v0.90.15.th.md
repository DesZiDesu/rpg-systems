# Pokémon 1.7.0 / RoleForge 0.90.15

ระบบแปลงร่างที่คุยกันเปิดใช้งานทุกหมวดเป็นค่าเริ่มต้น ไม่ต้องเปิด Mega, Tera หรือ Dynamax ทีละระบบหลังติดตั้ง ใช้กับแชทเดิมได้โดยไม่ล้าง Pokémon ไอเทม รูปแบบภาพ หรือข้อมูลรายตัว

## วิธีใช้

- **Settings → Journey tools → Transformations**: เปิด/ปิดแต่ละระบบ กำหนดเงื่อนไขอุปกรณ์ อนุญาตหลายระบบในศึกเดียว และอนุญาต Trainer ใช้ระบบแปลงร่าง
- ค่าเริ่มต้น **Require equipment เปิด**: ต้องมีอุปกรณ์ผู้ฝึกและไอเทมถือที่ตรงกัน เช่น Key Stone + Raichunite X สามารถปิดข้อกำหนดนี้เพื่อเล่นโดยไม่ต้องหาอุปกรณ์ ระบบทุกหมวดยังเปิดอยู่ทั้งสองกรณี
- **Fight → Special power → เลือกพลัง → เลือกท่า**: แปลงร่างและใช้ท่าในเทิร์นเดียว การเลือกพลังเฉย ๆ ไม่หักโควตาหรือแก้เซฟ
- **รายละเอียด Pokémon → Forms & special powers** หรือหน้า Transformations: ตั้ง Tera Type, Dynamax Level 0–10, Gigantamax Factor และเปลี่ยนร่างถาวรที่รองรับ
- **Abilities & held items**: ให้ถือ Mega Stone, Orb, Z-Crystal, Plate, Memory, Drive และหน้ากากตามที่มีในคลังจริง ไม่มีการคัดลอกไอเทม
- กติกาและการตั้งค่าพลังรายตัวเก็บเป็นเหตุการณ์ในแชทและย้อนตาม Branch กติกาของศึกที่เริ่มแล้วถูกเก็บไว้กับศึก การเปลี่ยนกติกามีผลกับศึกถัดไป ส่วนธีม Sprite/Artwork แอนิเมชัน และระดับเสียงยังเป็นค่าประจำตัวละครตามเดิม

แต่ละฝ่ายมีโควตาของตัวเอง Mega หนึ่งตัวไม่ทำให้คู่แข่งเสียสิทธิ์ เมื่อเปิด Multiple systems สามารถใช้คนละระบบกับคนละตัวในศึกเดียวได้ ไม่ซ้อน Mega/Tera/Dynamax บน Pokémon ตัวเดียว Primal เป็นการคืนร่างจาก Orb ไม่บังคับโควตา Mega

เพิ่ม Electric/Grassy/Psychic/Misty Terrain, สภาพอากาศของ Primal, Ability ที่เกี่ยวข้องกับร่างและท่า เช่น Electric Surge, Pixilate, Aerilate, Mega Launcher, Skill Link, Parental Bond, Magic Bounce และ Neuroforce รวมถึงท่าหลายครั้งที่รองรับ ร่างที่เปลี่ยนจึงมีผลต่อการต่อสู้ ไม่ใช่เปลี่ยนรูปอย่างเดียว

Trainer ใช้ตาม loadout ที่เปิดเผยในคำท้าและผ่านการตรวจหลักฐาน AI ต้องระบุ Pokémon ร่าง อุปกรณ์ถือ และอุปกรณ์ผู้ฝึกในคำบรรยายจริง ไม่หยิบของจากกระเป๋าผู้เล่นหรือสร้างทีมลับขึ้นเอง Main chat ได้รับร่างที่กำลังใช้ ประเภท Ability ท่า Max/Tera สภาพสนาม โควตา และผลที่เครื่องคำนวณแล้ว

## จุดในภาพที่แก้

**Pokédex ค้นหาหน่วง:** ก่อนหน้านี้ทุก input สั่ง render dialog ใหม่ รวมช่องค้นหา ภาพและเมนู แล้วค่อย focus ช่องใหม่อีกครั้ง ทำให้การพิมพ์บนมือถือสะดุด รุ่นนี้เก็บช่องค้นหาเดิมและเคอร์เซอร์ไว้ อัปเดตเฉพาะผลค้นหาหลังหยุดพิมพ์ 90 ms รองรับ composition/IME และยังแสดงครั้งละ 24 รายการ

**เลื่อนซ้าย–ขวา:** บังคับกริดมือถือเป็น `minmax(0,1fr)` สองคอลัมน์ แก้ความกว้างขั้นต่ำ การตัดคำ ขนาดภาพ และหัวข้อพร้อมตัวนับ แก้ต้นเหตุร่วมกับจำกัด scrollport ให้เลื่อนแนวตั้ง ตรวจทุกหน้าหลักและหน้าเครื่องมือทั้ง Original/Aperture

**Journey:** จัดปุ่มให้ห่อบรรทัดตามพื้นที่ เอาวงรีของ artwork ที่ลอยผิดตำแหน่งเมื่อใช้ Sprite ออก ตัวหมดสภาพมีป้าย Fainted และภาพลดสี หยุด idle และไม่ให้เริ่ม Explore เมื่อทั้งทีมหมดสภาพ

**รายละเอียด / Evolution:** การ์ดวิวัฒนาการและป้าย Reference ใช้พื้นกับข้อความของธีมจริง แก้พื้นขาวกับข้อความสีอ่อนใน Aperture ป้าย Hidden Ability เป็นป้ายโปร่งที่อ่านได้แทนสี่เหลี่ยมทึบ

## เซฟและความเข้ากันได้

เก็บร่างฐานและ Ability เดิมแยกจากร่างต่อสู้ คืนร่างเมื่อจบศึก หนี ยอมแพ้ หรือหมดสภาพตามประเภทของระบบ รักษา UID ชื่อเล่น Shiny เพศ Nature IV/EV ท่าและ PP ไม่สร้าง Pokémon ใหม่จากการแปลงร่าง การรวมร่างเก็บคู่เดิมไว้จริง ไม่ลบทิ้งหรือสร้างสำเนาคืน

เก็บกติกาเครื่องรุ่น 1.6 ไว้สำหรับ replay เหตุการณ์ engine 1–3 การกระทำใหม่ใช้ engine 4 แชทเก่าจึงไม่ถูกคำนวณใหม่ด้วย Ability หรือชุดท่าที่เพิ่งเพิ่มกลางประวัติ ทดสอบกับ snapshot จาก commit `b27d26e42a7200bb2fa3702994a6a39b3117a88c`: 73 จังหวะของ 8 สายพันธุ์ได้ผลเดิม เมื่อผู้เล่นทำการกระทำใหม่ในศึกเก่าที่ยังค้างอยู่ จะเริ่มใช้กติกาใหม่จากจังหวะนั้น

การบันทึกยังรอ server acknowledgement เมื่อสลับสไวป์ แก้/ลบข้อความ หรือเปลี่ยน Branch จะเล่นประวัติใหม่และคืน/ยกเลิกพลังตามเหตุการณ์ที่ยังอยู่ ไม่มีการแปลงข้อมูลเซฟเป็นร่าง Mega ถาวร

## ขอบเขตที่ยังต้องแยกให้ชัด

รองรับหมวดระบบข้างต้น แต่ยังไม่ใช่ตัวจำลองการแข่งขันครบทุกกติกา ท่าที่ engine เดิมยังไม่รองรับ เช่น charge/recharge และ forced switching บางท่ายังถูกล็อก ไม่อ้างว่าทุก Ability ทำงานครบแล้ว รายการ Ability ที่ไม่มีผลยังระบุเป็น Reference ใน UI ความสามารถที่ต้องมีคู่ต่อสู้แบบ doubles เช่น Commander ยังไม่มีบริบททำงาน

G-Max Gold Rush ยังไม่จ่ายเงินเข้าระบบสกุลเงิน, Furfrou trim expiry และการคืนร่างนอกศึกตามเวลาบางภาคยังไม่จำลอง ไม่มี PvP, doubles, breeding, เครือข่ายแลก Pokémon หรือเส้นทางยิมครบทุกภูมิภาคเพิ่มในรุ่นนี้ ร่างภูมิภาค เพศ ขนาด และสายพันธุ์ย่อยที่เปลี่ยนสลับกันไม่ได้จะไม่ถูกแปลงฟรีด้วยปุ่มเปลี่ยนฟอร์ม

ภาพและข้อมูลอิง snapshot เดิมของ PokeAPI; กติกาอุปกรณ์ Z/Max และข้อมูลประกอบอิง Pokémon Showdown revision `ccfaa20f32af363569cd21a9d501b2bc1ded26b1` มีเครดิตและเครื่องมือสร้างซ้ำ บางรายการในแหล่งข้อมูลมีสถานะ provisional/future ไม่ใช่การยืนยันว่าเล่นได้ในทุกเกมทางการ

ยังไม่ได้ทดสอบบน iPhone/Safari เครื่องจริงหรือกับโมเดล/API ของผู้ใช้ ผลตรวจมือถือในรายงานนี้เป็น browser emulation ไม่ใช่การรับประกันอุปกรณ์ทุกเครื่อง
