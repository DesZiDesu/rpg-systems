# Alternate Information ของ NPC และ Extension Drawer — 0.46.0

NPC หนึ่งตัวเก็บได้ทั้งข้อมูลหลักและเวอร์ชันอื่น เช่น **คอร่า · วัยเด็ก**, **คอร่า · วัยผู้ใหญ่** หรือ **คอร่า · หลังเข้ากิลด์** แต่ยังเป็น NPC ตัวเดิมในคลัง ไม่ต้องสร้างตัวละครชื่อซ้ำเพื่อเก็บแต่ละช่วงชีวิต

ผู้เล่นเลือกเวอร์ชันที่ใช้อยู่เอง รูปและข้อมูลของเวอร์ชันนั้นจึงใช้ในหน้าข้อมูล NPC และเป็นข้อมูลอ้างอิงของ AI สำหรับคำตอบถัดไป การเลือกเวอร์ชันไม่ได้ย้อนเวลาในเรื่องหรือแก้ข้อความเก่าที่บันทึกไว้

## ข้อมูลหลักกับข้อมูลแต่ละเวอร์ชัน

| ข้อมูล | วิธีเก็บ |
| --- | --- |
| ตัวตนของ NPC | ใช้รหัส NPC ชื่อ ชื่อเรียกอื่น สถานะเคยพบ และสถานะ Hostile ร่วมกันทุกเวอร์ชัน |
| ข้อมูลช่วงชีวิต | แยกอายุ รูปลักษณ์ บุคลิก ภูมิหลัง เป้าหมาย วิธีพูด อาชีพ สังกัด สถานที่ กิจกรรม และรายละเอียดความสัมพันธ์ได้ |
| ค่าสถานะและความสามารถ | แยก Stats, ค่าความสัมพันธ์, Abilities และมาตรวัดเพิ่มเติมของแต่ละเวอร์ชันได้ |
| รูปและรูปแบบหัวตัวละคร | แต่ละเวอร์ชันมีรูป กรอบภาพ สี และสัญลักษณ์ของตัวเองได้ |
| การเชื่อมโยงและประวัติเดิม | รายชื่อผู้ติดต่อ กลุ่ม Knowledge และ NPC Diary ยังอ้าง NPC ตัวเดิม ไม่เพิ่มสมาชิกอีกคนหรือสร้างคลังความจำแยกเพราะเพิ่มเวอร์ชัน |

**ข้อมูลหลัก / เวอร์ชันต้นฉบับ** คือข้อมูล NPC ที่มีอยู่ก่อนเพิ่ม Alternate Information และยังอยู่ให้เลือกใช้เสมอ การแก้ชื่อหรือชื่อเรียกอื่นให้ทำในข้อมูลหลัก เพราะเป็นตัวตนร่วมกัน ไม่ใช่ชื่อใหม่ของแต่ละช่วงชีวิต

ข้อมูลแต่ละเวอร์ชันเก็บเฉพาะค่าที่เวอร์ชันนั้นกำหนดไว้ ถ้าไม่ได้กำหนดฟิลด์ใด ระบบใช้ค่าของข้อมูลหลักสำหรับฟิลด์นั้น ส่วน Stats รวมค่าที่กำหนดเฉพาะเวอร์ชันเข้ากับ Stats ของข้อมูลหลัก เมื่อเพิ่มเวอร์ชันโดยเลือก **เริ่มจากข้อมูลของเวอร์ชันปัจจุบัน** จะคัดลอกข้อมูลที่รองรับจากเวอร์ชันที่กำลังใช้อยู่มาเป็นจุดเริ่มต้น แล้วแก้ให้ตรงกับช่วงชีวิตใหม่ได้

## เพิ่มเวอร์ชันช่วงชีวิต

1. เปิด **Extension Settings → RoleForge → NPC Management** แล้วเลือก NPC เดิมจากรายการ
2. ในหน้ารายละเอียด หา **ALTERNATE INFORMATION / ตัวละครเดียว · หลายช่วงชีวิต**
3. กด **＋ เพิ่มเวอร์ชัน**
4. กรอก **ชื่อเวอร์ชัน** เช่น `วัยเด็ก · อายุ 12 ปี`
5. กรอก **ช่วงเวลาหรือเงื่อนไขของเวอร์ชันนี้** เช่น `ช่วงก่อนย้ายเข้าเมือง ยังไม่รู้จักผู้เล่น` ข้อความนี้ช่วยระบุว่าเวอร์ชันมีไว้สำหรับช่วงไหน
6. เลือก **เริ่มจากข้อมูลของเวอร์ชันปัจจุบัน** หากต้องการนำข้อมูลเดิมมาแก้ต่อ หากปิดช่องนี้ เวอร์ชันใหม่เริ่มด้วยข้อมูลข้อความและ Abilities ว่าง พร้อมค่าสถานะเริ่มต้น แล้วให้กรอกข้อมูลที่เหมาะกับช่วงนั้นเอง
7. กด **สร้างแล้วแก้ไข** ระบบบันทึกเวอร์ชันใหม่และเลือกใช้เวอร์ชันนั้น จากนั้นเปิดแบบฟอร์มให้แก้ไข
8. แก้อายุ รูปลักษณ์ บุคลิก ภูมิหลัง Stats และ Abilities ให้เหมาะกับช่วงนั้น เลือกรูปของช่วงนั้นและจัดกรอบภาพได้ในแบบฟอร์มเดียวกัน
9. กด **บันทึกเวอร์ชันนี้** แล้วตรวจข้อความสถานะว่าบันทึกสำเร็จ

ระบบรองรับเวอร์ชันเพิ่มเติมได้สูงสุด **20 เวอร์ชันต่อ NPC** นอกเหนือจากข้อมูลหลัก

หากกด **ยกเลิก** ในหน้าตั้งชื่อ ยังไม่สร้างเวอร์ชัน หากกด **สร้างแล้วแก้ไข** ไปแล้วและออกจากแบบฟอร์มโดยทิ้งการแก้ไข เวอร์ชันที่สร้างยังอยู่ แต่ค่าที่แก้ในแบบฟอร์มยังไม่บันทึก ควรกรอกอายุและข้อมูลสำคัญให้ครบก่อนเล่นต่อ หากไม่ต้องการเวอร์ชันนั้นให้ลบจากหน้ารายละเอียด

## เลือกเวอร์ชันระหว่างเล่น

1. เปิดรายละเอียด NPC ตัวเดิม
2. ที่ **เวอร์ชันที่ใช้ตอนนี้** เลือกเวอร์ชันที่ต้องการ เช่น `วัยเด็ก · อายุ 12 ปี`
3. ตรวจรูปและข้อมูลในหน้ารายละเอียดว่าเป็นช่วงที่เลือก
4. เล่นต่อโดยระบุช่วงเวลาของเรื่องให้ตรงกับเวอร์ชันที่เลือก เช่น `ย้อนกลับไปช่วงที่คอร่าอายุ 12 ปี`
5. เมื่อกลับมาเล่นช่วงปัจจุบัน เลือก **ข้อมูลหลัก / เวอร์ชันต้นฉบับ** หรือเวอร์ชันช่วงปัจจุบันที่เตรียมไว้

การเลือกเวอร์ชันบันทึกเป็นการเลือกของผู้เล่นและปรับข้อมูลอ้างอิงสำหรับ AI ในคำตอบถัดไป การคลิกเลือกไม่ได้สั่งให้ AI เจนคำตอบเองหรือทำให้เวลาของฉากเปลี่ยนโดยอัตโนมัติ

Alternate Information แยกข้อมูลตัวละครแต่ละช่วง แต่ไม่ได้แยกประวัติแชตหรือความจำที่เคยบันทึกของ NPC ทั้งหมด การเล่นย้อนอดีตจึงควรระบุเวลาของฉากและสิ่งที่ตัวละครรู้ในช่วงนั้นให้ชัดเจนด้วย

## แก้ข้อมูลและรูป

เลือกเวอร์ชันที่ต้องการก่อน แล้วกด **แก้ไขเวอร์ชันนี้** การแก้ในฟอร์มเป็นร่างจนกด **บันทึกเวอร์ชันนี้** การออกจากฟอร์มโดยทิ้งการแก้ไขจึงไม่เขียนทับข้อมูลที่บันทึกไว้เดิม

ถ้าเวอร์ชันยังไม่มีรูปของตัวเอง จะใช้รูปจากข้อมูลหลัก เมื่ออัปโหลดรูปใหม่ รูปนั้นเก็บแยกสำหรับเวอร์ชันที่แก้ รูปข้อมูลหลักและเวอร์ชันอื่นยังอยู่ตามเดิม

- **ลบภาพ**: กำหนดให้เวอร์ชันนั้นไม่มีภาพ ไม่ลบภาพของข้อมูลหลักหรือเวอร์ชันอื่น
- **ใช้ภาพหลัก**: ยกเลิกการกำหนดภาพเฉพาะเวอร์ชัน แล้วกลับไปใช้ภาพของข้อมูลหลัก

เมื่อต้องการเปลี่ยนภาพข้อมูลหลัก ให้เลือก **ข้อมูลหลัก / เวอร์ชันต้นฉบับ** ก่อนเข้าแก้ไข

## ลบเวอร์ชัน

1. เลือกเวอร์ชันที่ต้องการลบในรายละเอียด NPC
2. กด **ลบเวอร์ชันนี้** แล้วอ่านชื่อเวอร์ชันในหน้าต่างยืนยัน
3. ยืนยันการลบ ระบบกลับมาใช้ข้อมูลหลัก

การลบเวอร์ชันไม่ลบ NPC ทั้งตัว และไม่ลบข้อมูลหลักหรือเวอร์ชันอื่น ถ้าต้องการลบ NPC ทั้งตัวให้ใช้ **ลบตัวละคร** ซึ่งเป็นคนละการทำงาน

## AI ใช้และพัฒนาข้อมูลอย่างไร

1. RoleForge อ่านเวอร์ชันที่ผู้เล่นเลือกอยู่
2. เตรียมข้อมูล NPC จากข้อมูลหลักรวมกับค่าของเวอร์ชันนั้น
3. แนบข้อมูลที่ใช้งานให้ AI ตามการตั้งค่าการแนบสถานะเดิม พร้อมชื่อเวอร์ชันที่มี ข้อมูลเต็มของชีวประวัติทุกเวอร์ชันไม่ได้แนบรวมกัน
4. AI สร้างคำตอบตามปกติ หากมีข้อมูลอัปเดตของ NPC ใน state patch ที่ระบบรองรับ ข้อมูลที่แยกต่อเวอร์ชันจะอัปเดตเวอร์ชันที่กำลังใช้อยู่
5. เวอร์ชันอื่นยังเก็บข้อมูลเดิม จึงกลับไปเลือกเล่นช่วงนั้นต่อได้

AI ไม่สร้าง ลบ หรือเลือกเวอร์ชันเอง การกล่าวว่า NPC โตขึ้นในเรื่องจึงไม่ได้ทำให้ระบบเปลี่ยนจากเวอร์ชันวัยเด็กเป็นวัยผู้ใหญ่โดยอัตโนมัติ ผู้เล่นต้องสร้างหรือเลือกเวอร์ชันที่ต้องการก่อน ส่วนชื่อ สถานะ Hostile และข้อมูลตัวตนร่วมยังอัปเดตตามระบบ NPC เดิม

การติดตามยังขึ้นกับการตั้งค่าและข้อมูลที่ AI ส่งมา ถ้าปิดการแนบสถานะหรือการติดตามอัตโนมัติ ระบบจะทำงานตามสวิตช์นั้น การมี Alternate Information ไม่ได้เพิ่มคำขอ AI แยกเอง การใช้ปุ่มช่วยเจนข้อมูลใน NPC Management ยังคงเรียก AI ตามการทำงานเดิมของปุ่มนั้น

## Chat กับ Character และการย้ายแชต

**Chat · เฉพาะแชตนี้** เก็บ NPC และเวอร์ชันของมันในแชตที่กำลังเล่น ไม่ทำให้ NPC ตัวนี้กลายเป็นรายการร่วมของทุกแชตเพียงเพราะเพิ่มเวอร์ชัน

**Character · ผูกกับการ์ด** เก็บ NPC และชุดเวอร์ชันในคลังของการ์ดเดิม ใช้ร่วมกันได้ในแชตของการ์ดนั้น การแก้ผ่าน NPC Management ใน Character จึงเป็นการแก้คลังร่วม ส่วนพัฒนาการจากการเล่นแชตเก็บเป็นค่าที่เปลี่ยนเฉพาะแชตนั้น รายการเวอร์ชันที่ไม่ได้เปลี่ยนไม่ได้ถูกคัดลอกทับทั้งชุดในแต่ละแชต

ก่อนย้ายแชต ให้ตรวจแหล่งข้อมูลของ NPC และการตั้งค่า **Continue the same character state into new chats** ตามการใช้งานเดิม หากต้องการใช้ NPC เดิมในหลายแชตของการ์ดเดียวกัน ให้จัดเก็บใน Character การมีเวอร์ชันเพิ่มเติมไม่ได้เปลี่ยน NPC ที่อยู่ใน Chat ให้ย้ายไป Character เอง


## สำรองข้อมูลและภาพ

การสร้างสำเนาไปอีก Scope เก็บทุกเวอร์ชันและรูปของแต่ละเวอร์ชันไว้ รูปที่เคยเก็บในอุปกรณ์จะอัปโหลดเป็นลิงก์บนเซิร์ฟเวอร์ก่อนสร้างสำเนา หากอ่านภาพเดิมไม่ได้ ระบบจะแจ้งปัญหาและยังไม่สร้างสำเนาที่มีภาพไม่ครบ ปุ่มสำรองภาพเก่าครอบคลุมทั้งภาพหลักและภาพของเวอร์ชันเพิ่มเติม

ไฟล์ส่งออกข้อมูล RoleForge เก็บรายละเอียดทุกเวอร์ชันและเวอร์ชันที่เลือก แต่ไม่รวมไฟล์ภาพจริง รูปที่อัปโหลดบนเซิร์ฟเวอร์มี reference อยู่ในข้อมูลและใช้ต่อได้บนเซิร์ฟเวอร์เดิม รูปที่เก็บเฉพาะในอุปกรณ์ไม่ติดไปกับไฟล์ JSON ให้สำรองไปเซิร์ฟเวอร์ก่อน หรือเลือกอัปโหลดใหม่เมื่อย้ายเซิร์ฟเวอร์

## Extension Drawer จัดไว้ตรงไหน

เปิด **Extension Settings → RoleForge** แล้วใช้ปุ่ม **Open RoleForge** หรือ **Sync latest turn** ด้านบนสำหรับงานที่ใช้บ่อย การตั้งค่าถูกแยกเป็นหมวด โดยตัวเลือกละเอียดเปิดดูเฉพาะเมื่อต้องการได้

| หมวด | ใช้ตั้งค่าอะไร |
| --- | --- |
| General & continuity | ภาษา ปุ่มเข้าใช้งาน และการสานต่อสถานะตัวละครไปแชตใหม่ |
| Story tracking | การติดตามจากคำตอบปกติ การแนบสถานะ และวิธีส่งคำสั่งจาก UI |
| Chat appearance & NPCs | NPC Management, Header / Dialogue / Narrative, เอฟเฟกต์บทสนทนา, การรักษาหน้าตา regex / HTML, Scene Tracker, Travel Tracker และความถี่ NPC Diary |
| ระบบเสริม | เปิดเฉพาะระบบเล่นที่ต้องการ เช่น Mission Board, Auctions และระบบความจำ |
| Notifications | เปิดการแจ้งเตือน แล้วขยายตัวเลือกเพื่อเลือกหมวดเหตุการณ์ |
| Interface appearance | สี ความหนาแน่น ความโปร่ง และเอฟเฟกต์ออร่า |
| World rules & presets | Power Presets และ Character Forge Presets |
| Writing preferences | ตัวเลือกแนวการเขียน แท็ก และ prompt ที่ผู้เล่นกำหนด |
| Diagnostics & tracking guide | จำนวนคำขอ AI และคำอธิบายการติดตามข้อมูล |

การจัดหน้าใหม่ใช้การตั้งค่าที่บันทึกไว้เดิม สวิตช์ที่เคยเปิดหรือปิดยังคงใช้ค่านั้น ระบบเสริมที่ยังไม่เคยเปิดยังเริ่มปิดตามเดิม
