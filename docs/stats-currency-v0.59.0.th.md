# RoleForge 0.59.0 — Stats, Tactical Strip และค่าเงิน 8-bit

อัปเดตนี้รวมการฝึกสถิติ ระบบค่าเงิน และการแก้ Character Forge พร้อมดีไซน์ที่ผู้ใช้อนุมัติ

## Status / Training

ใช้ **C · Tactical Strip** เป็นค่าเริ่มต้นทั้งสองหน้าต่าง เก็บ **A · Character Dossier** และ **B · Vital Core** ไว้ให้เลือกแยกกันได้ที่ `Extensions → RoleForge → User stats` กรอบ หัวแถบ และปุ่มใช้ชุดเดียวกับ Incantation สีแถบพลังอิงธีม RoleForge ส่วนตั้งค่าใน extension drawer ใช้รูปแบบของ SillyTavern

Status แสดง HP / MP / ST / Hunger / Thirst พร้อมชื่อ เลเวล สภาพตัวละคร อาชีพ สถิติ Party/Guild สถานที่ และเงิน สถิติ custom ที่เปิดแสดงยังอยู่ครบ หน้าฝึก C แสดงสถิติ วิธีฝึก ค่าปัจจุบัน และขอบเขตการเพิ่ม ส่วนรายละเอียดวิธีและเงื่อนไขเปิดดูเพิ่มได้

การกดฝึกและการพิมพ์ฝึกเองในแชทใช้ระบบเดียวกัน HP / MP / ST เพิ่มค่าสูงสุดถาวรเมื่อ AI ยืนยันว่าฝึกสำเร็จ ไม่เติมค่าปัจจุบันทันที INT / STR / DF / AG เพิ่มค่าตัวเลข มีสถิติ custom พร้อมความหมาย วิธีฝึก ช่วงค่า หน่วยและขอบเขตการเพิ่ม การคลิกเลือก วิธีฝึกที่ล้มเหลว คำถาม และแผนอนาคตไม่เพิ่มค่า ผลที่อ่านข้อความซ้ำไม่เพิ่มซ้ำ

แจ้งเตือน SillyTavern หลังบันทึกผลสำเร็จเท่านั้น การบันทึกล้มเหลวย้อนค่าและไม่แจ้งว่าฝึกสำเร็จ ฟอร์มที่กำลังแก้ไม่ถูกข้อมูลสดเขียนทับ การส่งฝึกที่จบหลังปิดแชทไม่เปิดแผงเก่ากลับขึ้นมา

หน้าต่างเหนือช่องพิมพ์เริ่มแบบย่อเมื่อเปิดโปรแกรมใหม่หรือเข้าแชท งานซื้อขายและรายการค้างยังอยู่ครบ

## เงินและไอคอน

ตั้งระบบเงินของแชทนี้ได้ 1–3 หน่วย พร้อมชื่อ สัญลักษณ์ ชื่อเรียกอื่น อัตราแลก รูปทรง ชุดไอคอนและสีของแต่ละหน่วย อัตราเป็นจำนวนเต็มที่แปลงลงหน่วยเล็กถัดไปได้พอดี หน่วยเล็กสุดมีค่า 1

เปลี่ยน preset หรืออัตราแล้วเก็บมูลค่าเดิมในหน่วยเล็กสุด ทั้งเงินผู้เล่น เงิน Party และคลัง Guild ชื่อและอัตราใหม่เชื่อมกับร้านค้า ซื้อ/ขาย ประมูล ค่าธรรมเนียม มัดจำ คืนเงิน และบันทึกธุรกรรม ถ้ามีธุรกรรมหรือมัดจำค้าง จะต้องจบก่อนเปลี่ยนความหมายของเงิน แต่ยังเปลี่ยนรูปลักษณ์ไอคอนได้

ทั้ง 8 ชุดเป็น **SVG พิกเซล 8-bit แบบสี่เฟรม** ชุดแรกคงทรงเหรียญซ้อนที่อนุมัติไว้ ไม่มีแสงเบลอหรือเส้นโค้งในตัวไอคอน การเคลื่อนไหวใช้ CSS ไม่ใช้ timer JavaScript และเก็บรูปทรงที่ใช้ร่วมกันใน cache รองรับปิดแอนิเมชันและ Reduce Motion

| ชุด | รูปร่างและการขยับ | รหัสเดิมที่เก็บไว้ |

รหัสหน่วยเงินและชุดไอคอนเดิมยังใช้ได้ ข้อมูลเก่าที่ไม่มี currency scheme ใช้ชุดไอคอนส่วนกลาง ส่วนข้อมูลที่ตั้งแยกแต่ละหน่วยแล้วคงชุดของหน่วยนั้น การแปลงและทำ change ใช้การหารจำนวนเต็มแบบแม่นยำ ยอดที่เกินขอบเขตตัวเลขจะไม่ถูกบันทึกหรือจ่ายออก

## การตรวจและปัญหาที่แก้เพิ่ม

- Unit / host tests ผ่าน **1,155/1,155** ครอบคลุมขอบเขตสถิติ การฝึกซ้ำ การบันทึกล้มเหลว เงินเดิม การเปลี่ยนอัตรา ธุรกรรม มัดจำ/คืนเงิน และพิกเซลทุกชุด/รูปทรง
- Syntax checks และ release cache keys ใช้เวอร์ชัน 0.59.0 ตรงกัน
- Production browser ตรวจที่ **320 / 390 / 1280 px** ครบ A/B/C ทั้ง Status และ Training รวมวิธีฝึกจริง สถิติ custom การซ่อนปุ่ม native settings การสลับแชท โหลดใหม่ และการไม่ล้นจอ
- ตรวจว่าไอคอนเงินเดินเฟรมจริงใน dock สีแต่ละหน่วยทำงาน และ Reduce Motion หยุดที่เฟรมแรกครบทุกชุด
- แก้การเลือกชุดไอคอนส่วนกลางที่กระเป๋าเงินแบบเก่าอาจไม่เปลี่ยนตาม และป้องกันกรอบ Incantation ส่งสีเส้น stroke เข้าไปทำให้พิกเซลขอบมน
- ตรวจการเช่าจริงผ่านแชทด้วย Dollar/Cent อัตรา 10:1 จนจ่ายค่าเช่าและมัดจำ รับไอเทม และสร้างสิทธิ์ได้ โดยไม่ต้องเรียก AI เติมข้อมูลเพิ่ม
- Browser regression ผ่าน **20 suites** รวม Incantation ไอเทม/Loot ร้านค้า สต็อก/ส่วนลด การกู้รายการ สิทธิ์เช่า การประมูล Character Forge ข้อความฝั่ง User Voice MP3 native drawer และ startup; ดู [ผลตรวจแต่ละชุด](validation-stats-currency-v0.59.0.json)
- ตรวจซื้อขายผ่านโรลและปุ่มต่อเนื่อง รวมการยกเลิกระหว่างรอ API การคงยอดเสนอของ NPC การจ่ายครั้งเดียว กระดานภารกิจ/Party และราคาผสม
- Assertion เก่าของ combined commerce/inn ให้ผลเหมือนกันบน main เดิม 0.58.15 จึงปรับ fixture ให้ใช้คำสั่งซื้อชัดเจน เปิดแถบที่ย่อ และจับ prompt ระหว่าง generation จริง คงการตรวจยอดเงิน ไอเทม และจำนวน API ครบ แล้วทั้งสองชุดผ่านที่ 320/390/1280 px

การเรียกโมเดลและ Voice ใช้คำตอบ/ข้อมูลจำลอง ไม่ใช้ API แบบเสียเงิน การตรวจนี้ไม่ได้ยืนยัน Proxy รุ่นที่ผู้ใช้เรียกว่า “3.8” เพราะยังไม่มีชื่อโมเดลเต็มหรือรายละเอียด HTTP 400 จากผู้ให้บริการ การแก้รูปแบบคำขอ Forge ใช้ hook ทางการของโฮสต์เฉพาะการเริ่มเรื่องและคงข้อมูล draft; ดู [รายละเอียด](forge-opening-proxy-pending.th.md) ยังไม่ได้ตรวจ Safari บน iPhone จริง
