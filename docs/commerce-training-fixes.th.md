# RoleForge 0.55.2 · ซื้อขายและการฝึกความเข้าใจ

อัปเดตส่วนเสริมแล้วรีโหลดหน้า SillyTavern เพื่อโหลดโค้ดและ CSS รุ่นเดียวกัน ไม่ต้องล้างข้อมูลแชตหรือ API key

## ซื้อขายจากคำตอบเดียว

ข้อความผู้เล่นที่ใช้ตรวจสอบตรงกับข้อความที่รายงาน:

> ฉันพยักหน้าก่อนจะจ่ายตังขอซื้อห้องพัก 1 คืน
>
> “เท่าไหร่ครับสำหรับ 1 คืน”

ข้อความนี้ผ่านการตรวจเจตนาซื้อ ปัญหาคือคำตอบไม่มี marketplace patch จริง และตัวอ่านบทพูดเดิมรับรูปประโยคได้จำกัด โดยเฉพาะเมื่อ NPC เปลี่ยนจาก “คืนละ…” เป็น “ราคา…” และบอกเงื่อนไขในบทพูดถัดไป

ตัวอ่านใหม่แยกผู้พูด ตัวเลือก ราคา และเงื่อนไขจากบทพูดสาธารณะของคำตอบที่จบแล้ว ข้อมูลจาก patch และบทพูดผ่านจุดตรวจเปิดรายการเดียวกัน ราคาใน patch ต้องตรงกับรายการและบทพูดผู้ขาย ถ้าข้อมูลขัดกันจะไม่แทนที่ด้วยราคาใหม่โดยเงียบ ๆ บันทึก commerceOpening ในข้อมูลเหตุการณ์ของคำตอบเพื่อระบุแหล่งและผลการตรวจ

กรณีภาพล่าสุดเปิดห้องพักธรรมดา ราคา **5 เงิน** ได้ทันที พร้อมกุญแจห้องพักธรรมดา น้ำร้อนที่รวมอยู่ และเงื่อนไข **ไม่รวมอาหารเช้า** เก็บระยะหนึ่งคืนโดยไม่เดาเวลาเช็กเอาต์หรือเปลี่ยนหนึ่งคืนเป็น 24 ชั่วโมง เก็บสิทธิ์เช่า ไม่เปลี่ยนเป็นกรรมสิทธิ์ถาวร

ไม่อ่าน CoT เป็นหลักฐานธุรกรรม ไม่เรียก AI เพิ่มเพื่อสร้างรายการเปิดซื้อขาย ข้อมูลที่ไม่มีในคำตอบ เช่น จำนวนห้องในสต็อกหรือค่าพลังลับ ยังแสดงว่าไม่ทราบ การกดยืนยัน/เสนอ/ยกเลิกยังใช้คำขอเดิมของระบบและมีแจ้งเตือน API ตามเดิม ยืนยันแล้วจึงหักเงิน ส่งกุญแจ และต่อโรลด้วย narrative/dialogue

การพูดถึงซื้อ/ขายเฉย ๆ การปฏิเสธ ร้านที่ยังไม่เปิด ราคาไม่ตรง ผู้ขายไม่ตรง และของที่ผู้เล่นไม่ได้ครอบครอง ยังไม่เปิดรายการซื้อขาย ส่วนระบบประมูลใช้เส้นทางเดิม

## ข้อ 3 · ความเข้าใจ

เมื่อฝึกวิชาหรือทักษะที่ไม่มีคำอธิบายหรือข้อมูลการทำงาน ข้อ 3 ขอ **ผลฝึกและ abilityDetails ในคำขอฝึกครั้งเดียว** รายละเอียดครอบคลุมการทำงาน เงื่อนไข Cost, Cooldown จุดแข็ง/จุดอ่อน และบทร่ายตามชนิดวิชาและ canon ข้อมูลที่ยังไม่ทราบใช้สถานะไม่ทราบ ไม่ตั้งค่าเป็นศูนย์

ตรวจ targetId ให้ตรงกับวิชาเดิม เติมเฉพาะช่องว่าง เก็บรายละเอียดและ Mastery ที่มีไว้ ไม่เพิ่มรายการวิชาใหม่ ไม่หักทรัพยากรจากการอ่านรายละเอียด และไม่ให้ Mastery เพิ่มซ้ำจากการเขียนข้อมูล ทักษะกายภาพ/ดาบไม่ได้รับบทร่ายอัตโนมัติ การอธิบายรายละเอียดไม่ปลดล็อกร่ายไร้เสียง

บันทึกรายละเอียดและผลฝึกพร้อมกัน แล้วแสดง **บันทึกรายละเอียดวิชา / ทักษะแล้ว** ในหน้าต่างฝึก อ่านข้อมูลที่บันทึกได้จากหน้าวิชา/ทักษะ หาก AI ส่งผลฝึกที่ถูกต้องแต่ไม่ได้ส่งรายละเอียดครบ จะแจ้งให้เห็นตรงนั้นและเก็บข้อมูลเดิม ไม่มีคำขอแก้อัตโนมัติ หากจบการฝึกระหว่างรอ ผลที่มาทีหลังไม่ถูกบันทึก

## มือถือและหน้าต่างหลายระบบ

ผลฝึกตัดบรรทัดทั้งคำอธิบายและเหตุผล รวมข้อความยาวติดกัน ไม่ล้นไปด้านขวา แม้ธีมโฮสต์ตั้งข้อความเป็น nowrap ฟิลด์ที่ให้ผู้เล่นอ่านในคำขอฝึกระบุให้ใช้ภาษาที่ตั้งไว้ทั้งหมด

เมื่อมีหน้าต่างฝึกเปิดอยู่ ข้อเสนอซื้อที่ตรวจผ่านจะเพิ่ม Tab ซื้อ และเปิดหน้าต่างนั้นโดยเก็บการฝึกเดิมไว้ สลับกลับได้ การย่อยังเป็นแถบแบนตามเดิม

## หลักฐานการตรวจ

ทดสอบผ่าน loader, interceptor, MESSAGE_RECEIVED / GENERATION_ENDED และ composer จริง ด้วยคำตอบ AI ที่ควบคุมไว้ ไม่ได้ทดสอบกับบัญชีโมเดลของผู้ใช้:

- 795 unit/host tests และ syntax checks
- จอ 320, 390 และ 1280px: ข้อเสนอห้องพักล่าสุดโดยไม่มี patch ขณะเปิดฝึก ไม่มี API เปิดรายการเพิ่ม ยืนยันหัก 5 เงินและได้กุญแจ ไม่มีเวลาเช็กเอาต์ที่เดาขึ้น
- ปุ่มความเข้าใจบันทึก Fire Ball พร้อมผลฝึกด้วย API หนึ่งครั้ง ดูข้อมูลที่บันทึกจากหน้าวิชาได้ และเหตุผลยาวไม่ล้นจอ
- ซื้อของทั่วไป ขายหลายชิ้นโดยตัดบางชิ้นออก การหักเงิน/โอนของครั้งเดียวและ duplicate event
- ระบบเช่า/สิทธิ์เข้าใช้/ซื้อถาวร งานบริการ มัดจำ การคืนสิทธิ์ และการยกเลิกผลฝึกที่กำลังรอ
