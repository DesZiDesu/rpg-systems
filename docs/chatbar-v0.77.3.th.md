# UI เหนือ Chatbar — RoleForge 0.77.3

เลื่อนแท็บซ้าย–ขวาได้โดยไม่เปลี่ยนคำตอบแชท ปุ่มสี่ช่องเปิดแผงเลือกหน้าต่างของ RoleForge แทน native dropdown ของ iOS เลือกหน้าต่างแล้วกลับมาใช้งานได้ทันที ปิดแผงด้วยปุ่มปิด แตะด้านนอก หรือ Escape ได้ การย่อและเปิดกลับยังเก็บหน้าต่างและข้อความร่างไว้

เปลี่ยนไอคอนฝึกวิชาและชุดไอคอนสถานะเป็น Font Awesome ที่ SillyTavern มีอยู่แล้ว และแก้ปุ่มกำหนดคุณสมบัติไอเทมซึ่งเดิมเรียกไอคอนที่ไม่มีจนแสดงเป็นเหรียญแทนฟันเฟือง SVG สำหรับโมเดลอาวุธ เอฟเฟกต์ มาตรวัด และภาพเงินยังทำหน้าที่เดิม

H-Stats ตัดบรรทัดชื่อและข้อมูลยาวภายในแต่ละช่อง ปรับขนาดคอลัมน์และรีเซ็ตสไตล์ dt/dd ที่อาจได้รับจากธีม ส่วนเนื้อหาของหน้าต่างเหนือ Chatbar อยู่ภายในความกว้างของแถบและเลื่อนขึ้น–ลงได้ แถบแท็บยังเลื่อนซ้าย–ขวาได้ตามปกติ

อัปเดต RoleForge แล้ว Reload SillyTavern เพื่อโหลดรุ่นนี้

## ผลทดสอบ

Unit tests ผ่าน **1,414 / 1,414** และ `npm run check` ผ่าน

ใช้ **SillyTavern 1.19.0 (06bde93)** จริงในเบราว์เซอร์ Chromium โดย Import การ์ดผ่าน API ของ SillyTavern และใช้ส่วนเสริมจริง ทดสอบธีม **Dark Lite, Azure, Dark V 1.0** ที่ความกว้าง **320, 390, 430, 768, 1440 px**:

- ตรวจขอบกล่อง 190 กรณี รวมอาวุธ กระเป๋า ภารกิจ H-Stats สถานะ ฝึก Stats Loot วิชา / ทักษะ Great Sage ไอเทม และฝึกฝน
- ส่ง touch input ให้เบราว์เซอร์จริง: แถบแท็บเลื่อนได้ทั้งสองทิศทางโดย swipe ของข้อความไม่เปลี่ยน และการปัดบนข้อความยังเปลี่ยนคำตอบได้
- เลื่อนเนื้อหาแนวตั้งได้หลังแยก gesture ออกจาก host
- เปิด–ปิดตัวเลือกหน้าต่างซ้ำได้โดยไม่มี native select; ปิดด้วย Escape และแตะด้านนอกได้
- ตรวจ H-Stats ครบห้าหมวด พร้อมชื่อยาวและข้อความติดกันยาวถึงขีดจำกัดของช่อง โดยวัดขอบข้อความเทียบกับช่องที่บรรจุ
- การเปิดดูไม่แก้ข้อมูล RPG ไม่ส่งข้อความร่าง และไม่เรียกโมเดล
- หน้าซื้อ ขาย และประมูลผ่านทั้งมือถือและคอม รวมเลือกทุกแท็บและย่อ–เปิดกลับ การทดสอบส่วนนี้ใช้คำตอบแบบ streaming ที่ควบคุมไว้ ผ่านกระบวนการ Generate ของ SillyTavern จริง ไม่เรียกผู้ให้บริการโมเดลภายนอก

ชุด DOM fixture แยกต่างหากผ่านด้วย: แถบ 11 หน้าต่างและคีย์บอร์ด การฝึกวิชา สถานะ/เงิน และแถบสรุปความจำ รวมการยกเลิก งานผิดพลาด การแทนที่หน้าต่าง และ cleanup

มือถือใช้ viewport/touch จำลอง **ยังไม่ได้ทดสอบบน iPhone หรือ Safari/WebKit จริง**
