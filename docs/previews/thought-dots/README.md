# Animated thought dots — preview

สามจุดข้าง “พูดในใจ” ของ NPC และผู้เล่น (เมื่อปิดกรอบ Dialogue) ขยับไล่กันเบา ๆ รอบละ 2.2 วินาที ข้อความอยู่นิ่ง ไม่มีการเรียก AI เพิ่ม

ปิดการเคลื่อนไหวได้จาก Motion ในดีไซน์แชททุกธีม และหยุดอัตโนมัติเมื่อเปิด Reduce Motion ของระบบหรือ SillyTavern

ตัวอย่างบันทึกจาก SillyTavern 1.19.0: PC 1920×1080 (16:9), มือถือ 1170×2532 จาก viewport 390×844 พร้อม touch emulation; วิดีโอประมาณ 7.2 วินาที GIF วนซ้ำเอง

เปิด `index.html` เพื่อดู GIF ของทั้งสองฝั่งและวิดีโอทั้งสองขนาด GIF เป็นสื่อบันทึกจึงไม่มีสวิตช์ Motion; หน้าแกลเลอรีแสดงภาพนิ่งแทนเมื่อระบบขอ Reduce Motion

งานนี้อยู่บน preview/unframed-player-thought ไม่ได้รวมเข้า main

ตรวจแล้ว: unit tests ที่เกี่ยวข้อง 40 ข้อผ่าน; Chromium และ WebKit ผ่าน PC/มือถือ ทั้ง 5 ธีม รวม Motion, Reduce Motion, ภาษาไทย/อังกฤษ และข้อความ/สถานะเดิมไม่เปลี่ยน
