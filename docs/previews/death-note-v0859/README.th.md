# Death Note — ภาษาชื่อและการแสดงชื่อจริง

RoleForge 0.85.9 / Death Note 0.4.3

ไปที่ **Workshop → Death Note → ตั้งค่า → ชื่อและการแสดงผลดวงตา**

- **ภาษาชื่อตัวละคร:** ต้นฉบับ / ไทย / English แยกจากภาษาเมนู
- **แสดงชื่อจริงเสมอ:** แสดงชื่อจริงที่ข้อมูลระบุไว้โดยไม่ต้องแลกหรือมีดวงตายมทูต ปิดเพื่อกลับไปใช้ชื่อที่รู้ในโรล / ชื่อที่ NPC บอก / ???
- การแสดงชื่อจริงมีลำดับก่อนสวิตช์ซ่อนชื่อที่ยังไม่รู้จัก แต่ไม่เพิ่มชื่อที่ตัวละครรู้จริงในเนื้อเรื่อง
- จำการตั้งค่าตามการ์ดตัวละคร ใช้กับแชทใหม่และหลังโหลดหน้าใหม่ได้

ชื่อใน Header, Dialogue, NPC Management, ป้ายดวงตา และป้ายตัวละครในสมุด ใช้ตัวเลือกเดียวกันผ่านตัวแสดงชื่อส่วนกลางทุกธีม การเปลี่ยนภาษาจะไม่เปลี่ยน NPC ID ไม่เปลี่ยนชื่อในข้อมูลต้นฉบับ ไม่สร้าง NPC ซ้ำ และไม่แก้ข้อความโรลเก่าหรือหมึกที่ผู้เล่นเขียนไว้

ตัวอย่าง: Light Yagami ↔ ไลท์ ยางามิ เป็นชื่อจริงเดียวกันตามข้อมูลที่รับรองไว้ ขณะที่ Kira ↔ คิระ เป็นกลุ่มนามแฝงแยกกัน การเปลี่ยนภาษาของนามแฝงไม่ทำให้ใช้แทนชื่อจริงในสมุดได้

ถ้าไม่มีคำแปลที่รับรอง ระบบใช้ชื่อเดิม ไม่เรียก AI เพื่อแปล ไม่เดาชื่อใหม่ และไม่ใช้ aliases ทั่วไปเป็นหลักฐานว่าชื่อนั้นคือชื่อจริง ตัวละครที่ไม่มีชื่อจริงเผยแพร่ในเวอร์ชันที่เลือกจะใช้ชื่อในแฟ้มเป็นค่าทดแทน ไม่ยืมชื่อจริงจากคนละเวอร์ชัน

การเปิดชื่อจริงเป็นมุมมองของผู้ใช้ ไม่ได้มอบดวงตาหรือความสามารถอ่านอายุขัย ไม่ให้ตัวละครในโรลรู้ชื่อหรือใบหน้าทันที และไม่ข้ามข้อกำหนดการครอบครองสมุด การจำใบหน้า เผ่าพันธุ์ ชื่อปลอม หรือผลการตาย ตัวเลขอายุขัย/ประวัติข้อตกลงเดิมไม่เปลี่ยน

แก้การอ่านคำแนะนำตัวภาษาไทยที่กล่าวชื่อที่มีในข้อมูลแล้วตามด้วยประโยคใหม่ เช่น “ฉันชื่อ Kira วันนี้…” ให้เก็บเฉพาะ Kira แทนการเอาประโยคถัดไปมาต่อเป็นชื่อ โดยชื่อใหม่อย่าง Kira Silver ยังคงเป็นชื่อนั้นทั้งชุด ไม่ตัดนามสกุลทิ้ง

เมื่อปิด Death Note ป้ายชื่อจะกลับไปใช้การแสดงผล RoleForge ปกติ ข้อมูลการตั้งค่ายังเก็บไว้ เปิด Addon อีกครั้งจึงใช้ต่อ

## สำหรับผู้สร้างการ์ด

เพิ่มชื่อจริงหลายภาษาใน `roleforge_death_note.trueNameSpellings` ได้ตามเดิม หรือใช้ตารางชื่อที่รับรองโดยผู้สร้างใน `nameTranslations`:

```json
{
  "nameTranslations": {
    "npc-stable-id": [
      {"name": "Elias Voss", "en": "Elias Voss", "th": "อีเลียส วอสส์"},
      {"name": "Adrian Grey", "en": "Adrian Grey", "th": "เอเดรียน เกรย์"}
    ]
  }
}
```

ถ้า `trueNames[npc-stable-id]` คือ `Elias Voss` เฉพาะแถวชื่อจริงจะเพิ่มรูปสะกดที่ใช้เขียนได้ ส่วนแถว `Adrian Grey` ช่วยแสดงนามแฝงสองภาษาเท่านั้น ไม่ทำให้ชื่อปลอมใช้ฆ่าตัวละครนั้นได้ ใช้ envelope `{default: [...], versions: {alternateId: [...]}}` สำหรับชื่อที่แตกต่างตามเวอร์ชันได้

ตารางชื่อ Death Note ที่มาพร้อมระบบใช้ NPC ID และตรวจชื่อจริงของเวอร์ชันที่เลือก ก่อนเพิ่มคำแปลเป็นรูปสะกดที่ใช้เขียนได้
