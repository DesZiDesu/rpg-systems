ตัวเลือกในพรีวิว:

- เลือกดูทั้ง 6 แบบหรือขยายดูแบบเดียว
- จำลองขนาดมือถือบนคอมได้
- เปิด/ปิด Header, Narrative และ Dialogue เป็นอิสระ ปิดกรอบแล้วยังอ่านข้อความได้ครบ
- กด Header เพื่อเปิดข้อมูลตัวละครตัวอย่าง
- เปิด/ปิดแอนิเมชัน มี Reduce Motion และหยุดเมื่อ UI พ้นจอหรือแท็บอยู่เบื้องหลัง

ทุกภาพเป็นตัวอย่างที่เรนเดอร์จาก HTML/CSS ของต้นแบบ ตัวละครและเรื่องราวเป็นตัวอย่าง ไม่มีการเรียก AI หรืออ่านข้อมูลแชทจริง

ตรวจใน Chromium ขนาด 320, 390 และ 1280 พิกเซล ครบทั้ง 6 แบบและสวิตช์ 8 รูปแบบ ตรวจข้อความยาว ปุ่มข้อมูล โหมดมือถือ การปิด animation และ Reduce Motion แล้ว รายละเอียดอยู่ใน [validation.json](validation.json) การทดสอบร่วมกับตัวแสดงผลจริง, Voice และ Regex/MVU จะทำในขั้นนำดีไซน์ที่ผ่านการตรวจเข้าระบบ
