# Player thought — Dialogue frame off preview

ต้นแบบสำหรับกรณีปิด **Dialogue · กรอบบทพูด** โดยยังเปิด **จัดรูปแบบข้อความผู้เล่น** (`userChatPresentation`) อยู่ รองรับการปิด Header/Narrative ร่วมกันด้วย

พิมพ์ `|ความคิดของฉัน|` ตามเดิม เมื่อ Dialogue ปิด ความคิดจะไม่มีพื้นหลัง กรอบ หรือแถบสีด้านข้าง ใช้ตัวเล็กลงประมาณ 10% โดยมีขนาดต่ำสุด 14px ตามฟอนต์ของ host สีเทาอุ่นหม่น พร้อมป้าย “พูดในใจ” ขนาดเล็ก เมื่อเปิด Motion และไม่ได้เปิด Reduce Motion จะค่อย ๆ ปรากฏครั้งเดียว 0.36 วินาที ไม่มีแสงกะพริบหรือการวนซ้ำ

เปิด Dialogue กลับแล้วใช้รูปแบบความคิดประจำธีมเดิม ไม่เปลี่ยนข้อความที่บันทึก ไม่เปลี่ยนข้อมูลเกม ไม่เรียก AI และไม่เปลี่ยนเสียง/เนื้อหาของ Regex/MVU

NPC `*text*` ยังคงเดิม เพราะเครื่องหมายนี้ใช้กับคำบรรยายท่าทางและการเน้นข้อความด้วย จึงไม่ตีความตัวเอียงทุกส่วนว่าเป็นความคิด

หากปิด **จัดรูปแบบข้อความผู้เล่นทั้งระบบ** ข้อความจะใช้ renderer ปกติของ SillyTavern พรีวิวนี้ไม่ได้ข้ามสวิตช์ปิดระบบดังกล่าว

ทดสอบใน SillyTavern 1.19.0 ผ่าน Chromium/WebKit ทั้ง PC และมือถือจำลอง ครบ 5 ธีม, ความกว้าง 320px, ภาษาไทย/อังกฤษ, การคืนกรอบ, ปิด Motion และ Reduce Motion; related tests ผ่าน 20 tests

อยู่ branch `preview/unframed-player-thought` ไม่ได้รวมเข้า main โดย Pokémon และ Smartphone ยังพักไว้ตามเดิม
