## การเปิดหน้าสร้าง

- การ์ดที่ไม่มี First Message ใช้การเปิดหน้าสร้างเดิม
- ถ้ามี First Message แล้วผู้เล่นลบออกจนแชทว่าง หน้าสร้างจะแสดงขึ้นทันที หากยังมีบทสนทนาอยู่ จะไม่เปิดฟอร์มแทรก
- เมื่อโหลดแชทว่างซ้ำ SillyTavern อาจเติม greeting ของการ์ดกลับมา ระบบจำ hash / chat ID / avatar ของข้อความที่ลบ และนำออกเฉพาะ greeting ที่เติมกลับมาในแชทเดิม ไม่ลบข้อความใหม่ที่ AI สร้าง ไม่ใช้ตัวบอกนี้ข้าม Branch หรือข้ามการ์ด
- ร่างเดิมกลับมาหลังรีโหลด การเริ่มเรื่องใหม่ต้องกดปุ่มเริ่มเอง ไม่สร้างคำตอบอัตโนมัติจากการกรอกช่อง
- การลบข้อความแรกไม่ใช่คำสั่งล้างข้อมูล RoleForge ทั้งหมด

## เลือกหน้าตาตาม Addon

| Addon ที่เปิด | หน้าสร้าง |
| --- | --- |
| ปิดทั้งสอง | RoleForge ตามธีมที่ตั้งไว้ |
| Death Note | แฟ้มตัวละคร กระดาษงาช้าง ปกดำ และหมึกแดง |
| Pokémon | Trainer ID สีแดง/ขาว/ฟ้า พร้อมภาพคู่หู |
| เปิดทั้งสอง | เลือกโลกก่อนสร้าง สลับกลับได้และเก็บร่างของแต่ละแบบ |

เลือกหน้าสร้างไม่ได้ปิด Addon อีกตัว การเปิด/ปิด Addon ยังจำตามการ์ด ส่วนร่างและตัวละครที่สร้างอยู่ในแชท

## Death Note

สามหน้า: ตัวตน → จุดเริ่มต้น → ทบทวน

- ชื่อจริง นามแฝง อายุ อัตลักษณ์ บทบาท ถิ่นที่อยู่ รูปลักษณ์ และประวัติ
- เลือกตามเส้นเรื่องของการ์ด อนิเมะ/มังงะ หรือภาพยนตร์ญี่ปุ่น เป็นแนวทางเปิดเรื่องและไม่ผสมเส้นเรื่อง ไม่กดรับเควสแทนผู้เล่น
- สมุด: ใช้สถานะจากการ์ด / เริ่มโดยไม่มี / ครอบครองของตนเอง ใช้เล่มที่มีอยู่แล้วก่อน ไม่เพิ่มสำเนาฟรีซ้ำโดยไม่จำเป็น
- ดวงตา: ตามการ์ดและตั้งค่า / ไม่มี / ติดตัวมาแต่เกิด / ได้รับพลัง ไม่มีการหักอายุขัยสำหรับ innate หรือ gift การแลกดวงตาจริงยังใช้ข้อตกลงในเนื้อเรื่อง
- ไม่เดายมทูตเจ้าของเล่มให้โดยไม่มีข้อมูล ไม่เปิดเผยชื่อและประวัติลับต่อ NPC อัตโนมัติ
- สิ่งที่เลือกเป็นค่าตั้งต้นจริง ส่วนสิทธิ์ การส่งต่อสมุดและเหตุการณ์ต่อมาทำงานตามระบบ Death Note เดิม ผู้ใช้ปรับดวงตาใน Workshop ภายหลังได้

## Pokémon

สามหน้า: Trainer → คู่หู → ทบทวน

- ชื่อ อายุ อัตลักษณ์ บทบาท บ้านเกิด รูปลักษณ์ และประวัติ
- ภูมิภาค 9 แห่ง คู่หูเริ่มต้น 27 ตัวพร้อม artwork ที่บันเดิลไว้ เลือกหนึ่งตัวเลเวล 5 ตั้งชื่อเล่นได้ หรือใช้ทีมตามการ์ด / เริ่มโดยไม่มี
- ชุดเริ่มต้น Poké Ball ×5 / Potion ×2, ใช้คลังตั้งต้นของ Addon/การ์ด หรือไม่รับไอเทม
- คู่หูและไอเทมเข้าระบบจริง ไม่สร้างข้อความรับของซ้ำ IV/Nature/เพศของคู่หูใช้ seed ที่บันทึกไว้และไม่สุ่มใหม่ตอนรีโหลด
- หน้าทบทวนตรวจตัวละคร คู่หู ภูมิภาค และชุดอุปกรณ์ก่อนเริ่ม

## ตัวเลือกของ RoleForge ปกติ

ช่องที่มีรายการเปิด choice sheet ภายในธีมของเราแทน native iOS select/datalist แตะได้ทั้งช่อง ปุ่มรายการสูงอย่างน้อย 44px มีค้นหา ตัวเลือกที่เลือกไว้ และปิดกลับได้

ช่องเดิมที่พิมพ์อิสระได้ยังพิมพ์ค่าเองผ่านช่องค้นหาแล้วกด “ใช้ข้อความนี้” ได้ รายการเลือกจำกัดค่า เช่นชนิดไอเทม จะเลือกเฉพาะตัวเลือกจริง ไม่มีปุ่มล้างที่ทำให้ค่า enum ใช้งานไม่ได้ รองรับคีย์บอร์ดและ focus ที่ไม่เรียกแป้นพิมพ์มือถือทันทีเมื่อเพียงเปิดรายการ

ใช้ preset เดิม ไม่เปลี่ยนสี/พลัง/ร่าง/ค่าที่ผู้เล่นบันทึกไว้ แก้เฉพาะวิธีเปิดรายการและการแตะ

## ทดลองและหลักฐาน

ใช้ runtime จากสาขาพรีวิวนี้กับสำเนา SillyTavern เปิดการ์ดและ Addon ที่ต้องการ ลบ First Message ถ้ามี จากนั้นกรอกสามหน้าและกดเริ่ม ถ้าปล่อยช่องแชทมีข้อความที่ยังไม่ส่งอยู่ ระบบให้จัดการข้อความนั้นก่อน โดยไม่ล้างหรือส่งแทน

```sh
npm test
npm run check
npm run test:forge:addons:real
FORGE_RECORD=1 FORGE_ARTIFACTS=/workspace/artifacts/creation-preview/recordings-final npm run test:forge:addons:real
npm run preview:forge:addons
```

วิดีโอ PC 1920×1080 (16:9) และมือถือ 1170×2532 (สัดส่วน iPhone) มีซับไทยขนาดใหญ่ พักแต่ละช่วงอย่างน้อย 8 วินาที และสารบัญ 17 ช่วง ทดสอบปุ่ม/การบันทึก/ผลใน Addon จริงใน SillyTavern 1.19.0 คำตอบ AI เป็น controlled SSE และมือถือเป็น browser emulation ไม่ใช่การจับภาพจาก iPhone จริง ไม่มีการเรียกโมเดลหรือ Voice ภายนอก

ภาพคู่หูใช้ artwork เดิมของ Pokémon addon ดูแหล่งและสิทธิ์ใน `src/workshop/pokemon/CREDITS.md` ภาพปกสมุดในหน้านี้สร้างด้วย CSS
