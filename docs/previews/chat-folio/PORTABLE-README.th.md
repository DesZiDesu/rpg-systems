# RoleForge · The Mage’s Folio

เปิด standalone.html ด้วยเบราว์เซอร์ ใช้งานได้ออฟไลน์ สลับ RoleForge Original / The Mage’s Folio เลือกสีตัวละคร ภาพ 1:1 ป้ายข้อมูล และเปิด/ปิด Header / Dialogue / Narrative ได้แยกกัน

Preview จับ DOM จาก renderer จริง พร้อม CSS ภาพและฟอนต์ในไฟล์เดียว กรอบ SillyTavern และข้อมูล NPC เป็นตัวอย่าง ปุ่มข้อมูลเปิดรายละเอียดตัวอย่าง ปุ่มบทพากย์เปิดคำอธิบาย ไม่มีการเรียก API หรือเชื่อมต่อแชทผู้ใช้
