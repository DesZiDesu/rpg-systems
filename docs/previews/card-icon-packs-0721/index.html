ชุด Servant เฉพาะการ์ด Fate

ภาพจาก SillyTavern 1.19.0 จริงในโปรไฟล์ทดสอบ RoleForge 0.72.1 เมนูอ่านชุดไอคอนจากการ์ดที่เปิดอยู่ บอทอื่นยังอัปโหลดภาพ custom และเลือกสัญลักษณ์ทั่วไปได้

ตัวละครและข้อความเป็น fixture ไม่เรียกโมเดลและไม่ใช่แชทส่วนตัวของผู้ใช้ ทดสอบ Chromium และ WebKit บน Linux ไม่ใช่ iPhone เครื่องจริง
