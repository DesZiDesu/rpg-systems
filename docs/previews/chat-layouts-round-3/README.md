# RoleForge · Portrait & Novel Study · รอบ 3

พรีวิวนี้ต่อยอด **แบบ 4 และ 5** จากรอบก่อน และเพิ่ม **Novel Style ขาวดำ** เป็นแบบ 7 ทุกแบบมีเวอร์ชันมีภาพและไม่มีภาพ ใช้ภาพที่คุณส่งมาและข้อความเดียวกันเพื่อเปรียบเทียบ

**ยังไม่รวมเข้า main และยังไม่เชื่อมกับตัวแสดงผลจริงของส่วนเสริม** อยู่บน branch พรีวิวแยกเท่านั้น

เปิด [standalone.html](standalone.html) เพื่อทดลองได้โดยไม่ต่ออินเทอร์เน็ต หรือ [ดาวน์โหลด ZIP](roleforge-portrait-novel-r3.zip) แล้วแตกไฟล์ เปิด `standalone.html` ภาพฝังอยู่ในไฟล์นี้แล้ว

ตัวเลือกในพรีวิว:

- ดูทั้ง 3 ดีไซน์ หรือเลือกดูแบบเดียว
- เทียบมีภาพและไม่มีภาพคู่กัน หรือเลือกดูเวอร์ชันเดียว
- จำลองความกว้างมือถือบนคอมได้
- เปิด/ปิด Header, Narrative และ Dialogue แยกกัน ปิดเฉพาะการตกแต่งแล้วข้อความยังอยู่ครบ
- กด Header เพื่อเปิดข้อมูลตัวละครตัวอย่าง
- เปิด/ปิดแอนิเมชัน ตราวงเวทและกลีบบัวหยุดเมื่อพ้นจอหรือแท็บอยู่เบื้องหลัง และรองรับ Reduce Motion
- Novel ใช้กระดาษขาว ตัวอักษรดำ ภาพขาวดำในการแสดงผล และไม่มีแสงหรือแอนิเมชันตกแต่ง
- เมื่อไม่มีภาพหรือภาพโหลดไม่สำเร็จ ชื่อและเนื้อเรื่องยังแสดงได้ ไม่มีกรอบภาพเปล่าค้างไว้

ไฟล์ `assets/sample-character.jpg` เป็นภาพต้นฉบับที่คุณส่งมา ไม่มีการแก้ไฟล์ภาพ Novel แสดงภาพขาวดำด้วย CSS เท่านั้น ชื่อ Aster Vale และเนื้อเรื่องเป็นตัวอย่างสำหรับเทียบดีไซน์

ภาพทั้งหมดจับจาก HTML/CSS ที่เรนเดอร์จริงใน Chromium ตรวจขนาด 320, 390 และ 1280 พิกเซล รวมทั้ง 3 ดีไซน์ × 2 เวอร์ชันภาพ × 8 รูปแบบสวิตช์ รายละเอียดอยู่ใน [validation.json](validation.json) รอบนี้ทดสอบเฉพาะต้นแบบ การเชื่อมกับข้อมูล NPC, Voice, Regex/MVU และตัวแสดงผลจริงจะทำเมื่อคุณเลือกดีไซน์แล้ว
