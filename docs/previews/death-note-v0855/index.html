ข้อความเปิด CRLF ลงทะเบียนสมุดจากกติกาการ์ดได้ เมื่อผู้เล่นพิมพ์หยิบและ AI ยืนยันการเก็บลงกระเป๋า สมุดที่พบเพียงเล่มเดียวเข้า Inventory ได้แม้คำสั่งประกอบจาก AI อ้าง ID ผิด ย้อน Branch ไปก่อนหยิบแล้วไม่มีการถือครองติดตามไป

1,800 unit tests และ syntax checks ผ่าน ตรวจทั้ง Chromium / WebKit, พิมพ์หยิบ, ปุ่มหยิบ, Inventory จำนวน 1, Branch จริงก่อนหยิบ, ไม่สร้าง User turn เพิ่ม, เก็บ draft ที่ยังไม่ได้ส่ง และจำลองการอ่านแฟ้มถูกยกเลิกหนึ่งครั้ง สำเนาไฟล์ Branch จริงกู้ได้โดยไม่เรียกโมเดลเพิ่มหรือแก้ข้อความต้นฉบับ การทดสอบ Send/Continue ใช้ controlled SSE ภายในเครื่อง ไม่ใช่บริการโมเดลหรือเสียงจริง มือถือใช้ browser emulation ไม่ใช่ iPhone จริง
