# ความคิดผู้เล่นและ NPC — พรีวิวรุ่นที่ 2

ยังอยู่ใน branch `preview/unframed-player-thought` ไม่ได้รวมเข้า main และไม่เกี่ยวกับ Pokémon / Smartphone ที่พักไว้

## วิธีใช้

ผู้เล่นเปิด UI จัดรูปแบบข้อความผู้เล่น แล้วพิมพ์ตามเดิม:

```text
*ฉันเก็บสมุดลงกระเป๋า*
"ไม่มีอะไรหรอก"
|ถ้าเขารู้เรื่องนี้คงยุ่งแน่ ตอนนี้ต้องทำตัวให้เป็นปกติไว้ก่อน|
```

เมื่อปิด **Dialogue · กรอบบทพูด** ความคิดผู้เล่นเป็นข้อความเล็กลง สีเทาอุ่น พร้อมป้าย “พูดในใจ” โดยไม่มีกรอบ ส่วน **NPC มีกล่องความคิดเงียบแยกต่างหาก** ซึ่งยังปรากฏเมื่อปิด Dialogue กรอบบาง พื้นหม่น ไม่มีแถบสีด้านข้าง รองรับทุกธีมปัจจุบัน

AI ได้รับคำสั่งให้ใช้บล็อกนี้เองในคำตอบใหม่ ไม่ต้องให้ผู้ใช้พิมพ์แท็กแทน NPC:

```html
<tr-header name="aoi"/>
<tr-narrative>เขาเห็นคุณเก็บสมุดลงกระเป๋า</tr-narrative>
<tr-thought name="aoi">เขาดูมีอะไรปิดบัง แต่ฉันยังไม่รู้ว่าเป็นเรื่องอะไร</tr-thought>
<tr-dialogue name="aoi">เมื่อกี้เก็บอะไรไว้ในกระเป๋าเหรอ?</tr-dialogue>
```

ใช้ `name` เป็นชื่อ/รหัส NPC ที่มีอยู่ตามกฎของการ์ด แต่ละบล็อกแยกกัน ไม่ซ้อนใน Narrative/Dialogue ความคิดต้องเป็นของ NPC เจ้าของบล็อก ไม่ใช่การสร้างความคิดหรือคำพูดแทนผู้เล่น

`*ข้อความ*` ใน Narrative เดิมยังเป็นตัวเอียงตามเดิม ไม่ถูกเดาว่าเป็นความคิดทั้งหมด เพราะอาจเป็นท่าทาง การเน้นคำ หรือคำบรรยาย ข้อความเก่าไม่ถูกแก้ย้อนหลังและไม่ถูกเจนใหม่อัตโนมัติ

## กติกาที่เพิ่มให้ AI

- `|…|` ของผู้เล่นที่อยู่นอกบทพูด โค้ด และตาราง คือความคิดที่ไม่ได้พูดออกเสียง
- NPC ห้ามได้ยิน อ้างคำ ตอบเนื้อหา หรือเรียนรู้ความคิดนั้นโดยตรง AI ผู้เล่าเรื่องเห็นข้อความเพื่อเล่าต่อ แต่ความรู้ของตัวละครแยกกัน
- ตอบโต้ได้จากสิ่งที่เกิดขึ้นจริง เช่น คำพูด ท่าทาง สีหน้า ไม่สร้างท่าทางเพิ่มเพื่อใช้เป็นข้ออ้างเปิดเผยความคิด
- ความคิด NPC ที่แสดงแก่ผู้อ่านไม่ได้ทำให้ตัวละครผู้เล่นหรือ NPC อื่นรู้ความคิดนั้น ห้ามคัดลอกเข้าความรู้/ความจำ/ไดอารี่ของบุคคลอื่น
- ข้อยกเว้นคือมีพลังอ่านใจ/โทรจิตที่ตั้งไว้จริงและตรงเงื่อนไข ขอบเขตของพลังยังคงเดิม UI ไม่ได้มอบพลัง
- ความคิดไม่ใช่การกระทำที่สำเร็จแล้วหรือความยินยอมให้ซื้อ โอนเงิน จดสมุด ฯลฯ
- กล่องความคิดใช้กับบทบาทสมมติของตัวละครเท่านั้น ไม่ใช่การเปิดเผย reasoning/analysis ภายในของโมเดล

กติกาความคิดส่วนตัวถูกใส่ใน prompt ของแชทและ Manual Sync ส่วนคำสั่งรูปแบบ NPC ใช้เมื่อเปิด RoleForge Chat Presentation การปิดกรอบไม่ปิดกติกานี้

กล่องความคิด NPC ไม่มีปุ่มเล่นเสียงและไม่ถูกเพิ่มเข้า Voice play-all/autoplay รายการพากย์ของบทพูดและผู้บรรยายทำงานตามเดิม การปิด Motion หรือเปิด Reduce Motion หยุดการเคลื่อนไหวของกล่อง แต่ยังเก็บสีและขนาดตัวอักษร

## ผลตรวจ

- Unit/integration 1,862 tests ผ่านทั้งหมด และ syntax checks ผ่าน
- Native SillyTavern 1.19.0 บน Chromium/WebKit ทั้ง PC/มือถือจำลอง ครบ 5 ธีม
- ตรวจ Shared และ RoleForge renderer, ชื่อเจ้าของบล็อก, ความกว้างแคบ, ไทย/English, การคืนกรอบ, Motion/Reduce Motion และไม่มีปุ่มเสียงในความคิดแม้เปิด Voice Addon
- ตรวจว่าคำสั่งความคิดส่วนตัวและตัวอย่าง `tr-thought` อยู่ใน prompt จริงของ host ข้อความที่บันทึกและข้อมูลเกมไม่เปลี่ยน ไม่มี model API call เพิ่มจากการเปิด/ปรับหน้าตา
- การตอบของโมเดลไม่ได้ถูกทดสอบกับผู้ให้บริการภายนอกในรอบนี้ การตรวจ UI ใช้ข้อความตัวอย่าง กติกาความรู้เป็นคำสั่งกำกับโมเดล ไม่ใช่การซ่อนข้อความผู้เล่นออกจาก context ของ AI
