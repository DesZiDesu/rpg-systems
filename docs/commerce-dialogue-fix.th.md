# RoleForge 0.54.1 — ข้อเสนอใน Dialogue และปุ่มเสียง

แก้กรณีเจ้าของโรงเตี๊ยมเสนอห้องสองแบบราคา 5/10 เงินในคนละ Dialogue แต่ไม่มี `marketplace` หรือ `tretaresia_patch` เลย รายการซื้อจะอ่านราคาจากคำตอบเดียวกันและเปิดทันทีเมื่อเป็นคำขอซื้อ/เช่าจริง ผู้ขายคนเดียวและกุญแจถูกเสนอในคำตอบ ไม่เรียก API เพิ่มเพื่อสร้างรายการ

ตัวตรวจเดิมรับเมนูห้องใน Dialogue เดียว ต้องมีเวลาเช็กเอาต์แน่นอน และคำว่า “รวมอาหารเช้าพรุ่งนี้” ในประโยคเดียวกันทำให้ข้อเสนอปัจจุบันถูกปฏิเสธเป็นเหตุการณ์อนาคต แก้ให้ตรวจข้อเสนอราคาแยกจากเวลาของบริการที่รวมมา และใช้หลักฐานแยกตามตัวเลือกจาก NPC คนเดิม

กรณีผู้เล่นขอพัก **1 คืน** และ NPC เสนอราคาต่อคืนแต่ยังไม่บอกเวลาเช็กเอาต์ บันทึกเป็นการเช่าหนึ่งคืน พร้อมข้อความ **ยังไม่ระบุเวลาเช็กเอาต์** ไม่มีการสมมุติ 24 ชั่วโมงหรือเปลี่ยนห้องเป็นกรรมสิทธิ์ถาวร กุญแจอยู่ใน Inventory หลังยืนยันและ NPC ยอมรับ; สิทธิ์นี้ไม่สมมุติเวลาหมดอายุจากนาฬิกา บันทึกการคืนตามโรล ข้อเสนอที่ระบุเวลาเช็กเอาต์แน่นอนยังใช้สิทธิ์ตามเวลานั้นตามเดิม

คำตอบปกติยังได้รับ instruction ให้ AI สร้างข้อมูลทุกตัวเลือกและเงื่อนไขในคำตอบเดียวกัน โดยเพิ่มตัวอย่างการใช้ `items[].evidence` เมื่อเมนูแยกเป็นหลาย Dialogue ตัวอ่านเฉพาะข้อเสนอที่ชัดเจนในข้อความเป็นทางรองรับเมื่อ AI ลืมข้อมูลเครื่อง ไม่สร้างรายละเอียดที่ไม่ถูกบอก ไม่แทนข้อมูลเครื่องที่ขัดแย้งกับราคาในเรื่อง ไม่เดาสต็อก มัดจำหรือเวลาสิ้นสุด คำขอหลายคืน เงื่อนไขกำกวมและค่าบริการเพิ่มยังต้องมีข้อมูลที่ครบจาก AI

สินค้าปกติรองรับคำเสนอขายที่ระบุชื่อและราคาโดยตรง เช่น `ข้าขายเชือก ราคา 6 เหรียญเงิน` และรายการ `Potion: 2 silver` การขายรองรับ NPC รับซื้อของที่ผู้เล่นมีจริง พร้อมราคาแต่ละรายการใน Dialogue เดียวหรือหลายบทจาก NPC คนเดิม ผู้เล่นเอารายการที่ไม่อยากขายออกได้

การเปิดรายการและการเลือกไม่เปลี่ยนเงินหรือของ ปุ่มเสนอ/ยืนยัน/ยกเลิกยังใช้ API เพื่อให้ NPC ตัดสินและต่อเรื่องตามเดิม เมื่อยืนยันและยอมรับราคาจึงมีการหัก/รับเงินและส่งมอบเพียงครั้งเดียว การพูดถึง ซื้อ/ขาย สมมุติ ปฏิเสธหรือ `commerceIntent:none` ยังไม่เปิดร้านจากคำเหล่านั้น

ปุ่มเสียงย้ายเข้าเป็นส่วนท้ายของกรอบ Dialogue ใช้สีเดียวกับกรอบ ไม่มีแถวปุ่มสี่เหลี่ยมลอยใต้คำพูด ปุ่มฟังใช้วงกลมเล็กพร้อมชื่อ **ฟังบทพูด** และเปลี่ยนเป็น **พักเสียง / ฟังต่อ / ยกเลิก** ตามสถานะ ปุ่มเชื่อม/เลือกเสียงบอกหน้าที่เมื่อยังไม่พร้อม ตัวพากย์ยังอ่านเฉพาะเนื้อหาคำพูด ไม่อ่านชื่อปุ่มที่เพิ่มเข้าไป
