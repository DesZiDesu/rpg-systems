# ธีมบทสนทนา · RoleForge 0.63.0

ตั้งค่าที่ **Extensions → RoleForge → Chat appearance & NPCs** เลือก **Story theme · this chat** และเปิด/ปิดกรอบแต่ละส่วนได้อิสระ หน้าตั้งค่าใช้ช่องและปุ่มตามธีม SillyTavern ส่วน Header, Dialogue และ Narrative ใช้ดีไซน์ที่เลือก

| ชื่อธีม | เหมาะกับ | รายละเอียดและเอฟเฟกต์ |
| --- | --- | --- |
| Gilded Chronicle | RoleForge | กรอบระบบทอง ป้ายชื่อสลัก เส้นบันทึก และประกายบนตรา |
| Starlit Reverie | Fantasy Anime | กรอบบทพูดสีมุกทรงโค้ง ดาวพาสเทลลอยเบา ๆ |
| Ashen Covenant | Dark Fantasy | กรอบเหล็กดำ ตราสีชาด และแสงถ่านที่ค่อย ๆ สว่าง |
| Astral Grimoire | โรงเรียนเวท / Magical Academy | กรอบตำราเวท กระดาษเก่า และตราเวทหมุนช้า ๆ |
| Jade Lotus | Chinese Fantasy | คัมภีร์หยก กระดาษงาช้าง ตราประทับชาด และกลีบบัวลอย |
| Neon Protocol | Advanced Futuristic | HUD สีฟ้า กรอบสัญญาณแบ่งส่วน และจุดเชื่อมต่อกะพริบ |

กด **Preview this theme** เพื่อดูตัวอย่างใน drawer หรือ **View all 6 themes** เพื่อเปิด [หน้าพรีวิวครบทุกชุด](previews/chat-themes/index.html) หน้าพรีวิวมีตัวเลือกเปิด/ปิดกรอบและ animation โดยไม่ใช้ AI

ดู [ภาพรวมทั้ง 6 ธีม](previews/chat-themes/all-six-desktop.png) หรือดาวน์โหลด [พรีวิว HTML แบบเปิดออฟไลน์](previews/chat-themes/standalone.html) แล้วเปิดด้วยเบราว์เซอร์ได้ ภาพแต่ละธีมบนมือถือและคอมอยู่ในโฟลเดอร์เดียวกัน

[ดาวน์โหลดพรีวิวทั้งชุด](previews/chat-themes/roleforge-chat-themes-previews.zip) มีภาพมือถือ/คอมครบทุกธีม ภาพหน้าตั้งค่า ไฟล์ HTML และวิดีโอ/ภาพเคลื่อนไหวตัวอย่าง

- **Header**: ปิดแล้วเหลือชื่อผู้พูดธรรมดา ไม่มีป้ายตัวละคร ภาพ หรือปุ่มข้อมูลในหัวเรื่อง
- **Dialogue**: ปิดเฉพาะกรอบบทพูด ข้อความและตัวหนา/ตัวเอียงยังอ่านได้
- **Narrative**: ปิดเฉพาะกรอบบทบรรยาย รวมถึงปากกาและเส้นตกแต่ง เนื้อหายังอยู่
- **Animated accents**: ปิดเอฟเฟกต์ทุกธีมได้ เมื่อเปิดไว้ เอฟเฟกต์ขยับเฉพาะตรา SVG หยุดเมื่อตราพ้นจอหรือแท็บอยู่เบื้องหลัง และปิดเมื่ออุปกรณ์ตั้ง Reduce Motion

สวิตช์รวม Header / Dialogue / Narrative เดิมยังใช้ได้ สวิตช์ย่อยไม่แก้ข้อความต้นฉบับ ไม่เปลี่ยนบทบาท AI และไม่ปิดระบบติดตามข้อมูลหรือ Voice เมื่อเปิด User UI ไว้ User ใช้ธีมและสวิตช์ชุดเดียวกัน โดยยังอยู่ฝั่งขวา และมี UI พูดในใจตามเดิม

ค่าธีมจำแยกแชท บอทอื่นไม่ถูกเปลี่ยน สามารถเก็บเป็น **Chat appearance** ใน Chat presets หรือรวมใน World preset แล้ว Import/Export ได้ การบันทึก setup ลงการ์ดพ่วงธีมและสวิตช์นี้ด้วย การ์ดเก่ายังทำงานโดยใช้ Gilded Chronicle หรือค่าที่ตั้งไว้เดิม เมื่อเปิดแชทครั้งแรกหลังอัปเดต ระบบจะเก็บค่าหน้าตาของแชทนั้นไว้ การเปลี่ยนค่าระหว่างเจนหรือระหว่างบันทึกงานอื่นจะแจ้งให้รอ หากบันทึกไม่สำเร็จจะคืนค่าก่อนหน้า

ธีมเหล่านี้แต่งเฉพาะบล็อกของ RoleForge การ์ด HTML/Regex และ iframe ของ MVU ใช้หน้าตาของเจ้าของเดิม กรณี Regex ครอบทั้งคำตอบจะรักษาการ์ดนั้นและเพิ่มเฉพาะป้ายข้อมูล/Voice ที่แสดงร่วมได้ สีประจำตัว NPC ยังแสดงในข้อมูลหัวเรื่อง และ Gilded Chronicle รักษาสีชื่อและสีกรอบบทพูดของ NPC ด้วย ธีมอื่นใช้ palette ประจำธีมสำหรับกรอบหลัก

พรีวิวใช้โค้ดและ CSS ของตัวแสดงผลจริง ทดสอบหน้าจอ 320, 390 และ 1280 พิกเซลครบทั้ง 6 ธีมและการเปิด/ปิดทั้งสามส่วนครบ 8 แบบ รวมถึงการเปลี่ยนแชท/โหลดใหม่/บันทึกล้มเหลว, preset/การ์ด, Regex, MVU และ Voice รายละเอียดอยู่ใน [ผลตรวจ](validation-chat-themes-v0.63.0.json) ยังไม่ได้ทดสอบ Safari บน iPhone จริงหรือ API พากย์เสียงสด

สำหรับผู้สร้างการ์ด ข้อมูลใน `roleforge_character_pack` หรือ `config` ของ World preset ใช้รูปแบบนี้:

```json
"chatAppearance": {
  "theme": "arcane",
  "header": true,
  "dialogue": true,
  "narrative": true,
  "effects": true
}
```

รหัสธีมคือ `roleforge`, `anime`, `dark`, `arcane`, `jade`, `future` ระบบรับเฉพาะรหัสและตัวเลือกข้างต้น ไม่มีการนำ CSS หรือ JavaScript จาก preset มารัน

หลังอัปเดต ให้โหลด SillyTavern ใหม่เพื่อรับ JavaScript และ CSS ของ 0.63.0
