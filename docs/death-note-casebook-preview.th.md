# Death Note — บันทึกคดีและเศษกระดาษ (Preview)

งานนี้อยู่ใน branch `preview/death-note-evidence` บนฐาน RoleForge 0.84.1 ยังไม่รวมเข้า `main`

## 1. รายชื่อที่เขียนและสาเหตุที่ยังไม่เกิดผล

- **ยังไม่ส่ง**: หมึกมีชื่อแล้ว แต่ยังไม่ผ่านเงื่อนไข เช่น ไม่เคยเห็นใบหน้า จะแสดงเหตุผลที่หน้า “รายชื่อ” โดยไม่เฉลยชื่อจริง
- **รอเวลาในเรื่อง**: แสดงระยะเวลาที่เหลือและเส้นความคืบหน้า เวลาเดินตามโรล ไม่ใช่เวลาจริง
- **รอคำยืนยันในโรล**: ถึงกำหนดแล้ว แต่ยังไม่มีหลักฐานการเสียชีวิตที่ยืนยันได้ การผ่านเวลาเพียงอย่างเดียวไม่ลด HP
- **ไม่เกิดผล**: มีคำตอบยืนยันความล้มเหลว ถ้าชื่อไม่ตรง จะบอกเพียงชื่อที่เขียนไม่ตรงกับบุคคลที่นึกถึง โดยไม่เปิดเผยชื่อจริง
- **เกิดผลแล้ว**: มีเหตุการณ์ยืนยันการเสียชีวิตตามกติกา เปิดอ่านหลักฐานได้

ชื่อกับสาเหตุยังเขียนได้ทั้งแยกบรรทัดและบรรทัดเดียวกัน ใช้ “ต่อเรื่อง” เพื่อ Continue คำตอบ AI เดิม หรือปล่อยหมึกไว้แล้วส่งโรลถัดไปตามปกติ ไม่มีการสร้าง User message แทนผู้เล่น ปิดสมุดระหว่างรอได้

## 2. บันทึกคดี: NPC แต่ละคนรู้ไม่เหมือนกัน

เปิดที่คั่นหน้า **คดี / Cases** หรือปุ่มลายนิ้วมือบนหัว Death Note เหนือ chatbar

แฟ้มแยกตาม **ผู้สังเกต → ผู้ถูกสงสัย** ครอบคลุม NPC → ผู้เล่น และ NPC → NPC หลักฐานเป็นการเห็นเหตุการณ์ เอกสาร คำให้การ หรือการทดลองที่เกิดขึ้นจริงในบท ไม่เพิ่มเองจากจำนวนเทิร์นหรือข้อมูลเจ้าของสมุดที่เป็นความลับ

หลักฐานเล็กน้อย/สำคัญ/หนักแน่น เพิ่ม 5/12/20 คะแนน หลักฐานหักล้างลดในขนาดเดียวกัน คะแนนอยู่ระหว่าง 0–100 หลักฐานซ้ำไม่นับซ้ำ หน้าหลักฐานแสดงล่าสุดไม่เกิน 64 รายการ แต่คะแนนยังใช้ประวัติทั้งหมด และหลักฐานใหม่ยังหักล้างข้อสงสัยได้ในแชทยาว คะแนนเป็นความสงสัย ไม่ใช่ความผิดหรือคำสั่งจับกุม AI ใช้ประกอบการถาม ตรวจสอบพยานที่อยู่ หรือสืบสวนตามโอกาสในเรื่อง

หน้าผู้เล่นแสดงเฉพาะหลักฐานที่เปิดเผยให้รับรู้ในบท คะแนนที่แสดงคำนวณจากหลักฐานที่เปิดเผยเท่านั้น ไม่เปิดเผยคะแนนรวมลับของ NPC และไม่แชร์ความรู้ให้ NPC อื่นอัตโนมัติ การใส่ชื่อในแฟ้มยังใช้ชื่อที่ผู้เล่นรู้หรือ ??? ตามระบบเดิม

## 3. เศษกระดาษเป็นของจริงใน Inventory

หน้า **สิทธิ์ / Possession → เศษกระดาษจากสมุด → ฉีกกระดาษหนึ่งชิ้น** ต้องถือสมุดต้นทางอยู่ก่อน

ชิ้นกระดาษมีรหัสของตัวเองและ `parentBookId` ซึ่งเปลี่ยนไม่ได้ สร้างของประเภท Artifact ใน Inventory พร้อม properties `roleforge:addon:death-note-fragment` และ `roleforge:death-note:parent:<book id>`

- เลือก “เขียน” หรือเลือกชิ้นกระดาษจากช่องสมุดเพื่อใช้หน้าจดอิสระ ใช้ได้แม้ไม่ได้ถือเล่มหลัก
- ส่งให้ NPC ในฉาก วาง หยิบคืน หรือยืนยันทำลายได้
- AI สามารถรายงานการฉีก/ส่งต่อ/หยิบ/วาง/ทำลายโดย NPC ได้เมื่อมีหลักฐานการกระทำจริงในบท การส่งต่อลับไม่เฉลยผู้ถือใหม่ให้ผู้เล่น
- กติกาชื่อจริง ใบหน้า มนุษย์ และเวลาในเรื่องเหมือนเล่มหลัก
- ไม่สร้างเจ้าของสิทธิ์คนใหม่ ไม่ย้ายสิทธิ์สมุดต้นทาง และไม่ให้สิทธิ์แลกดวงตา
- ทำลายเศษกระดาษไม่คืนชีวิต ไม่ยกเลิกชื่อที่จดแล้ว และไม่ลบหน้าบันทึกผล
- Preview จำกัด 32 ชิ้นต่อสมุด รวมชิ้นที่ทำลายแล้วเพื่อจำกัดข้อมูลประวัติ

## 4. ใครอ่านและเชื่อกฎปลอม

ใช้หน้ากติกา “จารึกเพิ่ม” ตามเดิม แล้วดูส่วน **ใครอ่าน ใครเชื่อ** ในหน้า “คดี”

ระบบต้องมีเหตุการณ์อ่านจารึกชิ้นนั้นก่อน จึงบันทึกว่าเชื่อ สงสัย หรือไม่เชื่อได้ คนที่ไม่อ่านไม่ได้รับความรู้นี้ การเปลี่ยนความเชื่อต้องมีข้อความรองรับ ไม่เกิดจากการเปลี่ยนคะแนนความสัมพันธ์

ถ้าผู้เล่นเห็นว่าอ่าน แต่ยังไม่รู้ความเห็น จะแสดงเพียง “อ่านแล้ว · ยังไม่แสดงความเห็น” การสงสัยลับไม่รั่วออกมา ความเชื่อมีผลต่อการตัดสินใจในโรล ไม่สร้างนาฬิกาตายหรือเปลี่ยนกติกาจริงของ Death Note

## 5. แชทยาว การย้อนเนื้อเรื่อง และประสิทธิภาพ

บันทึกคดี ความเชื่อ และชิ้นกระดาษใช้ journal ต่อข้อความใน `message.extra.roleforge_death_note_world_preview` ร่วมกับกลไกสมุดเดิม ส่วนหมึกและผลการเขียนยังใช้ journal เดิม ข้อมูลผูกกับแชท ข้อความ และ Swipe ที่เลือก

Branch ใช้เฉพาะข้อความก่อนจุดที่เลือก การแก้ข้อความจนหลักฐานเดิมหายไปจะทำให้หลักฐานนั้นหมดอำนาจ ข้อมูลเศษกระดาษใน Inventory ที่ติดมาจากอนาคตแต่ไม่อยู่ใน journal ปัจจุบันจะไม่สามารถใช้เขียนได้ และจะถูกปรับให้ตรงกับ Branch

เพิ่ม cache เฉพาะผลแยกเหตุการณ์จากข้อความเดิม เมื่อข้อความหรือข้อมูลระบุตัว NPC เปลี่ยน จะอ่านใหม่ ยัง replay โลกและ journal จากข้อความปัจจุบันเสมอ ไม่เก็บโลกเก่าข้าม Branch/Swipe

ปิด Addon จะซ่อนหน้าระบบและพัก prompt เสริม ข้อมูลยังอยู่ ผลการตายที่เกิดแล้วและ Inventory ปกติไม่ถูกย้อนคืน เปิดใหม่ใช้งานต่อได้ แชทเก่าไม่ถูกเติมคะแนนสืบสวนหรือความเชื่อย้อนหลังโดยเดาเหตุการณ์

## ภาพและขอบเขตการทดสอบ

ดู [แกลเลอรี PC / Mobile](previews/death-note-casebook/index.html) และ `validation.json` ในโฟลเดอร์เดียวกัน

ทดสอบใน SillyTavern จริงด้วย Chromium และ WebKit ทั้ง viewport คอมและมือถือ คำตอบ AI ใช้ controlled SSE ผ่านการ Generate ของโฮสต์จริง ไม่ได้เชื่อมโมเดลภายนอกหรือบริการเสียง การทดสอบมือถือเป็น viewport/touch emulation ไม่ใช่เครื่อง iPhone จริง

ระบบใหม่ต้องอาศัย AI สร้างเหตุการณ์พร้อมหลักฐานตาม prompt หากคำตอบไม่ระบุเหตุการณ์ที่ตรวจยืนยันได้ ระบบจะไม่เดาคะแนน ความเชื่อ หรือการเสียชีวิตให้เอง

ผลทดสอบในเครื่องนี้: ชุดอัตโนมัติ 1,755 ข้อผ่าน การเปิดหน้าในแชท 500 / 1,000 / 2,000 ข้อความ มีค่ากลาง JavaScript ประมาณ 63–67 / 103 / 185 ms โดยใช้การอ่าน context และ replay โลกอย่างละ 2 รอบต่อการเปิด ตัวเลขนี้เป็นผลใน executor ไม่ใช่การรับประกันเวลาบนมือถือจริง
