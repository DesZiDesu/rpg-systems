- `npm run check`: ผ่าน รวมโมดูลใหม่ของ Pokémon

- จำลอง HTTP 500 ขณะย้ายของ: ย้อนทั้งของเดิมและ journal ไม่มีจำนวนหาย/เพิ่มหลอก ลองใหม่สำเร็จ แสดงยอดเดียวกันใน RoleForge และ Chatbar ปิด Addon แล้วซ่อนยอด เปิดใหม่ข้อมูลเท่าเดิม
- Workshop: อัปเดตแพ็กเป็น 0.2.0 และเปิดหน้าตั้งค่าผ่าน Configure สำเร็จ
