# Pokémon · Game UI preview

พรีวิวนี้ทำใน worktree `/workspace/roleforge-pokemon-preview` บน branch `preview/pokemon-addon` จาก main `b175f1e945b5eb2723183818ad8ef4b582f868d5` ยังไม่มี commit, merge หรือ push งาน Pokémon เข้า main

## วิธีลอง

ใช้ runtime ของ branch พรีวิวนี้ในสำเนา SillyTavern สำหรับทดสอบ เปิดแชทแล้วเข้า RoleForge Workshop → Pokémon → ติดตั้ง → เปิดใช้ในแชทนี้ ปุ่มเปิดจะมีใน Wand Menu และปุ่มลอย สามารถปิดปุ่มลอยเฉพาะ Pokémon ได้จากหน้าจัดการ Addon ใน Workshop

เลือกคู่หูจาก 9 ภูมิภาค บันทึกการเลือกและการเล่นอยู่ใน metadata ของข้อความแชท กดขีดล่างบนหัวหน้าต่างเพื่อใช้เหนือ Chatbar หรือขยายกลับเต็มหน้าได้ มือถือใช้หน้าต่างเต็มจอ

หน้าต่าง Pokémon ใช้ธีมเกมเฉพาะ: Pokédex แดง/ขาว/น้ำเงิน ปุ่มสีเหลืองและสนามต่อสู้สีฟ้า/เขียว ไม่เปลี่ยนธีมหลัก RoleForge

สนามต่อสู้มี 20 แบบ ใช้ภาพพื้นหลังและฐานยืนจาก Pokémon FireRed ส่วน Poké Ball, Great Ball, Potion และหินวิวัฒนาการใช้ sprite จากเกม เก็บไฟล์หลักไว้ใน Addon แล้ว แหล่งภาพเป็น community mirror ของภาพต้นฉบับเกม ระบุ URL, revision และ checksum ใน `data/game-assets.json` ไม่ใช่ภาพวาดเลียนแบบหรือคำกล่าวอ้างว่า mirror เป็นเว็บ official

แถบหลักมี การเดินทาง / ทีม / Pokédex / กล่อง / กระเป๋า / ตั้งค่า การต่อสู้ การจับ การใช้ไอเทมและวิวัฒนาการตรวจเงื่อนไขแล้วคำนวณในเครื่อง กด “บรรยายต่อในแชท” เพื่อให้ AI ต่อข้อความเดิมโดยไม่เพิ่มข้อความผู้เล่น และไม่อ่าน draft ที่ยังไม่ส่ง เปิดการบรรยายอัตโนมัติได้ในตั้งค่า การปิดหน้าต่างไม่ยกเลิกการเจน

ไฟล์การ์ดตัวอย่าง `Pokemon-Preview-Adventure.json` ใช้กับ runtime พรีวิวนี้และเปิด Addon ให้อัตโนมัติ ตัวอย่างมี Ralts Lv.20 เป็นเพื่อนเก่าอยู่ก่อนแล้ว เพื่อให้ทดลองการพัฒนาเป็น Kirlia ได้ทันที การเริ่มผ่าน Addon ในแชททั่วไปจะเริ่มจากตัวที่เลือกตามปกติ

## สิ่งที่ทำงาน

- แค็ตตาล็อกออฟไลน์ 1,025 สายพันธุ์ / 1,579 รายการฟอร์มจาก snapshot PokeAPI ระบุ commit ไว้ใน `src/workshop/pokemon/data/source.json`
- ค้นหาชื่อ/หมายเลขเต็ม เช่น #0025 กรองธาตุและเจเนอเรชัน ดูฟอร์ม สถิติ ความสามารถและข้อมูลวิวัฒนาการ แสดงทีละ 24 รายการ ภาพโหลดเมื่อเปิดดู
- เลือกคู่หูจริงจาก 9 ภูมิภาค จัดทีมไม่เกิน 6 ตัว เลือกคู่หูนำทีม เปลี่ยนชื่อเล่น และเก็บ/ถอนตัวเดิมจากกล่อง
- ต่อสู้ป่าแบบเดี่ยว คิด HP ค่าพลัง ความเร็ว ประสิทธิภาพธาตุ STAB ความแม่นยำ critical และ PP มีการสวนกลับ ใช้ Potion เปลี่ยนตัวและออกจากการต่อสู้ ปุ่มหลักเป็น ต่อสู้ / กระเป๋า / โปเกมอน / หนี ใช้ Potion จากกระเป๋านอกสนามได้ด้วย
- การจับมีโอกาสล้มเหลว ใช้บอลทั้งเมื่อสำเร็จ/ไม่สำเร็จ ถ้าทีมเต็ม ตัวที่จับสำเร็จเข้ากล่อง ไม่ให้จับตัวที่หมดสภาพ
- ได้ EXP/เลเวลเมื่อชนะ ฟื้นฟู HP และ PP ที่ปุ่มศูนย์โปเกมอน วิวัฒนาการตามเงื่อนไขเลเวลหรือไอเทมที่รองรับ ตัวเดิมคง ID ชื่อเล่น ความเสียหาย HP และประวัติไว้
- ให้ AI เปิด encounter จากข้อความบรรยายที่มองเห็นและระบุชนิดชัดเจนได้ ผ่าน protocol ด้านล่าง ผลการจับ/การต่อสู้จริงยังตัดสินโดย engine
- บันทึกตามข้อความ swipe และเนื้อหาที่เป็นจุดยึด ตัด Branch ก่อนการจับแล้วไม่มีตัวจากอนาคตตามมา ปิด Addon ซ่อนหน้าต่าง ปุ่มลอย และ prompt โดยเก็บประวัติไว้
- รองรับ UI ไทยและอังกฤษ ชื่อสายพันธุ์ใช้ชื่อมาตรฐานภาษาอังกฤษ มี alias ค้นหาไทยสำหรับบางชื่อ

## ขอบเขตพรีวิว

เป็นระบบต่อสู้เดี่ยวแบบย่อ ไม่ใช่ competitive simulator ที่จำลองทุกกลไก ความสามารถตามสายพันธุ์ อากาศ สถานะผิดปกติ EV/natures การแลกเปลี่ยน การต่อสู้กับ Trainer, PvP, ช้อป และการเปลี่ยนร่างต่อสู้ เช่น Mega/Tera/Dynamax ยังไม่ได้จำลอง รายละเอียดของสิ่งเหล่านี้ใน Pokédex เป็นข้อมูลอ้างอิง การพัฒนาที่มีเงื่อนไขพิเศษยังปิดปุ่มไว้

จำนวนข้อมูลเป็นขอบเขต snapshot จาก PokeAPI ไม่ใช่คำยืนยันว่ารวมเนื้อหาแฟรนไชส์ที่แหล่งข้อมูลยังไม่มี ภาพมีตรงฟอร์ม 1,531 รายการ อีก 48 รายการแสดงว่าไม่มีภาพตรงฟอร์ม ภาพคู่หูและตัวใน showcase เก็บในพรีวิว ส่วนภาพอื่นโหลดจาก public sprite repository เมื่อเปิดดู ต้องใช้อินเทอร์เน็ต ไม่มีการใช้รูปฟอร์มอื่นหลอกว่าเป็นรูปของฟอร์มนั้น

กระเป๋าโปเกมอนแยกจากกระเป๋าและเงินหลัก RoleForge ในรุ่นนี้ มีชุดไอเทมเริ่มต้น ยังไม่มีร้านเติมไอเทม การสำรวจใช้ตัวอย่างชนิดโปเกมอนตามภูมิภาค การเดินทาง/สถานที่ในเนื้อเรื่องยังบรรยายโดย AI

การสำรอง Workshop ส่งออกแพ็กและสถานะเปิดใช้ ความคืบหน้าเกมอยู่ใน **ไฟล์แชท** จึงต้อง export แชทเพื่อย้ายเครื่องด้วย

## ข้อมูลจากการ์ดและ AI

การ์ดระบุ `data.extensions.roleforge_pokemon` ได้ เช่น:

```json
{"format":"roleforge-pokemon-rules","version":1,"region":"Kanto","starterLevel":5,"initialParty":[{"speciesId":280,"level":20}]}
```

การ์ดที่ต้องการเปิด Addon ให้อัตโนมัติใช้ `data.extensions.roleforge_workshop`:

```json
{"format":"roleforge-workshop-card-defaults","version":1,"enabled":["pokemon"]}
```

เมื่อ AI บรรยายการพบโปเกมอนในฉากจริง ให้แนบเหตุการณ์พร้อมคำบรรยายที่มองเห็นและมีชื่อ species ภาษาอังกฤษชัดเจน เช่น:

```html
<tr-narrative>Pidgey ป่าตัวหนึ่งโผล่ออกมาจากพุ่มไม้ตรงหน้าคุณ</tr-narrative>
<!--roleforge_pokemon:{"events":[{"type":"encounter","speciesId":16,"level":3,"evidence":"Pidgey ป่าตัวหนึ่งโผล่ออกมาจากพุ่มไม้ตรงหน้าคุณ"}]}-->
```

ข้อมูลซ่อนอย่างเดียว ชื่อใน lore หรือคำพูดถึงโปเกมอนที่ไม่ได้อยู่ในฉาก ไม่สร้าง encounter ไม่มีคำสั่ง AI สำหรับบังคับให้จับสำเร็จหรือเพิ่มของโดยข้าม engine

## วิดีโอและการทดสอบ

บันทึกจาก SillyTavern 1.19.0 ด้วย Playwright มี PC และ mobile touch emulation มือถือเป็นการจำลองเบราว์เซอร์ ไม่ใช่ iPhone จริง ตัวอย่างคำตอบ AI ใช้ controlled SSE ภายในเครื่อง ไม่ใช้บริการโมเดลหรือเสียงภายนอก กลไกเกมใช้ reducer จริงทั้งหมด

วิดีโอเว้นให้อ่านแต่ละช่วง 8 วินาที แบ่งสารบัญ 40 ขั้นตอน ซับไทยอยู่บนแถบทึบภายในกรอบจอ ไม่ทับ UI และไม่ต่อภาพให้ยาวกว่าสัดส่วนที่เลือก คอม 1920×1080 (16:9) ใช้ซับ 46 px มือถือ 1170×2532 (สัดส่วน iPhone 390×844) ใช้ซับ 68 px

คำสั่งตรวจสอบ:

```sh
npm test
npm run check
npm run test:pokemon:real
PK_RECORD=1 npm run test:pokemon:all
node tests/build-pokemon-game-showcase.mjs
```

ดูการอ้างอิงข้อมูล/ภาพที่ `src/workshop/pokemon/CREDITS.md` และ BSD license ของข้อมูลที่ `src/workshop/pokemon/data/LICENSE-PokeAPI.txt`

## ตัวอย่าง Showcase ทุกฟีเจอร์

การ์ด `Pokemon-Feature-Tour.json` มีเพื่อนเก่า 5 ตัวก่อนเลือก starter ตัวที่ 6 เพื่อให้ลองทีมเต็มและส่งตัวที่จับเข้ากล่องได้ Ralts Lv.20 ใช้แสดงวิวัฒนาการตามเลเวล Eevee ใช้แสดงวิวัฒนาการด้วยหิน และ Bulbasaur Lv.15 มี EXP ก่อนเลเวลถัดไป 1 หน่วย เมื่อชนะการต่อสู้จริงจึงขึ้น Lv.16 ไม่ได้ให้เลเวลล่วงหน้าหรือให้ปุ่มข้ามเงื่อนไข

ค่า `initialParty[].exp` เป็นข้อมูลเริ่มต้นจากการ์ดและถูกจำกัดภายในเลเวลนั้น ไม่รับ EXP ที่ข้ามหลายเลเวล ตัวที่เล่นตามปกติยังต้องสะสม EXP จากเกม

ตารางฟีเจอร์ที่แสดง ผลตรวจ PC / mobile ใน Chromium และ WebKit รวมถึงรายการกลไกที่ยังไม่จำลองอยู่ในไฟล์ `feature-coverage.json` ของชุด showcase
