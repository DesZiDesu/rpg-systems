## ผลตรวจเดิมก่อนอัปเดต 0.2.0

| ระบบ | สถานะปัจจุบัน |
| --- | --- |
| ไอเทม | ใช้งาน 8 ชิ้น: Poké Ball, Great Ball, Potion, Fire/Water/Thunder/Leaf/Moon Stone ไม่มี Master Ball หรือ Ultra Ball |
| การเชื่อมกระเป๋า | กระเป๋า Pokémon เป็นของ engine แยกจาก RoleForge สิ่งที่ AI เพิ่มลงกระเป๋าหลักยังไม่เพิ่มลง Pokémon โดยอัตโนมัติ |
| สนาม | เพิ่มเป็น 20 แบบจากภาพและ palette เกม FireRed เลือกเองหรืออัตโนมัติจากสถานที่ในโรล ภาพยิมไม่ได้ทำให้มีระบบ Trainer battle |
| Center | มีปุ่มฟื้น HP/PP นอกการต่อสู้ แต่ยังไม่มีหน้าศูนย์หรือเงื่อนไขว่าต้องอยู่ในศูนย์จริง |
| ฝึกท่า | สร้างชุดท่าจากท่าตามเลเวล และเติมท่าเมื่อเลเวลขึ้นหากมีช่องว่าง ยังไม่มีหน้าฝึก/ลืม/จำท่า และ engine รองรับท่าโจมตีเป็นหลัก |
| สเตตัสรายตัว | ชนิด/ฟอร์มมี base stats ต่างกัน แต่ชนิด ฟอร์ม และเลเวลเดียวกันมีค่าสเตตัสเท่ากัน เพราะใช้ IV 31 ทุกค่า ไม่มี EV/Nature รายตัว |
| Cheat | ยังไม่มีหน้าเสกตัว เสกของ หรือแก้ค่ารายตัว |
| เพศ | ยังไม่มีข้อมูลเพศรายตัวหรือการสุ่มตามสัดส่วนสายพันธุ์ |
| ความครอบคลุม | ข้อมูล 1,025 สายพันธุ์ / 1,579 รายการฟอร์ม Gen 1–9 ใน snapshot ที่บันทึกไว้ 1,531 ฟอร์มมีภาพตรงฟอร์ม |
| การพบและจับ | engine รับ encounter ของทั้ง 1,025 สายพันธุ์ได้ แต่ปุ่มสำรวจใช้กลุ่มตัวอย่าง 83 รายการ / 82 สายพันธุ์ไม่ซ้ำ ไม่ใช่ spawn table ครบโลก ฟอร์ม battle-only ไม่ปรากฏเป็นตัวป่า |
| โปเกมอนในตำนาน | 71 Legendary + 23 Mythical นับสายพันธุ์ไม่ซ้ำตาม flags ของ PokeAPI ไม่รวม Ultra Beast/Paradox เป็น Legendary เพิ่มเอง และไม่สื่อว่าปลดล็อกให้พบอัตโนมัติ |

## แผนที่ดำเนินการใน 0.2.0

- [x] สร้างทะเบียนไอเทมที่แยก “มีข้อมูล” กับ “ใช้เอฟเฟกต์ได้จริง” รองรับ Master/Ultra และบอลพิเศษทีละกลไก Master Ball จับตัวป่าที่จับได้สำเร็จแน่นอน แต่ไม่เปลี่ยนสิทธิ์จับโปเกมอนของ Trainer
- [x] เพิ่มการรับของจากโรล รางวัล และร้าน ผ่าน event ที่มีรหัสกันซ้ำก่อนเพิ่มจำนวน ไม่ให้การพูดถึงไอเทมเท่ากับได้รับของ
- [x] เชื่อมกระเป๋า RoleForge ด้วย adapter และ ID เช่น pokemon:master-ball แสดงร่วมได้แต่เก็บจำนวนจริงจากแหล่งเดียว ไม่คัดลอกสต๊อกไว้สองชุดหรือตัดจำนวนสองครั้ง ต้องมีแผนย้ายข้อมูลเก่าและทดสอบ Branch
- [x] ทำหน้า Pokémon Center พร้อมรายชื่อทีมและปุ่มรักษา ฟื้นตัวหมดสภาพ HP/PP และสถานะที่ระบบรองรับ การเข้ารับบริการต้องอิงสถานที่ในโรล การเปิด UI ไม่ย้ายตัวละครไปศูนย์เอง
- [x] เพิ่มหน้าจัดท่า 4 ช่อง: เรียนท่าที่ถึงเลเวลแล้ว จำท่าเดิม และเลือกท่าที่จะลืมโดยยืนยันก่อน บอกชัดว่าท่าไหน engine ยังไม่รองรับ
- [x] เพิ่มข้อมูลความเข้ากันได้ของ TM/TR/Move Tutor ตามภาค ก่อนอนุญาตให้สอนจริง ไม่ใช้เพียงการมีชื่อท่าใน Pokédex
- [x] เพิ่ม IV รายตัว 0–31, EV 0–252 ต่อค่า/รวม 510 และ Nature ตามสูตรเกม สุ่มด้วย seed ที่บันทึกไว้และคงค่าผ่านการพัฒนา รีโหลด จับ และ Branch
- [x] ย้ายข้อมูลเก่าอย่างคงค่าเดิม เพื่อไม่ให้โปเกมอนที่มีอยู่ถูกสุ่มสเตตัสใหม่เอง
- [x] เพิ่มเพศผู้/เมีย/ไม่มีเพศตาม gender_rate ของสายพันธุ์ ไม่สุ่มทุกชนิดแบบ 50/50 และไม่เปลี่ยนเมื่อรีโหลด
- [x] เพิ่มหน้า Sandbox/Cheat ที่ผู้ใช้เปิดเอง: เสกสายพันธุ์/ฟอร์มที่รองรับ เลือกเข้าทีมหรือกล่อง ปรับเลเวล IV/EV/Nature/เพศ/Shiny/ชื่อเล่น เสกไอเทม และแก้ค่าสเตตัสโดยตรงในโหมด override
- [x] ให้ Cheat ใช้ event ที่บันทึกและย้อนตาม Branch ได้เหมือนการเล่นปกติ แสดงเครื่องหมายว่ามีการแก้ไข และกัน AI เปิด Cheat หรือเสกของเอง
- [x] เพิ่มตาราง encounter ที่ครอบคลุมภูมิภาคและชีวนิเวศมากขึ้น พร้อมเงื่อนไขเควสสำหรับ Legendary/Mythical แยกจากการมีรายการใน Pokédex
- [x] เตรียมให้ต้นแบบทำงานร่วมกับ RoleForge รุ่นล่าสุด ก่อนเสนอรวมเข้า main
