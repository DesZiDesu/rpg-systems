# RoleForge 0.66.1 · ตั้งจำนวน Lore ได้

Lore Management ไม่มีเพดาน 200 รายการแล้ว ค่าเริ่มต้นเป็น **ไม่จำกัดจำนวนรายการ** รวมรายการที่เปิดและปิดไว้ คลังเดิมยังอยู่ครบและไม่ถูกตัดเมื่ออ่านข้อมูล

## ตั้งค่า

เปิด **Lore Management → ⋯ → คลังและการส่ง Lore** แล้วเลือก **จำนวนรายการ Lore**:

- **ไม่จำกัดจำนวนรายการ**: เพิ่มได้โดยไม่มีเพดานจำนวนจาก RoleForge
- **กำหนดจำนวนสูงสุด**: กรอกจำนวนเต็มตั้งแต่ 1 ขึ้นไป เช่น 500 / 1,000 / 5,000 แล้วกด **บันทึกการตั้งค่า Lore**

ตั้งค่าจำนวนไว้ใน Preset ของแชท ใช้ผ่าน World Preset และข้อมูลพ่วงการ์ดได้ตามเดิม ส่วนคลัง Lore ยังคงผูกกับการ์ดร่วมกันทุกแชท ลดเพดานต่ำกว่าจำนวนเดิมแล้วข้อมูลยังอยู่และแก้ไข/ลบได้ แต่เพิ่มจำนวนให้มากขึ้นไม่ได้จนกว่าจะเพิ่มเพดานหรือเลือกไม่จำกัด

## คลังใหญ่กับงบส่งให้ AI

จำนวนรายการในคลังแยกจากงบที่ส่งให้ AI ไม่จำกัดจำนวนไม่ได้เพิ่ม Context หรือส่งข้อมูลทั้งหมดโดยอัตโนมัติ งบและการตรวจโหมดส่งทั้งหมดคงกติกาเดิม สำหรับโลกที่มีข้อมูลมาก ให้เลือก **อัตโนมัติเฉพาะที่เกี่ยวข้อง** เพื่อเลือกข้อมูลภายในงบที่ตั้งไว้

หน้ารายชื่อยังแสดง 20 รายการต่อหน้า ค้นหา กรอง เปิด/ปิดหลายรายการ และ Undo ได้ตามเดิม จำนวน Lore และการเลือกไม่ทำคำขอ AI เพิ่ม

## Import / Export และการ์ด

Import/Export ไม่ตัดรายการหลังอันที่ 200 นำเข้าจะใช้เพดานที่ตั้งในแชทนั้นและเพิ่มรวมแบบข้ามข้อมูลซ้ำ หากเกินเพดานหรือการบันทึกล้มเหลว จะไม่เขียนทับคลังเดิม

ไฟล์นำเข้าแต่ละไฟล์ยังไม่เกิน 12 MB หากคลังใหญ่กว่านั้น กด Export JSON แล้วจะเห็นปุ่มดาวน์โหลดส่วนที่ 1 / 2 / … ให้ดาวน์โหลดครบทุกส่วน แล้วนำเข้าแต่ละไฟล์ในการ์ดเดียวกัน แต่ละส่วนเป็นไฟล์ Lore JSON ปกติ ไม่มีการตัดรายการหรือแบ่งเนื้อหาหนึ่งรายการกลางทาง ค่าขีดจำกัดและงบไม่เปลี่ยนจากการนำเข้าไฟล์ข้อมูล

การบันทึก RoleForge Character Card Pack และนำเข้าการ์ดใหม่เก็บ Lore จำนวนมากพร้อมค่าที่ตั้งไว้ ข้อมูลเดิมและค่าที่ผู้ใช้ปรับในแชทมีลำดับความสำคัญตามระบบ Preset เดิม ขีดจำกัดจำนวน NPC ไม่เปลี่ยนในการอัปเดตนี้
