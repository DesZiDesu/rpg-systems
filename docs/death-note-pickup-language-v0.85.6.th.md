# RoleForge 0.85.6 — อ่านการหยิบสมุดจากสำนวนและโรล

ตัวตรวจเดิมรองรับสำนวนไม่ครบ ใช้คำปฏิเสธกับข้อความทั้งย่อหน้า และข้ามคำบรรยายที่ยาวเกิน 1,200 ตัวอักษร แม้ท้ายย่อหน้าจะยืนยันว่าผู้เล่นหยิบสมุดสำเร็จ ทำให้การเก็บสมุดที่เกิดขึ้นในโรลไม่สะท้อนใน Addon

## สิ่งที่เปลี่ยน

- อ่านการกระทำผู้เล่นร่วมกับผลในโรล AI รองรับ “หยิบ”, “เก็บ”, “คว้า”, “ฉวย”, “รับ”, “ยก”, “สอด/เก็บใส่กระเป๋า” และ pick up, take, grab, lift, scoop up, retrieve, collect, receive, pocket, tuck/stow into a bag
- เมื่อมีสมุดที่พบแล้วเพียงเล่มเดียว รองรับการละกรรม เช่น “เก็บขึ้นมา”, “เก็บใส่กระเป๋า” และ “I lift it” โดยยังต้องมีการยืนยันจากโรล AI
- แยกประโยค ย่อหน้าและคำเชื่อมสำคัญ อ่านได้ทั้งโรลสั้นและยาว รวมผลยืนยันอย่าง “สมุดมาอยู่ในมือคุณ” หรือ “The notebook now rests in your pocket” หลังการหยิบจริงของผู้เล่น
- คำปฏิเสธที่ไม่เกี่ยวกับการหยิบ เช่น “ไม่ได้สนใจฝน” หรือ “never hesitate” ไม่ยกเลิกการหยิบในประโยคเดียวกัน ส่วนแผน คำถาม ความพยายามที่ยังไม่สำเร็จ คำสั่งให้คนอื่นหยิบ และการปฏิเสธการหยิบจริงยังไม่ให้สมุด
- ใช้ผลการกระทำหลังสุด: การปฏิเสธภายหลังลบคำยืนยันก่อนหน้าได้ทั้งในย่อหน้าเดียวและคนละบล็อก narrative
- อ่านจากเนื้อหาที่มองเห็น ไม่ใช้ think, hidden comments หรือ dialogue อย่างเดียวเป็นหลักฐานว่าสมุดถูกเก็บแล้ว ปรับคำสั่ง AI ให้ใช้ ID เดิมและอ้างคำบรรยายสำเร็จจริง

เปลี่ยนที่ runtime ส่วนกลาง ใช้กับทุกแชทที่เปิด Death Note Addon หลังอัปเดต RoleForge และรีโหลด ไม่แก้ไขข้อความเฉพาะไฟล์ของผู้เล่น ระบบเล่นซ้ำตามข้อความปัจจุบันและช่วง Branch ที่เลือก

การกู้จากโรลยังจำกัดที่สมุดจริงซึ่งพบแล้วเพียงเล่มเดียวและไม่มีผู้ถือ เพื่อไม่เดาเล่มผิดหรือดึงสมุดจาก NPC สมุดหลายเล่ม การยืม/ส่งต่อ และเศษกระดาษยังใช้เหตุการณ์ที่ระบุเล่ม/เจ้าของชัดเจน ไม่มีการสร้างความยินยอม การค้นพบ หรือเล่มใหม่จากคำกล่าวคลุมเครือ ไม่มี User turn เพิ่ม และไม่เรียกโมเดลเพื่อกู้ประวัติ

## การตรวจสอบ

ทดสอบหน่วยทั้งชุด 1,833 รายการและ syntax checks บนโค้ดรุ่นนี้ รวมสำนวนไทย/อังกฤษ โรลเกิน 1,200 ตัวอักษร คำปฏิเสธ วัตถุอื่น NPC หยิบ เศษกระดาษ สมุดหลายเล่ม การแก้ข้อความ และ Branch ก่อนหยิบ

ทดสอบ SillyTavern 1.19.0 บน Chromium และ WebKit ทั้ง PC 1440×1120 กับ mobile touch emulation 390×844: Send จริงผ่านคำตอบ SSE จำลองที่ใช้ ID ผิด, ได้สมุดถูกเล่มจำนวน 1, native Branch ก่อนหยิบกลับเป็นจำนวน 0 และกดปุ่มหยิบผ่าน Continue ได้โดยไม่ส่งข้อความ User และไม่ล้าง draft

นำเข้าสำเนาไฟล์ Branch เดิมพร้อมการ์ด No Portraits เพื่อตรวจว่าการเล่นซ้ำกู้สมุดถูกเล่มได้ ข้อความทุกข้อความและสถานะตำแหน่งไม่ถูกแก้ ไม่มีการเรียกโมเดลเพิ่มเพื่อซ่อมประวัติ ไฟล์และภาพส่วนตัวไม่รวมใน Git ภาพที่เผยแพร่ใช้ข้อมูลทดสอบเท่านั้น
