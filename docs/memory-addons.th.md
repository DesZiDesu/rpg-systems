# RoleForge Memory Addons · v0.55.1

ย้าย Summary ออกจากหน้าต่าง RoleForge มาเป็น drawer แยกในตั้งค่าส่วนเสริม ใช้หน้าตาดำ–เทาตามแบบที่เลือก ระบบสรุปและคลังความจำยังเป็นระบบเดิม ไม่ต้องติดตั้งส่วนเสริมอีกตัวหรือล้างข้อมูล

## เปิดใช้งาน

1. อัปเดต RoleForge แล้วรีโหลดหน้า SillyTavern หนึ่งครั้ง
2. เปิด **ตั้งค่าส่วนเสริม → RoleForge → ระบบเสริม → RoleForge Memory Addons**
3. drawer **RoleForge Memory Addons** จะแสดงในตั้งค่าส่วนเสริม ถัดจาก RoleForge โดยเริ่มแบบพับไว้ กดชื่อเพื่อขยายหรือพับได้ แม้เปิดระบบไว้แล้ว เมื่อโหลดหน้าใหม่ drawer ก็เริ่มพับไว้

ผู้ที่เปิด Summary อยู่แล้วจะเห็น drawer ใหม่โดยใช้ค่าตั้งเดิม ผู้ที่ยังไม่เคยเปิดยังต้องเปิดสวิตช์ตามเดิม ปิดสวิตช์แล้วระบบหยุดงานความจำและซ่อน drawer แต่เก็บคลังกับค่าตั้งไว้ เปิดกลับหรือรีโหลดแล้วยังอ่านคลังเดิมได้

## สิ่งที่อยู่ใน drawer

- ด้านบนแสดงแชตปัจจุบัน จำนวนข้อความที่สรุปแล้ว ข้อความรอสรุป และบทที่บันทึกแล้ว
- **สรุปข้อความที่เหลือ** ประมวลผลข้อความรอสรุปเป็นชุด บันทึกทุกชุดที่สำเร็จ มีแจ้งเตือน API แบบ SillyTavern ก่อนแต่ละคำขอ
- **เตรียมความจำสำหรับแชตใหม่** ใช้งานเดิมสำหรับสรุปประวัติที่ยังค้างและเตรียมความจำส่งต่อ อาจเรียก AI หากยังมีข้อความรอสรุป การย้ายสถานะ RPG ใช้สวิตช์สานต่อข้อมูลตัวละครเดิม
- **ค้นความจำ** เปิดช่องค้นทันที ค้นต้นฉบับ ดูหลักฐาน และเลือกข้อมูลที่ให้ความสำคัญได้โดยไม่เรียก AI เพิ่ม
- แถบโทเคนแสดงความจำที่เตรียมส่งเข้า prompt เทียบกับงบภาพรวมและค้นคืน รวมคำอธิบายของระบบ ไม่ใช่ context ทั้งหมดหรือยอดเรียกเก็บของ provider
- ส่วนที่พับได้เก็บการสรุปอัตโนมัติ งบความจำ คลังบทสรุปและรุ่นแก้ไข หมวดความจำ 15 หมวด มุมมอง Smart Memory วิธีสรุป/API ประวัติที่เชื่อม รุ่นส่งต่อ การนำเข้า–ส่งออก และรายละเอียดงานล่าสุด

การบันทึกค่าตั้งแต่ละกลุ่มจะเปลี่ยนเฉพาะกลุ่มนั้น ค่าที่กำลังพิมพ์ยังอยู่เมื่อความคืบหน้าอัปเดต แต่ล้างร่างที่ยังไม่บันทึกเมื่อเปลี่ยนแชตเพื่อไม่ให้ข้อมูลของแชตเก่าตามไป ถ้ายังไม่เปิดแชต จะปรับค่าตั้งทั่วไปได้ แต่ปุ่มสรุปและการทำงานกับคลังจะปิดไว้

## ระหว่างสรุป

พับ drawer หรือปิดหน้าตั้งค่าได้ งานยังทำต่อ สถานะและปุ่มหยุดยังอยู่เหนือ chatbar กด **ดู** เพื่อเปิด drawer ความจำในตั้งค่าส่วนเสริมโดยตรง ไม่เปิดหน้าต่าง RoleForge ซ้อนขึ้นมา

กด **หยุด** แล้วเก็บทุกชุดที่บันทึกสำเร็จไว้ ผล API ที่มาถึงหลังยกเลิกจะไม่ถูกนำมาใช้ หากเกิดข้อผิดพลาดใหม่ ระบบเปิดส่วนรายละเอียดงานให้ตรวจได้ และรอให้กดลองใหม่เอง ไม่มีการเรียก API ซ้ำเพียงเพราะเปิดหรือพับ UI

## ข้อมูลเดิม

ยังใช้คลัง IndexedDB เดิม บทสรุป รุ่นแก้ไข ข้อความต้นฉบับ ลิงก์ต้นทาง การค้นหา สำรองคลัง และประวัติที่เชื่อมไว้ยังใช้งานได้ การแยกแขนงของเนื้อเรื่องและการส่งต่อแชตใหม่คงพฤติกรรมเดิม การซ่อน drawer ไม่ลบฐานข้อมูล

นี่เป็นการย้าย UI ของ Summary เดิม ไม่ได้เพิ่มกลไกความจำใหม่ตามทุกฟีเจอร์ของส่วนเสริมในภาพอ้างอิง
