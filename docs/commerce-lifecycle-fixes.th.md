# RoleForge 0.55.3 · รอข้อเสนอ เปิดรายการ และยืนยันซื้อขาย

อัปเดตส่วนเสริมแล้วรีโหลดหน้า SillyTavern เพื่อโหลด JavaScript และ CSS รุ่นเดียวกัน ไม่ต้องล้างข้อมูลแชต เงิน ไอเทม หรือ API key

## ปัญหาที่แก้

เส้นทางเดิมแสดงหน้าต่างรอเฉพาะประมูล ตัวอ่านข้อเสนอห้องพักปฏิเสธเมนูที่ใช้หลายหน่วยเงิน และยังต้องเห็นกุญแจในเรื่องก่อนเปิดรายการ จึงไม่เปิด Tab ซื้อแม้ผู้เล่นขอเช่าจริงและ NPC เสนอราคาแล้ว

ตอนนี้คำขอซื้อ เช่า หรือขายที่ผ่านการตรวจเจตนาจะเปิด Tab ของระบบนั้นพร้อมข้อความ **รอ AI ตอบข้อเสนอและราคา…** ระหว่างเจน ไม่มีปุ่มจ่ายเงินหรือส่งของในขั้นรอ เมื่อคำตอบเสร็จ ตัวอ่านข้อมูลตรวจทั้ง marketplace patch และบทพูดสาธารณะผ่านจุดเปิดรายการเดียวกัน ไม่ใช้ planning/thinking เป็นหลักฐานราคา

การเอ่ยคำว่าซื้อขายเฉย ๆ การปฏิเสธ ข้อความนอกโรล และแผนในอนาคตยังไม่เปิดรายการซื้อขาย ถ้า NPC ไม่เสนอรายการพร้อมราคา จะแสดงสถานะที่อธิบายให้ถามต่อในแชตได้ หากข้อมูลที่มีโครงสร้างขัดกับบทพูด จะไม่ทิ้งข้อมูลนั้นแล้วเปิดด้วยราคาอีกชุด

## คำตอบล่าสุดที่ใช้ตรวจ

> “ผมอยากเช่าห้อง 1 คืนครับ”

บทพูดของ Garrick ที่ไม่มี marketplace patch และยังไม่ได้หยิบกุญแจ เปิดสองตัวเลือกจากคำตอบเดียว:

| ตัวเลือก | ราคา | รายละเอียดจากบทพูด |
| --- | --- | --- |
| ห้องพักรวมเตียงเดี่ยว | 5 ทองแดง | นอนรวม มีล็อกเกอร์เก็บของ |
| ห้องพักเดี่ยวชั้นบน | 2 เงิน | เตียงนุ่ม หน้าต่างมองถนน รวมอาหารเช้าซุปเนื้อแกะและขนมปังหนึ่งมื้อ |

รายละเอียดและของที่รวมอยู่ผูกกับห้องของตัวเอง ไม่คัดลอกอาหารเช้าของห้องเดี่ยวไปให้ห้องพักรวม แต่ละตัวเลือกแสดงราคาหน่วยเดิม บัญชีรวมใช้หน่วยเล็กที่สุดตามอัตราเดิม **1 ทอง = 100 เงิน และ 1 เงิน = 100 ทองแดง** เลือกห้องเดี่ยวอย่างเดียวจึงแสดง 2 เงินและส่งยอดยืนยัน 200 ทองแดง ไม่ตีความเป็น 2 ทองแดง การขายหลายชิ้นใช้การคำนวณเดียวกันและแปลงงบที่ทราบของผู้ซื้อด้วย

การเปิดรายการเป็นเพียงข้อเสนอ ยังไม่หักเงินหรือให้ไอเทม ยืนยันและบันทึกผลสำเร็จแล้วจึงให้ **กุญแจห้องพักเดี่ยวชั้นบน** พร้อมสิทธิ์เช่าหนึ่งคืน ข้อความนี้ไม่ได้บอกเวลาเช็กเอาต์ จึงไม่สร้างวันหมดอายุหรือเปลี่ยนหนึ่งคืนเป็น 24 ชั่วโมง การซื้อสถานที่ถาวรยังต้องมีหลักฐานประเภทและเงื่อนไขของสิทธิ์นั้น

ไม่มีคำขอ AI เพิ่มเพื่อเปิดรายการจากคำตอบนี้ การเสนอ ยืนยัน หรือยกเลิกยังใช้คำขอของระบบเดิม พร้อมแจ้งเตือน API และต่อโรลด้วย narrative/dialogue ตามเดิม

## ข้อมูลแชตเดิมและหน้าต่างร่วมกัน

คำตอบล่าสุดที่เคยถูกบันทึกว่าเปิดจากบทพูดไม่ได้ จะถูกอ่านใหม่ในเครื่องหลังอัปเดต หากยังตรงกับคำขอจริงของผู้เล่น ไม่ต้อง Regenerate และไม่เรียก API เพิ่ม ข้อมูลที่ผิดหรือขัดแย้งและรายการที่ยืนยัน ยกเลิก หรือปฏิเสธแล้วไม่ถูกเปิดซ้ำ

รายการเก่าที่ยังเปิดอยู่และมีหลายหน่วยเงินจะปรับราคาตัวเลือกและยอดรวม เก็บมูลค่าราคาที่ต่อรองไว้จริง พร้อมข้อความให้ตรวจราคาก่อนยืนยัน ไม่แก้ยอดเงินหรือผลธุรกรรมที่เสร็จแล้ว

เมื่อข้อเสนอพร้อม Tab ซื้อหรือขายจะเปิดให้เห็น โดยเก็บหน้าวิชาและการฝึกไว้แยกกัน สลับกลับได้ และยังรักษาสถานะย่อแถบของผู้เล่น ข้อมูลวิชา Cost, Cooldown จุดแข็ง จุดอ่อน เงื่อนไข และเหตุผลที่ยังร่ายเงียบไม่ได้ตัดบรรทัดในกรอบ แม้ธีมโฮสต์ตั้งข้อความเป็น nowrap หรือขนาดใหญ่

## หลักฐานการตรวจ

ทดสอบผ่าน loader, generation interceptor และเหตุการณ์ MESSAGE_RECEIVED / GENERATION_ENDED จริงของส่วนเสริม โดยควบคุมคำตอบ AI สำหรับการตรวจ ไม่ได้ใช้บัญชีโมเดลของผู้ใช้:

- Unit/host tests 800 เคส และ syntax checks ผ่าน
- จอ 320, 390 และ 1280px: แถบรอซื้อ/ขาย เมนูห้องต่างหน่วยเงิน การเปลี่ยนจากรอเป็นรายการ และการเก็บหน้าฝึก/วิชาไว้
- ยืนยันห้องเดี่ยว หัก 2 เงิน ให้กุญแจและสิทธิ์หนึ่งคืน ไม่มีเวลาเช็กเอาต์ที่เดาขึ้น เหตุการณ์ซ้ำไม่หักเงินอีก
- อ่านคำตอบล่าสุดที่เคยเปิดไม่สำเร็จใหม่ในเครื่อง ยกเลิกแล้วไม่เปิดซ้ำ ไม่มี API สร้างรายการเพิ่ม
- ขายหลายชิ้นต่างหน่วยเงิน เลือกตัดบางชิ้นออก จ่ายและโอนเฉพาะของที่เลือก
- ระบบสิทธิ์เช่า เข้าใช้ ซื้อถาวร งานบริการ มัดจำ คืนสิทธิ์ และการฝึก/บทร่ายเดิม
- บังคับ CSS โฮสต์ให้รายละเอียดวิชากว้างและไม่ตัดบรรทัด แล้วตรวจว่าข้อความและปุ่มยังอยู่ในกรอบ
