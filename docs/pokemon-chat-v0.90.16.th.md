# Pokémon 1.7.1 / RoleForge 0.90.16 — League Circuit

นำแบบ A ที่เลือกมาใช้กับ Header, Dialogue และ Narrative ของโปเกมอนในแชทจริง กรอบเป็นสี่เหลี่ยมครบทั้งสี่มุม ไม่มีการตัดมุม ทั้งคอมและมือถือ

## การใช้งาน

อัปเดต RoleForge จาก main แล้วรีเฟรชหน้า SillyTavern แชทที่เปิด Pokémon addon อยู่แล้วใช้ระบบนี้ได้โดยไม่ต้องล้างข้อมูลหรือสร้างตัวละครใหม่ Workshop มีแพ็ก Pokémon 1.7.1 ด้วย

- **ชื่อ:** ใช้ nickname ถ้ามี ถ้าไม่มีใช้ชื่อจาก Pokédex ของ addon โดยตรง ไม่ใช้ชื่อไทยที่กำหนดไว้เฉพาะภาพพรีวิว
- **Header:** แสดงภาพ, Lv, เพศ, HP ปัจจุบัน/ค่าสูงสุด และเจ้าของ ข้อมูลมาจากโปเกมอนรายตัว ไม่ใช่ค่าสเตตัส NPC ทั่วไป HP 0 แสดงเป็น 0
- **เจ้าของ:** ตัวในทีม/กล่องเป็นของผู้เล่น ตัวในทีม Trainer ใช้ชื่อ Trainer ตัวป่าแสดงว่าไม่มีเจ้าของ ค่าที่ไม่มีข้อมูลไม่ถูกเติมขึ้นเอง
- **ภาพ:** ตาม Artwork/Sprite และการเปิด–ปิด motion ที่ตั้งค่าไว้เดิม รวมฟอร์ม Shiny และภาพเพศที่มีในดัชนี เมื่อปิด motion จะเลือกไฟล์ภาพนิ่ง เมื่อเปิดแต่ไม่มีไฟล์ขยับใช้ภาพที่ตรงฟอร์มพร้อม idle เล็กน้อยตามพฤติกรรมของ addon
- **เปิดข้อมูล:** กด Header ของตัวที่เป็นเจ้าของเพื่อเปิดรายละเอียดตัวนั้นโดยตรง Header ของฝ่ายตรงข้ามเปิดข้อมูล Pokédex ของฟอร์มนั้น
- **กรอบ/ฟอนต์:** ใช้สวิตช์ Header, Dialogue และ Narrative เดิมของ RoleForge แยกกัน ฟอนต์ชื่อ บทพูด และบรรยายตามธีม RoleForge ปัจจุบัน คนกับผู้เล่นใช้หน้าตาเดิม
- **ประวัติ:** เปลี่ยนชื่อ, รีโหลด, ลบ/สลับข้อความ และเปลี่ยนแชทใช้ข้อมูลจากการ replay เกม ไม่เก็บสำเนา HP หรือชื่อแยกอีกชุดใน Header

Dark Lite ตามไฟล์ที่ผู้ใช้ส่งมาใช้สำหรับถ่ายภาพและตรวจในโปรไฟล์ QA การอัปเดตไม่เปลี่ยนธีม SillyTavern ของผู้เล่นคนอื่น

## การเชื่อมกับแชท

บริบท Pokémon ที่ส่งให้ AI มี `chatSpeaker` ของแต่ละตัว เช่น `pokemon:initial-0` ให้ใช้เป็นชื่อผู้พูดในแท็ก RoleForge ตามเดิม ตัวเรนเดอร์แสดงชื่อจริงจากข้อมูลเกมแทน ID และไม่เพิ่มโปเกมอนลง NPC directory

ชื่อเล่นหรือชื่อสายพันธุ์ที่ไม่กำกวมยังจับคู่ได้ แต่เมื่อมีชื่อซ้ำหรือมีมนุษย์ใช้ชื่อนั้น ระบบใช้ ID เพื่อแยกตัวและเจ้าของ ไม่เลือกตัวแรกโดยเดา ทั้งโหมด RoleForge และโหมด Shared ที่รักษา HTML/Regex ของโฮสต์ใช้ส่วนแสดงผลเดียวกัน

ตัวแก้ข้อมูลเมื่อจบข้อความจะข้าม namespace `pokemon:` แม้ addon ยังอยู่ระหว่างเริ่มทำงาน จึงไม่สร้าง NPC ปลอมจาก Header ระหว่างเปิดแชทใหม่

## ตรวจสอบ

- Unit/host tests 2,177 รายการผ่าน รวมชื่อเล่น/ชื่อ Pokédex, HP 0/ค่าที่ไม่มี, เจ้าของ, ชื่อชนกัน, ฟอร์ม/เพศ/Shiny, ภาพนิ่ง/ขยับ และการย้อนประวัติ
- ตรวจ syntax และความสอดคล้องของเวอร์ชัน asset ทั้ง runtime เพื่อไม่ให้ browser โหลด singleton คนละรุ่น
- ตรวจ renderer ธีม RoleForge เดิมที่ 320, 390 และ 1280 px ผ่าน
- ตรวจส่วนแสดงผลใหม่ใน SillyTavern จริงด้วยข้อความทดสอบ โดยไม่เรียกโมเดล ผลและภาพอยู่ใน `previews/pokemon-league-release/`

มือถือเป็น Chromium touch emulation ไม่ใช่การทดสอบ Safari บน iPhone จริง รูป Screenshot เป็นภาพนิ่งแม้ถ่ายขณะ Sprite animation เปิดอยู่

มีข้อจำกัดเดิมในชุด browser test `regex-shared.browser.mjs:111`: คาดว่า macro `{{user}}` ในผล Regex จะถูกแทนเป็น `you` แต่ได้ `Nova` ทดสอบซ้ำบน main เดิม `f6bb61f` แล้วล้มเหลวแบบเดียวกัน จุดนี้ไม่ใช่การถดถอยจาก Pokémon Header ชุดนี้ ส่วนการรักษา native control/listener ใน Shared สำหรับโปเกมอนตรวจแยกด้วย `pokemon-chat.real.browser.mjs`

คำสั่งตรวจ:

```sh
npm test
npm run check
node tests/chat-themes.browser.mjs
ST_REAL_URL=http://127.0.0.1:18404 node tests/pokemon-chat.real.browser.mjs
```
