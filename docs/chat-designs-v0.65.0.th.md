# RoleForge 0.65.0 · ดีไซน์แชท

เปิด **Extensions → RoleForge → Chat appearance & NPCs** เปิดระบบ Header / Dialogue / Narrative แล้วเลือก **Chat design**:

- **RoleForge Original**: ป้ายชื่อ กรอบบทพูด และเส้นบรรยายแบบเดิม
- **The Mage’s Folio**: ภาพตัวละครสี่เหลี่ยม 1:1 ฝั่งขวา ชื่อแบบหนังสือ ป้ายข้อมูล NPC กรอบบทพูดโค้งพร้อมป้ายชื่อ และลายเซ็นปากกาท้ายคำบรรยาย

Header และ Narrative ไม่มีพื้นหลังทั้งสองแบบ เลือกเปิด/ปิดแต่ละส่วนได้อิสระครบ 8 ชุด เมื่อปิด Header เหลือชื่อธรรมดา เมื่อปิด Dialogue บทพูดแสดงเป็น `"text"` ด้วยสีประจำตัวผู้พูด เมื่อปิด Narrative แสดงคำบรรยายเป็นตัวเอียงโดยไม่มีดอกจัน ข้อความ ลำดับเนื้อเรื่อง และปุ่ม Voice ยังอยู่

## สีตัวละคร

Folio ใช้ **Identity color ของ NPC** กับชื่อ ขอบภาพ ป้ายข้อมูล ป้ายชื่อบน Dialogue ขอบและพื้นกรอบบทพูด ถ้าตั้งสีแดง ชื่อและกรอบจะเป็นโทนแดง พื้น Dialogue ผสมสีแดงกับสีเข้ม และข้อความภายในคงสีอ่อนเพื่อให้อ่านง่าย

NPC แต่ละคนใช้สีของตัวเอง แม้อยู่ในคำตอบเดียวกัน ไม่มีการเปลี่ยนสีทุกตัวละครตามคนแรก สีคำบรรยายอิงธีม SillyTavern ส่วน UI ฝั่งผู้เล่นยังอยู่ด้านขวาและใช้สี accent ของ RoleForge ปรับ Identity color จากข้อมูล NPC ได้ตามเดิม

## ป้ายข้อมูลใน Folio

เลือก **Folio · Header badge** ได้สามแบบ:

| ตัวเลือก | ข้อมูลที่อ่าน | ตัวอย่าง |
| --- | --- | --- |
| Occupation + NPC rank | `occupation` และ `stats.rank` ของ NPC | Detective · Senior / Sniper · Sergeant |
| Selected skill + mastery | `abilities[].name` และ `abilities[].level` ของสกิลที่เลือก | Water Magic · Intermediate / Marksmanship · Expert |
| Hide badge | ซ่อนป้ายข้อมูล | ชื่อและข้อมูล Header อื่นยังอยู่ |

ระดับ NPC เป็นระดับโดยรวมของ NPC ไม่ใช่ Adventurer Rank ของผู้เล่น และไม่ถูกนำไปแทนขั้นความเชี่ยวชาญของเวทมนตร์หรือสกิล โหมดสกิลให้เลือกชื่อสกิลหรือหมวดหมู่ที่มีอยู่ในข้อมูล NPC หากหมวดมีหลายสกิลต้องเลือกชื่อสกิลโดยตรง แต่ละ NPC จะแสดงเฉพาะสกิลที่ตรงกับตัวเลือกนี้

ข้อมูลที่ยังไม่มี ชื่อที่ไม่ตรง หมวดที่กำกวม และระดับ `Unranked` จะถูกซ่อน ระบบไม่เติมคำว่า Mage หรือ Intermediate ให้เอง จึงใช้กับบอทที่ไม่มีเวทมนตร์ได้ ชื่อธีมไม่บังคับประเภทข้อมูล

## แยกแชทและนำเข้า

ธีม สวิตช์ทั้งสาม และตัวเลือกป้ายข้อมูลบันทึกแยกแชท รวมอยู่ใน World preset และ RoleForge Character Card Pack เมื่อสลับบอทหรือกลับเข้าแชท ระบบใช้ค่าของแชทนั้น ค่าเริ่มต้นยังเป็น RoleForge Original การเลือกธีมไม่เรียก AI และเมื่อบันทึกไม่สำเร็จ ตัวเลือกจะคืนค่าก่อนหน้า

Preset ธีมเก่าที่เลิกใช้แล้วจะกลับเป็น Original พร้อมเก็บสวิตช์เดิม ฟิลด์โหมด Light / Dark ที่เลิกใช้แล้วถูกละไว้ ไม่เพิ่มระบบโหมดสีกลับมา

## Regex / MVU / Voice

การเปลี่ยนดีไซน์ใช้เฉพาะ DOM ของ RoleForge ไม่แก้ข้อความ `message.mes` หรือเพิ่มป้ายชื่อเข้าไปในบทพากย์ โหมด Shared เก็บโหนด native และ event handler เดิมไว้ การ์ด HTML หรือ iframe ของ Regex/MVU ที่ครอบทั้งข้อความยังใช้ดีไซน์ของระบบนั้น ไม่มีการบังคับให้การ์ดภายนอกกลายเป็น Folio

หากเบราว์เซอร์ไม่รองรับการย้าย DOM โดยรักษาสถานะ iframe ระบบจะเก็บ widget นั้นในรูปแบบ native ปุ่มและข้อมูลของทั้งสองระบบยังแยกจากกัน

การเปลี่ยนธีมหรือสร้างการ์ดใหม่จากการปรับหน้าตาจะเก็บร่างในหน้าต่างแก้บทพากย์ที่เปิดอยู่ โดยผูกกับบล็อกเดิมเมื่อข้อความและแชทตรงกัน หากแก้ข้อความต้นฉบับ เปลี่ยน swipe หรือสลับแชท ระบบยังตรวจและยกเลิกการใช้ร่างกับแหล่งเดิม ป้ายชื่อบนกรอบไม่ถูกส่งให้ระบบเสียงอ่าน
