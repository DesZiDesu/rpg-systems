# Workshop และ Great Sage — RoleForge 0.77.0

Workshop รุ่น Beta มี Great Sage 1.1.0 และ Field Notes 1.0.0 ให้ติดตั้งจากคลังที่มากับส่วนเสริม การติดตั้งและเปิดหน้าต่างไม่เรียก AI และยังไม่เปิด Addon ให้ทุกแชท

## เริ่มทดสอบ

1. อัปเดต RoleForge ในหน้า Extensions ของ SillyTavern แล้ว Reload เมื่อบันทึกข้อความร่างเรียบร้อย
2. เปิดการ์ดและแชทที่ต้องการ
3. ไปที่ **Extensions → RoleForge → RoleForge Workshop** หรือ **Wand Menu → RoleForge Workshop**
4. เปิดรายละเอียด **Great Sage** แล้วกด **ติดตั้ง Addon**
5. เปิด **ใช้กับแชทนี้** หรือกดเปิด Great Sage แล้วเลือกเปิดใช้กับแชทนี้
6. ต่อไปเปิดตรงจากปุ่มลูกกลมที่ลากได้ หรือ **Wand Menu → Great Sage** ได้ทันที
7. พิมพ์คำถามแล้วกดวิเคราะห์ ใช้การเชื่อมต่อข้อความที่ตั้งไว้ใน SillyTavern

## หน้าตาและการตั้งค่า

- ลูกกลมหมุนช้า ๆ ขณะรอ และเปลี่ยนจังหวะตามระดับเสียงที่กำลังเล่นจริง ถ้าเบราว์เซอร์ถอดเสียงเพื่อวัดระดับไม่ได้ จะใช้สถานะกำลังพูดแทน
- ผลวิเคราะห์อยู่ในกรอบที่เปิดอย่างนุ่มนวล ข้อความทยอยปรากฏ ส่วนรายละเอียดเปิดอ่านเพิ่มได้
- ขยายฉากได้จาก Great Sage หรือแผงเหนือ Chatbar โดยไม่ต้องส่งข้อความในฐานะ User
- กดตั้งค่าเพื่อเลือก Prismatic / Azure, Motion, แผงเหนือ Chatbar, ปุ่มลอย และ Wand Menu
- ตำแหน่งปุ่มและค่าของ Great Sage แยกแต่ละแชท ปิดแชทหนึ่งไม่เปิดให้แชทอื่น
- การลดการเคลื่อนไหวของอุปกรณ์และการปิด Motion ทำให้ฉากนิ่ง

## เสียงสังเคราะห์

1. เปิด **Voice Addon** ในระบบเสริมของ RoleForge และเชื่อม ElevenLabs ตามระบบเสียงเดิม
2. ใน **Great Sage → ตั้งค่า** เลือกเสียงจาก **My Voices**
3. กดฟังตัวอย่าง หรือเปิด **อ่านผลวิเคราะห์อัตโนมัติ** ตามต้องการ

การสร้างเสียงใช้โควตา ElevenLabs การเล่นเสียงเดิมซ้ำใช้ cache เดิมเมื่อข้อความ เสียง และโมเดลตรงกัน เปิดหน้าต่างเฉย ๆ ไม่สร้างเสียง ไม่มีเสียงเฉพาะจากอนิเมะติดตั้งให้อัตโนมัติ

## ข้อมูลและขอบเขต

Great Sage อ่านเฉพาะแหล่งที่เลือก: ฉากและคำตอบ AI ล่าสุด ค่าสถานะ กระเป๋า และความสามารถที่ทราบ ไม่อ่านโปรไฟล์ NPC ที่ยังไม่พบหรือคลัง Lore ทั้งหมด ไม่แก้ Stats หรือไอเทม และไม่ส่งข้อความแทน User การกดวิเคราะห์หนึ่งครั้งมีคำขอข้อความเพิ่มหนึ่งครั้ง ส่วน **ทบทวนข้อมูลเมื่อ AI ตอบจบ** เป็นการรีเฟรชข้อมูลในแผงโดยไม่วิเคราะห์อัตโนมัติ

แพ็กติดตั้งเก็บใน IndexedDB ของเบราว์เซอร์ ค่าที่เลือกและประวัติสูงสุด 20 ผลแยกตามการ์ดและแชท ไม่คัดลอกไปยัง checkpoint หรือ chat metadata ใช้ **Workshop → สำรอง → ส่งออกไฟล์สำรอง** แล้วนำเข้าในแชทปลายทางเมื่อย้ายเครื่อง ไฟล์นี้ไม่รวม API key ไฟล์เสียง ข้อความสนทนา หรือฐานข้อมูล NPC/Lore ของ RoleForge

การถอนติดตั้งมีตัวเลือกเก็บการตั้งค่าและประวัติไว้ การอัปเดตตรวจ hash และบันทึกแพ็กสำเร็จก่อนใช้รุ่นใหม่ หากไฟล์ผิดหรือบันทึกไม่สำเร็จ แพ็กเดิมยังอยู่ รองรับไฟล์สำรองจาก Preview เดิมของ Great Sage/Field Notes ด้วย

รุ่นนี้เป็นคลังที่มากับ RoleForge ยังไม่มีหน้าส่งแพ็กสาธารณะ ดาวน์โหลดสคริปต์ภายนอก หรือแนบ Addon ไปกับการ์ดไฟล์เดียว

## การตรวจสอบก่อนเผยแพร่

ดูผลที่บันทึกไว้ใน [validation-workshop-v0.77.0.json](validation-workshop-v0.77.0.json) แยก unit tests ออกจากการรันเบราว์เซอร์ SillyTavern จริง และระบุการใช้ข้อมูลตอบกลับ/เสียงควบคุมไว้ชัดเจน

คำสั่งสำหรับนักพัฒนา:

```sh
npm run check
npm test
npm run test:workshop
npm run test:workshop:real
```

ชุดทดสอบเบราว์เซอร์ใช้ SillyTavern ทดสอบบน localhost ไม่ใช้เครื่องหรือแชทส่วนตัวของผู้ใช้ ตั้ง `ST_REAL_URL` และ `WORKSHOP_ARTIFACTS` ได้ ชุดเสียงต้องมี `synthetic-test-voice.mp3` ในโฟลเดอร์ artifacts (สร้างด้วย `ffmpeg` ที่มี Flite ได้) และต้องมี Playwright/Chromium ตามสภาพแวดล้อมทดสอบ หน้าจอมือถือใช้การจำลอง viewport/touch ไม่ใช่ iPhone/Safari จริง
