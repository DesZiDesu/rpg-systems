# Pokémon 1.3.1 — Trainer Archive

The Classic Dark option now uses its own desktop navigation, lighter archive header, typography, materials, panels, controls and mobile navigation. The original interface remains available. The design uses bundled Inter and Noto Sans Thai fonts; CSS motion respects the browser reduced-motion setting.

Battle motion is inline without a title or visible skip button. Escape can still skip the current sequence on a keyboard. While a catch is in progress, both in-arena HP panels and the battle controls disappear, then return as the already-computed success or failure is revealed. The ball stays within the central part of the field. This is presentation only: the saved game determines outcomes.
