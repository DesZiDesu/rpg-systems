# แก้หน้าตั้งค่าร่วมกับธีม Minimalism Tone — 0.68.1

ทำซ้ำและทดสอบบน **SillyTavern 1.19.0 ตัวจริง** (`release`, revision `06bde93`) ที่ติดตั้ง RoleForge โดย Import ไฟล์ Minimalism Tone ที่แนบมาผ่าน UI ของ SillyTavern และเลือกใช้ธีมตามปกติ ใช้บัญชีและตัวละครทดสอบใน dataRoot แยก ไม่มีการเข้าถึง SillyTavern ของผู้ใช้

สาเหตุ: CSS ธีมกำหนดพื้นหลัง มุมโค้ง และลบขอบของ `.menu_button` ด้วย `!important` เมนู RoleForge เดิมใช้เส้นคั่นและไม่มีระยะขอบด้านข้าง เมื่อเส้นคั่นหายจึงกลายเป็นกล่องติดกัน ไอคอนและลูกศรชิดขอบ อีกกฎหนึ่งกำหนด margin ช่องกรอกเป็น 4px ทำให้ปุ่มล้างที่ยืดตามแถวสูงกว่าช่องค้นหา

แก้โดยเพิ่มพื้นที่ภายในและช่องว่างของรายการเมนูใน RoleForge รวมผลค้นหาและเมนูย่อย และล้าง margin เฉพาะช่องค้นหาให้ยืดในแถวเดียวกับปุ่มล้าง สี พื้นหลัง มุมปุ่ม และหัว drawer ยังใช้ธีม SillyTavern ตามเดิม ไม่แก้ CSS ของธีมที่นำเข้า

ตรวจจริงที่ 320/390/768/1440px ครบ 20 หน้า: เมนูไม่ติดกัน ไอคอน/ลูกศรอยู่ในปุ่ม ช่องค้นหากับปุ่มล้างตรงกัน ขยายตัวอักษรได้ ค้นหาและย้อนกลับได้ เก็บร่างที่ยังไม่บันทึก และกดบันทึก Stats แล้ว Reload/เปิดตัวละครเดิมเพื่อยืนยันค่าจากเซิร์ฟเวอร์จริง ทดสอบ Dark Lite เพิ่มโดยใช้ตัวเลือกธีมของ SillyTavern เช่นกัน

ภาพใน [แกลเลอรี](previews/settings-theme-fix/index.html) มาจาก SillyTavern ตัวจริงบน Chromium โดยใช้ขนาดหน้าจอมือถือและ PC ไม่ใช่การทดสอบบน iPhone จริง

การรันทดสอบซ้ำสำหรับนักพัฒนา:

```sh
# เปิดจากโฟลเดอร์ SillyTavern โดยใช้ข้อมูลทดสอบแยก
node server.js --port 18174 --dataRoot /path/to/test-data --browserLaunchEnabled false

# ติดตั้ง RoleForge ในโปรไฟล์ทดสอบ แล้วรันจาก repo RoleForge
ST_REAL_URL=http://127.0.0.1:18174 \
ST_THEME_FILE=/path/to/Minimalism-Tone.json \
npm run test:settings-theme:real
```

ชุดทดสอบใช้ Playwright/Chromium และสร้างการ์ด `RoleForge Theme Test` รวมถึงบันทึกค่าและธีมในโปรไฟล์ทดสอบ มีการปิดการค้นหา Horde ที่ไม่เกี่ยวกับงานนี้ แต่ใช้ frontend, context, ระบบธีม และ API บันทึกข้อมูลของ SillyTavern จริง ไม่สร้าง host จำลอง

อัปเดตส่วนเสริมจาก `main` แล้ว Reload SillyTavern หลังบันทึกร่างและจบการเจน เพื่อโหลด CSS เวอร์ชันใหม่ ไม่ต้องแก้หรือ Import ธีมใหม่
