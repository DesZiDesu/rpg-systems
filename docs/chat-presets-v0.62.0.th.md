# Preset แยกแชทและข้อจำกัดโดเมน · RoleForge 0.62.0

ตั้งแต่ **0.64.0** ส่วน **Chat appearance** ใช้ Original แบบเดียว เลือก Light / Dark / User Setting และสวิตช์ Header / Dialogue / Narrative แยกแชท ดู [คู่มือ Original](chat-original-v0.64.0.th.md)
เล่น Madoka แล้วสลับไป Mushoku Tensei ได้โดยไม่ต้องลบการตั้งค่าของอีกโลก แชทเก็บสำเนา configuration ของตัวเอง และมีคลัง preset ที่ตั้งชื่อไว้เพื่อนำกลับมาใช้ได้ UI ใน extension drawer ใช้ปุ่มและช่องกรอกของ SillyTavern ตามเดิม

## ระบบที่บันทึกเป็น preset ได้

| ชุด | สิ่งที่เก็บ |
| --- | --- |
| Power | รายการพลัง ประเภท ค่าเริ่มต้น ขอบเขตและรายละเอียด |
| Character Creation | ตัวเลือก Origin, Social Standing, Arsenal, Skill, Mastery, Path rank, Alignment และชื่อหัวข้อ rank |
| Currency | ชื่อค่าเงิน 1–3 หน่วย อัตราแลก ชื่อเรียก สัญลักษณ์ สี ไอคอนและ animation |
| Stats & training | นิยาม custom stats ค่าเริ่มต้น/ขอบเขต/อัตราพัฒนา วิธีฝึก และปุ่มฝึกที่ซ่อน |
| Lore options | โหมด All/Relevant และงบข้อความ Lore |
| World systems | Auto Track, State injection, Scene Tracker, Incantation/ภาษา, ร้านค้า, ประมูล, กระดานภารกิจ/กลุ่ม, Story Memory, Agenda, Quest Objectives และความถี่ NPC Diary |

เลือก **World · all systems** เพื่อเก็บหกชุดรวมกัน หรือเลือกเฉพาะระบบหนึ่งชุด

คลังเนื้อหา NPC และ Lore ยังเป็นข้อมูลของการ์ดและใช้ระบบ Import/Export เดิม NPC มีขอบเขต Character/Chat ให้เลือกอยู่แล้ว จึงไม่ปนกันระหว่างบอท คลัง preset นี้เก็บตัวเลือกการใช้ Lore ไม่คัดลอกเนื้อหาคลัง Lore/NPC ไปในทุกแชท การ์ดที่ส่งให้ผู้เล่นใช้ Character Card Pack เพื่อรวมเนื้อหากับ preset

ธีม ภาษา UI รูปแบบหน้าต่าง/แถบเหนือช่องพิมพ์ การเชื่อมต่อและการตั้งค่า Memory/Voice addon เป็นความชอบส่วนตัวของผู้เล่น ไม่ส่งต่อผ่าน world preset ไม่มี API key, Proxy, รุ่นโมเดล, ประวัติแชท, เงินหรือค่าพัฒนาตัวละครในไฟล์ preset

## ใช้คลัง preset

เปิด **Extensions → RoleForge → World rules & presets → Chat presets** หรือหัวข้อ **คลัง preset และการตั้งค่าประจำแชท** เมื่อใช้ภาษาไทย

1. ตั้งค่าระบบในแชทปัจจุบัน เลือกระบบที่จะเก็บ แล้วตั้งชื่อ เช่น `Madoka — Standard`
2. กด **Save as new / บันทึกเป็นชุดใหม่** เพื่อเพิ่มในคลัง
3. เปิดแชทที่จะใช้ เลือกชุดในคลัง แล้วกด **Load into this chat / ใช้กับแชทนี้**
4. ใช้ **Rename**, **Update selected**, **Export selected** หรือ **Delete selected** เพื่อจัดการชุดที่เลือก
5. ใช้ **Import JSON to library** เพื่อนำไฟล์เข้าไปเก็บก่อน ปุ่ม Import ไม่ใช้ชุดนั้นกับแชททันที ต้องกด Load เอง

การโหลดสร้างสำเนา การแก้ชื่อ อัปเดตหรือลบ preset ในคลังไม่เปลี่ยนแชทที่โหลดไปแล้ว การโหลดชุดที่มีเฉพาะ Currency ไม่แทนชุด Power หรือ Character Creation และการแก้ในแชทไม่เขียนทับ preset ในคลังจนกด Update

**Reset chat to card defaults / กลับค่าจากการ์ด** โหลด configuration เริ่มต้นของการ์ดกลับมาโดยรักษาความคืบหน้าของแชท การ์ดเก่าที่ไม่มีแพ็กใช้ค่าตั้งเดิมของการ์ดเป็น fallback ส่วน preset สำเร็จรูป Original/Fantasy/Modern ยังเป็นตัวเลือกเริ่มต้นของโปรแกรม การลบจากคลังใช้กับชุดที่ผู้เล่นบันทึกหรือนำเข้า

คลังรองรับ 100 ชุด รวมไม่เกิน 2 MiB และไฟล์ Import ไม่เกิน 1 MiB รองรับ World preset v1, Power preset v1, Character Forge preset v1 และ Currency preset v1 ชื่อชุดในคลังต้องไม่ซ้ำกัน

## ค่าเงินและข้อมูลผู้เล่น

ใน **Currency setup** มี **Export currency preset** และ **Import currency preset** เพิ่มเติม Import เข้าเป็นแบบร่างก่อน เงินยังไม่เปลี่ยนจนกด Save สามารถใช้ไฟล์ค่าเงินเดียวกันนำเข้าไปเก็บในคลัง Chat presets ได้

การเปลี่ยนอัตราแลกรักษามูลค่าเงินในหน่วยเล็กสุด ทั้งกระเป๋าผู้เล่น เงินกองกลางปาร์ตี้และคลังกิลด์ เช่นมูลค่าเดิม 12,345 หน่วย เปลี่ยนเป็นเงินหน่วยเดียวก็ยังเป็น 12,345 หน่วย ไม่คัดลอกยอดเงินของแชทต้นทาง

HP/MP/ST สูงสุด สกิล ไอเทม เควสต์และค่าพลังเดิมยังอยู่ Custom stat ที่พักใช้เก็บค่าไว้ตาม ID; เปิดกลับมาใช้ค่าเดิม ไม่แจกค่าเริ่มต้นซ้ำ หากขอบเขตใหม่ไม่ครอบคลุมค่าที่มี จะปฏิเสธการโหลดเพื่อให้แก้ขอบเขตก่อน

รอการเจนและการบันทึกที่ค้างให้จบก่อนโหลด การเปลี่ยนหน่วยเงิน/อัตรา/ชื่อที่กระทบธุรกรรมต้องจบหรือยกเลิกซื้อขายและมัดจำที่ค้างก่อน การเปลี่ยนชุดพลังหรือวิธีฝึกต้องจบหรือหยุดการฝึกที่ค้างด้วย

บันทึก preset กับ RPG state ของแชทด้วยกัน หากบันทึกล้มเหลวจะคืนค่าทั้งคู่ และไม่แสดงว่าใช้สำเร็จ กด Send ระหว่างบันทึกจะรอผลบันทึกก่อนสร้างคำสั่งให้ AI หากเปลี่ยนแชทระหว่างรอจะยกเลิกคำขอนั้น

การ swipe/regenerate ย้อนความคืบหน้าของคำตอบโดยใช้ preset ปัจจุบัน ยอดเงินเก่าถูกแปลงตามมูลค่า หากคำตอบเก่ามีธุรกรรมที่ขัดกับค่าเงินใหม่หรือ stat นอกขอบเขต จะรักษาสถานะปัจจุบันและแจ้งข้อผิดพลาด ให้เลือกคำตอบเดิมหรือปรับ preset แล้วลองใหม่ ไม่มีการย้อนข้อมูลบางส่วนแล้วเดินหน้าต่อโดยใช้กฎคนละชุด

## แชทเดิม การ์ดและการย้ายแชท

แชทที่ยังไม่มีสำเนา preset จะบันทึกค่าที่ใช้อยู่ในการเปิดครั้งแรกของรุ่นนี้ ใช้ค่า override เดิมของการ์ดเป็น fallback และรักษาเงิน/ข้อมูล RPG เดิม การเปลี่ยนค่าเริ่มต้นในการ์ดภายหลังไม่เปลี่ยน preset ของแชทที่มีสำเนาแล้ว แชทใหม่ใช้ค่าของการ์ดปัจจุบัน

**Export state** รวมสำเนา preset ของแชท และการนำเข้าชุด state ใช้ preset นั้นด้วย ไฟล์ Export state มีข้อมูลผู้เล่น ต่างจากไฟล์ preset การสานต่อไปแชทใหม่ในการ์ดเดียวกันพา preset ไปด้วย โดยไม่แทนสำเนาที่แชทปลายทางตั้งไว้แล้ว

Character Card Pack v1 ใช้กับการ์ดเดิมได้ และเพิ่ม `currencyPreset`, `trainingPreset`, `systems` ผู้สร้างตั้งค่าทั้งหมดในแชท แล้วกด **Save setup in this card** ก่อน Export Character ตามปกติ ผู้รับ Import Character ครั้งเดียวได้ NPC, Lore และ configuration ที่แพ็กไว้ เลือกเก็บ starting state เฉพาะเมื่อผู้สร้างต้องการกำหนดข้อมูลผู้เล่น/โลกเริ่มต้น การ์ดไม่ติดตั้งส่วนเสริมให้ผู้รับโดยอัตโนมัติ ดู [คู่มือการ์ด](character-pack-v0.61.0.th.md)

## โดเมนที่ปิดการทำงาน

เมื่อเปิดผ่าน `chat.rolezy.com` หรือโดเมนลูก RoleForge แสดง **ไม่รองรับการใช้งานเซิร์ฟเวอร์สาธารณะนี้** ใน drawer ส่วนเสริมและไม่เริ่ม runtime, CSS, UI หรือ API clients ตรวจ hostname โดยไม่ขึ้นกับ HTTP/HTTPS หรือ port; localhost และโดเมนส่วนตัวอื่นยังใช้ได้

นี่เป็นข้อจำกัดการเริ่มใช้งานใน browser การติดตั้งไฟล์บนเซิร์ฟเวอร์ยังเป็นหน้าที่ของ SillyTavern และผู้ดูแลเซิร์ฟเวอร์ ไม่ใช่ระบบยืนยันสิทธิ์ที่ป้องกันการแก้ source code หรือย้ายไปใช้ hostname อื่น

## การตรวจสอบ

ทดสอบแชท A/B ของการ์ดเดียวกันและการ์ดคนละโลก, สำเนากับการลบ/อัปเดตคลัง, JSON Import/Export, ล้มเหลว/บันทึกซ้อน/เปลี่ยนแชทระหว่างบันทึก, กด Send ระหว่างบันทึก, การย้อนคำตอบ, มูลค่ากระเป๋าและ stat เดิม พร้อม UI 320/390/1280 พิกเซล ใช้ loader และ runtime จริงใน controlled SillyTavern host ไม่มีการเรียกโมเดลเพื่อจัดการ preset

ตรวจการนำเข้าการ์ด Madoka ใน bundle จริง, startup, MVU/Regex, ไอเทม/Loot, ร้านค้า, ประมูล, Incantation, Character Forge และ Stats/Currency ประกอบด้วย รายละเอียดคำสั่งและขอบเขตการทดสอบอยู่ใน [ผลตรวจ 0.62.0](validation-chat-presets-v0.62.0.json) การตอบของ Proxy จริงและ Safari บน iPhone จริงไม่ได้ทดสอบในสภาพแวดล้อมนี้

หลังอัปเดตจาก main ให้ reload SillyTavern เพื่อใช้ loader/runtime รุ่นเดียวกัน ไม่ต้องล้างข้อมูลหรือรีเซ็ตแชท
